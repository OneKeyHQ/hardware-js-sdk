# Agent Wallet 内测导航设计

## 背景

OneKey Developers 的 Agent Wallet 文档已经存在并可直接访问，但中英文顶层 `_meta.js` 将 `agent-wallet` 菜单配置整段注释。进入 Agent Wallet 路由后，Nextra 无法把该目录关联回完整的顶层页面地图，因此左侧只剩 Agent Wallet 子页面，其他导航上下文消失。

产品要求是继续公开展示 Agent Wallet 文档，不隐藏入口，同时清晰标记该功能仍处于内测阶段。

## 目标

- 恢复 Agent Wallet 在中英文顶层导航中的正式配置。
- 进入任一 Agent Wallet 页面后，保持完整、正确的导航上下文。
- 在顶层导航、当前页面面包屑和移动端完整目录中显示醒目的内测徽标。
- 保持现有 Agent Wallet 路由、页面顺序和文档内容不变。

## 非目标

- 不修改 Agent Wallet 的业务文档内容。
- 不隐藏、鉴权或限制 Agent Wallet 路由。
- 不重构 Nextra 的通用导航和侧边栏实现。
- 不改变 Hardware Integration、dApp Integration 和 Offline Signing 的导航结构。

## 方案

### 页面地图

恢复 `content/en/_meta.js` 与 `content/zh/_meta.js` 中已有的 `agent-wallet` 菜单配置，继续沿用当前子页面链接和排序。该配置重新建立 Agent Wallet 与顶层页面地图的关系，修复进入该目录后其他导航上下文消失的问题。

### 内测标识

新增一个轻量、可复用的导航标题组件，用于组合 Agent Wallet 文本和状态徽标：

- 英文显示 `Private Beta`。
- 中文显示 `内测`。
- 使用高对比度暖色背景、清晰边框和紧凑字重，在深色主题中保持醒目。
- 徽标不单独成为链接，不改变原菜单项的点击区域和键盘交互。

顶层 Agent Wallet 入口使用同一标题节点驱动 Nextra 的顶部导航、当前页面面包屑和移动端完整目录，避免不同位置的状态文案或视觉样式漂移。组件使用 `React.createElement`，因此中英文元数据文件可以继续保留 `.js` 扩展名。

### 响应式与可访问性

- 标题容器允许文本和徽标在窄空间中保持同一行；空间不足时优先压缩间距，不截断 `Agent Wallet` 主标题。
- 徽标文字保持可读对比度，不只依赖颜色表达内测状态。
- 不覆盖 Nextra 的侧边栏滚动、折叠或移动端菜单逻辑。

## 验证

- 生产构建成功生成全部文档页面。
- 英文与中文 Agent Wallet 页面均显示对应内测徽标。
- 从顶部入口进入 Agent Wallet 后，导航上下文仍完整存在。
- Agent Wallet 的九个子页面链接保持可访问且活动态正确。
- 在桌面宽度、短视口和移动端宽度检查菜单无溢出、遮挡或错误折叠。

## 风险与控制

- Nextra 元数据标题对 React 节点的渲染位置可能不同。实现时用真实浏览器同时检查顶部菜单、面包屑与移动端目录。
- 暖色徽标可能与活动态背景冲突。徽标使用独立边框和文字色，并分别验证默认态、悬停态和活动态。
