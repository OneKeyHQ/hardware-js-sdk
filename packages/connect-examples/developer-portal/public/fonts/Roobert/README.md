# OneKey website typeface

Roobert is the typeface specified by OneKey for its website and developer portal. These unmodified WOFF2 files were obtained from the live OneKey Pro 2 page on 2026-10-10 for the OneKey developer portal:

- [Regular, 400](https://asset.onekey.so/portal/def498d5961dad82d9e746499e7c9e809b46b470/_next/static/media/Roobert_Regular-s.p.27dqztsd86_ve.woff2)
- [Medium, 500](https://asset.onekey.so/portal/def498d5961dad82d9e746499e7c9e809b46b470/_next/static/media/Roobert_Medium-s.p.3cxlhxraw1mma.woff2)
- [SemiBold, 600](https://asset.onekey.so/portal/def498d5961dad82d9e746499e7c9e809b46b470/_next/static/media/Roobert_SemiBold-s.p.06vba9p270gs5.woff2)

The root layout loads them through `next/font/local`, so production, static previews, and base-path deployments serve the same font files from their own origin. Their inclusion does not relicense the typeface under the SDK's software license; the font remains subject to its own license.
