# ハードウェア制御

ハードウェアを利用するセッションでは、対応する署名リクエストに接続済みの OneKey デバイスを使用します。ユーザーはデバイス上でリクエストを確認して承認します。利用できるデバイス機能や確認可能なトランザクション詳細は、チェーン、ファームウェア、CLI のバージョンによって異なります。

## ハードウェアでの確認が必要な場面 [#when-to-escalate]

| フロー | ハードウェアで期待される動作 |
| --- | --- |
| 高額の送金 | ユーザーが OneKey デバイス上で受取人、金額、チェーン、手数料を確認します。 |
| コントラクト操作 | エージェントが先にシミュレーションを実行し、対応している場合はデバイスにクリア署名の詳細を表示します。 |
| スワップの実行 | エージェントが先に見積もりと構築を行います。デバイス上での確認は、ユーザーが実行を承認した後にのみ行われます。 |
| 隠しウォレット | パスフレーズモードを明示し、隠しウォレットが有効かどうかをエージェントが推測しないようにします。 |
| デバイスの信頼性確認 | `onekey device verify` はデバイスの検証を実行します。検証に成功しても、トランザクションの安全性が保証されるわけではありません。 |

## 接続とログイン [#connect-and-login]

接続済みデバイスを一覧表示します:

```bash
onekey device search
```

ハードウェアウォレットで認証します:

```bash
onekey auth login --hardware
```

複数のデバイスが接続されている場合は、使用するデバイスを明示的に選択します:

```bash
onekey auth login --hardware --device-id <uuid>
```

対象のウォレットに使用するパスフレーズモードを 1 つ選択します。以下は選択肢であり、順に実行する手順ではありません:

| モード | ウォレットの選択 |
| --- | --- |
| `none` | パスフレーズを使用しない標準ウォレット。 |
| `on-host` | ホスト上でパスフレーズを入力する隠しウォレット。パスフレーズをエージェントのメッセージやログに含めないでください。 |
| `on-device` | 対応デバイス上でパスフレーズを入力する隠しウォレット。 |

モードを選択する前に、インストール済み CLI のスキーマを確認してください。ログイン後は有効なアドレスを確認してください。パスフレーズが異なると、選択されるウォレットも異なります。

## 有効なセッション [#active-session]

ハードウェアを利用するセッションでは、`onekey auth status` が次の情報を報告します:

| フィールド | 期待される値 |
| --- | --- |
| `loginMethod` | `hardware` |
| `walletKind` | `hw` |
| `device` | 接続済み OneKey デバイスの情報 |
| `passphraseMode` | `none`, `on_host`, または `on_device` |

ログイン後、以降のコマンドは有効なセッションを自動的に使用します。

## デバイスのライフサイクル [#device-lifecycle]

インストール済み CLI のスキーマを確認し、設定変更について説明したうえで、ユーザーが求めた操作のみを実行してください:

| 操作 | コマンドの種類 |
| --- | --- |
| 接続済みデバイスを検証 | `onekey device verify` |
| デバイスの PIN を変更 | `onekey device change-pin` |
| パスフレーズ保護を変更 | `onekey device toggle-passphrase` |
| デバイス設定を確認または変更 | `onekey device settings` |

`onekey schema --list` にコマンドが存在しない場合は、パラメーターを推測せず、そのコマンドが未対応であることを報告してください。

デバイス上での物理的な確認を省略しないでください。デバイスがロック中、未接続、PIN またはパスフレーズの入力待ち、あるいはリクエストを拒否した場合は、その状態を報告して停止してください。
