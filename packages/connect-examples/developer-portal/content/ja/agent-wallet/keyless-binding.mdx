# キーレス連携

キーレス連携は、秘密鍵を覚えたり、エクスポートしたり、エージェントの実行環境に貼り付けたりすることなく、OneKey GUI で Agent Wallet を管理できるようにする製品上の仕組みです。

CLI は App Transfer セッションを受け取ります。生の鍵データ、復号済みの認証情報、アクセストークン、シードフレーズ、キーチェーンの内容をエージェントに公開してはいけません。

## ユーザー体験 [#user-experience]

ユーザーにとっては、鍵管理の作業ではなく、管理されたウォレットとして利用できるようにしてください:

| ユーザーのニーズ | OneKey の動作 |
| --- | --- |
| 自動化用ウォレットを作成 | OneKey GUI で Agent Wallet を作成して管理します。 |
| AI クライアントから利用 | 鍵を貼り付ける代わりに App Transfer でペアリングします。 |
| 有効なウォレットを把握 | エージェントに `onekey auth status` を読み取らせ、アドレスを表示させます。 |
| 資金を移動 | 明示的な確認を必須とし、必要に応じてハードウェア制御に切り替えます。 |
| アクセスを終了 | `onekey auth logout` を使用して、有効な CLI セッションを消去します。 |

## 責任の分担 [#responsibility-split]

| インターフェース | 責任 |
| --- | --- |
| OneKey GUI | Agent Wallet とキーレスアカウントの関連付けを作成・管理 |
| `onekey` CLI | 有効なセッションを保持し、スキーマに基づくウォレットコマンドを公開し、OS の認証情報ストアを使用 |
| エージェント実行環境 | スキーマの読み取り、コマンドの呼び出し、結果の要約、書き込み操作の確認要求 |

## エージェントのルール [#agent-rules]

- GUI で管理される Agent Wallet を、アカウントの関連付けの正しい情報源として扱ってください。
- `onekey auth status` を使用し、有効なウォレットを推測しないでください。
- `onekey get-address` を使用して、資金移動の前に有効なアドレスを表示してください。
- 秘密鍵、シードフレーズ、復号済みの認証情報を貼り付けるようユーザーに求めてはいけません。
- キーチェーンのパスや認証情報のペイロードを回答として出力してはいけません。

## 便利なコマンド [#useful-commands]

```bash
onekey auth status
onekey get-address
onekey balance --chain eth
onekey history --chain eth --detail
```
