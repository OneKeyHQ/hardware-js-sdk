# 安全上のルール

Agent Wallet のワークフローでは、残高の読み取り、トランザクションの構築、スワップの実行が可能です。安全上の境界を明確にしてください。

## 読み取りと書き込み [#read-versus-write]

| リクエストの種類 | 例 | 必須の動作 |
| --- | --- | --- |
| 読み取り専用 | 残高、受取アドレス、価格、注目のトークン、履歴、トークン情報 | 簡潔な結果と、役立つ次の手順を 1 つ返します。 |
| 準備 | スワップの見積もり、トランザクションの構築、トークン監査、シミュレーション | 結果とリスクに関する情報を表示し、送信はしません。 |
| 書き込み | 送金、スワップの実行、承認、ブロードキャスト、署名 | 実行前に明示的な確認を求めます。 |
| ハードウェアでの承認が必要な書き込み | 高額送金、機密性の高いコントラクト呼び出し、隠しウォレットでの署名 | OneKey デバイス上での確認を必須とし、デバイスが拒否した場合は停止します。 |

## 秘密情報を決して公開しない [#never-expose-secrets]

エージェントは次を決して公開してはいけません:

- 秘密鍵またはシードフレーズ。
- 復号済みの Agent Wallet 認証情報。
- ハードウェアのパスフレーズ。
- アクセストークン。
- キーチェーンの内容または認証情報のペイロード。

## 書き込みを確認 [#confirm-writes]

送金、スワップの実行、承認、署名のリクエスト前に、簡潔な確認を表示してください:

| フィールド | 必須 |
| --- | --- |
| 操作 | 送金、スワップ、署名、承認、ブロードキャスト |
| 送信元 | ウォレットアドレスとチェーン |
| 送信先 | 受取人、コントラクト、または対象チェーン |
| 金額 | ネイティブ通貨またはトークンの金額 |
| 手数料 | 取得できる場合はガス代または手数料の見積もり |
| リスクの結果 | 取得できる場合はセキュリティ監査またはシミュレーションの結果 |
| ハードウェアでの手順 | 該当する場合はデバイス上での確認要件 |

ユーザーが確認するまで送信しないでください。

## 停止条件 [#stop-conditions]

次の場合は停止し、状態を報告してください:

- `onekey auth status` が未認証。
- 有効なアドレスがユーザーの想定するウォレットと一致しない。
- デバイスがロック中、未接続、拒否済み、または PIN/パスフレーズの入力待ち。
- エージェントが使いたいパラメーターが CLI スキーマに公開されていない。
- セキュリティコマンドが高リスクの結果を報告し、ユーザーがそのリスクを明示的に受け入れていない。
