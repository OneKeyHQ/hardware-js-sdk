# 統合ガイド

接続が動くだけの状態から、安心して使える統合へ進みます。これらのガイドは、プロバイダーの選択、アプリのメタデータ、トランザクションのコンテキスト、保守を扱います。

| タスク | ガイド |
| --- | --- |
| 複数のウォレットがあるブラウザーで OneKey を選択 | [プロバイダーの選択](./provider-selection) |
| 接続プロンプトでアプリを識別 | [サイトのメタデータ](./site-metadata) |
| トークンの追跡をユーザーに依頼 | [トークンのメタデータ](./token-metadata) |
| コントラクト呼び出しを正確に説明 | [コントラクトのメタデータ](./contract-metadata) |
| 別のウォレットアプリケーションに接続 | [WalletConnect セッション](./walletconnect) |
| 意図的なデバイス管理フローを構築 | [デバイスの設定と消去](./device-management) |
| ウォレットと署名の用語を理解 | [用語集](./glossary) |
| 問題を報告、または変更に貢献 | [貢献方法](./contributing) |

OneKey は初めてですか? [統合方法を選択](/ja/getting-started) から始めてください。古いアプリケーションを保守する場合は、次を参照してください: [従来の統合方法](/ja/legacy).
