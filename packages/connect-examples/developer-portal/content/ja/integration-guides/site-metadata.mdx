# サイトのメタデータ

ウォレットとブラウザーがサイトを識別できるよう、ファビコンを用意します。ドキュメントの `<head>` にアイコンのリンクを置き、公開アクセス可能な画像 URL を使用してください:

```html
<head>
  <link rel="icon" href="https://example.com/icon.png" type="image/png" />
  <link rel="shortcut icon" href="https://example.com/icon.png" />
</head>
```

ウォレット接続ライブラリのメタデータには、実際のアプリ名、オリジン、アイコンを使ってください。メタデータは要求元サイトを識別するもので、その信頼性を証明しません。

ウォレットのバージョンによって、メタデータの取得やキャッシュが異なる場合があります。デプロイ後は実際の接続プロンプトを確認してください。ファビコンの更新が既存セッションにすぐ反映されるとは限りません。
