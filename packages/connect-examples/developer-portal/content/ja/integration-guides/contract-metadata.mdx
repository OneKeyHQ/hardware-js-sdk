# コントラクトのメタデータ

ウォレットは確認時に呼び出しデータをデコードしてメソッド名を表示する場合があります。関数セレクターは正規シグネチャの Keccak-256 ハッシュの先頭 4 バイトです。例: `transfer(address,uint256)`.

## 検証可能なメタデータを公開 [#publish-verifiable-metadata]

該当するブロックエクスプローラーでコントラクトのソースと ABI を公開・検証してください。呼び出しを正しくエンコードできるよう、アプリから ABI を使える状態にします。表示されたメソッド名だけではコントラクトの識別や動作の証明になりません。セレクターは衝突する場合があります。

## 署名レジストリ [#signature-registries]

従来の GitBook ガイドは Parity のオンチェーンレジストリへのシグネチャ登録を説明していました。現在のプロバイダーソースからは、OneKey がトランザクションのデコードにそのレジストリを使うことは確認できません。OneKey の確認画面が変わると想定して、レジストリのトランザクションに支払わないでください。

メソッド名が表示されない場合は、チェーン、コントラクトアドレス、メソッドシグネチャ、取得可能ならトランザクションハッシュ、ウォレットのバージョンを、次で報告してください: [OneKey の Issue トラッカー](https://github.com/OneKeyHQ/app-monorepo/issues)。秘密鍵やリカバリーフレーズを含めてはいけません。

ハードウェア統合は次を参照: [クリアサイニング](/ja/hardware-sdk/signers/evm#clear-signing)。デバイスでのデコードはファームウェアと calldata に依存します。アプリのメタデータがデバイスの確認内容を上書きすることはありません。
