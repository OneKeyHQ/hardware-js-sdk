# 貢献方法

機能を管理するリポジトリを選び、作業前に README、貢献手順、セキュリティポリシーを読んでください。

| 分野 | リポジトリ |
| --- | --- |
| アプリとブラウザー拡張機能 | [app-monorepo](https://github.com/OneKeyHQ/app-monorepo) |
| Hardware SDK とこの開発者ポータル | [hardware-js-sdk](https://github.com/OneKeyHQ/hardware-js-sdk) |
| 注入型ウォレットプロバイダー | [cross-inpage-provider](https://github.com/OneKeyHQ/cross-inpage-provider) |
| ファームウェア | [ファームウェア](https://github.com/OneKeyHQ/firmware) |
| 従来の GitBook コレクション | [ドキュメント](https://github.com/OneKeyHQ/docs) |

## 変更を提案 [#propose-a-change]

新しいチェーンや統合の変更では、実行環境、署名メソッド、シリアライズ形式、必要なデバイス/ファームウェアの対応を説明してください。ソフトウェアウォレットとハードウェア署名の統合は、別のリポジトリが担当する場合があります。まず既存の Issue とプルリクエストを確認してください。

## 修正を提出 [#submit-a-fix]

1. リポジトリの開発手順に従います。
2. 範囲を絞って変更し、影響を受ける例やドキュメントを更新します。
3. 必要なチェックを実行します。
4. 問題、変更後の動作、根拠を説明するプルリクエストを作成します。

ドキュメントの報告にはページ URL と誤った例/記述を含めてください。統合の失敗では次を使用します: [報告用チェックリスト](/ja/troubleshooting#report-an-issue)。脆弱性については、Issue で悪用方法を公開せず、対象リポジトリのセキュリティポリシーに従ってください。
