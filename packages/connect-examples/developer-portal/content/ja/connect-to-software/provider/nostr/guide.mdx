# ガイド

## 概要 [#overview]

このガイドでは、OneKey プロバイダー API を使って、Nostr プロトコルを利用するネットワークアプリケーションを簡単に構築する方法を説明します。

OneKey プロバイダー API は次で規定されています: [NIP-07](https://github.com/nostr-protocol/nips/blob/master/07.md).

## インストール [#install]

### 1. OneKey ウォレットをダウンロード [#1-download-onekey-wallet]

次をダウンロードします: [OneKey ウォレット](https://onekey.so/download?client=browserExtension)。OneKey ブラウザー拡張機能をインストールしてください。

#### 2. API の注入について [#2-api-injection-explanation]

* OneKey ブラウザー拡張機能は、アクセスした Web サイトに `Provider API` を注入します。
* 2 種類の API が提供されています: `window.nostr` および `window.$onekey.nostr`.
* `window.$onekey.nostr` の使用を推奨します。

> 次を優先してください: `window.$onekey.nostr` を使うと OneKey を明示的に選択できます。グローバルの `window.nostr` は、複数の拡張機能がインストールされている場合、別のウォレットに属していることがあります。

### Provider API 対応の検出 [#detecting-provider-api-support]

リクエスト前にプロバイダーが利用可能か確認してください:

```javascript
const provider = (window.$onekey && window.$onekey.nostr) || window.nostr;

if (!provider) {
  throw new Error("No provider is available.");
}
```

## リクエストの処理 [#handling-requests]

ウォレットへのリクエストは async 関数または ES モジュールから実行してください。Promise の拒否をキャッチし、アプリケーションにエラーを表示します。接続、署名、支払いはユーザー操作から要求し、リクエストの処理中は起点となったボタンを無効にしてください。
