# JSON-RPC リファレンス

OneKey で使う主な Ethereum JSON-RPC メソッドとウォレットメソッドのリファレンス。

<Callout type="info">
すべてのメソッドは次を通じて呼び出します: `window.$onekey.ethereum.request({ method, params })`.
</Callout>

---

## アカウントのメソッド [#account-methods]

| メソッド | 説明 |
|--------|-------------|
| [eth_requestAccounts](./eth_requestAccounts) | ユーザーアカウントを要求 (接続ポップアップを表示) |
| [eth_accounts](./eth_accounts) | 接続済みアカウントを取得 (ポップアップなし) |
| [wallet_requestPermissions](./wallet_requestPermissions) | 特定の権限を要求 |
| [wallet_getPermissions](./wallet_getPermissions) | 現在の権限を取得 |

---

## トランザクションのメソッド [#transaction-methods]

| メソッド | 説明 |
|--------|-------------|
| [eth_sendTransaction](./eth_sendTransaction) | トランザクションを送信 |
| [eth_call](./eth_call) | トランザクションを作成せずに呼び出しを実行 |
| [eth_estimateGas](./eth_estimateGas) | トランザクションのガスを見積もる |
| [eth_getTransactionByHash](./eth_getTransactionByHash) | ハッシュでトランザクションを取得 |
| [eth_getTransactionReceipt](./eth_getTransactionReceipt) | トランザクションレシートを取得 |

## 標準の Ethereum メソッド [#standard-ethereum-methods]

その他の Ethereum JSON-RPC メソッドは、接続中のネットワークとウォレットの実装によって異なります。参照: [Ethereum JSON-RPC 仕様](https://ethereum.github.io/execution-apis/) に完全な一覧があります。

主なメソッドは次のとおりです:
- `eth_blockNumber` - 現在のブロック番号を取得
- `eth_getBalance` - アカウント残高を取得
- `eth_getCode` - コントラクトコードを取得
- `eth_getLogs` - イベントログを取得
