# 署名

以下の署名例では、[はじめに](/ja/connect-to-software/provider/sui/getting-started#account-context-for-signing)で説明する `connectSuiAccount()` を使用します。この関数は Wallet Standard アカウントと有効なチェーンを返します。例では `@mysten/sui@1.28.2` を使用します。従来の `*TransactionBlock` メソッドも、現在は `@mysten/wallet-standard@0.14.7` で定義された `Transaction` を入力として宣言しています。

署名前に権限を要求し、接続済みアカウントを選択して、有効なチェーンを読み取ってください。これらの例では、現在のプロバイダーが受け入れる `@mysten/wallet-standard@0.14.7` の形式に合う `@mysten/sui@1.28.2` を使用します。

認証用のメッセージに署名する方法を説明します。

以下の例を実行する前に、アカウントコンテキストを初期化してください:

```typescript
const { account, chain } = await connectSuiAccount()
```

---

## 個人メッセージに署名 [#sign-personal-message]

認証のために任意のメッセージに署名します:

```typescript
const message = new TextEncoder().encode('Hello, Sui!')

const result = await provider.signPersonalMessage({
  account,
  chain,
  message,
})

console.log({
  signature: result.signature,   // Base64 encoded signature
  bytes: result.bytes,           // Signed message bytes
})
```

## 署名を検証 [#verify-signature]

```typescript
import { verifyPersonalMessageSignature } from '@mysten/sui/verify'

const message = new TextEncoder().encode('Hello, Sui!')
const { signature } = await provider.signPersonalMessage({ message, account, chain })

const signerKey = await verifyPersonalMessageSignature(message, signature)
const isExpectedSigner = signerKey.toSuiAddress() === account.address
console.log('Expected signer:', isExpectedSigner)
```

```typescript

  await provider.requestPermissions()

  }
```
