# はじめに

[**OneKey**](https://www.onekey.so) は、デジタル資産の管理と、[Near](https://docs.near.org) ブロックチェーン上の分散型アプリケーションへのアクセスに使用できるウォレット兼ブラウザー拡張機能です。

ユーザーに代わって秘密鍵を作成・管理し、資金の保管やトランザクションへの署名を可能にします。

Web アプリケーションは拡張機能ウォレットとやり取りでき、たとえばトランザクション実行の許可を求めることができます。
