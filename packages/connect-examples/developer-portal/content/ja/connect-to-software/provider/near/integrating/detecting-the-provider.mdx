# プロバイダーの検出

一部のプロバイダーメソッドは、ユーザーのブラウザーに OneKey 拡張機能がインストールされている場合にのみ呼び出せます。

拡張機能がインストールされているかは、非同期メソッドの `detectWalletInstalled` で検出できます。

OneKey がインストールされていない場合は、ユーザーを次へ案内することを推奨します: [公式 Web サイト](https://www.onekey.so)。全体では次のようになります。

```javascript
const installed = await provider.detectWalletInstalled();
if (installed) {
  await provider.request({ method: 'near_accounts' });
} else {
  window.open('https://www.onekey.so');
}
```
