# enable

操作を始めるには、まず適切な権限を取得する必要があります。`provider.enable()` を呼び出すと、ユーザーの Lightning アカウントへのアクセスを要求します。他のメソッドを呼び出す前に承認を待ってください。その後の支払いや署名には、別途承認が必要な場合があります。

## メソッド [#method]

```typescript
declare function enable(): Promise<void>;
```


## 例 [#example]

```typescript
const provider = (window.$onekey && window.$onekey.webln) || window.webln;

await provider.enable()
```
