# WebLN のイベント

WebLN リクエストの成功を、アカウントやネットワークのイベントから判断しないでください。各メソッドの完了を待ち、結果または拒否を処理してください。

プロバイダーの型は `accountChanged` (単数形) と `disconnect` を宣言していますが、現在の WebLN 実装ではアカウント変更イベントの購読は確立されません。対象ウォレットのバージョンで動作を検証せずに、これらの通知に依存しないでください。

必要な接続フローは次を参照してください: [はじめに](/ja/connect-to-software/provider/webln/guide).
