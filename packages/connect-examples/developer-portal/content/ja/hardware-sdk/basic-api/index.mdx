# 基本 API

デバイス検出、セッション管理、イベント処理のための主要な SDK メソッド。

| メソッド | 説明 |
|--------|-------------|
| [デバイスを検索](./search-devices) | 接続済み OneKey ハードウェアデバイスをスキャンして検出 |
| [デバイス状態を取得](./get-device-state) | V1/V2 共通のデバイススナップショット |
| [ウォレットセッションを開く](./open-wallet-session) | 標準 / 隠しウォレットを開く、または選択 |
| [機能を取得](./get-features) | **非推奨** — デバイス状態を取得を使用 |
| [パスフレーズ状態を取得](./get-passphrase-state) | **非推奨** — ウォレットセッションを開くを使用 |
| [UI イベントに応答](./response-ui-event) | デバイス操作の UI イベントを処理 |
| [リクエストをキャンセル](./cancel-request) | 実行中のデバイス操作をキャンセル |
