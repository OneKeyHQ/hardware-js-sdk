# tronSignMessage

## TRON: メッセージに署名 <a href="#ethereum-sign-message" id="ethereum-sign-message"></a> [#tron-sign-message-]

指定パスから導出した鍵でメッセージの署名を要求します。

```typescript
const result = await HardwareSDK.tronSignMessage(connectId, deviceId, params);
```

### パラメーター [#params]

[**任意の共通パラメーター**](/ja/hardware-sdk/concepts/common-params)

* `path` - _必須_ `string | Array<number>` SDK の最小長は `3`. [パス形式](/ja/hardware-sdk/concepts/common-params#hd-path)
* `messageHex` - _必須_ `string` 署名するメッセージ。16 進数文字列にエンコードします。

* `messageType` - `"V2"`。明示的に渡してください。現在の実行時処理は、値の省略と従来の `"V1"` リクエストを拒否します。公開型には引き続き両方の値が含まれます。

### 例 [#example]

```typescript
// Original message
const message = "Hello World";

// Convert to hex
const messageHex = Buffer.from(message).toString('hex');

HardwareSDK.tronSignMessage(connectId, deviceId, {
    path: "m/44'/195'/0'/0/0",
    messageHex,
    messageType: 'V2'
});
```

結果

```typescript
{
    success: true,
    payload: {
        signature: string;
        address: string;
    }
}
```

エラー

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
