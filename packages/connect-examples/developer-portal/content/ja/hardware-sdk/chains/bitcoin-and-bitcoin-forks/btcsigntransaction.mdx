# btcSignTransaction

## Bitcoin: トランザクションに署名 [#bitcoin-sign-transaction]

準備済みトランザクションの入力と出力に対する署名を要求します。ユーザーはデバイス上でリクエストを確認して承認します。

```typescript
const result = await HardwareSDK.btcSignTransaction(connectId, deviceId, params);
```

## パラメーター [#params]

[**任意の共通パラメーター**](/ja/hardware-sdk/concepts/common-params)

* `coin` - _必須_ `string` 次で指定されたネットワーク定義を決定します: [bitcoin.json](https://github.com/OneKeyHQ/hardware-js-sdk/blob/onekey/packages/core/src/data/coins/bitcoin.json) ファイル。コインの `shortcut`, `name` または `label` を使用できます。
* `inputs` - _必須_ `Array` の [TxInputType](https://github.com/OneKeyHQ/hardware-js-sdk/blob/728279dc70c5bde56c5d72d86598815f977b0c7f/packages/hd-transport/src/types/messages.ts#L363),
* `outputs` - _必須_ `Array` の [TxOutputType](https://github.com/OneKeyHQ/hardware-js-sdk/blob/728279dc70c5bde56c5d72d86598815f977b0c7f/packages/hd-transport/src/types/messages.ts#L390),
* `refTxs` - _必須_ `Array` の [RefTransaction](https://github.com/OneKeyHQ/hardware-js-sdk/blob/728279dc70c5bde56c5d72d86598815f977b0c7f/packages/core/src/types/api/btcSignTransaction.ts#L26)。Zcash と Komodo の refTxs には次も必要です: `expiry`, `version_group_id` および `extra_data` フィールド。
* `locktime` - _任意_ `number`,
* `version` - _任意_ `number` トランザクションのバージョン、
* `expiry` - _任意_ `number`, Decred と Zcash のみ、
* `versionGroupId` - _任意_ `number` Zcash のみ。overwintered が設定されている場合の nVersionGroupId、
* `overwintered` - _任意_ `boolean` Zcash のみ
* `timestamp` - _任意_ `number` Capricoin のみ。トランザクションのタイムスタンプ、
* `branchId` - _任意_ `number`, Zcash のみ。overwintered が設定されている場合の BRANCH\_ID

## トランザクションのパラメーターを構築 [#build-transaction-parameters]

### 入力を構築 [#build-an-input]

```
const buildHardwareInput = async (
  input: TxInput,
  path: string,
): Promise<Messages.TxInputType> => {
  const { getHDPath, getScriptType } = await CoreSDKLoader();
  const addressN = getHDPath(path);
  const scriptType = getScriptType(addressN);
  const utxo = input.utxo as UTXO;

    return {
    prev_index: utxo.vout,
    prev_hash: utxo.txid,
    amount: utxo.value.integerValue().toString(),
    address_n: addressN,
    script_type: scriptType,
  };
};
```

### 出力を構築 [#build-an-output]

```
const buildHardwareOutput = async (
  output: TxOutput,
): Promise<Messages.TxOutputType> => {
  const { isCharge, bip44Path } = output.payload || {};

  if (isCharge && bip44Path) {
    const { getHDPath, getOutputScriptType } = await CoreSDKLoader();
    const addressN = getHDPath(bip44Path);
    const scriptType = getOutputScriptType(addressN);
    return {
      script_type: scriptType,
      address_n: addressN,
      amount: output.value.integerValue().toString(),
    };
  }

  return {
    script_type: 'PAYTOADDRESS',
    address: output.address,
    amount: output.value.integerValue().toString(),
  };
};
```

### 以前のトランザクションを構築 [#build-a-previous-transaction]

```
import * as BitcoinJS from 'bitcoinjs-lib';
const buildPrevTx = (rawTx: string): RefTransaction => {
    const tx = BitcoinJS.Transaction.fromHex(rawTx);

    return {
      hash: tx.getId(),
      version: tx.version,
      inputs: tx.ins.map((i) => ({
        prev_hash: Buffer.from(i.hash).reverse().toString('hex'),
        prev_index: i.index,
        script_sig: Buffer.from(i.script).toString('hex'),
        sequence: i.sequence,
      })),
      bin_outputs: tx.outs.map((o) => ({
        amount: o.value.toString(),
        script_pubkey: Buffer.from(o.script).toString('hex'),
      })),
      lock_time: tx.locktime,
    };
  };
```

## 例 [#example]

以下のスニペットはパラメーターの形式を示します。実際に使用可能な UTXO、一致する金額、完全な以前のトランザクションを使用してください。この固定データは、そのままブロードキャストできるトランザクションではありません。

### PAYTOADDRESS [#paytoaddress]

```typescript
import type { BTCSignTransactionParams } from "@onekeyfe/hd-core";

// Load the actual previous transactions for the UTXOs below.
declare const refTxs: BTCSignTransactionParams["refTxs"];
declare const previousOutputAmount: string;

HardwareSDK.btcSignTransaction(connectId, deviceId, {
    inputs: [
        {
            address_n: [(44 | 0x80000000) >>> 0, (0 | 0x80000000) >>> 0, (2 | 0x80000000) >>> 0, 1, 0],
            prev_index: 0,
            prev_hash: 'b035d89d4543ce5713c553d69431698116a822c57c03ddacf3f04b763d1999ac',
            amount: previousOutputAmount,
        }
    ],
    outputs: [
        {
            address_n: [(44 | 0x80000000) >>> 0, (0 | 0x80000000) >>> 0, (2 | 0x80000000) >>> 0, 1, 1],
            amount: '3181747',
            script_type: 'PAYTOADDRESS',
        }, {
            address: '18WL2iZKmpDYWk1oFavJapdLALxwSjcSk2',
            amount: '200000',
            script_type: 'PAYTOADDRESS',
        }
    ],
    refTxs,
    coin: 'btc'
});
```

### 結果 [#result]

```typescript
{
    success: true,
    payload: {
        signatures: Array<string>, // Array of signer signatures
        serializedTx: string,        // serialized transaction
        txid?: string,             // transaction ID, if returned; signing does not broadcast
    }
}
```

エラー

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
