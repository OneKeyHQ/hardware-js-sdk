# btcGetAddress

## Bitcoin: アドレスを取得 [#bitcoin-get-address]

指定パスのアドレスを導出して返します。`showOnOneKey` が `true` の場合は、 ユーザーがデバイス上でアドレスを確認する必要があります。

```typescript
const result = await HardwareSDK.btcGetAddress(connectId, deviceId, params);
```

### パラメーター [#params]

[**任意の共通パラメーター**](/ja/hardware-sdk/concepts/common-params)

#### 単一のアドレス [#single-address]

* `path` - _必須_ `string | Array<number>` SDK の最小長は `1`. [詳細を読む](/ja/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _任意_ `boolean` アドレスをデバイスに表示するかどうか。デフォルトは `true`.
* `coin` - _任意_ `string` 次で指定されたネットワーク定義を決定します: [coins.json](https://github.com/OneKeyHQ/hardware-js-sdk/blob/onekey/packages/core/src/data/coins/bitcoin.json) ファイル。コインの `shortcut`, `name` または `label` を使用できます。`coin` が設定されていない場合、API は `path` からネットワーク定義の取得を試みます。
* `multisig` - _任意_ MultisigRedeemScriptType、redeem script の情報 (マルチシグアドレスのみ)
* `scriptType` - _任意_ InputScriptType、アドレスのスクリプトタイプ

#### 複数のアドレス [#multiple-addresses]

* `bundle` - `path`, `showOnOneKey`, `coin` フィールドを持つオブジェクトの配列

### 異なる種類のアドレスを取得 [#get-different-types-of-addresses]

BTC アドレスタイプごとに、異なる導出パスのパラメーターが必要です。

| 型                | パス            | 例                                                          |
| ------------------- | --------------- | ------------------------------------------------------------ |
| レガシー BIP44        | m/44'/0'/x'/x/x | 「1」で始まり、26 ～ 35 文字で構成されます     |
| ネスト型 SegWit BIP49 | m/49'/0'/x'/x/x | 「3」で始まり、26 ～ 35 文字で構成されます     |
| ネイティブ SegWit BIP84 | m/84'/0'/x'/x/x | メインネットは次で始まります: `bc1q`; テストネットは次で始まります: `tb1q` |
| Taproot BIP86       | m/86'/0'/x'/x/x | メインネットは次で始まります: `bc1p`; テストネットは次で始まります: `tb1p`     |

## 例 [#example]

最初の bitcoin アカウントの 3 番目のアドレスを表示します:

```typescript
HardwareSDK.btcGetAddress(connectId, deviceId, {
    path: "m/49'/0'/0'/0/2",
    coin: "btc"
});
```

デバイスに表示せず、最初の bitcoin アカウントのアドレスをまとめて返します:

```typescript
HardwareSDK.btcGetAddress(connectId, deviceId, {
    bundle: [
        { path: "m/49'/0'/0'/0/0", showOnOneKey: false }, // address 1
        { path: "m/49'/0'/0'/0/1", showOnOneKey: false }, // address 2
        { path: "m/49'/0'/0'/0/2", showOnOneKey: false }  // address 3
    ]
});
```

#### 結果 [#result]

単一アドレスのレスポンス

```typescript
{
    success: true,
    payload: {
        address: string,     // displayed address
        path: string // serialized BIP32 path
    }
}
```

アドレスのバッチレスポンス

```typescript
{
    success: true,
    payload: [
        { address: string, path: string }, // address 1
        { address: string, path: string }, // address 2
        { address: string, path: string }, // address 3
    ]
}
```

エラー

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
