# btcDeriveContextHash

選択した Bitcoin キー、アプリ、コンテキスト、ネットワークに対して、デバイス上で 32 バイトの Babylon コンテキストハッシュを導出します。レスポンスには、アプリで使用する機密値 `secret` が含まれます。

SDK `1.2.8-alpha.6` で利用できます。**Classic 1s または Classic 1s Pure のファームウェア 3.21.0 以降**と **Protocol V1** が必要です。その他のデバイスシリーズと Protocol V2 はサポートされません。

```typescript
const result = await HardwareSDK.btcDeriveContextHash(connectId, deviceId, params);
```

## 呼び出し前の準備 [#before-you-call]

- [SDK を初期化し、デバイスを選択します](/ja/hardware-sdk/getting-started)。
- [UI イベントハンドラー](/ja/hardware-sdk/core-api-guide#events-ui)を登録し、目的の[ウォレットセッション](/ja/hardware-sdk/concepts/wallet-session)を明示的に選択してください。
- 呼び出し前に、要求元アプリとそのオリジンについてユーザーの承認を得てください。`appName` は呼び出し元が指定するため、アプリ側でどのサイトやアプリがアクセスを要求しているかを確認する必要があります。

## 例 [#example]

このコード断片は、SDK が初期化され、標準ウォレットが選択済みであることを前提とします。例の `path`、`appName`、`context`、`network` を、ユーザーが承認した値に置き換えてください。以下のコンテキストは 16 進数でエンコードしたデータの例です。

```typescript
const result = await HardwareSDK.btcDeriveContextHash(connectId, deviceId, {
  path: "m/84'/0'/0'/0/0",
  appName: 'babylon-example',
  context: '48656c6c6f',
  network: 'bitcoin-mainnet',
  useEmptyPassphrase: true,
});

if (result.success === false) throw new Error(result.payload.error);
const secret = result.payload.secret;
// Use only for the approved application and context. Do not log or persist it.
```

この例では `useEmptyPassphrase: true` で標準ウォレットを明示的に選択します。隠しウォレットの場合は、接続済み Bitcoin アカウントの確認時に使用したものと同じ `passphraseState` を渡してください。通常の PIN、パスフレーズ、デバイス確認のフローが引き続き適用されます。

## エラーと機密値の扱い [#errors-and-secret-handling]

`path`、`appName`、`context`、`network` が無効な場合、導出コマンドの送信前に `CallMethodInvalidParameter`（`405`）が返されます。未対応のデバイスシリーズまたは Protocol V2 では `DeviceNotSupportMethod`（`415`）が返されます。3.21.0 未満のファームウェアは更新が必要です。

デバイスでキャンセルすると、標準の `success: false` レスポンスが返されます。要求を停止し、`payload.error` と `payload.code` を処理してから、再度呼び出すか判断してください。

SDK は実際の `secret` をアプリに返します。機密値として扱い、ログ、テレメトリー、クリップボード、永続ストレージに含めないでください。導出はデバイス上で実行され、内部ウォレットキーはエクスポートされません。
