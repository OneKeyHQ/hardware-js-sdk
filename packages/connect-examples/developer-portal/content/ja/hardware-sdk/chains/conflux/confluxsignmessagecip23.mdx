# confluxSignMessageCIP23

## 要件 [#requirements]

* 最小ファームウェアバージョン
  * Touch: 3.0.0
  * Classic/Mini: 2.4.0

## Conflux: CIP23 メッセージに署名 <a href="#ethereum-sign-message" id="ethereum-sign-message"></a> [#conflux-sign-message-cip23-]

指定パスから導出した鍵でメッセージの署名を要求します。このメソッドは次の [CIP23](https://github.com/Conflux-Chain/CIPs/blob/master/CIPs/cip-23.md) 仕様の実装に従います

### パラメーター [#params]

[**任意の共通パラメーター**](/ja/hardware-sdk/concepts/common-params)

* `path` - _必須_ `string | Array<number>` SDK の最小長は `3`. [パス形式](/ja/hardware-sdk/concepts/common-params#hd-path)
* `messageHash` - _必須_ `string` 署名するメッセージ。16 進数文字列にエンコードします。
* `domainHash` - _必須_ `string` CIP-23 ドメインの 16 進数エンコードされた 32 バイトハッシュ。

### 例 [#example]

```typescript
HardwareSDK.confluxSignMessageCIP23(connectId, deviceId, {
    path: "m/44'/503'/0'/0/0",
    messageHash: "0x07bc1c4f3268fc74b60587e9bb7e01e38a7d8a9a3f51202bf25332aa2c75c644",
    domainHash: "7c872d109a4e735dc1886c72af47e9b4888a1507557e0f49c85b570019163373"
});
```

結果

```typescript
{
    success: true,
    payload: {
        signature: string;
        address: string;
    }
}
```

エラー

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
