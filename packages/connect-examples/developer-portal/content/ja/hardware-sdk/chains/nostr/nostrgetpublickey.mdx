# nostrGetPublicKey

### 要件 [#requirements]

* SDK が要求する最小ファームウェアバージョン
  * Touch / Pro (`model_touch`): 4.7.0
  * Classic / Classic1s / Classic Pure / Mini (`model_mini`): 3.6.0

## Nostr: 公開鍵を取得 [#nostr-get-publickey]

指定パスから導出した公開鍵を返します。`showOnOneKey` を使用すると、デバイス上での確認を要求できます。

```typescript
const result = await HardwareSDK.nostrGetPublicKey(connectId, deviceId, params);
```

## パラメーター [#params]

[**任意の共通パラメーター**](/ja/hardware-sdk/concepts/common-params)

### 単一の公開鍵 [#single-public-key]

* `path` - _必須_ `string | Array<number>` SDK の最小長は `1`. [詳細を読む](/ja/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _任意_ `boolean` 公開鍵をデバイスに表示するかどうか。デフォルトは `true`.

#### 複数の公開鍵 [#multiple-public-keys]

* `bundle` - `path`, `showOnOneKey` フィールドを持つオブジェクトの配列

### 例 [#example]

最初の Nostr キーの公開鍵を返します:

```typescript
HardwareSDK.nostrGetPublicKey(connectId, deviceId, {
    path: "m/44'/1237'/0'/0/0",
    showOnOneKey: true,
});
```

複数の Nostr キーの公開鍵をまとめて返します:

```typescript
HardwareSDK.nostrGetPublicKey(connectId, deviceId, {
    bundle: [
        { path: "m/44'/1237'/0'/0/0" }, // account 1
        { path: "m/44'/1237'/0'" }, // account 2
        { path: "m/44'/1237'/0'/0/1" }  // account 3
    ]
});
```

### 結果 [#result]

単一公開鍵のレスポンス

```typescript
{
    success: true,
    payload: {
        path: string, // serialized BIP32 path
        pub?: string, // public key in hexadecimal
        publickey?: string, // legacy runtime alias
        npub?: string,        // npub
    }
}
```

公開鍵のバッチレスポンス

```typescript
{
    success: true,
    payload: [
        { path, pub, publickey, npub }, // account 1
        { path, pub, publickey, npub }, // account 2
        { path, pub, publickey, npub }, // account 3
    ]
}
```

エラー

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```

公開鍵には `pub` を使用します。実行時には従来の `publickey` エイリアスも返します。現在の型宣言にある任意の `publicKey` という綴りは、そのエイリアスを表していません。
