# nostrSignEvent

### 要件 [#requirements]

現在の SDK には次のファームウェア制約が宣言されています: `model_touch` ≥ 4.7.0 および `model_mini` ≥ 3.6.0。これらは SDK のバージョン範囲キーです。統合対象のデバイスモデルとの対応関係と、リリース済みファームウェアでの対応を確認してください。

## Nostr: nostr イベントに署名 [#nostr-sign-nostr-event]

指定パスの鍵で Nostr イベントへの署名を要求します。ユーザーはデバイス上でリクエストを確認します。

```typescript
const result = await HardwareSDK.nostrSignEvent(connectId, deviceId, params);
```

### パラメーター [#params]

[**任意の共通パラメーター**](/ja/hardware-sdk/concepts/common-params)

* `path` - _必須_ `string | Array<number>` SDK の最小長は `5`. [詳細を読む](/ja/hardware-sdk/concepts/common-params#hd-path)
* `event` - _必須_ `NostrEvent` nostr イベント。

```
enum EventKind {
  Metadata = 0,
  Text = 1,
  RelayRec = 2,
  Contacts = 3,
  DM = 4,
  Deleted = 5,
  Reaction = 7,
  BadgeAward = 8,
  ChannelCreation = 40,
  ChannelMetadata = 41,
  ChannelMessage = 42,
  ChannelHideMessage = 43,
  Reporting = 1984,
  ZapRequest = 9734,
  Zap = 9735,
  RelayListMetadata = 10002,
  ClientAuthentication = 22242,
  NostrConnect = 24133,
  ProfileBadges = 30008,
  BadgeDefinition = 30009,
  LongFormContent = 30023,
  ApplicationSpecificData = 30078,
}

type NostrEvent = {
  id?: string;
  kind: EventKind;
  pubkey?: string;
  content: string;
  tags: string[][];
  created_at: number;
  sig?: string;
};
```

### 例 [#examples]

```typescript
const response = await HardwareSDK.nostrSignEvent(
  connectId,
  deviceId,
  {
    path: "m/44'/1237'/0'/0/0",
    event: {
      kind: 1,
      content: 'Hello world',
      tags: [],
      created_at: 1702268010,
    },
  }
);
```

結果

```typescript
{
  success: true,
  payload: {
    path: string,
    event: {
      kind: 1,
      content: 'Hello world',
      tags: [],
      created_at: 1702268010,
      sig: 'signature returned by the device',
    },
  }
}
```

エラー

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
