# aptosGetAddress

## 要件 [#requirements]

* 最小ファームウェアバージョン
  * Touch: 3.0.0
  * Classic/Mini: 2.6.0

## Aptos: アドレスを取得 [#aptos-get-address]

指定パスのアドレスを導出して返します。`showOnOneKey` が `true` の場合は、 ユーザーがデバイス上でアドレスを確認する必要があります。

```typescript
const response = await HardwareSDK.aptosGetAddress(connectId, deviceId, params)
```

### パラメーター [#params]

[任意の共通パラメーター](/ja/hardware-sdk/concepts/common-params)

**単一のアドレス**

* `path` - _必須_ `string | Array<number>`  SDK の最小長は `3`. [詳細情報](/ja/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _任意_ `boolean` アドレスをデバイスに表示するかどうか。デフォルトは `true`.

**複数のアドレス**

* `bundle` - `path` および `showOnOneKey` フィールドを持つオブジェクトの配列

#### 例 [#example]

最初の aptos アカウントのアドレスを表示します:

```typescript
HardwareSDK.aptosGetAddress(connectId, deviceId, {
    path: "m/44'/637'/0'/0'/0'"
});
```

デバイスに表示せず、aptos アドレスをまとめて返します:

```typescript
HardwareSDK.aptosGetAddress(connectId, deviceId, {
    bundle: [
        { path: "m/44'/637'/0'/0'/0'", showOnOneKey: false }, // account 1
        { path: "m/44'/637'/1'/0'/0'", showOnOneKey: false }, // account 2
        { path: "m/44'/637'/2'/0'/0'", showOnOneKey: false }  // account 3
    ]
});
```

#### 結果 [#result]

単一アドレスのレスポンス

```typescript
{
    success: true,
    payload: {
        address: string,     // displayed address
        path: string // serialized BIP32 path
    }
}
```

リクエストと同じ順序のバッチレスポンス

```typescript
{
    success: true,
    payload: [
        { address: string, path: string }, // account 1
        { address: string, path: string }, // account 2
        { address: string, path: string }  // account 3
    ]
}
```

エラー

```
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
