# aptosSignMessage

## 要件 [#requirements]

* 最小ファームウェアバージョン
  * Touch: 3.0.0
  * Classic/Mini: 2.6.0

## Aptos: メッセージに署名 <a href="#ethereum-sign-message" id="ethereum-sign-message"></a> [#aptos-sign-message-]

指定パスから導出した鍵でメッセージの署名を要求します。

```typescript
const result = await HardwareSDK.aptosSignMessage(connectId, deviceId, params);
```

### パラメーター [#params]

[**任意の共通パラメーター**](/ja/hardware-sdk/concepts/common-params)

* `path` - _必須_ `string | Array<number>` SDK の最小長は `3`. [パス形式](/ja/hardware-sdk/concepts/common-params#hd-path)
* `payload` - `AptosMessagePayload` 型
  * `address` - _任意  `string`_ パスから導出したアドレス
  * `chainId` - _任意  `string`_ チェーンの ID
  * `application` - _任意  `string`_ DApp の Web サイト URL
  * `nonce` - _必須  `string`_ 乱数
  * `message` - _必須_ `string` 署名するメッセージテキスト

### 例 [#example]

```typescript
HardwareSDK.aptosSignMessage(connectId, deviceId, {
    path: "m/44'/637'/0'/0'/0'",
    payload: {
        nonce: "1",
        message: "hello world"
    }
});
```

結果

```typescript
{
    success: true,
    payload: {
        path: string;
        fullMessage: string;
        signature: string;
        address: string;
    }
}
```

エラー

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
