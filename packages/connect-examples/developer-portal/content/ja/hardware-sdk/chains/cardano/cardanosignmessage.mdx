# cardanoSignMessage

## 要件 [#requirements]

* SDK が要求する最小ファームウェアバージョン
  * Touch / Pro (`model_touch`): 4.10.0

このメソッドでは、Classic/Mini の最小ファームウェアバージョンは定義されていません。SDK にバージョンチェックがないことは、ファームウェアがこのメソッドに対応していることを意味しません。

## Cardano: メッセージに署名 <a href="#ethereum-sign-message" id="ethereum-sign-message"></a> [#cardano-sign-message-]

指定パスから導出した鍵でメッセージの署名を要求します。

```typescript
const result = await HardwareSDK.cardanoSignMessage(connectId, deviceId, params);
```

### パラメーター [#params]

[**任意の共通パラメーター**](/ja/hardware-sdk/concepts/common-params)

* `path` - _必須_ `string` 少なくとも `3` 個の構成要素を持つ BIP32 パスです。このメソッドは数値配列を受け付けません。[パス形式](/ja/hardware-sdk/concepts/common-params#hd-path)
* `message` - _必須_ `string` 署名するメッセージ。16 進数文字列にエンコードします。
* `networkId` - _必須_ `Integer` メインネットは 1、テストネットは 0
* `derivationType` - _必須_ `CardanoDerivationType` 列挙型。導出アルゴリズムを選択します。実行時のデフォルトは `ICARUS` (`1`).

現在の TypeScript API では `derivationType` を明示する必要があります。実行時のデフォルトは ICARUS です。

### 例 [#example]

```typescript
import { PROTO } from "@onekeyfe/hd-core";

// Original message
const message = "Hello World";

// Convert to hex
const messageHex = Buffer.from(message).toString('hex');

HardwareSDK.cardanoSignMessage(connectId, deviceId, {
    path: "m/1852'/1815'/0'/0/0",
    message: messageHex,
    networkId: 1,
    derivationType: PROTO.CardanoDerivationType.ICARUS
});
```

結果

```typescript
{
    success: true,
    payload: {
        signature: string;
        key: string;
    }
}
```

エラー

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
