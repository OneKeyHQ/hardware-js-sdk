# cardanoGetPublicKey

## 要件 [#requirements]

* 最小ファームウェアバージョン
  * Touch: 4.1.0
  * Classic/Mini: 3.0.0

## Cardano: 公開鍵を取得 [#cardano-get-public-key]

指定された Cardano パスから導出した拡張公開鍵を返します。

```typescript
const result = await HardwareSDK.cardanoGetPublicKey(connectId, deviceId, params);
```

## パラメーター [#params]

[**任意の共通パラメーター**](/ja/hardware-sdk/concepts/common-params)

### 単一の公開鍵 [#single-public-key]

* `path` - _必須_ `string | Array<number>` SDK の最小長は `3`. [パス形式](/ja/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _任意_ `boolean` 公開鍵をデバイスに表示するかどうか。デフォルトは `false`.
* `derivationType` - _任意_ `CardanoDerivationType` 列挙型。使用する導出タイプを決定します。デフォルトは ICARUS=1

#### 複数の公開鍵 [#multiple-public-keys]

* `bundle` - `path`, `showOnOneKey` フィールドを持つオブジェクトの配列

### 例 [#example]

最初の cardano アカウントの公開鍵を返します:

```typescript
HardwareSDK.cardanoGetPublicKey(connectId, deviceId, {
    path: "m/1852'/1815'/0'/0/0",
    showOnOneKey: true
});
```

複数の cardano アカウントの公開鍵をまとめて返します:

```typescript
HardwareSDK.cardanoGetPublicKey(connectId, deviceId, {
    bundle: [
        { path: "m/1852'/1815'/0'/0/0", }, // account 1
        { path: "m/1852'/1815'/1'/0/0", }, // account 2
        { path: "m/1852'/1815'/2'/0/0", }  // account 3
    ]
});
```

### 結果 [#result]

単一公開鍵のレスポンス

```typescript
{
    success: true,
    payload: {
        path: Array<number>, // hardened path
        serializedPath: string,
        xpub: string,
        node: HDNodeType,
    }
}
```

エラー

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
