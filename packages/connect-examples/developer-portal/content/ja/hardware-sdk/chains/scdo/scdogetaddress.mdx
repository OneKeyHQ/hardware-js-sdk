# scdoGetAddress

#### 要件 [#requirements]

* 最小ファームウェアバージョン
  * Touch: 4.10.0

#### SCDO: アドレスを取得 [#scdo-get-address]

指定パスのアドレスを導出して返します。`showOnOneKey` が `true` の場合は、 ユーザーがデバイス上でアドレスを確認する必要があります。

```typescript
const response = await HardwareSDK.scdoGetAddress(connectId, deviceId, {
    path: "m/44'/541'/0'/0/0",
    showOnOneKey: true
});
```

**パラメーター**

任意の共通パラメーター

**単一のアドレス**

* `path` - _必須_ `string | Array<number>` SDK の最小長は `3`. [パス形式](/ja/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _任意_ `boolean` アドレスをデバイスに表示するかどうか。デフォルトは `true`.

**複数のアドレス**

* `bundle` - `path` および `showOnOneKey` フィールドを持つオブジェクトの配列

**例**

```typescript
// Get single address
const response = await HardwareSDK.scdoGetAddress(connectId, deviceId, {
    path: "m/44'/541'/0'/0/0",
    showOnOneKey: false
});

// Get multiple addresses
const bundleResponse = await HardwareSDK.scdoGetAddress(connectId, deviceId, {
    bundle: [
        {
            path: "m/44'/541'/0'/0/0",
            showOnOneKey: false
        },
        {
            path: "m/44'/541'/1'/0/0",
            showOnOneKey: false
        }
    ]
});
```

単一アドレスの結果

```typescript
{
    success: true,
    payload: {
        address: string,
        path: string
    }
}
```

アドレスのバッチレスポンス

```typescript
{
    success: true,
    payload: [
        { address: string, path: string }, // account 1
        { address: string, path: string }  // account 2
    ]
}
```

エラー

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number  // error code
    }
}
```
