# scdoSignTransaction

#### 要件 [#requirements]

* 最小ファームウェアバージョン
  * Touch: 4.10.0

#### SCDO: トランザクションに署名 [#scdo-sign-transaction]

指定の BIP32 パスから導出した秘密鍵でトランザクションに署名します。

```typescript
const response = await HardwareSDK.scdoSignTransaction(connectId, deviceId, {
    path: "m/44'/541'/0'/0/0",
    nonce: "0x0",
    gasPrice: "0xbebc200",
    gasLimit: "0x5208",
    to: "1S0118a02f993fc7a4348fd36b7f7a596948f02b31",
    value: "0xf4240",
    timestamp: "0",
    data: "0x", // optional
    txType: 0   // optional
});
```

**パラメーター**

任意の共通パラメーター

* `path` - _必須_ `string | Array<number>` SDK の最小長は `3`. [パス形式](/ja/hardware-sdk/concepts/common-params#hd-path)
* `nonce` - _必須_ `string` トランザクションの nonce (16 進数)
* `gasPrice` - _必須_ `string` トランザクションのガス価格 (16 進数)
* `gasLimit` - _必須_ `string` トランザクションのガスリミット (16 進数)
* `to` - _必須_ `string` 送信先アドレス
* `value` - _必須_ `string` トランザクションの値 (16 進数)
* `timestamp` - _任意_ `string` トランザクションのタイムスタンプ
* `data` - _任意_ `string` トランザクションデータ (16 進数)
* `txType` - _任意_ `number` トランザクションの種類

**例**

```typescript
const response = await HardwareSDK.scdoSignTransaction(connectId, deviceId, {
    path: "m/44'/541'/0'/0/0",
    nonce: "0x0",
    gasPrice: "0xbebc200",
    gasLimit: "0x5208",
    to: "1S0118a02f993fc7a4348fd36b7f7a596948f02b31",
    value: "0xf4240",
    timestamp: "0"
});
```

結果

```typescript
{
    success: true,
    payload: {
        signature?: string,
        data_length?: number,
        path: string
    }
}
```

エラー

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number  // error code
    }
}
```
