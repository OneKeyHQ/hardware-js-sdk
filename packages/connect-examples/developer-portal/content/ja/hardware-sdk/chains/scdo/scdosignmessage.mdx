# scdoSignMessage

#### 要件 [#requirements]

* 最小ファームウェアバージョン
  * Touch: 4.10.0

#### SCDO: メッセージに署名 [#scdo-sign-message]

指定の BIP32 パスから導出した秘密鍵でメッセージに署名します。

```typescript
// Original message
const message = "Hello World";

// Convert to hex
const messageHex = Buffer.from(message).toString('hex');

const response = await HardwareSDK.scdoSignMessage(connectId, deviceId, {
    path: "m/44'/541'/0'/0/0",
    messageHex: messageHex
});
```

**パラメーター**

任意の共通パラメーター

* `path` - _必須_ `string | Array<number>` SDK の最小長は `3`. [パス形式](/ja/hardware-sdk/concepts/common-params#hd-path)
* `messageHex` - _必須_ `string` 署名するメッセージ (16 進数形式)

**例**

```typescript
// Original message
const message = "Hello World";

// Convert to hex
const messageHex = Buffer.from(message).toString('hex');

const response = await HardwareSDK.scdoSignMessage(connectId, deviceId, {
    path: "m/44'/541'/0'/0/0",
    messageHex,
});
```

結果

```typescript
{
    success: true,
    payload: {
        signature: string,
        address: string
    }
}
```

エラー

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number  // error code
    }
}
```
