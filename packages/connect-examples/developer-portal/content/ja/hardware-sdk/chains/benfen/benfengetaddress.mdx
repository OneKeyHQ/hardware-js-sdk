# benfenGetAddress

### Benfen: アドレスを取得 [#benfen-get-address]

指定パスのアドレスを導出して返します。`showOnOneKey` が `true` の場合は、 ユーザーがデバイス上でアドレスを確認する必要があります。

**要件**

* 最小ファームウェアバージョン
  * Pro: 4.12.0
  * Classic 1S / Classic 1S Pure: 3.11.0

```typescript
const result = await HardwareSDK.benfenGetAddress(connectId, deviceId, params);
```

#### パラメーター [#params]

**任意の共通パラメーター**

* `path` - _必須_ `string | Array<number>` SDK の最小長は `3`. [パス形式](/ja/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _任意_ `boolean` アドレスをデバイスに表示するかどうか

#### 戻り値 [#returns]

* success: boolean - 成功時は True
* payload:
  * address: string - 導出された BFC 形式のアドレス
  * path: string - 使用した BIP32 パス
  * pub?: string - 取得可能な場合の公開鍵

例:

```typescript
const params = {
  path: "m/44'/728'/0'/0'/0'",
  showOnOneKey: false
};

// Single address
const response = await HardwareSDK.benfenGetAddress(connectId, deviceId, params);

// Batch addresses
const batchParams = {
  bundle: [
    {
      path: "m/44'/728'/0'/0'/0'",
      showOnOneKey: false
    },
    {
      path: "m/44'/728'/1'/0'/0'",
      showOnOneKey: false
    }
  ]
};
const batchResponse = await HardwareSDK.benfenGetAddress(connectId, deviceId, batchParams);
```

**結果**

単一アドレスのレスポンス

```typescript
{
    success: true,
    payload: {
        address: string,     // displayed address
        pub?: string,
        path: string // serialized BIP32 path
    }
}
```

リクエストと同じ順序のバッチレスポンス

```typescript
{
    success: true,
    payload: [
        { address: string, pub?: string, path: string }, // account 1
        { address: string, pub?: string, path: string }, // account 2
        { address: string, pub?: string, path: string }  // account 3
    ]
}
```

エラー

```
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
