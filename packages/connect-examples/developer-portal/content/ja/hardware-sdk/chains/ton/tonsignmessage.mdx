# tonSignMessage

### 要件 [#requirements]

* 最小ファームウェアバージョン
  * Touch: 4.10.0
  * Pro 2 / Neo: Protocol V2 (同じ公開メソッド。SDK がフィールドを対応付け)

### TON: メッセージに署名 [#ton-sign-message]

指定の BIP32 パスから導出した秘密鍵でメッセージまたはトランザクションに署名します。ユーザーは OneKey デバイス上で操作を確認する必要があります。

```typescript
const response = await HardwareSDK.tonSignMessage(connectId, deviceId, {
    path: "m/44'/607'/0'",
    destination: "UQBYkuShkZzRYAWX_HrK3kFpeAixiRKd-K7QBXYxl9OBXM0_",
    tonAmount: 100,
    seqno: 0,
    expireAt: Math.floor(Date.now() / 1000) + 60 * 60 * 24,
    walletVersion: 3,
    isBounceable: false,
    isTestnetOnly: false
});
```

#### パラメーター [#params]

[任意の共通パラメーター](/ja/hardware-sdk/concepts/common-params)

**必須パラメーター**

* `path` - _必須_ `string | Array<number>` SDK の最小長は `3`
* `destination` - _必須_ `string` 送信先アドレス
* `tonAmount` - _必須_ `number | string` 送金額 (nanoton 単位)
* `seqno` - _必須_ `number` シーケンス番号
* `expireAt` - _必須_ `number | string` メッセージの有効期限 (Unix 秒)

**任意のパラメーター**

* `walletVersion` - _任意_ `TonWalletVersion` TON ウォレットのバージョン (デフォルト: 3)
* `isBounceable` - _任意_ `boolean` メッセージが bounceable かどうか (デフォルト: false)
* `isTestnetOnly` - _任意_ `boolean` テストネットを使用するかどうか (デフォルト: false)
* `jettonMasterAddress` - _任意_ `string` Jetton のマスターコントラクトアドレス
* `jettonAmount` - _任意_ `number | string` トークンの最小単位で表した jetton の数量
* `fwdFee` - _任意_ `number | string` jetton 送金の転送手数料 (nanoton 単位)
* `comment` - _任意_ `string` メッセージのコメント
* `mode` - _任意_ `number` メッセージモード
* `workchain` - _任意_ `TonWorkChain` TON ワークチェーン
* `walletId` - _任意_ `number` ウォレット ID

#### 例 [#example]

```typescript
// Simple TON transfer
const response = await HardwareSDK.tonSignMessage(connectId, deviceId, {
    path: "m/44'/607'/0'",
    destination: "UQBYkuShkZzRYAWX_HrK3kFpeAixiRKd-K7QBXYxl9OBXM0_",
    tonAmount: 100,
    seqno: 0,
    expireAt: Math.floor(Date.now() / 1000) + 60 * 60 * 24,
    walletVersion: 3,
    isBounceable: false,
    isTestnetOnly: false
});

// Multiple native TON transfers
const jettonResponse = await HardwareSDK.tonSignMessage(connectId, deviceId, {
    path: "m/44'/607'/0'",
    destination: 'UQBYkuShkZzRYAWX_HrK3kFpeAixiRKd-K7QBXYxl9OBXM0_',
    tonAmount: 100,
    seqno: 0,
    expireAt: Math.floor(Date.now() / 1000) + 60 * 60 * 24,
    walletVersion: 3,
    isBounceable: false,
    isTestnetOnly: false,
    extDestination: ['UQBYkuShkZzRYAWX_HrK3kFpeAixiRKd-K7QBXYxl9OBXM0_'],
    extTonAmount: [100],
    extPayload: ['48656c6c6f204f6e654b6579'],
});

```

結果

```typescript
{
    success: true,
    payload: {
        skip_validate: boolean; // Used to skip validation in classic 1s.
        signature: string;
        signing_message?: string; // Canonical field. Pro2/Neo return this; the SDK also copies it from the legacy V1 typo.
        signning_message?: string; // Deprecated Protocol V1 typo. Do not read this in new code.
    }
}
```

エラー

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
