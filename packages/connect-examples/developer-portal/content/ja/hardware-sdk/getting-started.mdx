# 最初のデバイスを接続

Hardware SDK **1.2.x** をインストールし、デバイスを接続して最初のアドレスを確認します。

このページは初回実行の手順です。動作したら[トランスポートガイド](/ja/hardware-sdk/transport/web-usb)を選び、続いて [Core API ガイド](/ja/hardware-sdk/core-api-guide)で PIN、パスフレーズ、イベント、署名について確認してください。

Hardware SDK 1.2.0 は Protocol V1 (Classic / Mini / Touch / Pro) と Protocol V2 (Pro 2 / Neo) を**同じ JavaScript API** で扱います。`init()` でプロトコルを選択するわけではありません。

## 2. 一度だけ初期化 [#2-initialize-once]

```ts
import HardwareSDK from '@onekeyfe/hd-common-connect-sdk';

const initialized = await HardwareSDK.init({
  env: 'webusb',
  debug: false,
  fetchConfig: true,
});
if (!initialized) throw new Error('SDK initialization failed');
```

アプリの入り口で `init()` を一度呼び出します。同じ実行環境で `@onekeyfe/hd-web-sdk` と `@onekeyfe/hd-common-connect-sdk` を併用しないでください。

## 3. 検索、識別、アドレスの取得 [#3-search-identify-read-an-address]

保護された呼び出しの前に [UI イベントハンドラー](/ja/hardware-sdk/core-api-guide#events-ui)を登録し、ロック中のデバイスで PIN 入力を完了できるようにします。WebUSB では、検出前にユーザーの接続ボタンからデバイスを許可してください:

```ts
import { ONEKEY_WEBUSB_FILTER } from '@onekeyfe/hd-shared';

// Run directly in the Connect button handler.
if (!navigator.usb) throw new Error('WebUSB is unavailable in this browser');
await navigator.usb.requestDevice({ filters: ONEKEY_WEBUSB_FILTER });
```

続いてデバイスを検出します。この例では候補が 1 台だけである必要があります。複数のデバイスが見つかった場合は、ユーザーに 1 台を選択してもらってから続行してください。

```ts
const devices = await HardwareSDK.searchDevices();
if (!devices.success || !devices.payload.length) {
  throw new Error('No OneKey device found');
}

// Select explicitly in the application when more than one device is available.
if (devices.payload.length !== 1) throw new Error('Select exactly one device before continuing');
const { connectId } = devices.payload[0];
if (!connectId) throw new Error("Missing connectId");

const state = await HardwareSDK.getDeviceState(connectId);
if (state.success === false) throw new Error(state.payload.error);
const deviceId = state.payload.identity.deviceId;
if (!deviceId) throw new Error("Device has no wallet identity");

const address = await HardwareSDK.evmGetAddress(connectId, deviceId, {
  path: "m/44'/60'/0'/0/0",
  useEmptyPassphrase: true,
  showOnOneKey: true,
});

if (address.success === false) throw new Error(address.payload.error);
console.log(address.payload.address);
```

`payload` を読み取る前に、必ず `success` を確認します。`useEmptyPassphrase: true` は最初の呼び出しを標準ウォレットに固定し、残っている隠しウォレットセッションによってアドレスが知らないうちに変わるのを防ぎます。

`getDeviceState()` は V1/V2 共通の読み取り API です。`getFeatures()` は Protocol V1 のみです。Pro 2 と Neo では `getDeviceState()` を使用する必要があります。

WebUSB には HTTPS とユーザー操作が必要です。BLE には OS の Bluetooth 権限が必要です。

## デバイスとウォレットのサポート [#what-120-does-for-you]

- SDK は実際のデバイスから Protocol V1 と V2 を検出します。USB PID、BLE 名、製品文字列で分岐させないでください。参照: [Protocol V1 と V2](/ja/hardware-sdk/concepts/protocol).
- Pro 2 と Neo は Classic / Pro と同じメソッドを使用します。デバイスごとの違いは次に記載しています: [デバイス](/ja/hardware-sdk/concepts/devices).
- `openWalletSession` でウォレットを開くか切り替えます。`getPassphraseState` は非推奨です。[ウォレットセッション](/ja/hardware-sdk/concepts/wallet-session)を参照してください。
