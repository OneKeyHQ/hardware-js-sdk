# 従来の統合方法

古い統合を保守する場合はこのセクションを使用してください。従来のインターフェースと現在の代替を説明するもので、現在のウォレット、SDK、ファームウェアでの対応を保証しません。

- [OneKey Bridge](./bridge): 従来のデスクトップブリッジのチェックと WebUSB への移行経路。
- [Aptos WalletConnect v1](./aptos-walletconnect): 従来のカスタムメソッドと、現在のブラウザー統合の方法。
- [初期の firmwareUpdate API](./firmware-update): 旧 API とバージョン付きファームウェアメソッドの違い。

新しい統合は[ここから開始](/ja/getting-started)してください。デバイスの初期化と消去は、別途[デバイス管理](/ja/integration-guides/device-management)で扱います。
