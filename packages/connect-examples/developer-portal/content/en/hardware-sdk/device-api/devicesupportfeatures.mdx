# deviceSupportFeatures

Check runtime capability objects. Read `.support`, not the truthiness of the object; `{ support: false }` is still a truthy JavaScript value. `require` may identify a minimum firmware version.

```ts
const result = await HardwareSDK.deviceSupportFeatures(connectId);
if (!result.success) throw new Error(result.payload.error);
const canEnterPinOnHost = result.payload.inputPinOnSoftware.support;
```

```typescript
const response = await HardwareSDK.deviceSupportFeatures(connectId);
```

### Params

[Optional common params](/en/hardware-sdk/concepts/common-params)

### Example

```typescript
const response = await HardwareSDK.deviceSupportFeatures(connectId);
```

Result

```typescript
{
    success: true,
    payload: {
      inputPinOnSoftware: { support: boolean, require?: string },
      modifyHomescreen: { support: boolean, require?: string },
      device: Device | null
    }
}
```

Error

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
