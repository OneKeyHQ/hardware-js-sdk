# deviceUpdateReboot

## Reboot device

Request bootloader mode on **Protocol V1** devices as part of an explicit firmware-update flow. This method does not declare Protocol V2 support; use the [Protocol V2 firmware update flow](/en/hardware-sdk/device-api/firmwareupdatev4) for Pro 2 and Neo.

The device may disconnect and enumerate under a different connection ID. Re-discover it and verify its state before continuing.

```typescript
const response = await HardwareSDK.deviceUpdateReboot(connectId);
if (!response.success) throw new Error(response.payload.error);
```

## Params

* empty

## Example

```typescript
const response = await HardwareSDK.deviceUpdateReboot(connectId);
if (!response.success) throw new Error(response.payload.error);
```

## Result

A successful SDK result acknowledges the request. Do not use a hard-coded payload shape to infer the new mode; read device state again after the device reconnects.

Error

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
