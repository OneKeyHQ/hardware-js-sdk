# cosmosGetPublicKey

## Requirements

* Minimum firmware versions
  * Touch: 4.0.0
  * Classic/Mini: 2.10.0

## Cosmos: get public key

Returns the public key derived from the specified path. Use `showOnOneKey` to request confirmation on the device.

```typescript
const result = await HardwareSDK.cosmosGetPublicKey(connectId, deviceId, params);
```

## Params

[**Optional common params**](/en/hardware-sdk/concepts/common-params)

### Single public key

* `path` - _required_ `string | Array<number>` SDK minimum length is `3`.
* `curve` - _optional_ `string` of the elliptic curve algorithm, default is `secp256k1`
* `showOnOneKey` - _optional_ `boolean` Whether to display the public key on the device. Defaults to `true`.

#### Multiple public keys

* `bundle` - array of objects with `path`, `showOnOneKey` , `curve` fields

### Example

Return the public key for first Cosmos account:

```typescript
HardwareSDK.cosmosGetPublicKey(connectId, deviceId, {
    path: "m/44'/118'/0'/0/0",
    curve: 'secp256k1',
    showOnOneKey: true
});
```

Return a bundle of public keys for multiple cosmos accounts:

```typescript
HardwareSDK.cosmosGetPublicKey(connectId, deviceId, {
    bundle: [
        { path: "m/44'/118'/0'/0/0" }, // account 1
        { path: "m/44'/118'/1'/0/0" }, // account 2
        { path: "m/44'/118'/2'/0/0" }, // account 3
    ]
});
```

### Result

Single-public-key response

```typescript
{
    success: true,
    payload: {
        path: string, // serialized BIP32 path
        pub: string
    }
}
```


Batch public-key response

```typescript
{
    success: true,
    payload: [
        { path: serializedPath, pub }, // account 1
        { path: serializedPath, pub }, // account 2
        { path: serializedPath, pub }, // account 3
    ]
}
```

Error

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
