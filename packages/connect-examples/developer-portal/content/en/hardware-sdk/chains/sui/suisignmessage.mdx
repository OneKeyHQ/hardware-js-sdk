# suiSignMessage

### Requirements

* Minimum firmware versions
  * Touch: 4.6.0
  * Classic/Mini: 3.4.0

### Sui: sign message

Requests a message signature using the key derived from the specified path.

```typescript
const result = await HardwareSDK.suiSignMessage(connectId, deviceId, params);
```

### Params

[**Optional common params**](/en/hardware-sdk/concepts/common-params)

* `path` - _required_ `string | Array<number>` SDK minimum length is `3`. [read more](/en/hardware-sdk/concepts/common-params#hd-path)
* `messageHex` - _required_ `string` Message to sign, encoded as a hexadecimal string.

### Example

```typescript
// Original message
const message = "Hello World";

// Convert to hex
const messageHex = Buffer.from(message).toString('hex');

HardwareSDK.suiSignMessage(connectId, deviceId, {
    path: "m/44'/784'/0'/0'/0'",
    messageHex,
});
```

#### Result

```typescript
{
    success: true,
    payload: {
        address: string,
        signature: string,
    }
}
```

Error

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
