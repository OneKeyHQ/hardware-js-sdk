# cardanoSignMessage

## Requirements

* SDK minimum firmware versions
  * Touch / Pro (`model_touch`): 4.10.0

This method does not declare a minimum firmware version for Classic/Mini. The absence of an SDK version guard does not establish firmware support.

## Cardano: sign message <a href="#ethereum-sign-message" id="ethereum-sign-message"></a>

Requests a message signature using the key derived from the specified path.

```typescript
const result = await HardwareSDK.cardanoSignMessage(connectId, deviceId, params);
```

### Params

[**Optional common params**](/en/hardware-sdk/concepts/common-params)

* `path` - _required_ `string` BIP32 path with at least `3` components. This method does not accept a number array. [Path format](/en/hardware-sdk/concepts/common-params#hd-path)
* `message` - _required_ `string` Message to sign, encoded as a hexadecimal string.
* `networkId` - _required_ `Integer` 1 for Mainnet, 0 for Testnet
* `derivationType` - _required_ `CardanoDerivationType` enum. Selects the derivation algorithm. The runtime defaults to `ICARUS` (`1`).

The current TypeScript API requires `derivationType` explicitly even though the runtime defaults to ICARUS.

### Example

```typescript
import { PROTO } from "@onekeyfe/hd-core";

// Original message
const message = "Hello World";

// Convert to hex
const messageHex = Buffer.from(message).toString('hex');

HardwareSDK.cardanoSignMessage(connectId, deviceId, {
    path: "m/1852'/1815'/0'/0/0",
    message: messageHex,
    networkId: 1,
    derivationType: PROTO.CardanoDerivationType.ICARUS
});
```

Result

```typescript
{
    success: true,
    payload: {
        signature: string;
        key: string;
    }
}
```

Error

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
