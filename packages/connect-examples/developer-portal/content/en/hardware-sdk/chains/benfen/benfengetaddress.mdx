# benfenGetAddress

### Benfen: get address

Derives and returns the address at the specified path. When `showOnOneKey` is `true`, the user must confirm the address on the device.

**Requirements**

* Minimum firmware versions
  * Pro: 4.12.0
  * Classic 1S / Classic 1S Pure: 3.11.0

```typescript
const result = await HardwareSDK.benfenGetAddress(connectId, deviceId, params);
```

#### Params

**Optional common params**

* `path` - _required_ `string | Array<number>` SDK minimum length is `3`. [Path format](/en/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _optional_ `boolean` whether to display address on device

#### Returns

* success: boolean - True if successful
* payload:
  * address: string - Derived BFC format address
  * path: string - BIP32 path used
  * pub?: string - Public key if available

Example:

```typescript
const params = {
  path: "m/44'/728'/0'/0'/0'",
  showOnOneKey: false
};

// Single address
const response = await HardwareSDK.benfenGetAddress(connectId, deviceId, params);

// Batch addresses
const batchParams = {
  bundle: [
    {
      path: "m/44'/728'/0'/0'/0'",
      showOnOneKey: false
    },
    {
      path: "m/44'/728'/1'/0'/0'",
      showOnOneKey: false
    }
  ]
};
const batchResponse = await HardwareSDK.benfenGetAddress(connectId, deviceId, batchParams);
```

**Result**

Single-address response

```typescript
{
    success: true,
    payload: {
        address: string,     // displayed address
        pub?: string,
        path: string // serialized BIP32 path
    }
}
```

Batch response, in the same order as the request

```typescript
{
    success: true,
    payload: [
        { address: string, pub?: string, path: string }, // account 1
        { address: string, pub?: string, path: string }, // account 2
        { address: string, pub?: string, path: string }  // account 3
    ]
}
```

Error

```
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
