# evmGetAddress

## Ethereum: get address

Derives and returns the address at the specified path. When `showOnOneKey` is `true`, the user must confirm the address on the device.

```typescript
const response = await HardwareSDK.evmGetAddress(connectId, deviceId, params)
```

### Params

[**Optional common params**](/en/hardware-sdk/concepts/common-params)

**Single address**

* `path` - _required_ `string | Array<number>`  SDK minimum length is `3`. [more information](/en/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _optional_ `boolean` Whether to display the address on the device. Defaults to `true`.
* `chainId` - _optional_ `number` The ChainId in ETH is a unique identifier for a specific Ethereum network, used to distinguish different versions of the blockchain. [Reference](https://github.com/ethereum-lists/chains/tree/master/\_data/chains).

**Multiple addresses**

* `bundle` - array of objects with `path` and `showOnOneKey` fields

#### Example

Display the address for the first ethereum account:

```typescript
HardwareSDK.evmGetAddress(connectId, deviceId, {
    path: "m/44'/60'/0'/0/0",
    chainId: 1
});
```

Return a bundle of ethereum addresses without displaying them on the device:

```typescript
HardwareSDK.evmGetAddress(connectId, deviceId, {
    bundle: [
        { path: "m/44'/60'/0'/0/0", chainId: 1, showOnOneKey: false }, // account 1
        { path: "m/44'/60'/1'/0/0", chainId: 1, showOnOneKey: false }, // account 2
        { path: "m/44'/60'/2'/0/0", chainId: 1, showOnOneKey: false }  // account 3
    ]
});
```

#### Result

Single-address response

```typescript
{
    success: true,
    payload: {
        address: string,     // displayed address
        path: string // serialized BIP32 path
    }
}

```

Batch response, in the same order as the request

```typescript
{
    success: true,
    payload: [
        { address: string, path: string }, // account 1
        { address: string, path: string }, // account 2
        { address: string, path: string }  // account 3
    ]
}
```

Error

```
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
