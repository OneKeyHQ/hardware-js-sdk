# filecoinGetAddress

### Requirements

* Minimum firmware versions
  * Touch: 3.5.0
  * Classic/Mini: 2.10.0

## Filecoin: get address

Derives and returns the address at the specified path. Use `showOnOneKey` to request confirmation on the device.

```typescript
const result = await HardwareSDK.filecoinGetAddress(connectId, deviceId, params);
```

## Params

[**Optional common params**](/en/hardware-sdk/concepts/common-params)

### Single address

* `path` - _required_ `string | Array<number>` SDK minimum length is `3`. [read more](/en/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _optional_ `boolean` Whether to display the address on the device. Defaults to `true`.
* `isTestnet` - _optional_ `boolean` Whether to use the testnet.

#### Multiple addresses

* `bundle` - array of objects with `path`, `showOnOneKey`, and `isTestnet` fields

### Example

Return address of first Filecoin account:

```typescript
HardwareSDK.filecoinGetAddress(connectId, deviceId, {
    path: "m/44'/461'/0'/0/0",
    showOnOneKey: true,
    isTestnet: false
});
```

Return a bundle of addresses for multiple Filecoin accounts:

```typescript
HardwareSDK.filecoinGetAddress(connectId, deviceId, {
    bundle: [
        { path: "m/44'/461'/0'/0/0" }, // account 1
        { path: "m/44'/461'/0'" }, // account 2
        { path: "m/44'/461'/0'/0/1" }  // account 3
    ]
});
```

### Result

Single-address response

```typescript
{
    success: true,
    payload: {
        path: string, // serialized BIP32 path
        address: string,   // address
    }
}
```

Batch address response

```typescript
{
    success: true,
    payload: [
        { path, address }, // account 1
        { path, address }, // account 2
        { path, address }, // account 3
    ]
}
```

Error

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
