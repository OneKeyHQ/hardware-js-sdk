# btcDeriveContextHash

Derive a 32-byte Babylon context hash on the device for the selected Bitcoin key, application, context and network. The response contains a sensitive `secret` for your application to use.

Available in SDK `1.2.8-alpha.6`. Requires **Classic 1s or Classic 1s Pure firmware 3.21.0 or later** and **Protocol V1**. Other device families and Protocol V2 are not supported.

```typescript
const result = await HardwareSDK.btcDeriveContextHash(connectId, deviceId, params);
```

- [Initialize the SDK and select a device](/en/hardware-sdk/getting-started).

## Example [#example]

This fragment assumes an initialized SDK and a selected standard wallet. Replace the sample `path`, `appName`, `context` and `network` with the values approved by your user. The context below is illustrative hex-encoded data.

```typescript
const result = await HardwareSDK.btcDeriveContextHash(connectId, deviceId, {
  path: "m/84'/0'/0'/0/0",
  appName: 'babylon-example',
  context: '48656c6c6f',
  network: 'bitcoin-mainnet',
  useEmptyPassphrase: true,
});

if (result.success === false) throw new Error(result.payload.error);
const secret = result.payload.secret;
// Use only for the approved application and context. Do not log or persist it.
```

The example explicitly selects the standard wallet with `useEmptyPassphrase: true`. For a hidden wallet, pass the same `passphraseState` used when confirming the connected Bitcoin account. The normal PIN, passphrase and device-confirmation flow still applies.

## Errors and secret handling [#errors-and-secret-handling]

Invalid `path`, `appName`, `context` or `network` returns `CallMethodInvalidParameter` (`405`) before the derivation command is sent. Unsupported device families or Protocol V2 return `DeviceNotSupportMethod` (`415`); firmware below 3.21.0 requires an upgrade.

Device cancellation returns the standard `success: false` response. Stop the request and handle `payload.error` and `payload.code` before attempting another call.

The SDK returns the actual `secret` to your application. Treat it as sensitive: keep it out of logs, telemetry, the clipboard and persistent storage. Derivation runs on the device; the internal wallet key is not exported.
