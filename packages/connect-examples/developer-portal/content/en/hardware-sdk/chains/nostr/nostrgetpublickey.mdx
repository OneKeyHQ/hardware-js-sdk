# nostrGetPublicKey

### Requirements

* Minimum firmware versions
  * Touch: 4.6.0
  * Classic/Mini: 3.5.0
  * Classic1s: 3.6.0

## Nostr: get publicKey

Returns the public key derived from the specified path. Use `showOnOneKey` to request confirmation on the device.

```typescript
const result = await HardwareSDK.nostrGetPublicKey(connectId, deviceId, params);
```

## Params

[**Optional common params**](/en/hardware-sdk/concepts/common-params)

### Single public key

* `path` - _required_ `string | Array<number>` SDK minimum length is `1`. [read more](/en/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _optional_ `boolean` Whether to display the public key on the device. Defaults to `true`.

#### Multiple public keys

* `bundle` - array of objects with `path`, `showOnOneKey` fields

### Example

Return the public key for first Nostr key:

```typescript
HardwareSDK.nostrGetPublicKey(connectId, deviceId, {
    path: "m/44'/1237'/0'/0/0",
    showOnOneKey: true,
});
```

Return a bundle of public keys for multiple Nostr keys:

```typescript
HardwareSDK.nostrGetPublicKey(connectId, deviceId, {
    bundle: [
        { path: "m/44'/1237'/0'/0/0" }, // account 1
        { path: "m/44'/1237'/0'" }, // account 2
        { path: "m/44'/1237'/0'/0/1" }  // account 3
    ]
});
```

### Result

Single-public-key response

```typescript
{
    success: true,
    payload: {
        path: string, // serialized BIP32 path
        pub?: string, // public key in hexadecimal
        publickey?: string, // legacy runtime alias
        npub?: string,        // npub
    }
}
```

Batch public-key response

```typescript
{
    success: true,
    payload: [
        { path, pub, publickey, npub }, // account 1
        { path, pub, publickey, npub }, // account 2
        { path, pub, publickey, npub }, // account 3
    ]
}
```

Error

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```

Use `pub` for the public key. The runtime also returns the legacy `publickey` alias; the current declaration's optional `publicKey` spelling does not describe that alias.
