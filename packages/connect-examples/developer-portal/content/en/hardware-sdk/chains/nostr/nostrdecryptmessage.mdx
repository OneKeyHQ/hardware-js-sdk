# nostrDecryptMessage

### Requirements

* Minimum firmware versions
  * Touch: 4.6.0
  * Classic/Mini: 3.5.0
  * Classic1s: 3.6.0

## Nostr: Decrypt Message

Requests message decryption using the key at the specified path and the other participant's public key.

```typescript
const result = await HardwareSDK.nostrDecryptMessage(connectId, deviceId, params);
```

### Params

[**Optional common params**](/en/hardware-sdk/concepts/common-params)

* `path` - _required_ `string | Array<number>` SDK minimum length is `5`. [read more](/en/hardware-sdk/concepts/common-params#hd-path)
* `pubkey` - _required_ `string`. The other participant's public key.
* `ciphertext` - _required_ `string` encrypted message.
* `showOnOneKey` - _optional_ `boolean` Whether to display the request on the device. Defaults to `true`.

### Examples

```typescript
const response = await HardwareSDK.nostrDecryptMessage(
  connectId,
  deviceId,
  {
     path: "m/44'/1237'/0'/0/0",
     pubkey: '2118c65161c7d68b4bdbe1374f658532670057ab1bb0c99937d0ff7cff45cb5e',
     ciphertext: encryptedMessage,
     showOnOneKey: true,
  }
);
```

Result

```typescript
{
  success: true,
  payload: {
    path: string;
    pubkey: string;
    ciphertext: string;
    decryptedMessage: string;
  }
}
```

Error

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
