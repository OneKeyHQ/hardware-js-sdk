# nostrSignEvent

### Requirements

The current SDK declares these firmware guards: `model_touch` ≥ 4.7.0 and `model_mini` ≥ 3.6.0. These are SDK range keys; confirm device-model mapping and released firmware support for your integration.

## Nostr: Sign nostr event

Requests a signature over a Nostr event using the key at the specified path. The user confirms the request on the device.

```typescript
const result = await HardwareSDK.nostrSignEvent(connectId, deviceId, params);
```

### Params

[**Optional common params**](/en/hardware-sdk/concepts/common-params)

* `path` - _required_ `string | Array<number>` SDK minimum length is `5`. [read more](/en/hardware-sdk/concepts/common-params#hd-path)
* `event` - _required_ `NostrEvent` nostr event.

```
enum EventKind {
  Metadata = 0,
  Text = 1,

  Contacts = 3,
  DM = 4,
  Deleted = 5,
  Reaction = 7,

  ApplicationSpecificData = 30078,
}

type NostrEvent = {
  id?: string;
  kind: EventKind;
  pubkey?: string;
  content: string;
  tags: string[][];
  created_at: number;
  sig?: string;
};
```

### Examples

```typescript
const response = await HardwareSDK.nostrSignEvent(
  connectId,
  deviceId,
  {
    path: "m/44'/1237'/0'/0/0",
    event: {
      kind: 1,
      content: 'Hello world',
      tags: [],
      created_at: 1702268010,
    },
  }
);
```

Result

```typescript
{
  success: true,
  payload: {
    path: string,
    event: {
      kind: 1,
      content: 'Hello world',
      tags: [],
      created_at: 1702268010,
      sig: 'signature returned by the device',
    },
  }
}
```

Error

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
