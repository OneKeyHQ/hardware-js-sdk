# nostrSignSchnorr

### Requirements

The current SDK declares these firmware guards: `model_touch` ≥ 4.7.0 and `model_mini` ≥ 3.6.0. These are SDK range keys; confirm device-model mapping and released firmware support for your integration.

## Nostr: Sign Schnorr

Requests a Schnorr signature over the supplied hash using the key at the specified path. The user confirms the request on the device.

```typescript
const result = await HardwareSDK.nostrSignSchnorr(connectId, deviceId, params);
```

### Params

[**Optional common params**](/en/hardware-sdk/concepts/common-params)

* `path` - _required_ `string | Array<number>` SDK minimum length is `5`. [read more](/en/hardware-sdk/concepts/common-params#hd-path)
* `hash` - _required_ `string`. A 32-byte hash encoded as hexadecimal.

### Examples

```typescript
const response = await HardwareSDK.nostrSignSchnorr(
  connectId,
  deviceId,
  {
    path: "m/44'/1237'/0'/0/0",
    hash: '2118c65161c7d68b4bdbe1374f658532670057ab1bb0c99937d0ff7cff45cb5e',
  }
);
```

Result

```typescript
{
  success: true,
  payload: {
    path: string;
    rawHash: string,
    signature: string,
  }
}
```

Error

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
