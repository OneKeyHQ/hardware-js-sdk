# confluxSignMessage

## Requirements

* Minimum firmware versions
  * Touch: 3.0.0
  * Classic/Mini: 2.4.0

## Conflux: sign message <a href="#ethereum-sign-message" id="ethereum-sign-message"></a>

Requests a message signature using the key derived from the specified path.

```typescript
const result = await HardwareSDK.confluxSignMessage(connectId, deviceId, params);
```

### Params

[**Optional common params**](/en/hardware-sdk/concepts/common-params)

* `path` - _required_ `string | Array<number>` SDK minimum length is `3`. [Path format](/en/hardware-sdk/concepts/common-params#hd-path)
* `messageHex` - _required_ `string` Message to sign, encoded as a hexadecimal string.

### Example

```typescript
// Original message
const message = "Hello World";

// Convert to hex
const messageHex = Buffer.from(message).toString('hex');

HardwareSDK.confluxSignMessage(connectId, deviceId, {
    path: "m/44'/503'/0'/0/0",
    messageHex
});
```

Result

```typescript
{
    success: true,
    payload: {
        signature: string;
        address: string;
    }
}
```

Error

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
