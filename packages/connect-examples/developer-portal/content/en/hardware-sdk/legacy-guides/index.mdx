# Migration Guide

Start here if you already ship Hardware SDK **1.1.x** and need **1.2.x**.

## 1.1.x → 1.2.x

- [From 1.1.x to 1.2.x](./from-1x) — `getDeviceState`, `openWalletSession`, Pro 2 / Neo, firmware V4

## Bridge → WebUSB

- [Bridge to WebUSB (hd-common-connect-sdk)](./migrate-bridge-to-common-connect-webusb) — recommended
