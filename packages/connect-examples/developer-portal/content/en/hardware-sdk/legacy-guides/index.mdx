# Migration Guide

Choose the guide for your existing integration: upgrade Hardware SDK **1.1.x** to **1.2.x**, or migrate a OneKey Bridge connection to WebUSB.

## 1.1.x → 1.2.x

- [Upgrade to Hardware SDK 1.2](./from-1x) — `getDeviceState`, `openWalletSession`, Pro 2 / Neo, firmware V4

## Bridge → WebUSB

Only if you still use OneKey Bridge (`env: 'web'`).

- [Bridge to WebUSB (hd-common-connect-sdk)](./migrate-bridge-to-common-connect-webusb) — recommended
- [Bridge to WebUSB (hd-web-sdk)](./migrate-bridge-to-webusb) — keep the iframe host

New projects: [Getting Started](/en/hardware-sdk/getting-started) with `@onekeyfe/hd-common-connect-sdk`.
