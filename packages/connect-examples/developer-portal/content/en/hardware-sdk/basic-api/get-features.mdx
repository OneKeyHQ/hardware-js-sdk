# Get Features

## Get device features

`getFeatures()` is retained only for Protocol V1 compatibility. It accesses the
device and returns the legacy `Features` shape. Protocol V2 devices, including
Pro 2, do not support this API.

New integrations and applications supporting both Pro and Pro 2 should use
[`getDeviceState()`](/en/hardware-sdk/basic-api/get-device-info). The SDK keeps
protocol messages such as `DeviceInfoGet` and `DeviceStatusGet` internal.

```typescript
const response = await HardwareSDK.getFeatures(connectId);
```

> This compatibility call may return a Protocol V1 device to its home screen. Do not use it to refresh Protocol V2 state.

### Params

[**Optional common params**](/en/hardware-sdk/core-api-guide#common-params)

### Example

```typescript
const response = await HardwareSDK.getFeatures(connectId);
```

Result

```typescript
{
    success: true,
    payload: {
        major_version: number, // major version number
        minor_version: number, // middle version number
        patch_version: number, // patch version number
        bootloader_mode: null,
        device_id: string,
        pin_protection: boolean,
        passphrase_protection: boolean, // enable passphrase
        language: string,
        label: string, // device name
        initialized: boolean, // device initialization status
        model: string,
        safety_checks: string,
        ble_name: string, // bluetooth name
        ble_ver: string, // bluetooth firmware version
        ble_enable: string,
        se_enable: boolean,
        se_ver: string,
        backup_only: boolean,
        onekey_version: string, // firmware Version
        onekey_serial: string, // device Serial Number
        bootloader_version: string, // bootloader version
  }
}
```

Error

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code: number // error code
    }
}
```
