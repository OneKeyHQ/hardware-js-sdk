# Get Passphrase State

## Get the passphraseState of the device

Prompts the user to enter their passphrase (on-device or via software), then returns device session information including a `passphrase_state` string — a device-side session identifier derived from the passphrase.

Pass the `passphrase_state` value as `passphraseState` in subsequent API calls. The device recognizes the active session and skips the passphrase prompt entirely, so the user only needs to enter their passphrase once per session.

```
Session flow:
  getPassphraseState(connectId)   ← user enters passphrase once
    → { passphrase_state: "abc123", session_id: "...", passphrase_protection: true }

  evmGetAddress(..., { passphraseState: "abc123" })  ← no passphrase prompt
  btcGetAddress(..., { passphraseState: "abc123" })  ← no passphrase prompt
```

> **Error 112 (Device passphrase state error)**: The session has expired (e.g. device was locked and re-unlocked, or seed changed). Call `getPassphraseState` again to obtain a fresh state, then retry. You can prevent error 112 by passing `skipPassphraseCheck: true` in your API calls — in that case, the SDK fires `REQUEST_PASSPHRASE` instead, letting your event handler re-prompt the user.

```typescript
const response = await HardwareSDK.getPassphraseState(connectId);
```

### Params

[**Optional common params**](/en/hardware-sdk/core-api-guide#common-params)

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `allowCreateAttachPin` | `boolean` | No | When `true`, allows the device to create a new attach-PIN binding for the passphrase session. Useful for first-time hidden wallet setup. |

### Example

```typescript
const response = await HardwareSDK.getPassphraseState(connectId);

if (response.success) {
  const { passphrase_state, session_id, passphrase_protection } = response.payload;
  // Use passphrase_state in subsequent calls
}
```

### Result

```typescript
{
    success: true,
    payload: {
        passphrase_state: string | undefined,   // session identifier — pass as passphraseState in subsequent calls
        session_id: string | undefined,          // device session ID
        unlocked_attach_pin: boolean | undefined, // whether attach-PIN was unlocked
        passphrase_protection: boolean | null     // whether passphrase protection is enabled on the device
    }
}
```

### Error

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code: number // error code
    }
}
```
