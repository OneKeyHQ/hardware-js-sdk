# Basic API

Core SDK methods for device discovery, session management, and event handling.

| Method | Description |
|--------|-------------|
| [Search Devices](./search-devices) | Scan and discover connected OneKey hardware devices |
| [Get Device State](./get-device-state) | Unified V1/V2 device snapshot (preferred in 1.2.0) |
| [Get Features](./get-features) | Compatibility Features read; still valid for existing apps |
| [Open Wallet Session](./open-wallet-session) | Open or resume the standard / hidden wallet |
| [Get Passphrase State](./get-passphrase-state) | Compatibility passphrase wallet binding |
| [Response UI Event](./response-ui-event) | Handle UI events from device interactions |
| [Cancel Request](./cancel-request) | Cancel an ongoing device operation |
