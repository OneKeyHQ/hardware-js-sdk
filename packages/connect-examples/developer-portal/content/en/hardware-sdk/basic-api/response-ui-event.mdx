# Response UI Event

### Transfer data to the device

Transfer data to the device, currently supporting data transfer for PIN and passphrase.

```typescript
import type { UiResponseEvent } from "@onekeyfe/hd-core";

// Construct a response for the current input request using your UI.
declare const uiResponse: UiResponseEvent;
HardwareSDK.uiResponse(uiResponse);

```

### Params

[**Optional common params**](/en/hardware-sdk/concepts/common-params)

* `type` - _required_ `string`. type to respond to `ui-receive_pin` or `ui-receive_passphrase`
* `payload` - _required_ `object`

#### Return the PIN code result

```typescript
import { UI_RESPONSE } from "@onekeyfe/hd-core";

// Value collected by the host PIN input UI.
declare const pinValue: string;

HardwareSDK.uiResponse({
  type: UI_RESPONSE.RECEIVE_PIN,
  payload: pinValue,
});
```

* If entering the PIN on the software side, replace the content of `pinValue`. If the PIN needs to be entered on the hardware side, set `pinValue` as `@@ONEKEY_INPUT_PIN_IN_DEVICE`.

#### Return the Passphrase result

```typescript
import { UI_RESPONSE } from "@onekeyfe/hd-core";

// Value collected by the host passphrase input UI.
declare const passphraseValue: string;

HardwareSDK.uiResponse({
  type: UI_RESPONSE.RECEIVE_PASSPHRASE,
  payload: {
    value: passphraseValue,
    passphraseOnDevice: false,
    save: false,
  },
});
```

* If the passphrase needs to be entered on the device, set value to '' and set passphraseOnDevice to true.

Only reply to input requests. `REQUEST_PASSPHRASE_ON_DEVICE` and device-only PIN prompts are notifications; see [UI wiring](/en/hardware-sdk/core-api-guide#events-ui).
