# AI Agent Integration

`@onekeyfe/hardware-cli` enables AI agents (Claude Code, Codex, Gemini CLI, etc.) to interact with OneKey hardware wallets via USB.

## Install

### 1. Install CLI

```bash
npm install -g @onekeyfe/hardware-cli
```

### 2. Install Claude Code Plugin

```bash
claude plugin marketplace add OneKeyHQ/hardware-js-sdk --sparse .claude-plugin packages/hd-cli
claude plugin install onekey-hardware@onekey-hardware-plugins
```

### 3. For Other AI Tools (Codex, Gemini, Cursor)

Place [AGENTS.md](https://github.com/OneKeyHQ/hardware-js-sdk/blob/onekey/packages/hd-cli/AGENTS.md) in your project. The AI agent reads it and learns the available commands.

## Skills

| Skill | Key Commands |
|-------|--------------|
| **Device** | `search`, `lock`, `device-verify`, `device-settings`, `device-wipe` |
| **Signing** (27 chains) | `get-address`, `sign-transaction`, `sign-message`, `sign-typed-data`, `sign-psbt`, `batch-get-address` |
| **Firmware** (read-only) | `firmware-check`, `firmware-check-all`, `bootloader-check` |
| **Security** | `change-pin`, `toggle-passphrase`, `passphrase-state` |

## Usage

```bash
# Search for connected devices (auto-fetches device info)
onekey-hw search

# Get an Ethereum address
onekey-hw get-address --chain evm --use-empty-passphrase

# Get a Bitcoin address
onekey-hw get-address --chain btc --use-empty-passphrase

# Sign a message
onekey-hw sign-message --chain evm --message "hello" --use-empty-passphrase

# Sign an EVM transaction
onekey-hw sign-transaction --chain evm \
  --tx '{"to":"0x...","value":"0xf4240","chainId":1,"nonce":"0x0","gasLimit":"0x5208","gasPrice":"0xbebc200"}' \
  --use-empty-passphrase

# Check firmware
onekey-hw firmware-check-all
```

Firmware updates must be done via the [OneKey App](https://onekey.so/download) or [firmware.onekey.so](https://firmware.onekey.so/).

## Supported Chains

| Category | Chains |
|----------|--------|
| **EVM** | Ethereum, BSC, Polygon, Arbitrum, Base, Optimism, Avalanche, and all EVM-compatible chains |
| **Bitcoin & Forks** | Bitcoin (Legacy/SegWit/Taproot), Litecoin, Bitcoin Cash, and other BTC forks |
| **Layer 1** | Solana, Cardano, Polkadot, Cosmos, Near, Aptos, Sui, TON, Stellar, XRP |
| **Others** | Tron, Filecoin, Kaspa, Algorand, Conflux, Nervos, Nostr, and more |

For chain-specific parameters, see the [Chain Methods](/en/hardware-sdk/chains) documentation.

## Output Format

All commands return structured JSON:

```json
{
  "success": true,
  "payload": {
    "address": "0x1234...",
    "path": "m/44'/60'/0'/0/0"
  }
}
```
