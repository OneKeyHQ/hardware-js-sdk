# AI Agent Integration

`@onekeyfe/hardware-cli` enables AI agents to interact with OneKey hardware wallets via USB.

Skills follow the [Agent Skills](https://agentskills.io) open standard, supported by 30+ tools including Claude Code, Codex, Gemini CLI, GitHub Copilot, Cursor, and JetBrains.

## Install

### Claude Code

```bash
claude plugin marketplace add OneKeyHQ/hardware-js-sdk --sparse .claude-plugin packages/hd-cli
claude plugin install onekey-hardware@onekey-hardware-plugins
```

The CLI is installed automatically on first use via the skill's pre-flight check.

### Codex (OpenAI)

```bash
npm install -g @onekeyfe/hardware-cli

# Copy skills to Codex skill directory
git clone --depth 1 --filter=blob:none --sparse https://github.com/OneKeyHQ/hardware-js-sdk.git /tmp/onekey-hw-skills
cd /tmp/onekey-hw-skills && git sparse-checkout set packages/hd-cli/skills
cp -r packages/hd-cli/skills/device ~/.codex/skills/hardware-device
cp -r packages/hd-cli/skills/signing ~/.codex/skills/hardware-signing
cp -r packages/hd-cli/skills/firmware ~/.codex/skills/hardware-firmware
cp -r packages/hd-cli/skills/security ~/.codex/skills/hardware-security
rm -rf /tmp/onekey-hw-skills
```

### Gemini CLI

```bash
npm install -g @onekeyfe/hardware-cli

# Install skills via Gemini's built-in command
gemini skills install https://github.com/OneKeyHQ/hardware-js-sdk.git --path packages/hd-cli/skills/device
gemini skills install https://github.com/OneKeyHQ/hardware-js-sdk.git --path packages/hd-cli/skills/signing
gemini skills install https://github.com/OneKeyHQ/hardware-js-sdk.git --path packages/hd-cli/skills/firmware
gemini skills install https://github.com/OneKeyHQ/hardware-js-sdk.git --path packages/hd-cli/skills/security
```

### Cursor / Copilot / Others

```bash
npm install -g @onekeyfe/hardware-cli
```

Copy the [skills/](https://github.com/OneKeyHQ/hardware-js-sdk/tree/onekey/packages/hd-cli/skills) directory into your project, or place `AGENTS.md` in your project root.

## Skills

| Skill | Key Commands |
|-------|--------------|
| **Device** | `search`, `lock`, `device-verify`, `device-settings`, `device-wipe` |
| **Signing** (27 chains) | `get-address`, `sign-transaction`, `sign-message`, `sign-typed-data`, `sign-psbt`, `batch-get-address` |
| **Firmware** (read-only) | `firmware-check`, `firmware-check-all`, `bootloader-check` |
| **Security** | `change-pin`, `toggle-passphrase`, `passphrase-state` |

## Usage

```bash
# Search for connected devices (auto-fetches device info)
onekey-hw search

# Get an Ethereum address
onekey-hw get-address --chain evm --use-empty-passphrase

# Get a Bitcoin address
onekey-hw get-address --chain btc --use-empty-passphrase

# Sign a message
onekey-hw sign-message --chain evm --message "hello" --use-empty-passphrase

# Sign an EVM transaction
onekey-hw sign-transaction --chain evm \
  --tx '{"to":"0x...","value":"0xf4240","chainId":1,"nonce":"0x0","gasLimit":"0x5208","gasPrice":"0xbebc200"}' \
  --use-empty-passphrase

# Check firmware
onekey-hw firmware-check-all
```

Firmware updates must be done via the [OneKey App](https://onekey.so/download) or [firmware.onekey.so](https://firmware.onekey.so/).

## Supported Chains

| Category | Chains |
|----------|--------|
| **EVM** | Ethereum, BSC, Polygon, Arbitrum, Base, Optimism, Avalanche, and all EVM-compatible chains |
| **Bitcoin & Forks** | Bitcoin (Legacy/SegWit/Taproot), Litecoin, Bitcoin Cash, and other BTC forks |
| **Layer 1** | Solana, Cardano, Polkadot, Cosmos, Near, Aptos, Sui, TON, Stellar, XRP |
| **Others** | Tron, Filecoin, Kaspa, Algorand, Conflux, Nervos, Nostr, and more |

For chain-specific parameters, see the [Chain Methods](/en/hardware-sdk/chains) documentation.

## Output Format

All commands return structured JSON:

```json
{
  "success": true,
  "payload": {
    "address": "0x1234...",
    "path": "m/44'/60'/0'/0/0"
  }
}
```
