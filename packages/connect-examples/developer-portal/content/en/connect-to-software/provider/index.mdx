# Provider API

Use the provider for your target chain to request accounts, signatures, and transactions. Each chain has its own methods, encodings, and events; an Ethereum request example is not interchangeable with a Bitcoin or Solana example.

## What this gives you

- **Chain-specific references**: Find connection, signing, transaction, and event documentation for each provider.
- **Connection options**: Use a wallet UI library for a chooser, or access the injected provider directly.
- **Implementation guidance**: Check network and account state, handle rejected requests, and clean up event listeners.

## Supported Chains

- **EVM**: Ethereum, Polygon, BSC, Arbitrum, Optimism, Base, etc.
- **Bitcoin**: BTC, Lightning Network (WebLN)
- **Solana**: SOL
- **Cosmos**: ATOM and Cosmos SDK chains
- **Move**: Aptos, Sui
- **Others**: Stellar, TON, TRON, Polkadot, Cardano, Algorand, Conflux, NEAR, Nostr

Select a chain from the sidebar to view detailed provider methods, signing flows, and examples.
