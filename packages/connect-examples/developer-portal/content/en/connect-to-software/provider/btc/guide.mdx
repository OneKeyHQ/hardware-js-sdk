# Guide

## Overview

This guide helps users understand how to use the OneKey Provider API to easily build web applications that can interact with BTC.


## Install

### 1. Download OneKey Wallet

Download the [OneKey Wallet](https://onekey.so/download?client=browserExtension). Install the OneKey browser extension.

#### 2. API Injection Explanation

* The OneKey browser extension injects `Provider API` into visited websites.
* Two types of APIs are provided: `window.unisat` and `window.$onekey.btc`.
* It is recommended to use `window.$onekey.btc`.

> Prefer `window.$onekey.btc` to select OneKey specifically. The global `window.unisat` may belong to another wallet when multiple extensions are installed.

### Detecting Provider API support

Check that a provider is available before making requests:

```javascript
const provider = (window.$onekey && window.$onekey.btc) || window.unisat;

if (!provider) {
  throw new Error("No Bitcoin provider is available.");
}
```

### Connecting to OneKey

Before using the following API, you first need to use the `provider.requestAccounts` method to request the user to access the relevant BTC account.

```
await provider.requestAccounts();
```

Other APIs can be called only after user authorization.

## API

Choose an API for the operation your application needs.

* Get user's account information: [`provider.getAccounts`](/en/connect-to-software/provider/btc/api-reference/getaccounts)
* Send a payment: [`provider.sendBitcoin`](/en/connect-to-software/provider/btc/api-reference/sendbitcoin)
* Request signature for any message: [`provider.signMessage`](/en/connect-to-software/provider/btc/api-reference/signmessage)

**More Interfaces**: [View Details](/en/connect-to-software/provider/btc/api-reference)

## Event

## Handling requests

Run wallet requests from an async function or an ES module. Catch rejected promises and show the error in your application. Request connections, signatures, and payments from a user action, and disable the triggering button while a request is pending.
