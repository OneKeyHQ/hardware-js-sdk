# Signing

The signing examples below use `connectSuiAccount()` from [Getting Started](/en/connect-to-software/provider/sui/getting-started#account-context-for-signing). It returns a Wallet Standard account and its active chain. The examples use `@mysten/sui@1.28.2`. Even the legacy `*TransactionBlock` methods now declare `Transaction` inputs in `@mysten/wallet-standard@0.14.7`.

Request permission before signing, select a connected account, and read the active chain. These examples use `@mysten/sui@1.28.2`, matching `@mysten/wallet-standard@0.14.7` accepted by the current provider.

Learn how to sign messages for authentication.

Initialize the account context before the following examples:

```typescript
const { account, chain } = await connectSuiAccount()
```

---

## Sign Personal Message

Sign arbitrary messages for authentication:

```typescript
const message = new TextEncoder().encode('Hello, Sui!')

const result = await provider.signPersonalMessage({
  account,
  chain,
  message,
})

console.log({
  signature: result.signature,   // Base64 encoded signature
  bytes: result.bytes,           // Signed message bytes
})
```

## Verify Signature

```typescript
import { verifyPersonalMessageSignature } from '@mysten/sui/verify'

const message = new TextEncoder().encode('Hello, Sui!')
const { signature } = await provider.signPersonalMessage({ message, account, chain })

const signerKey = await verifyPersonalMessageSignature(message, signature)
const isExpectedSigner = signerKey.toSuiAddress() === account.address
console.log('Expected signer:', isExpectedSigner)
```

## Error Handling

```typescript
try {
  await provider.requestPermissions()
} catch (error) {
  if (error.code === 4001) {
    console.log('User rejected the connection request')
  } else {
    console.error('Connection error:', error.message)
  }
}
```
