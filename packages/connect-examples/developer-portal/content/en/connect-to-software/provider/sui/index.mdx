# Sui

The signing examples below use `connectSuiAccount()` from [Getting Started](/en/connect-to-software/provider/sui/getting-started#account-context-for-signing). It returns a Wallet Standard account and its active chain. The examples use `@mysten/sui@1.28.2`. Even the legacy `*TransactionBlock` methods now declare `Transaction` inputs in `@mysten/wallet-standard@0.14.7`.

Integrate Sui blockchain using OneKey's provider. Access via `window.$onekey.sui`.

<Callout type="info">
OneKey implements the Sui Wallet Standard, for compatible wallet-standard integrations.
</Callout>

## Quick Start

### Check Permissions

```typescript
// Check if already connected
const hasPermission = await provider.hasPermissions()

if (hasPermission) {
  const accounts = await provider.getAccounts()
  console.log('Connected accounts:', accounts)
}
```

### Request Connection

```typescript
// Request permissions to connect
const result = await provider.requestPermissions()

if (result) {
  const accounts = await provider.getAccounts()
  console.log('Connected:', accounts[0].address)
}
```

### Disconnect

```typescript
await provider.disconnect()
```

```typescript
const accounts = await provider.getAccounts()
```


## Transactions

### Sign and Execute Transaction Block

The current injected provider does not forward `options` in `signAndExecuteTransactionBlock`. Query the returned digest with a Sui client on the same chain to request effects, events, or object changes.

```typescript
import { Transaction } from '@mysten/sui/transactions'

// Create transaction block
const txb = new Transaction()

// Add a transfer
txb.transferObjects(
  [txb.object('0xobject_id')],
  txb.pure.address('RECIPIENT_SUI_ADDRESS')
)

// Or send SUI
const [coin] = txb.splitCoins(txb.gas, [txb.pure.u64(1000000000)]) // 1 SUI
txb.transferObjects([coin], txb.pure.address('RECIPIENT_SUI_ADDRESS'))

const { account, chain } = await connectSuiAccount()

// Sign and execute
const result = await provider.signAndExecuteTransactionBlock({
  account,
  chain,
  transactionBlock: txb,
})

console.log({
  digest: result.digest,
})
```

### Sign Transaction Block (Without Executing)

```typescript
const txb = new Transaction()
// ... build transaction

const { account, chain } = await connectSuiAccount()

const signedTxb = await provider.signTransactionBlock({
  account,
  chain,
  transactionBlock: txb,
})

console.log({
  transactionBlockBytes: signedTxb.transactionBlockBytes,
  signature: signedTxb.signature,
```

## Message Signing

### Sign Personal Message

Sign arbitrary messages for authentication:

```typescript
const message = new TextEncoder().encode('Hello, Sui!')
const { account, chain } = await connectSuiAccount()

const result = await provider.signPersonalMessage({
  account,
  chain,
  message,
})

console.log({
  signature: result.signature,   // Base64 encoded signature
  bytes: result.bytes,           // Signed message bytes
})
```

### Sign Message (Legacy)

```typescript
const message = new TextEncoder().encode('Hello, Sui!')
const { account, chain } = await connectSuiAccount()

const result = await provider.signMessage({
  account,
  message,
})

console.log({
  signature: result.signature,
  messageBytes: result.messageBytes,
})
```

### Verify Signature

```typescript
import { verifyPersonalMessageSignature } from '@mysten/sui/verify'

const message = new TextEncoder().encode('Hello, Sui!')
const { account, chain } = await connectSuiAccount()
const { signature } = await provider.signPersonalMessage({ message, account, chain })

const signerKey = await verifyPersonalMessageSignature(message, signature)
const isExpectedSigner = signerKey.toSuiAddress() === account.address
console.log('Expected signer:', isExpectedSigner)
```

## Smart Contract Interaction

### Move Call

```typescript
const txb = new Transaction()

// Call a Move function
txb.moveCall({
  target: '0xpackage::module::function',
  arguments: [
    txb.pure.string('arg1'),
    txb.object('0xobject_id'),
  ],
  typeArguments: ['0x2::sui::SUI'],
})

const { account, chain } = await connectSuiAccount()

const result = await provider.signAndExecuteTransactionBlock({
  account,
  chain,
  transactionBlock: txb,
})
```

### Publish Package

```typescript
const txb = new Transaction()

const [upgradeCap] = txb.publish({
  modules: compiledModules,
  dependencies: [
    '0x1', // Move stdlib
    '0x2', // Sui framework
  ],
})

const { account, chain } = await connectSuiAccount()
txb.transferObjects([upgradeCap], txb.pure.address(account.address))

const result = await provider.signAndExecuteTransactionBlock({
  account,
  chain,
  transactionBlock: txb,
})
```

## API Reference

### Methods

| Method | Description |
|--------|-------------|
| `hasPermissions()` | Check if connected |
| `requestPermissions()` | Request connection |
| `disconnect()` | Disconnect wallet |
| `getAccounts()` | Get connected accounts (`address`, `publicKey` only) |
| `getActiveChain()` | Get current chain |
| `signAndExecuteTransactionBlock(input)` | Sign and execute, requires `account`/`chain` |
| `signTransactionBlock(input)` | Sign only, requires `account`/`chain` |
| `signAndExecuteTransaction(input)` | Sign and execute (new API, `Transaction`, requires `account`/`chain`) |
| `signTransaction(input)` | Sign transaction (new API, `Transaction`, requires `account`/`chain`) |
| `signMessage(input)` | Sign message (legacy, requires `account`) |
| `signPersonalMessage(input)` | Sign personal message (requires `account`/`chain`) |

### Types

`getAccounts()` returns `AccountInfo[]`. Signing inputs require the Wallet Standard `WalletAccount`, whose `publicKey` is a byte array and which also carries `chains` and `features`. Obtain it through `standard:connect`; do not cast `AccountInfo` to `WalletAccount`.

```typescript
import type { WalletAccount, IdentifierString } from '@mysten/wallet-standard'
import type { Transaction } from '@mysten/sui/transactions'

// provider.getAccounts()
interface AccountInfo {
  address: string
  publicKey: string // Hex-encoded public key
}

interface SignAndExecuteTransactionBlockInput {
  account: WalletAccount
  chain: IdentifierString
  transactionBlock: Transaction
  options?: {
    showEffects?: boolean
    showEvents?: boolean
    showObjectChanges?: boolean
    showBalanceChanges?: boolean
    showInput?: boolean
    showRawInput?: boolean
  }
}

interface SignTransactionBlockOutput {
  transactionBlockBytes: string
  signature: string
}

interface SignPersonalMessageInput {
  account: WalletAccount
  chain?: IdentifierString
  message: Uint8Array
}

interface SignPersonalMessageOutput {
  signature: string
  bytes: string
}
```

### Supported Chains

| Chain | Identifier |
|-------|------------|
| Mainnet | `sui:mainnet` |
| Testnet | `sui:testnet` |
| Devnet | `sui:devnet` |

## Error Handling

```typescript
try {
  await provider.requestPermissions()
} catch (error) {
  if (error.code === 4001) {
    console.log('User rejected the connection request')
  } else {
    console.error('Connection error:', error.message)
  }
}
```

### Common Error Codes

| Code | Description |
|------|-------------|
| 4001 | User rejected request |
| 4100 | Unauthorized |
| -32603 | Internal error |

## Using with Sui Wallet Kit

This React example uses the compatible package versions pinned below:

```bash
npm install @mysten/dapp-kit@0.16.0 @mysten/sui@1.28.2 @tanstack/react-query@^5
```

```tsx
import { SuiClientProvider, WalletProvider } from '@mysten/dapp-kit'
import { getFullnodeUrl } from '@mysten/sui/client'
import { QueryClient, QueryClientProvider } from '@tanstack/react-query'

const queryClient = new QueryClient()
const networks = {
  mainnet: { url: getFullnodeUrl('mainnet') },
  testnet: { url: getFullnodeUrl('testnet') },
}

function App() {
  return (
    <QueryClientProvider client={queryClient}>
      <SuiClientProvider networks={networks} defaultNetwork="mainnet">
        <WalletProvider>
          <YourApp />
        </WalletProvider>
      </SuiClientProvider>
    </QueryClientProvider>
  )
}
```

OneKey is automatically detected through the Sui Wallet Standard.

```typescript
import { SuiClient } from '@mysten/sui/client'

const client = new SuiClient({ url: 'https://fullnode.mainnet.sui.io' })

// Get balance
const balance = await client.getBalance({
  owner: accountAddress,
})

// Get objects
const objects = await client.getOwnedObjects({
  owner: accountAddress,
})

// Get transaction
const txn = await client.getTransactionBlock({
  digest: txDigest,
  options: { showEffects: true },
```
