# Signing

Call `enable()` before using the dApp API. Addresses returned by the CIP-30 API are hex-encoded bytes; transaction and value parameters are hex-encoded CBOR. Browser examples using `Buffer` require an explicit `buffer` import or a byte conversion helper.

Learn how to sign data for authentication on Cardano.

---

## Sign Data (CIP-8)

Sign arbitrary data for authentication:

```typescript
const api = await window.cardano.onekey.enable()

const addresses = await api.getUsedAddresses()
const address = addresses[0]

// Message to sign
const payload = Buffer.from('Hello Cardano!').toString('hex')

const signature = await api.signData(address, payload)

console.log({
  signature: signature.signature, // COSE_Sign1 signature
  key: signature.key,             // COSE_Key public key
})
```

## Error Handling

```typescript
try {
  const api = await window.cardano.onekey.enable()
} catch (error) {
  if (error.code === -3) {
    console.log('The wallet refused the request')
  } else if (error.code === -4) {
    console.log('The account changed; reconnect and retry')
  } else {
    console.error('Error:', error.message)
  }
}
```
