# WebLN Events

Do not rely on account or network events to determine whether a WebLN request succeeded. Await each method call and handle its result or rejection.

The provider types declare `accountChanged` (singular) and `disconnect`, but the current WebLN implementation does not establish an account-change event subscription. Integrations should not depend on these notifications without verifying behavior in their target wallet version.

For the required connection flow, see [Getting started](/en/connect-to-software/provider/webln/guide).
