# signMessage

Request that the user signs a string message.

## Method

```typescript
declare function signMessage(message: string): Promise<SignMessageResponse>;
```

## Response

```typescript
interface SignMessageResponse {
  message: string;
  signature: string;
}
```

## Example

```typescript
const provider = (window.$onekey && window.$onekey.webln) || window.webln;

const message = "Plain Message";
await provider.enable();
const signature = await provider.signMessage(message);
```
