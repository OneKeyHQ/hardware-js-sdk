# Signing Transaction

Signing transactions without sending.

The method returns a Promise. Its response shape needs version-specific verification: the public provider declaration names `transactionHashes`, while the public example reads `signatures`. Do not depend on either field until you have checked the installed provider and wallet version. This signing-only request does not broadcast the transaction.

```javascript
// `transaction` is created in the Create Transaction guide.

const res = await provider.request({
  method: 'near_signTransactions',
  params: {
    transactions: [transaction], // must be Array type
  },
});
console.log('near_signTransactions', res);
```
