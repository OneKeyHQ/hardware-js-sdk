# Signing Transaction

Signing transactions without sending.

The method call will return a [Promise](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise) for an object containing the `signatures`.

```javascript
// `transaction` is created in the Create Transaction guide.

const res = await provider.request({
  method: 'near_signTransactions',
  params: {
    transactions: [transaction], // must be Array type
  },
});
console.log('near_signTransactions', res, res.signatures);
```
