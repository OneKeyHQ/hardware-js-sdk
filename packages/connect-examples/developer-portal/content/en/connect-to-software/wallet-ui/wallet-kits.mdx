# Wallet UI Libraries

Wallet UI libraries provide a wallet chooser and connection state. Choose a library for your framework and target chains, then test account changes, rejected requests, and mobile connections.

<Callout type="info">
The guides below cover EVM integrations. For Aptos, use the [Aptos Wallet Adapter](/en/connect-to-software/wallet-ui/aptos-wallet-adapter). For other chains, start with the [chain-specific provider](/en/connect-to-software/provider).
</Callout>

---

## Choose Your Library

| Library | Framework | Features |
|---------|-----------|----------|
| [RainbowKit](/en/connect-to-software/wallet-ui/rainbowkit) | React only | Wallet chooser, theming, wagmi integration |
| [AppKit (formerly Web3Modal)](/en/connect-to-software/wallet-ui/web3modal) | React/Vue/JS | WalletConnect ecosystem, mobile QR codes, AppKit |
| [Web3-Onboard](/en/connect-to-software/wallet-ui/web3-onboard) | React/Vue/JS | Blocknative, extensive customization |

---

## Framework and Connection Support

| Feature | RainbowKit | AppKit | Web3-Onboard |
|---------|------------|-----------|--------------|
| React | ✅ | ✅ | ✅ |
| Vue | ❌ | ✅ | ✅ |
| Vanilla JS | ❌ | ✅ | ✅ |
| Mobile QR | ✅ | ✅ | ✅ |

---

## When to Use

Use Wallet UI Libraries when you:
- Need a wallet chooser with connection state
- Need mobile wallet support with QR codes
- Don't want to build custom wallet connection UI
- Want WalletConnect integration

---

## Alternative: Custom UI

If you need full control over the wallet UI, consider:
- [Wagmi](/en/connect-to-software/react-hooks/wagmi) - React hooks without UI
- [Provider API](/en/connect-to-software/provider/eth) - Direct wallet access
