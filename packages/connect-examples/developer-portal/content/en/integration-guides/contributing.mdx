# Contributing

Choose the repository that owns the feature. Read its README, contribution instructions, and security policy before starting.

| Area | Repository |
| --- | --- |
| Apps and browser extension | [app-monorepo](https://github.com/OneKeyHQ/app-monorepo) |
| Hardware SDK and this developer portal | [hardware-js-sdk](https://github.com/OneKeyHQ/hardware-js-sdk) |
| Injected wallet providers | [cross-inpage-provider](https://github.com/OneKeyHQ/cross-inpage-provider) |
| Firmware | [firmware](https://github.com/OneKeyHQ/firmware) |
| Historical GitBook collection | [docs](https://github.com/OneKeyHQ/docs) |

## Propose a change

For a new chain or integration change, describe the runtime, signing methods, serialization format, and required device or firmware support. Software-wallet and hardware-signing integrations may belong in different repositories. Check existing issues and pull requests first.

## Submit a fix

1. Follow the repository's development instructions.
2. Make a focused change and update affected examples or documentation.
3. Run its required checks.
4. Open a pull request explaining the problem, resulting behavior, and evidence.

Documentation reports should include the page URL and incorrect example or statement. For integration failures, use the [reporting checklist](/en/troubleshooting#report-an-issue). For security vulnerabilities, follow the affected repository's security policy rather than publishing exploit details in an issue.
