# CryptoCoinInfo

The `CryptoCoinInfo` class represents cryptocurrency information. This page describes the legacy export from `@onekeyfe/onekey-air-gap`, including its Ethereum enum value. Other registry packages can expose different enums; use the constructor and types from the same installed package.

## Types

```typescript
export enum Type {
  bitcoin = 0,
  ethereum = 60,
}

export enum Network {
  mainnet,
  testnet,
}
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `type` | `Type` | First constructor argument; currency type (e.g., `bitcoin = 0`, `ethereum = 60`) |
| `network` | `Network` | Second constructor argument; network type (`mainnet` or `testnet`) |

## UR type

The UR type is `crypto-coin-info`. Generate the encoded payload with the registry encoder.
