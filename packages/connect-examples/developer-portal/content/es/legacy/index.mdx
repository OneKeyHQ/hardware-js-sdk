# Integraciones antiguas

Usa esta sección al mantener una integración antigua. Estas referencias explican interfaces históricas y alternativas actuales; no certifican compatibilidad en una versión actual de cartera, SDK o firmware.

- [OneKey Bridge](./bridge): comprobaciones históricas de Bridge de escritorio y ruta de migración a WebUSB.
- [Aptos WalletConnect v1](./aptos-walletconnect): métodos personalizados históricos y una ruta actual de integración de navegador.
- [API firmwareUpdate original](./firmware-update): diferencias entre la API antigua y los métodos versionados de firmware.

Para nuevas integraciones, [empieza aquí](/es/getting-started). La inicialización y el borrado del dispositivo se explican por separado en [gestión del dispositivo](/es/integration-guides/device-management).
