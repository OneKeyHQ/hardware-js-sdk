# Referencia de OneKey Bridge

> Integración histórica. Las nuevas integraciones de navegador deben usar [WebUSB](/es/hardware-sdk/transport/web-usb). No hagas que instalar Bridge sea un requisito del flujo WebUSB actual.

El transporte Bridge antiguo exponía dos comprobaciones:

| Método | Carga histórica de éxito | Finalidad |
| --- | --- | --- |
| `checkBridgeStatus()` | `boolean` | Si el cliente Bridge local está operativo. |
| `checkTransportRelease()` | `string` | Estado de versión del Bridge local, documentado como `valid` o `outdated`. |

Ambas referencias históricas usan `success` y `payload`, con `payload.error` y un código de error opcional si falla. Superar una comprobación de Bridge no demuestra descubrimiento del dispositivo, acceso a la cartera ni permiso de firma.

Antes de mantener este flujo, verifica estas exportaciones y requisitos de transporte en la versión exacta del SDK de tu aplicación. Para migrar, elimina comprobaciones y avisos específicos de Bridge y sigue [De Bridge a common-connect WebUSB](/es/hardware-sdk/legacy-guides/migrate-bridge-to-common-connect-webusb).
