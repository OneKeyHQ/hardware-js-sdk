# NEAR

Integra NEAR Protocol en tu dApp con el proveedor de NEAR de OneKey. Usa el SDK del proveedor y su versión compatible de near-api-js para los métodos documentados a continuación.

## Funciones [#features]

- Conexión y administración de cuentas
- Firma y envío de transacciones
- Firma de mensajes
- Consultar el estado de la red (red principal o de pruebas)
- Solicitudes RPC a través del endpoint de la red seleccionada

## Instalación [#installation]

```bash
npm install @onekeyfe/onekey-near-provider near-api-js@^0.44.2
# or
yarn add @onekeyfe/onekey-near-provider near-api-js@^0.44.2
```

## Inicio rápido [#quick-start]

```typescript
import { OneKeyNearProvider } from '@onekeyfe/onekey-near-provider'

// Create provider instance
const provider = new OneKeyNearProvider()

// Request account access
const accounts = await provider.requestSignIn()
console.log('Connected accounts:', accounts)

// Get current network
const network = await provider.request({ method: 'near_network' })
console.log('Current network:', network)
```
