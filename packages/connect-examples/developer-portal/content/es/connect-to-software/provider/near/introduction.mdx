# Introducción

[**OneKey**](https://www.onekey.so) es una cartera y extensión de navegador que permite administrar activos digitales y acceder a aplicaciones descentralizadas en la cadena de bloques [Near](https://docs.near.org).

Crea y administra claves privadas en nombre de sus usuarios, lo que les permite almacenar fondos y firmar transacciones.

Las aplicaciones web pueden interactuar con la cartera de la extensión, por ejemplo para solicitar permiso para realizar una transacción.
