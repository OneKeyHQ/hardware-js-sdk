# Primeros pasos

Conecta el proveedor y usa la instancia de TronWeb asociada a esa misma cartera. Sustituye las direcciones y los métodos de contrato abreviados por valores válidos. Comprueba la red seleccionada antes de preparar una transacción.

Aprende a detectar, conectar e interactuar con TRON mediante el proveedor de OneKey.

<Callout type="info">
OneKey ofrece un proveedor compatible con TronLink y una integración con TronWeb. La disponibilidad de funciones depende de la versión de la cartera y de la red seleccionada.
</Callout>

---

## Detección del proveedor [#provider-detection]

```typescript
// OneKey injects both the provider and TronWeb instances
const provider = window.$onekey?.tron

// TronWeb is available globally after connection
let tronWeb = provider?.tronWeb

if (!provider) {
  throw new Error('OneKey TRON provider not detected')
}

// Check if it's TronLink compatible
console.log('isTronLink:', provider.isTronLink) // true
```

---

## Solicitar cuentas [#request-accounts]

```typescript
// Request connection
const result = await provider.request({
  method: 'tron_requestAccounts'
})

if (result.code === 200) {
  tronWeb = provider.tronWeb
  if (!tronWeb) throw new Error('OneKey TronWeb is not ready')
  console.log('Connected!')
  const address = tronWeb.defaultAddress.base58
  console.log('Address:', address)
} else {
  console.log('Connection rejected:', result.message)
}
```

---

## Comprobar el estado de conexión [#check-connection-status]

```typescript
// Check if TronWeb is ready
if (provider.ready && tronWeb && tronWeb.defaultAddress.base58) {
  console.log('Connected:', tronWeb.defaultAddress.base58)
} else {
  console.log('Not connected')
}
```

## Uso de TronWeb [#using-tronweb]

Después de conectar, usa `provider.tronWeb` para mantener las solicitudes asociadas a OneKey:

### Obtener el saldo [#get-balance]

```typescript
const balance = await tronWeb.trx.getBalance(tronWeb.defaultAddress.base58)
console.log('Balance:', tronWeb.fromSun(balance), 'TRX')
```

### Enviar TRX [#send-trx]

```typescript
const tx = await tronWeb.trx.sendTransaction(
  'TRecipientAddress...',
  tronWeb.toSun(10) // 10 TRX
)

console.log('Transaction:', tx.txid)
```

### Enviar un token TRC20 [#send-trc20-token]

```typescript
const contractAddress = 'TTokenContractAddress...'
const contract = await tronWeb.contract().at(contractAddress)

// Get decimals
const decimals = await contract.decimals().call()

// Transfer tokens
const amount = (100n * 10n ** BigInt(decimals.toString())).toString() // 100 tokens, exact integer
const tx = await contract.transfer(
  'TRecipientAddress...',
  amount
).send()

console.log('Transaction:', tx)
```

## Gestión de eventos [#event-handling]

### Escuchar cambios de cuenta [#listen-for-account-changes]

```typescript
provider.on('accountsChanged', (accounts) => {
  if (accounts[0]) {
    console.log('Account changed:', accounts[0])
  } else {
    console.log('Disconnected')
  }
})
```

### Escuchar cambios de red [#listen-for-network-changes]

```typescript
provider.on('chainChanged', (chainId) => {
  console.log('Network changed:', chainId)
  // Recommend page reload for network changes
})
```

### Eventos de ventana (compatibles con TronLink) [#window-events-tronlink-compatible]

```typescript
// Listen for TronLink initialization
window.addEventListener('tronLink#initialized', () => {
  console.log('TronLink initialized')
})

// Listen for messages
window.addEventListener('message', (event) => {
  if (event.source === window && event.data?.isTronLink && event.data?.message) {
    const { action, data } = event.data.message
    console.log('TronLink event:', action, data)
  }
})
```

## Migración desde TronLink [#migration-from-tronlink]

OneKey es compatible con TronLink. Actualiza tu lógica de detección:

```typescript
// Before (TronLink only)
const tronWeb = window.tronWeb

// After (OneKey with TronLink fallback)
const provider = window.$onekey?.tron || window.tronLink
const tronWeb = window.tronWeb // Compatibility global; verify which wallet owns it
```
