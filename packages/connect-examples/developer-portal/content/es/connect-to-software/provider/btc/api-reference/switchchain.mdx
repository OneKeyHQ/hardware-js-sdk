# switchChain

Cambiar de cadena

## Método [#method]

```typescript
declare function switchChain(chain: string): Promise<{
  enum: string;
  name: string;
  network: string;
}>;
```

## Parámetros [#params]

La enumeración de cadena. Por ejemplo, `BITCOIN_MAINNET`, `BITCOIN_TESTNET`

## Ejemplo [#example]

```typescript
const provider = (window.$onekey && window.$onekey.btc) || window.unisat;

await provider.switchChain("BITCOIN_TESTNET");
```
