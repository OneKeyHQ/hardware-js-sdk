# signPsbts


Firma varias PSBT a la vez. Este método recorre todas las entradas que coinciden con la dirección actual para firmarlas.

## Compatibilidad de carteras y tipos de direcciones [#wallet--address-type-compatibility]

| Tipo de cartera     | Modelo          | Tipos de direcciones compatibles                |
| --------------- | -------------- | -------------------------------------- |
| Cartera de software | Todos            | p2wpkh (Segwit nativo), p2tr (Taproot) |
| Cartera física | Pro, Classic1S | p2tr (Taproot)                         |

## Método [#method]

```typescript
declare function signPsbts(
    psbtHexs: string[],
    options?: {
        autoFinalized?: boolean;
        toSignInputs?: Array<{
            index: number;
            address?: string;
            publicKey?: string;
            sighashTypes?: number[];
            disableTweakSigner?: boolean;
            useTweakedSigner?: boolean;
        }>;
    },
): Promise<string[]>
```

## Parámetros [#parameters]

* `psbtHexs` — _obligatorio_ `string[]` Matriz de cadenas hexadecimales de las PSBT que se van a firmar
* `options` — _opcional_ `object`
  * `autoFinalized` — _opcional_ `boolean` Si se finalizan las PSBT tras firmarlas; el valor predeterminado es `true`
  * `toSignInputs` — _opcional_ `array` Especifica qué entradas firmar
    * `index` — _obligatorio_ `number` Qué entrada firmar
    * `address` — _opcional_ `string` Qué clave privada correspondiente usar para firmar (especifica address o publicKey)
    * `publicKey` — _opcional_ `string` Qué clave privada correspondiente usar para firmar (especifica address o publicKey)
    * `sighashTypes` — _opcional_ `number[]` Tipos sighash opcionales
    * `disableTweakSigner` — _opcional_ `boolean` El valor predeterminado es `false`. Establece `true` para usar la clave privada original al firmar entradas Taproot
    * `useTweakedSigner` — _opcional_ `boolean` Fuerza si se usa un firmante ajustado; tiene prioridad sobre `disableTweakSigner`

## Devuelve [#returns]

* `Promise<string[]>` Matriz de cadenas hexadecimales de las PSBT firmadas

## Ejemplo [#example]

```typescript
const provider = (window.$onekey && window.$onekey.btc) || window.unisat;

try {
    const psbtHexs = [
        "70736274ff01007d...",
        "70736274ff01007d..."
    ];

    const signeds = await provider.signPsbts(psbtHexs, {
        autoFinalized: true,
        toSignInputs: [
            {
                index: 0,
                publicKey: "02abc...",
                useTweakedSigner: true
            },
            {
                index: 1,
                address: "bc1p...",
                disableTweakSigner: true
            }
        ]
    });

    console.log(signeds);
} catch (e) {
    console.log(e);
}
```
