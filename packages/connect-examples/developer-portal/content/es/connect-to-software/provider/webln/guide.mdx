# Guía

## Descripción general [#overview]

Esta guía explica cómo crear aplicaciones de Bitcoin Lightning Network con la API del proveedor de Lightning Network de OneKey.


### Creación de aplicaciones web **Casos de uso** [#building-web-apps-use-cases]

* Aceptar pagos de Lightning Network
* aplicaciones de identidad descentralizada

## Instalación [#install]

### 1. Descargar OneKey Wallet [#1-download-onekey-wallet]

Descarga [OneKey Wallet](https://onekey.so/download?client=browserExtension). Instala la extensión de navegador OneKey.

#### 2. Explicación de la inyección de API [#2-api-injection-explanation]

* La extensión de navegador de OneKey inyecta `Provider API` en los sitios web visitados.
* Se ofrecen dos tipos de API: `window.webln` y `window.$onekey.webln`.
* Se recomienda usar `window.$onekey.webln`.

> Usa preferentemente `window.$onekey.webln` para seleccionar OneKey específicamente. La variable global `window.webln` puede pertenecer a otra cartera cuando hay varias extensiones instaladas.

### Detectar la compatibilidad con la API del proveedor [#detecting-provider-api-support]

Comprueba que haya un proveedor disponible antes de realizar solicitudes:

```javascript
const provider = (window.$onekey && window.$onekey.webln) || window.webln;

if (!provider) {
  throw new Error("No provider is available.");
}
```

### Conectarse a OneKey [#connecting-to-onekey]

Antes de usar la siguiente API, debes usar primero el método `provider.enable` para solicitar al usuario acceso a la cuenta correspondiente.

```typescript
const provider = (window.$onekey && window.$onekey.webln) || window.webln;

await provider.enable();
```

Solo se puede llamar a otras API después de obtener la autorización del usuario.

## API [#api]

Elige una API para la operación que necesite tu aplicación.

* Obtener información del nodo Bitcoin Lightning del usuario: [`provider.getInfo`](/es/connect-to-software/provider/webln/api-reference/getinfo)
* Enviar un pago: [`provider.sendPayment`](/es/connect-to-software/provider/webln/api-reference/sendpayment)
* Solicitar una factura para recibir un pago: [`provider.makeInvoice`](/es/connect-to-software/provider/webln/api-reference/makeinvoice)
* Solicitar la firma de cualquier mensaje: [`provider.signMessage`](/es/connect-to-software/provider/webln/api-reference/signmessage)

**Más interfaces**: [Ver detalles](/es/connect-to-software/provider/webln/api-reference)

## Gestión de solicitudes [#handling-requests]

Ejecuta las solicitudes de cartera desde una función asíncrona o un módulo ES. Captura las promesas rechazadas y muestra el error en tu aplicación. Solicita conexiones, firmas y pagos a partir de una acción del usuario, y desactiva el botón que los inicia mientras haya una solicitud pendiente.
