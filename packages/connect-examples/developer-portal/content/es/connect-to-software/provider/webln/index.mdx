# WebLN

Usa el proveedor WebLN de OneKey para interactuar con aplicaciones compatibles con Lightning.

## Enlaces rápidos [#quick-links]

- [Guía](guide)
- [Referencia de la API](api-reference)
- [Eventos](event)

## Patrón mínimo [#minimal-pattern]

```js
const provider = window.$onekey?.webln
if (!provider) throw new Error('OneKey WebLN provider not detected')

await provider.enable()
const info = await provider.getInfo()
```
