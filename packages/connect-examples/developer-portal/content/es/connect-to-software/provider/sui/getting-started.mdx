# Primeros pasos

Solicita permiso antes de firmar, selecciona una cuenta conectada y consulta la cadena activa. Estos ejemplos usan `@mysten/sui@1.28.2`, que coincide con `@mysten/wallet-standard@0.14.7` aceptado por el proveedor actual.

Aprende a detectar, conectar e interactuar con Sui mediante el proveedor de OneKey.

<Callout type="info">
OneKey implementa Sui Wallet Standard para integraciones compatibles con wallet-standard.
</Callout>

---

## Detección del proveedor [#provider-detection]

```typescript
// Detect OneKey Sui provider
const provider = window.$onekey?.sui

if (!provider) {
  throw new Error('OneKey Sui provider not detected')
}
```

---

## Comprobar permisos [#check-permissions]

```typescript
// Check if already connected
const hasPermission = await provider.hasPermissions()

if (hasPermission) {
  const accounts = await provider.getAccounts()
  console.log('Connected accounts:', accounts)
}
```

---

## Solicitar conexión [#request-connection]

```typescript
// Request permissions to connect
const result = await provider.requestPermissions()

if (result) {
  const accounts = await provider.getAccounts()
  console.log('Connected:', accounts[0].address)
}
```

## Contexto de cuenta para firmar [#account-context-for-signing]

Instala `@mysten/wallet-standard@0.14.7`. El método del proveedor inyectado `getAccounts()` devuelve `AccountInfo[]`, no el objeto `WalletAccount` que requieren los métodos de firma. La siguiente función auxiliar obtiene la cuenta completa mediante Wallet Standard. Llámala desde una acción del usuario después de registrar la cartera; gestiona el rechazo y vuelve a conectar tras cambios de cuenta o red.

```typescript
import { getWallets, isWalletWithRequiredFeatureSet } from '@mysten/wallet-standard'

async function connectSuiAccount() {
  const wallet = getWallets().get().find(wallet => wallet.name === 'OneKey Wallet')
  if (!wallet || !isWalletWithRequiredFeatureSet(wallet)) {
    throw new Error('OneKey Sui Wallet Standard is not available')
  }

  const { accounts } = await wallet.features['standard:connect'].connect()
  const [account] = accounts
  const chain = await provider.getActiveChain()
  if (!account || !chain || !account.chains.includes(chain)) {
    throw new Error('No connected Sui account for the active chain')
  }
  return { account, chain }
}
```

## Obtener cuentas [#get-accounts]

```typescript
const accounts = await provider.getAccounts()

accounts.forEach(account => {
  console.log({
    address: account.address,     // Sui address
    publicKey: account.publicKey, // Public key (hex string)
  })
})
```

## Obtener la cadena activa [#get-active-chain]

```typescript
const chain = await provider.getActiveChain()

console.log('Active chain:', chain) // e.g., 'sui:testnet'
```

## Escuchadores de eventos [#event-listeners]

### Escuchar cambios de cuenta [#listen-for-account-changes]

```typescript
provider.onAccountChange((account) => {
  if (account) {
    console.log('Account changed:', account.address)
  } else {
    console.log('Disconnected')
  }
})
```

### Escuchar cambios de red [#listen-for-network-changes]

```typescript
provider.onNetworkChange((network) => {
  console.log('Network changed:', network)
})
```

## Uso con Sui Wallet Kit [#using-with-sui-wallet-kit]

Este ejemplo de React usa las versiones compatibles de los paquetes fijadas a continuación:

```bash
npm install @mysten/dapp-kit@0.16.0 @mysten/sui@1.28.2 @tanstack/react-query@^5
```

```tsx
import { SuiClientProvider, WalletProvider } from '@mysten/dapp-kit'
import { getFullnodeUrl } from '@mysten/sui/client'
import { QueryClient, QueryClientProvider } from '@tanstack/react-query'

const queryClient = new QueryClient()
const networks = {
  mainnet: { url: getFullnodeUrl('mainnet') },
  testnet: { url: getFullnodeUrl('testnet') },
}

function App() {
  return (
    <QueryClientProvider client={queryClient}>
      <SuiClientProvider networks={networks} defaultNetwork="mainnet">
        <WalletProvider>
          <YourApp />
        </WalletProvider>
      </SuiClientProvider>
    </QueryClientProvider>
  )
}
```

OneKey se detecta automáticamente mediante Sui Wallet Standard.
