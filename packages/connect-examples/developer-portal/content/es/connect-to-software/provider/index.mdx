# API del proveedor

Usa el proveedor de la cadena de destino para solicitar cuentas, firmas y transacciones. Cada cadena tiene sus propios métodos, codificaciones y eventos; un ejemplo de solicitud de Ethereum no es intercambiable con uno de Bitcoin o Solana.

## Qué ofrece [#what-this-gives-you]

- **Referencias específicas por cadena**: Encuentra documentación de conexión, firma, transacciones y eventos para cada proveedor.
- **Opciones de conexión**: Usa una biblioteca de interfaz de carteras para mostrar un selector o accede directamente al proveedor inyectado.
- **Guía de implementación**: Comprueba el estado de red y cuenta, gestiona las solicitudes rechazadas y elimina los escuchadores de eventos cuando dejen de ser necesarios.

## Cadenas compatibles [#supported-chains]

- **EVM**: Ethereum, Polygon, BSC, Arbitrum, Optimism, Base, etc.
- **Bitcoin**: BTC, Lightning Network (WebLN)
- **Solana**: SOL
- **Cosmos**: ATOM y cadenas de Cosmos SDK
- **Move**: Aptos, Sui
- **Otras**: Stellar, TON, TRON, Polkadot, Cardano, Algorand, Conflux, NEAR, Nostr

Selecciona una cadena en la barra lateral para ver los métodos detallados del proveedor, los flujos de firma y los ejemplos.
