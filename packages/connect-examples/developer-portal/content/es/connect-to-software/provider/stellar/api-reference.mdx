# Referencia de la API

Referencia de métodos y tipos básicos de `window.$onekey.stellar`.

---

## Métodos [#methods]

| Método | Descripción |
|------|------|
| `getAddress(params?)` | Solicitar permiso (conectar) y devolver la dirección de Stellar actual |
| `getNetwork()` | Obtener información de la red actual |
| `signTransaction(xdr, opts?)` | Firmar el XDR de una transacción de Stellar |
| `signAuthEntry(authEntry, opts?)` | Firmar una entrada de autorización de Stellar (XDR de la entrada de autorización) |
| `signMessage(message, opts?)` | Firmar un mensaje arbitrario |

---

## Propiedades [#properties]

| Propiedad | Tipo | Descripción |
|------|------|------|
| `isOneKey` | `boolean` | Identificador de OneKey |

## Tipo básico (como referencia) [#basic-type-for-reference]

```ts
export type OneKeyStellarProvider = {
  isOneKey: boolean

  // Align with Stellar Wallets Kit (KitActions)
  getAddress: (params?: StellarGetAddressParams) => Promise<StellarGetAddressResponse>
  getNetwork: () => Promise<StellarNetworkInfo>
  signTransaction: (
    xdr: string,
    opts?: StellarSignTransactionOpts
  ) => Promise<StellarSignTransactionResponse>
  signAuthEntry: (
    authEntry: string,
    opts?: StellarSignAuthEntryOpts
  ) => Promise<StellarSignAuthEntryResponse>
  signMessage: (
    message: string,
    opts?: StellarSignMessageOpts
  ) => Promise<StellarSignMessageResponse>
}
```

Todos los métodos devuelven promesas. Gestiona las solicitudes rechazadas y trata el campo opcional `signerAddress` como tal, sin asumir que esté presente. El proveedor también ofrece `disconnect()` y emite `accountsChanged` con una cadena de dirección o `null`; borra el estado específico de la cuenta cuando cambie.
