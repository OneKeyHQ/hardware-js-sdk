<Callout type="info">
Todos los métodos se llaman mediante `window.$onekey.ethereum.request({ method, params })`.
</Callout>

## Métodos estándar de Ethereum [#standard-ethereum-methods]

Los métodos adicionales de JSON-RPC de Ethereum dependen de la red conectada y de la implementación de la cartera. Consulta la [especificación JSON-RPC de Ethereum](https://ethereum.github.io/execution-apis/) para ver la lista completa.

Algunos métodos habituales son:
- `eth_blockNumber` - Obtener el número del bloque actual
- `eth_getBalance` - Obtener el saldo de una cuenta
- `eth_getCode` - Obtener el código de un contrato
- `eth_getLogs` - Obtener registros de eventos
