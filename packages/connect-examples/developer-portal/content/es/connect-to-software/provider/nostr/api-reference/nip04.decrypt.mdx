# nip04.decrypt

## Método [#method]

```typescript
// provider.nip04.decrypt
(pubkey: string, ciphertext: string) => Promise<string>
```

## Parámetros [#params]

* `pubkey` — _obligatorio_ `string`  la clave pública del remitente
* `ciphertext` — _obligatorio_ `string` los datos cifrados

## Respuesta [#response]

Devuelve el texto sin formato descifrado.

## Ejemplo [#example]

```javascript
const provider = (window.$onekey && window.$onekey.nostr) || window.nostr;

const message = "Data to be encrypted";
const encrypted = await provider.nip04.encrypt(pubkey, message);
const decrypted = await provider.nip04.decrypt(pubkey, encrypted); // Data to be encrypted
```
