# nip04.encrypt

## Método [#method]

```typescript
// provider.nip04.encrypt
(pubkey: string, plaintext: string) => Promise<string>
```

## Respuesta [#response]

devuelve el texto cifrado y el iv según lo especificado en nip-04

## Parámetros [#params]

* `pubkey` — _obligatorio_ `string`  la clave pública del destinatario
* `plaintext` — _obligatorio_ `string` el texto sin formato que se va a cifrar

## Ejemplo [#example]

```javascript
const provider = (window.$onekey && window.$onekey.nostr) || window.nostr;

const encrypted = await provider.nip04.encrypt(pubkey, "Data to be encrypted")
```
