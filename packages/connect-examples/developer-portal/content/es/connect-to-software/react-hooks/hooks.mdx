# Hooks de React

Hooks de React con seguridad de tipos para Ethereum. Crea tu propia interfaz de conexión de carteras con control total sobre la experiencia de usuario.

<Callout>

## Cuándo usarlos [#when-to-use]

Usa hooks de React si:
- Necesitas control total sobre la interfaz de conexión de carteras
- Quieres hooks con seguridad de tipos para interactuar con Ethereum
- Estás creando una aplicación React
- No necesitas un modal de selección de carteras listo para usar

## Ejemplo rápido [#quick-example]

Configura `WagmiProvider` y `QueryClientProvider` con la [guía de wagmi](/es/connect-to-software/react-hooks/wagmi) primero. Este componente usa los conectores configurados.

```tsx
import { useAccount, useConnect, useDisconnect } from 'wagmi'

function ConnectButton() {
  const { address, isConnected } = useAccount()
  const { connect, connectors, isPending, error } = useConnect()
  const { disconnect } = useDisconnect()

  if (isConnected) {
    return (
      <div>
        <p>{address}</p>
        <button onClick={() => disconnect()}>Disconnect</button>
      </div>
    )
  }

  return (
    <div>
      {connectors.map((connector) => (
        <button key={connector.uid} disabled={isPending} onClick={() => connect({ connector })}>
          Connect {connector.name}
        </button>
      ))}
      {error && <p role="alert">{error.message}</p>}
    </div>
  )
}
```
