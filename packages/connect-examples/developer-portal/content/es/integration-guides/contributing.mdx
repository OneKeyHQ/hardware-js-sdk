# Cómo contribuir

Elige el repositorio responsable de la función. Lee su README, instrucciones de contribución y política de seguridad antes de empezar.

| Área | Repositorio |
| --- | --- |
| Aplicaciones y extensión de navegador | [app-monorepo](https://github.com/OneKeyHQ/app-monorepo) |
| Hardware SDK y este portal para desarrolladores | [hardware-js-sdk](https://github.com/OneKeyHQ/hardware-js-sdk) |
| Proveedores de cartera inyectados | [cross-inpage-provider](https://github.com/OneKeyHQ/cross-inpage-provider) |
| Firmware | [firmware](https://github.com/OneKeyHQ/firmware) |
| Colección histórica de GitBook | [documentación](https://github.com/OneKeyHQ/docs) |

## Proponer un cambio [#propose-a-change]

Para una cadena nueva o cambio de integración, describe entorno de ejecución, métodos de firma, formato de serialización y soporte requerido de dispositivo o firmware. Las integraciones de cartera de software y firma por hardware pueden pertenecer a repositorios distintos. Revisa antes incidencias y pull requests existentes.

## Enviar una corrección [#submit-a-fix]

1. Sigue las instrucciones de desarrollo del repositorio.
2. Haz un cambio concreto y actualiza los ejemplos o documentación afectados.
3. Ejecuta las comprobaciones requeridas.
4. Abre un pull request que explique el problema, el comportamiento resultante y las pruebas.

Los informes de documentación deben incluir la URL de la página y el ejemplo o afirmación incorrectos. Para fallos de integración, usa la [lista de comprobación para informes](/es/troubleshooting#report-an-issue). Para vulnerabilidades de seguridad, sigue la política de seguridad del repositorio afectado en lugar de publicar detalles de explotación en una incidencia.
