# API del dispositivo

Elige un método de consulta de estado de solo lectura antes de ofrecer un cambio en el dispositivo. Las operaciones de PIN, ajustes, bootloader y firmware requieren una acción explícita del usuario y la confirmación correspondiente en el dispositivo.
