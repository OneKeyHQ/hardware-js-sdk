# deviceSupportFeatures

Comprueba los objetos de capacidades en tiempo de ejecución. Lee `.support`, no la veracidad del objeto; `{ support: false }` sigue siendo un valor verdadero en una condición de JavaScript. `require` puede indicar una versión mínima del firmware.

```ts
const result = await HardwareSDK.deviceSupportFeatures(connectId);
if (!result.success) throw new Error(result.payload.error);
const canEnterPinOnHost = result.payload.inputPinOnSoftware.support;
```

```typescript
const response = await HardwareSDK.deviceSupportFeatures(connectId);
```

### Parámetros [#params]

[Parámetros comunes opcionales](/es/hardware-sdk/concepts/common-params)

### Ejemplo [#example]

```typescript
const response = await HardwareSDK.deviceSupportFeatures(connectId);
```

Resultado

```typescript
{
    success: true,
    payload: {
      inputPinOnSoftware: { support: boolean, require?: string },
      modifyHomescreen: { support: boolean, require?: string },
      device: Device | null
    }
}
```

Error

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
