# cardanoSignMessage

## Requisitos [#requirements]

* Versiones mínimas de firmware exigidas por el SDK
  * Touch / Pro (`model_touch`): 4.10.0

Este método no declara una versión mínima de firmware para Classic/Mini. La ausencia de una comprobación de versión en el SDK no demuestra que el firmware admita este método.

## Cardano: firmar un mensaje <a href="#ethereum-sign-message" id="ethereum-sign-message"></a> [#cardano-sign-message-]

Solicita una firma de mensaje con la clave derivada de la ruta especificada.

```typescript
const result = await HardwareSDK.cardanoSignMessage(connectId, deviceId, params);
```

### Parámetros [#params]

[**Parámetros comunes opcionales**](/es/hardware-sdk/concepts/common-params)

* `path` - _obligatorio_ `string` Ruta BIP32 con al menos `3` componentes. Este método no acepta un array de números. [Formato de ruta](/es/hardware-sdk/concepts/common-params#hd-path)
* `message` - _obligatorio_ `string` Mensaje que se va a firmar, codificado como cadena hexadecimal.
* `networkId` - _obligatorio_ `Integer` 1 para la red principal, 0 para la red de pruebas
* `derivationType` - _obligatorio_ `CardanoDerivationType`: enumeración que selecciona el algoritmo de derivación. El valor predeterminado en ejecución es `ICARUS` (`1`).

La API actual de TypeScript exige `derivationType` explícitamente, aunque el valor predeterminado en ejecución sea ICARUS.

### Ejemplo [#example]

```typescript
import { PROTO } from "@onekeyfe/hd-core";

// Original message
const message = "Hello World";

// Convert to hex
const messageHex = Buffer.from(message).toString('hex');

HardwareSDK.cardanoSignMessage(connectId, deviceId, {
    path: "m/1852'/1815'/0'/0/0",
    message: messageHex,
    networkId: 1,
    derivationType: PROTO.CardanoDerivationType.ICARUS
});
```

Resultado

```typescript
{
    success: true,
    payload: {
        signature: string;
        key: string;
    }
}
```

Error

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
