# cardanoGetAddress

## Requisitos [#requirements]

* Versiones mínimas de firmware
  * Touch: 4.1.0
  * Classic/Mini: 3.0.0

## Cardano: obtener una dirección [#cardano-get-address]

Deriva y devuelve una dirección de Cardano con los parámetros de dirección especificados. Cuando `showOnOneKey` es `true`, el usuario debe confirmar la dirección en el dispositivo.

```typescript
const response = await HardwareSDK.cardanoGetAddress(connectId, deviceId, params)
```

### Parámetros [#params]

[Parámetros comunes opcionales](/es/hardware-sdk/concepts/common-params)

**Una dirección**

* `addressParameters` - _obligatorio_ consulta la descripción siguiente
* `protocolMagic` - _obligatorio_ `Integer` 764824073 para la red principal, 1 para la red de pruebas Preprod y 2 para la red de pruebas Preview
* `networkId` - _obligatorio_ `Integer` 1 para la red principal, 0 para la red de pruebas
* `address` - _opcional_ `string` Dirección esperada, usada para validación
* `showOnOneKey` - _obligatorio_ `boolean` Si se muestra la dirección en el dispositivo. El valor predeterminado es `true`.
* `derivationType` - _obligatorio_ `CardanoDerivationType`: enumeración que selecciona el algoritmo de derivación. El valor predeterminado en ejecución es `ICARUS` (`1`).
* `isCheck` - _opcional_ `boolean` comprueba solo la dirección base

**Varias direcciones**

* `bundle` - matriz de objetos con los campos de una dirección individual

**Parámetros de dirección**

* `addressType` - _obligatorio_ `CardanoAddressType`/`number` - Usa la enumeración exportada `PROTO.CardanoAddressType`.
* `path` - `string | Array<number>` Obligatorio para direcciones de pago basadas en claves; omítelo para direcciones de pago por script o de recompensa. La longitud mínima del SDK, cuando está presente, es `3`.
* `stakingPath` - _opcional_ `string | Array<number>` La longitud mínima del SDK es `3`. Se usa para derivar direcciones base y de recompensas
* `stakingKeyHash` - _opcional_ `string` cadena hexadecimal del hash de la clave de staking. Se usa para derivar direcciones base (como alternativa a `stakingPath`)
* `certificatePointer` - _opcional_ Objeto CardanoCertificatePointer. Debe contener `blockIndex`, `txIndex` y `certificateIndex`, de tipo `number`. Se usa para derivar direcciones de puntero.
* `paymentScriptHash` - _opcional_ `string` cadena hexadecimal del hash del script de pago.
* `stakingScriptHash` - _opcional_ `string` cadena hexadecimal del hash del script de staking.

La API actual de TypeScript exige estos campos explícitamente, aunque los valores predeterminados en ejecución sean ICARUS y `showOnOneKey: true`.

### Ejemplo [#example]

Muestra la dirección Byron de la primera cuenta de Cardano:

```javascript
import { PROTO } from "@onekeyfe/hd-core";

HardwareSDK.cardanoGetAddress(connectId, deviceId, {
    addressParameters: {
        addressType: PROTO.CardanoAddressType.BYRON,
        path: "m/44'/1815'/0'/0/0",
    },
    protocolMagic: 764824073,
    networkId: 1,
    derivationType: PROTO.CardanoDerivationType.ICARUS,
    showOnOneKey: true,
});
```

Muestra la dirección base de la primera cuenta de Cardano:

```javascript
import { PROTO } from "@onekeyfe/hd-core";

HardwareSDK.cardanoGetAddress(connectId, deviceId, {
    addressParameters: {
        addressType: PROTO.CardanoAddressType.BASE,
        path: "m/1852'/1815'/0'/0/0",
        stakingPath: "m/1852'/1815'/0'/2/0",
    },
    protocolMagic: 764824073,
    networkId: 1,
    derivationType: PROTO.CardanoDerivationType.ICARUS,
    showOnOneKey: true,
});
```

```javascript

HardwareSDK.cardanoGetAddress(connectId, deviceId, {
    bundle: [
        // byron address, account 1, address 1
        {
            addressParameters: {
                addressType: 8,
                path: "m/44'/1815'/0'/0/0",
            },
            protocolMagic: 764824073,
            networkId: 1,
            derivationType: PROTO.CardanoDerivationType.ICARUS,
            showOnOneKey: false,
        },
        // base address with staking key hash, account 1, address 1
        {
            addressParameters: {
                addressType: 0,
                path: "m/1852'/1815'/0'/0/0",
                stakingKeyHash: '1bc428e4720702ebd5dab4fb175324c192dc9bb76cc5da956e3c8dff',
            },
            protocolMagic: 764824073,
            networkId: 1,
            derivationType: PROTO.CardanoDerivationType.ICARUS,
            showOnOneKey: false,
        },
        // byron address, account 2, address 3, testnet
        {
            addressParameters: {
                addressType: 8,
                path: "m/44'/1815'/1'/0/2",
            },
            protocolMagic: 1,
            networkId: 0,
            derivationType: PROTO.CardanoDerivationType.ICARUS,
            showOnOneKey: false,
        },
    ],
});
```
