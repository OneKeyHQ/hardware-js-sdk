# dnxSignTransaction

### Dynex: firmar una transacción [#dynex-sign-transaction]

Firma la transacción de Dynex proporcionada con la clave privada derivada de la ruta BIP32 especificada. Se pide al usuario que confirme los detalles de la transacción en OneKey.

```typescript
const result = await HardwareSDK.dnxSignTransaction(connectId, deviceId, params);
```

#### Requisitos [#requirements]

* Versiones mínimas de firmware
  * classic: 3.8.0

#### Parámetros [#parameters]

connectId: `string`

* Identificador único de la conexión

deviceId: `string`

* Identificador único del dispositivo físico

params: `object`

* path: `string` - Ruta BIP32 (p. ej., "m/44'/0'/0'/0/0") \[obligatorio\]
* inputs: `array` - Matriz de entradas de transacción \[obligatorio\]
  * prevIndex: `number` - Índice de la salida anterior
  * globalIndex: `number` - Índice global
  * txPubkey: `string` - Clave pública de la transacción
  * prevOutPubkey: `string` - Clave pública de la salida anterior
  * amount: `string` - Importe de la entrada
* toAddress: `string` - Dirección de destino \[obligatorio\]
* amount: `string` - Importe de la transacción \[obligatorio\]
* fee: `string` - Comisión de la transacción \[obligatorio\]
* paymentIdHex: `string` - ID de pago opcional (debe tener 32 bytes)

#### Ejemplo [#example]

```typescript
const response = await HardwareSDK.dnxSignTransaction('connect1', 'device1', {
    path: "m/44'/0'/0'/0/0",
    inputs: [{
        prevIndex: 0,
        globalIndex: 323,
        txPubkey: "0d708b68003ae5fee4c9f9aad56a8cfdb0a5dcbcdd2e3fc18eb813349457a78c",
        prevOutPubkey: "ff4df9a9fc83e48f2c0242c4d94f3906546a889950bccd8ba4392f3e7886c3a1",
        amount: "1000000000"
    }],
    toAddress: "XwmxTF8FxAy2s5cvtS62oSGxY3fzvDcgo2CiJ6rrpz9te68sApSDs3LQihubFtpsfT5z6NYHZzMKUjavNpTkW46i2dYgHBULG",
    amount: "1000000000",
    fee: "100000",
});
```

#### Devuelve [#returns]

Respuesta correcta:

```typescript
{
    success: true,
    payload: {
        path: string,              // BIP32 path used for signing
        txKey: {
            ephemeralTxSecKey: string,  // Transaction secret key
            ephemeralTxPubKey: string   // Transaction public key
        },
        computedKeyImages: string[],    // Array of computed key images
        signatures: string[],           // Array of signatures
        outputKeys: string[]            // Array of output keys
    }
}
```

Respuesta de error:

```typescript
{
    success: false,
    payload: {
        error: string,
        code?: string | number
    }
}
```
