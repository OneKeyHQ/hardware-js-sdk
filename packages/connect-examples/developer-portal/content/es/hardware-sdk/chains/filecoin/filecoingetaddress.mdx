# filecoinGetAddress

### Requisitos [#requirements]

* Versiones mínimas de firmware
  * Touch: 3.5.0
  * Classic/Mini: 2.10.0

## Filecoin: obtener una dirección [#filecoin-get-address]

Deriva y devuelve la dirección de la ruta especificada. Usa `showOnOneKey` para solicitar confirmación en el dispositivo.

```typescript
const result = await HardwareSDK.filecoinGetAddress(connectId, deviceId, params);
```

## Parámetros [#params]

[**Parámetros comunes opcionales**](/es/hardware-sdk/concepts/common-params)

### Una dirección [#single-address]

* `path` - _obligatorio_ `string | Array<number>` La longitud mínima del SDK es `3`. [leer más](/es/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _opcional_ `boolean` Si se muestra la dirección en el dispositivo. El valor predeterminado es `true`.
* `isTestnet` - _opcional_ `boolean` Si se usa la red de pruebas.

#### Varias direcciones [#multiple-addresses]

* `bundle` - matriz de objetos que incluyen `path`, `showOnOneKey`, y `isTestnet` como campos

### Ejemplo [#example]

Devuelve la dirección de la primera cuenta de Filecoin:

```typescript
HardwareSDK.filecoinGetAddress(connectId, deviceId, {
    path: "m/44'/461'/0'/0/0",
    showOnOneKey: true,
    isTestnet: false
});
```

Devuelve un conjunto de direcciones para varias cuentas de Filecoin:

```typescript
HardwareSDK.filecoinGetAddress(connectId, deviceId, {
    bundle: [
        { path: "m/44'/461'/0'/0/0" }, // account 1
        { path: "m/44'/461'/0'" }, // account 2
        { path: "m/44'/461'/0'/0/1" }  // account 3
    ]
});
```

### Resultado [#result]

Respuesta de una dirección

```typescript
{
    success: true,
    payload: {
        path: string, // serialized BIP32 path
        address: string,   // address
    }
}
```

Respuesta por lotes de direcciones

```typescript
{
    success: true,
    payload: [
        { path, address }, // account 1
        { path, address }, // account 2
        { path, address }, // account 3
    ]
}
```

Error

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
