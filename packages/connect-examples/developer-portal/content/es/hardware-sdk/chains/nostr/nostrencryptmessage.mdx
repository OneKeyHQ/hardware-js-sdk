# nostrEncryptMessage

### Requisitos [#requirements]

* Versiones mínimas de firmware exigidas por el SDK
  * Touch / Pro (`model_touch`): 4.7.0
  * Classic / Classic1s / Classic Pure / Mini (`model_mini`): 3.6.0

## Nostr: cifrar mensaje [#nostr-encrypt-message]

Solicita el cifrado de un mensaje con la clave de la ruta especificada y la clave pública del otro participante.

```typescript
const result = await HardwareSDK.nostrEncryptMessage(connectId, deviceId, params);
```

### Parámetros [#params]

[**Parámetros comunes opcionales**](/es/hardware-sdk/concepts/common-params)

* `path` - _obligatorio_ `string | Array<number>` La longitud mínima del SDK es `5`. [leer más](/es/hardware-sdk/concepts/common-params#hd-path)
* `pubkey` - _obligatorio_ `string`. La clave pública del otro participante.
* `plaintext` - _obligatorio_ `string`. El mensaje en texto plano que se cifrará.
* `showOnOneKey` - _opcional_ `boolean` Indica si se debe mostrar la solicitud en el dispositivo. El valor predeterminado es `true`.

### Ejemplos [#examples]

```typescript
const response = await HardwareSDK.nostrEncryptMessage(
  connectId,
  deviceId,
  {
     path: "m/44'/1237'/0'/0/0",
     pubkey: '2118c65161c7d68b4bdbe1374f658532670057ab1bb0c99937d0ff7cff45cb5e',
     plaintext: 'Hello world',
     showOnOneKey: true,
  }
);
```

Resultado

```typescript
{
  success: true,
  payload: {
    path: string;
    pubkey: string;
    plaintext: string;
    encryptedMessage: string;
  }
}
```

Error

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
