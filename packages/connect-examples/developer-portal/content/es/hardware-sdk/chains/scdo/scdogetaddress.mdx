# scdoGetAddress

#### Requisitos [#requirements]

* Versiones mínimas de firmware
  * Touch: 4.10.0

#### SCDO: obtener dirección [#scdo-get-address]

Deriva y devuelve la dirección de la ruta especificada. Cuando `showOnOneKey` es `true`, el usuario debe confirmar la dirección en el dispositivo.

```typescript
const response = await HardwareSDK.scdoGetAddress(connectId, deviceId, {
    path: "m/44'/541'/0'/0/0",
    showOnOneKey: true
});
```

**Parámetros**

Parámetros comunes opcionales

**Una dirección**

* `path` - _obligatorio_ `string | Array<number>` La longitud mínima del SDK es `3`. [Formato de ruta](/es/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _opcional_ `boolean` Si se muestra la dirección en el dispositivo. El valor predeterminado es `true`.

**Varias direcciones**

* `bundle` - matriz de objetos que incluyen `path` y `showOnOneKey` como campos

**Ejemplo**

```typescript
// Get single address
const response = await HardwareSDK.scdoGetAddress(connectId, deviceId, {
    path: "m/44'/541'/0'/0/0",
    showOnOneKey: false
});

// Get multiple addresses
const bundleResponse = await HardwareSDK.scdoGetAddress(connectId, deviceId, {
    bundle: [
        {
            path: "m/44'/541'/0'/0/0",
            showOnOneKey: false
        },
        {
            path: "m/44'/541'/1'/0/0",
            showOnOneKey: false
        }
    ]
});
```

Resultado con una sola dirección

```typescript
{
    success: true,
    payload: {
        address: string,
        path: string
    }
}
```

Respuesta por lotes de direcciones

```typescript
{
    success: true,
    payload: [
        { address: string, path: string }, // account 1
        { address: string, path: string }  // account 2
    ]
}
```

Error

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number  // error code
    }
}
```
