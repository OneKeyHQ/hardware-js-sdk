# scdoSignMessage

#### Requisitos [#requirements]

* Versiones mínimas de firmware
  * Touch: 4.10.0

#### SCDO: firmar mensaje [#scdo-sign-message]

Firma un mensaje con la clave privada derivada de la ruta BIP32 especificada.

```typescript
// Original message
const message = "Hello World";

// Convert to hex
const messageHex = Buffer.from(message).toString('hex');

const response = await HardwareSDK.scdoSignMessage(connectId, deviceId, {
    path: "m/44'/541'/0'/0/0",
    messageHex: messageHex
});
```

**Parámetros**

Parámetros comunes opcionales

* `path` - _obligatorio_ `string | Array<number>` La longitud mínima del SDK es `3`. [Formato de ruta](/es/hardware-sdk/concepts/common-params#hd-path)
* `messageHex` - _obligatorio_ `string` mensaje que se va a firmar en formato hexadecimal

**Ejemplo**

```typescript
// Original message
const message = "Hello World";

// Convert to hex
const messageHex = Buffer.from(message).toString('hex');

const response = await HardwareSDK.scdoSignMessage(connectId, deviceId, {
    path: "m/44'/541'/0'/0/0",
    messageHex,
});
```

Resultado

```typescript
{
    success: true,
    payload: {
        signature: string,
        address: string
    }
}
```

Error

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number  // error code
    }
}
```
