# benfenSignMessage

**Requisitos**

* Versiones mínimas de firmware
  * Pro: 4.12.0
  * Classic 1S / Classic 1S Pure: 3.11.0

### Benfen: firmar un mensaje [#benfen-sign-message]

Firma un mensaje con la clave privada derivada de la ruta BIP32 especificada. El usuario debe confirmar la acción en el dispositivo OneKey.

```typescript
const result = await HardwareSDK.benfenSignMessage(connectId, deviceId,{
  path: "m/44'/728'/0'/0'/0'",
  messageHex: "68656c6c6f" // "hello" in hex
});
```

#### Parámetros [#params]

**Parámetros comunes opcionales**

* `path` - _obligatorio_ `string | Array<number>` La longitud mínima del SDK es `3`. [Formato de ruta](/es/hardware-sdk/concepts/common-params#hd-path)
* `messageHex` - _obligatorio_ `string` Mensaje que se va a firmar, en formato hexadecimal

#### Devuelve [#returns]

* `success` - _boolean_ True si la operación tiene éxito
* `payload`
  * `signature` - _string_ Firma en formato hexadecimal
  * `address` - _string_ Dirección en formato BFC usada para firmar

Ejemplo:

```typescript
const params = {
  path: "m/44'/728'/0'/0'/0'",
  messageHex: "68656c6c6f" // "hello" in hex
};

const response = await HardwareSDK.benfenSignMessage(connectId, deviceId, params);
```

Resultado

```typescript
{
  success: true,
  payload: {
    signature: string,
    address: string,
  }
}
```

Error

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
