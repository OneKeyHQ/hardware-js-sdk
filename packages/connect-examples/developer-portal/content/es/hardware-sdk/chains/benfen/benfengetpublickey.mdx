# benfenGetPublicKey

Benfen: obtener una clave pública

Obtén la clave pública del dispositivo usando una ruta BIP32.

**Requisitos**

* Versiones mínimas de firmware
  * Pro: 4.12.0
  * Classic 1S / Classic 1S Pure: 3.11.0

```typescript
const result = await HardwareSDK.benfenGetPublicKey(connectId, deviceId, {
  path: "m/44'/728'/0'/0'/0'",
  showOnOneKey: false
});
```

#### Parámetros [#params]

**Parámetros comunes opcionales**

* `path` - _obligatorio_ `string | Array<number>` La longitud mínima del SDK es `3`. [Formato de ruta](/es/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _opcional_ `boolean` si se muestra la clave pública en el dispositivo

Devuelve:

* success: boolean - True si la operación tiene éxito
* payload:
  * path: string - Ruta BIP32 usada
  * pub: string - Clave pública en formato hexadecimal

Ejemplo:

```typescript
const params = {
  path: "m/44'/728'/0'/0'/0'",
  showOnOneKey: false
};

// Single public key
const response = await HardwareSDK.benfenGetPublicKey(connectId, deviceId, params);

// Batch public keys
const batchParams = {
  bundle: [
    {
      path: "m/44'/728'/0'/0'/0'",
      showOnOneKey: false
    },
    {
      path: "m/44'/728'/1'/0'/0'",
      showOnOneKey: false
    }
  ]
};
const batchResponse = await HardwareSDK.benfenGetPublicKey(connectId, deviceId, batchParams);
```
