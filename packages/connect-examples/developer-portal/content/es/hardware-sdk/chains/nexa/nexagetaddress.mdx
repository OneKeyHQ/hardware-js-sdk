# nexaGetAddress

### Requisitos [#requirements]

* Versiones mínimas de firmware
  * Touch: 4.4.0
  * Classic/Mini: 3.2.0

## Nexa: obtener dirección [#nexa-get-address]

Deriva y devuelve la dirección de la ruta especificada. Usa `showOnOneKey` para solicitar confirmación en el dispositivo.

```typescript
const result = await HardwareSDK.nexaGetAddress(connectId, deviceId, params);
```

## Parámetros [#params]

[**Parámetros comunes opcionales**](/es/hardware-sdk/concepts/common-params)

### Una dirección [#single-address]

* `path` - _obligatorio_ `string | Array<number>` La longitud mínima del SDK es `3`. [leer más](/es/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _opcional_ `boolean` Si se muestra la dirección en el dispositivo. El valor predeterminado es `true`.
* `prefix` - _opcional_ `string` Prefijo de dirección, por ejemplo `nexa` para mainnet; especifica explícitamente la red prevista
* `scheme` - _opcional_ `string` Modo del algoritmo de cifrado. El valor predeterminado es `schnorr`

#### Varias direcciones [#multiple-addresses]

* `bundle` - matriz de objetos que incluyen `path`, `prefix`, `scheme`, `showOnOneKey` como campos

### Ejemplo [#example]

Devuelve la dirección de la primera cuenta de Nexa:

```typescript
HardwareSDK.nexaGetAddress(connectId, deviceId, {
    path: "m/44'/29223'/0'/0/0",
    showOnOneKey: true,
    prefix: "nexa"
});
```

Devuelve un lote de direcciones de varias cuentas de Nexa:

```typescript
HardwareSDK.nexaGetAddress(connectId, deviceId, {
    bundle: [
        { path: "m/44'/29223'/0'/0/0" }, // account 1
        { path: "m/44'/29223'/0'" }, // account 2
        { path: "m/44'/29223'/0'/0/1" }  // account 3
    ]
});
```

### Resultado [#result]

Respuesta de una dirección

```typescript
{
    success: true,
    payload: {
        path: string, // serialized BIP32 path
        address: string,   // address
    }
}
```

Respuesta por lotes de direcciones

```typescript
{
    success: true,
    payload: [
        { path, address }, // account 1
        { path, address }, // account 2
        { path, address }, // account 3
    ]
}
```

Error

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
