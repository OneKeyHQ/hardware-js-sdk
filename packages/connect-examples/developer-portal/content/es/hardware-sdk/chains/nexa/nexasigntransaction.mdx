# nexaSignTransaction

### Requisitos [#requirements]

* Versiones mínimas de firmware
  * Touch: 4.4.0
  * Classic/Mini: 3.2.0

## Nexa: firmar transacción [#nexa-sign-transaction]

Solicita una firma de transacción con la clave derivada de la ruta especificada. El usuario revisa y confirma la solicitud en el dispositivo.

```typescript
const result = await HardwareSDK.nexaSignTransaction(connectId, deviceId, params);
```

### Parámetros [#params]

[**Parámetros comunes opcionales**](/es/hardware-sdk/concepts/common-params)

* `inputs` - _obligatorio_ `Array` entradas de la transacción
  * `path` - _obligatorio_ `string` La longitud mínima del SDK es `3`. [Formato de ruta](/es/hardware-sdk/concepts/common-params#hd-path)
  * `message` - _obligatorio_ `string` Transacción serializada y codificada como cadena hexadecimal.
  * `prefix` - _obligatorio_ `string` Prefijo de dirección de la red prevista. El SDK no proporciona un valor predeterminado; el ejemplo selecciona explícitamente `nexatest`.
### Ejemplos [#examples]

```typescript
const response = await HardwareSDK.nexaSignTransaction(
  connectId,
  deviceId,
  {
    inputs: [
      {
         path: "m/44'/29223'/0'/0/0",
         message: '000578c6c76f10156fbc7ee4a8faa7a4e92b6adadc978abf66ae70f13a03b75d36cd7a6acc0967cc9f2f632f585cb7b4297873858c23233792767fd4ae662ec1093bb13029ce7b1f559ef5e747fcac439f1455a2ec7c5f09b72290795e70665044026cad0dba749a112e0d2ea420fa68e0218453db6bb0744e44eb51edc76af8bb6871190000000000',
         prefix: 'nexatest',
      }
    ],
  }
);
```

Resultado

```typescript
{
  success: true,
  payload: [
    { index: 0, signature: "signed data" }
  ]
}
```

Error

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
