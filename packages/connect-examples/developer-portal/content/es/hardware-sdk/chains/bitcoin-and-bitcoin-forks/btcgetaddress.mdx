# btcGetAddress

## Bitcoin: obtener una dirección [#bitcoin-get-address]

Deriva y devuelve la dirección de la ruta especificada. Cuando `showOnOneKey` es `true`, el usuario debe confirmar la dirección en el dispositivo.

```typescript
const result = await HardwareSDK.btcGetAddress(connectId, deviceId, params);
```

### Parámetros [#params]

[**Parámetros comunes opcionales**](/es/hardware-sdk/concepts/common-params)

#### Una dirección [#single-address]

* `path` - _obligatorio_ `string | Array<number>` La longitud mínima del SDK es `1`. [leer más](/es/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _opcional_ `boolean` Si se muestra la dirección en el dispositivo. El valor predeterminado es `true`.
* `coin` - _opcional_ `string` determina la definición de red especificada en el archivo [coins.json](https://github.com/OneKeyHQ/hardware-js-sdk/blob/onekey/packages/core/src/data/coins/bitcoin.json). Puede usarse `shortcut`, `name` o `label` de la moneda. Si `coin` no se establece, la API intenta obtener la definición de red a partir de `path`.
* `multisig` - _opcional_ MultisigRedeemScriptType, información del script de canje (solo direcciones multifirma)
* `scriptType` - _opcional_ InputScriptType, tipo de script de dirección

#### Varias direcciones [#multiple-addresses]

* `bundle` - matriz de objetos que incluyen `path`, `showOnOneKey`, `coin` como campos

### Obtener distintos tipos de direcciones [#get-different-types-of-addresses]

Los distintos tipos de direcciones BTC requieren parámetros de ruta de derivación diferentes.

| Tipo                | Ruta            | Por ejemplo,                                                          |
| ------------------- | --------------- | ------------------------------------------------------------ |
| Heredada BIP44        | m/44'/0'/x'/x/x | Empieza por "1" y tiene entre 26 y 35 caracteres     |
| SegWit anidado BIP49 | m/49'/0'/x'/x/x | Empieza por "3" y tiene entre 26 y 35 caracteres     |
| SegWit nativo BIP84 | m/84'/0'/x'/x/x | En la red principal empieza por `bc1q`; en la red de pruebas empieza por `tb1q` |
| Taproot BIP86       | m/86'/0'/x'/x/x | En la red principal empieza por `bc1p`; en la red de pruebas empieza por `tb1p`     |

## Ejemplo [#example]

Muestra la tercera dirección de la primera cuenta de Bitcoin:

```typescript
HardwareSDK.btcGetAddress(connectId, deviceId, {
    path: "m/49'/0'/0'/0/2",
    coin: "btc"
});
```

Devuelve un conjunto de direcciones de la primera cuenta de Bitcoin sin mostrarlas en el dispositivo:

```typescript
HardwareSDK.btcGetAddress(connectId, deviceId, {
    bundle: [
        { path: "m/49'/0'/0'/0/0", showOnOneKey: false }, // address 1
        { path: "m/49'/0'/0'/0/1", showOnOneKey: false }, // address 2
        { path: "m/49'/0'/0'/0/2", showOnOneKey: false }  // address 3
    ]
});
```

#### Resultado [#result]

Respuesta de una dirección

```typescript
{
    success: true,
    payload: {
        address: string,     // displayed address
        path: string // serialized BIP32 path
    }
}
```

Respuesta por lotes de direcciones

```typescript
{
    success: true,
    payload: [
        { address: string, path: string }, // address 1
        { address: string, path: string }, // address 2
        { address: string, path: string }, // address 3
    ]
}
```

Error

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
