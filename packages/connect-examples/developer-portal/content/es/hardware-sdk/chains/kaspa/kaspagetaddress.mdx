# kaspaGetAddress

### Requisitos [#requirements]

* Versiones mínimas de firmware
  * Touch: 4.3.0
  * Classic/Mini: 3.0.0

## Kaspa: obtener una dirección [#kaspa-get-address]

Deriva y devuelve la dirección de la ruta especificada. Cuando `showOnOneKey` es `true`, el usuario debe confirmar la dirección en el dispositivo.

```typescript
const result = await HardwareSDK.kaspaGetAddress(connectId, deviceId, params);
```

## Parámetros [#params]

[**Parámetros comunes opcionales**](/es/hardware-sdk/concepts/common-params)

### Una dirección [#single-address]

* `path` - _obligatorio_ `string | Array<number>` La longitud mínima del SDK es `3`. [leer más](/es/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _opcional_ `boolean` Si se muestra la dirección en el dispositivo. El valor predeterminado es `true`.
* `prefix` - _opcional_ `string` Prefijo de dirección. El valor predeterminado es `kaspa`
* `scheme` - _opcional_ `string` Modo del algoritmo de cifrado. El valor predeterminado es `schnorr`

#### Varias direcciones [#multiple-addresses]

* `bundle` - matriz de objetos que incluyen `path`, `showOnOneKey`, `prefix`, y `scheme` como campos

### Ejemplo [#example]

Devuelve la dirección de la primera cuenta de Kaspa:

```typescript
HardwareSDK.kaspaGetAddress(connectId, deviceId, {
    path: "m/44'/111111'/0'/0/0",
    showOnOneKey: true,
    prefix: "kaspa",
    scheme: "schnorr",
});
```

Devuelve un conjunto de direcciones para varias cuentas de Kaspa:

```typescript
HardwareSDK.kaspaGetAddress(connectId, deviceId, {
    bundle: [
        { path: "m/44'/111111'/0'/0/0" }, // account 1
        { path: "m/44'/111111'/0'" }, // account 2
        { path: "m/44'/111111'/0'/0/1" }  // account 3
    ]
});
```

### Resultado [#result]

Respuesta de una dirección

```typescript
{
    success: true,
    payload: {
        path: string, // serialized BIP32 path
        address: string,   // address
    }
}
```

Respuesta por lotes de direcciones

```typescript
{
    success: true,
    payload: [
        { path, address }, // account 1
        { path, address }, // account 2
        { path, address }, // account 3
    ]
}
```

Error

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
