# evmGetPublicKey

## Ethereum: obtener una clave pública [#ethereum-get-public-key]

Devuelve la clave pública derivada de la ruta especificada. Usa `showOnOneKey` para solicitar confirmación en el dispositivo.

```typescript
const result = await HardwareSDK.evmGetPublicKey(connectId, deviceId, params);
```

## Parámetros [#params]

[**Parámetros comunes opcionales**](/es/hardware-sdk/concepts/common-params)

### Una clave pública [#single-public-key]

* `path` - _obligatorio_ `string | Array<number>` La longitud mínima del SDK es `3`. [leer más](/es/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _opcional_ `boolean` Si se muestra la clave pública en el dispositivo. El valor predeterminado es `true`.
* `chainId` - _opcional_ `number` ChainId en ETH es un identificador único de una red Ethereum específica, usado para distinguir distintas versiones de la cadena de bloques. [Referencia](https://github.com/ethereum-lists/chains/tree/master/\_data/chains).

#### Varias claves públicas [#multiple-public-keys]

* `bundle` - matriz de objetos que incluyen `path`, `chainId`, `showOnOneKey` como campos

### Ejemplo [#example]

Devuelve la clave pública de la primera cuenta de Ethereum:

```typescript
HardwareSDK.evmGetPublicKey(connectId, deviceId, {
    path: "m/44'/60'/0'/0/0",
    showOnOneKey: true,
    chainId: 1
});
```

Devuelve un conjunto de claves públicas para varias cuentas de Ethereum:

```typescript
HardwareSDK.evmGetPublicKey(connectId, deviceId, {
    bundle: [
        { path: "m/44'/60'/0'/0/0", chainId: 1 }, // account 1
        { path: "m/44'/60'/1'/0/0", chainId: 1 }, // account 2
        { path: "m/44'/60'/2'/0/0", chainId: 1 }  // account 3
    ]
});
```

### Resultado [#result]

Respuesta de una clave pública

```typescript
{
    success: true,
    payload: {
        path: string, // serialized BIP32 path
        xpub?: string,        // xpub in legacy format
        pub: string, // hexadecimal public key
        publicKey: string, // alias of pub
    }
}
```

[Más información sobre el formato de serialización BIP32](https://github.com/bitcoin/bips/blob/master/bip-0032.mediawiki#Serialization\_format)

Respuesta por lotes de claves públicas

```typescript
{
    success: true,
    payload: [
        { path, xpub, pub }, // account 1
        { path, xpub, pub }, // account 2
        { path, xpub, pub }, // account 3
    ]
}
```

Error

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```

Para solicitudes `bundle` con `useBatch: true`, una ruta por lotes compatible devuelve `{ path, pub, publicKey }` sin `xpub` o `node`. El flujo ordinario devuelve la clave pública extendida y el nodo; no exijas estos campos en una respuesta por lotes.
