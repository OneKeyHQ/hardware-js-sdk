# evmSignTransaction

<span id="ethereum-sign-transaction" />

Solicita una firma confirmada en el dispositivo para una transacción heredada o EIP-1559 (Type 2). El dispositivo deriva la clave a partir de tu ruta BIP32; tu aplicación serializa y difunde el resultado. Los detalles decodificados de la transacción dependen del firmware y de calldata.

```typescript
const result = await HardwareSDK.evmSignTransaction(connectId, deviceId, params);
```

## Antes de llamar [#before-you-call]

- [Inicializa el SDK y selecciona un dispositivo](/es/hardware-sdk/getting-started).

- Obtén el nonce, el gas y las comisiones actuales de la red de destino.

### Campos de la transacción [#transaction-fields]

| Campo | Tipo | Descripción |
| --- | --- | --- |
| `chainId` | `number` | ID de cadena de la red de destino. Va dentro de transaction. |
| `to` | `string` | Dirección de destino; el contrato del token para llamadas ERC-20. |
| `value` | `string` | Importe en wei codificado en hexadecimal. Usa 0x0 para llamadas ERC-20. |
| `nonce` | `string` | Número de transacciones de la cuenta remitente como cantidad hexadecimal. |
| `gasLimit` | `string` | Límite de gas como cantidad hexadecimal. |
| `data` | `string · optional` | Calldata completa codificada en hexadecimal; usa 0x si no hay calldata. |
| `maxFeePerGas` | `string · EIP-1559` | Comisión total máxima por unidad de gas, en wei codificados en hexadecimal. |
| `maxPriorityFeePerGas` | `string · EIP-1559` | Comisión de prioridad máxima por unidad de gas, en wei codificados en hexadecimal. |
| `gasPrice` | `string · Legacy` | Precio del gas heredado, en wei codificados en hexadecimal. |

Esta página cubre `EVMTransaction` y `EVMTransactionEIP1559`. Consulta [Rutas HD](/es/hardware-sdk/concepts/common-params#hd-path) para el formato de rutas. Asegúrate de que el RPC de destino admita el tipo de transacción.

EIP-1559 requiere ambos campos de comisión; el formato heredado usa `gasPrice`. No pases `type: 2` al SDK; selecciona el tipo al serializar la transacción firmada.

## Clear Signing [#clear-signing]

Usa este mismo método para transferencias nativas, transferencias ERC-20, autorizaciones o revocaciones y llamadas a contratos. Para llamadas ERC-20, `to` es el contrato del token y `value` es cero; calldata contiene el destinatario o beneficiario de la autorización y el importe del token. El firmware compatible decodifica automáticamente los formatos reconocidos. No existe un parámetro `clearSigning`, de metadatos de token ni de etiqueta de contrato.

Consulta la [guía de Clear Signing](/es/hardware-sdk/signers/evm#clear-signing) para ver la tabla de entrada/visualización y el comportamiento con contratos desconocidos. Para EIP-712 y firmas de propietarios de Safe, usa [evmSignTypedData](/es/hardware-sdk/chains/ethereum-and-evm/evmsigntypeddata).

## Serializar la transacción firmada [#serialize-the-signed-transaction]

El SDK devuelve una firma; tu aplicación ensambla y difunde la transacción. Este ejemplo usa paquetes de ethers v5. Mantén intactos los campos originales de la transacción después de que el usuario firme.

```typescript
import type { UnsignedTransaction } from '@ethersproject/transactions';
import { TransactionTypes, serialize } from '@ethersproject/transactions';
import { splitSignature } from '@ethersproject/bytes';
import { keccak256 } from '@ethersproject/keccak256';

// Illustrative fee values: populate nonce, gas, and fees from your network.
const transaction = {
  to: '0x7314e0f1c0e28474bdb6be3e2c3e0453255188f8',
  value: '0x0',
  data: '0x',
  chainId: 1,
  nonce: '0x0',
  maxFeePerGas: '0x14',
  maxPriorityFeePerGas: '0x0',
  gasLimit: '0x5208',
};

const result = await HardwareSDK.evmSignTransaction(connectId, deviceId, {
  path: "m/44'/60'/0'/0/0",
  transaction,
});
if (result.success === false) throw new Error(result.payload.error);

const unsignedTx: UnsignedTransaction = {
  ...transaction,
  nonce: Number.parseInt(transaction.nonce, 16),
  type: TransactionTypes.eip1559,
};
const signature = splitSignature({
  v: Number(result.payload.v),
  r: result.payload.r,
  s: result.payload.s,
});
const rawTx = serialize(unsignedTx, signature);
const txid = keccak256(rawTx);
// Submit rawTx using your Ethereum provider after verifying the signed result.
```

Para una transacción heredada, usa `gasPrice` en lugar de los dos campos de comisión EIP-1559 y serialízala como transacción heredada.
