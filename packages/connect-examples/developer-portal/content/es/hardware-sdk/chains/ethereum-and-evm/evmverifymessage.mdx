# evmVerifyMessage

## Ethereum: verificar un mensaje [#ethereum-verify-message]

Verifica un mensaje usando la dirección del firmante y la firma.

```typescript
const result = await HardwareSDK.evmVerifyMessage(connectId, deviceId, params);
```

## Parámetros [#params]

[**Parámetros comunes opcionales**](/es/hardware-sdk/concepts/common-params)

* `address` - _obligatorio_ `string` dirección del firmante. El prefijo "0x" es opcional
* `messageHex` - _obligatorio_ `string` Mensaje firmado codificado como cadena hexadecimal.
* `signature` - _obligatorio_ `string` firma en formato hexadecimal. El prefijo "0x" es opcional
* `chainId` - _opcional_ `number` ChainId en ETH es un identificador único de una red Ethereum específica, usado para distinguir distintas versiones de la cadena de bloques. [Referencia](https://github.com/ethereum-lists/chains/tree/master/_data/chains).

## Ejemplo [#example]

```typescript
HardwareSDK.evmVerifyMessage(connectId, deviceId, {
    address: "0xdA0b608bdb1a4A154325C854607c68950b4F1a34",
    messageHex: "4578616d706c65206d657373616765",
    signature: "11dc86c631ef5d9388c5e245501d571b864af1a717cbbb3ca1f6dacbf330742957242aa52b36bbe7bb46dce6ff0ead0548cc5a5ce76d0aaed166fd40cb3fc6e51c",
    chainId: 1
});
```

## Resultado [#result]

```typescript
{
    success: true,
    payload: {
        message: "Message verified"
    }
}
```

Error

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
