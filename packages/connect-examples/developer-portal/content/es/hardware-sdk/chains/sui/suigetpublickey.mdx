# suiGetPublicKey

## Sui: obtener clave pública [#sui-get-public-key]

Devuelve la clave pública derivada de la ruta especificada. Usa `showOnOneKey` para solicitar confirmación en el dispositivo.

```typescript
const result = await HardwareSDK.suiGetPublicKey(connectId, deviceId, params);
```

## Parámetros [#params]

[**Parámetros comunes opcionales**](/es/hardware-sdk/concepts/common-params)

### Una clave pública [#single-public-key]

* `path` - _obligatorio_ `string | Array<number>` La longitud mínima del SDK es `3`. [Formato de ruta](/es/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _opcional_ `boolean` Si se muestra la clave pública en el dispositivo. El valor predeterminado es `true`.

#### Varias claves públicas [#multiple-public-keys]

* `bundle` - matriz de objetos que incluyen `path`, `showOnOneKey` como campos

### Ejemplo [#example]

Devuelve la clave pública de la primera cuenta de Sui:

```typescript
HardwareSDK.suiGetPublicKey(connectId, deviceId, {
    path: "m/44'/784'/0'/0'/0'",
    showOnOneKey: true
});
```

Devuelve un lote de claves públicas de varias cuentas de Sui:

```typescript
HardwareSDK.suiGetPublicKey(connectId, deviceId, {
    bundle: [
        { path: "m/44'/784'/1'/0'/0'" }, // account 1
        { path: "m/44'/784'/2'/0'/0'" }, // account 2
        { path: "m/44'/784'/3'/0'/0'" }  // account 3
    ]
});
```

### Resultado [#result]

Respuesta de una clave pública

```typescript
{
    success: true,
    payload: {
        path: string, // serialized BIP32 path
        pub: string
    }
}
```


Respuesta por lotes de claves públicas

```typescript
{
    success: true,
    payload: [
        { path: serializedPath, pub }, // account 1
        { path: serializedPath, pub }, // account 2
        { path: serializedPath, pub }, // account 3
    ]
}
```

Error

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
