# Guía de migración

Elige la guía para tu integración actual: actualiza Hardware SDK **1.1.x** a **1.2.x** o migra una conexión OneKey Bridge a WebUSB.

## 1.1.x → 1.2.x [#11x--12x]

- [Actualizar a Hardware SDK 1.2](./from-1x) — `getDeviceState`, `openWalletSession`, Pro 2 / Neo, firmware V4

## Bridge → WebUSB [#bridge--webusb]

Solo si todavía usas OneKey Bridge (`env: 'web'`).

- [De Bridge a WebUSB (hd-common-connect-sdk)](./migrate-bridge-to-common-connect-webusb) — recomendado
- [De Bridge a WebUSB (hd-web-sdk)](./migrate-bridge-to-webusb) — conserva el host del iframe

Proyectos nuevos: [Primeros pasos](/es/hardware-sdk/getting-started) con `@onekeyfe/hd-common-connect-sdk`.
