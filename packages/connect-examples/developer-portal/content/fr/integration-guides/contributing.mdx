# Contribuer

Choisissez le dépôt responsable de la fonctionnalité. Lisez son README, ses consignes de contribution et sa politique de sécurité avant de commencer.

| Domaine | Dépôt |
| --- | --- |

| Hardware SDK et ce portail développeur | [hardware-js-sdk](https://github.com/OneKeyHQ/hardware-js-sdk) |

| Collection GitBook historique | [documentation](https://github.com/OneKeyHQ/docs) |

## Proposer une modification [#propose-a-change]

Pour une nouvelle chaîne ou un changement d’intégration, décrivez l’environnement d’exécution, les méthodes de signature, le format de sérialisation et la prise en charge requise de l’appareil ou du micrologiciel. Les intégrations de portefeuille logiciel et de signature matérielle peuvent relever de dépôts différents. Vérifiez d’abord les issues et pull requests existantes.

## Soumettre une correction [#submit-a-fix]

1. Suivez les consignes de développement du dépôt.
2. Effectuez une modification ciblée et mettez à jour les exemples ou la documentation concernés.
3. Exécutez les vérifications requises.
4. Ouvrez une pull request expliquant le problème, le comportement obtenu et les preuves.

Les signalements de documentation doivent inclure l’URL de la page et l’exemple ou l’affirmation erronés. Pour les échecs d’intégration, utilisez la [liste de vérification des signalements](/fr/troubleshooting#report-an-issue). Pour les failles de sécurité, suivez la politique de sécurité du dépôt concerné au lieu de publier les détails d’exploitation dans une issue.
