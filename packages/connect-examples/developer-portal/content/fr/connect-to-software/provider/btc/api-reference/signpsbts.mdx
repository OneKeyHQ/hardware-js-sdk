# signPsbts


Signer plusieurs PSBT à la fois. Cette méthode parcourt toutes les entrées correspondant à l’adresse actuelle pour les signer.

## Compatibilité des portefeuilles et types d’adresses [#wallet--address-type-compatibility]

| Type de portefeuille     | Modèle          | Types d’adresses pris en charge                |
| --------------- | -------------- | -------------------------------------- |
| Portefeuille logiciel | Tous            | p2wpkh (Segwit natif), p2tr (Taproot) |
| Portefeuille matériel | Pro, Classic1S | p2tr (Taproot)                         |

## Méthode [#method]

```typescript
declare function signPsbts(
    psbtHexs: string[],
    options?: {
        autoFinalized?: boolean;
        toSignInputs?: Array<{
            index: number;
            address?: string;
            publicKey?: string;
            sighashTypes?: number[];
            disableTweakSigner?: boolean;
            useTweakedSigner?: boolean;
        }>;
    },
): Promise<string[]>
```

## Paramètres [#parameters]

* `psbtHexs` — _obligatoire_ `string[]` Tableau de chaînes hexadécimales des PSBT à signer
* `options` — _facultatif_ `object`
  * `autoFinalized` — _facultatif_ `boolean` Indique s’il faut finaliser les PSBT après signature, la valeur par défaut est `true`
  * `toSignInputs` — _facultatif_ `array` Spécifier les entrées à signer
    * `index` — _obligatoire_ `number` Entrée à signer
    * `address` — _facultatif_ `string` Clé privée correspondante à utiliser pour la signature (spécifier address ou publicKey)
    * `publicKey` — _facultatif_ `string` Clé privée correspondante à utiliser pour la signature (spécifier address ou publicKey)
    * `sighashTypes` — _facultatif_ `number[]` Types sighash facultatifs
    * `disableTweakSigner` — _facultatif_ `boolean` La valeur par défaut est `false`. Définissez `true` pour utiliser la clé privée d’origine lors de la signature des entrées Taproot
    * `useTweakedSigner` — _facultatif_ `boolean` Imposer l’utilisation ou non d’un signataire ajusté ; priorité supérieure à `disableTweakSigner`

## Valeur de retour [#returns]

* `Promise<string[]>` Tableau de chaînes hexadécimales des PSBT signées

## Exemple [#example]

```typescript
const provider = (window.$onekey && window.$onekey.btc) || window.unisat;

try {
    const psbtHexs = [
        "70736274ff01007d...",
        "70736274ff01007d..."
    ];

    const signeds = await provider.signPsbts(psbtHexs, {
        autoFinalized: true,
        toSignInputs: [
            {
                index: 0,
                publicKey: "02abc...",
                useTweakedSigner: true
            },
            {
                index: 1,
                address: "bc1p...",
                disableTweakSigner: true
            }
        ]
    });

    console.log(signeds);
} catch (e) {
    console.log(e);
}
```

La signature ne diffuse pas de transaction.
