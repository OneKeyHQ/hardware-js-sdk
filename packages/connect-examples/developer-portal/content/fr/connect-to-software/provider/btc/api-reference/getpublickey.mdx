# getPublicKey

Obtenir la clé publique du compte actuel.

## Méthode [#method]

```typescript
declare function getPublicKey(): Promise<string>;
```

## Réponse [#response]

La clé publique sous forme de chaîne.

## Exemple [#example]

```typescript
const provider = (window.$onekey && window.$onekey.btc) || window.unisat;

const publicKey = await provider.getPublicKey();
```
