# Premiers pas

Détectez le fournisseur et demandez une adresse avant de signer. Utilisez la phrase secrète réseau renvoyée par le réseau sélectionné dans le portefeuille et les données XDR complètes construites par le SDK Stellar.

Découvrez comment détecter le fournisseur Stellar OneKey et demander une adresse Stellar.

<Callout type="warning">
La signature Stellar dépend généralement de la phrase secrète réseau correcte (par exemple Public ou Testnet). Assurez-vous de transmettre la bonne lors de la signature.
</Callout>

---

## Détection du fournisseur [#provider-detection]

```ts
const stellar = window.$onekey?.stellar

if (!stellar?.isOneKey) {
  throw new Error('OneKey Stellar provider not detected')
}
```

---

## Obtenir l’adresse (connexion) [#get-address-connect]

```ts
// Triggers wallet permission / connect flow and returns the address (G...)
const { address } = await stellar.getAddress()
console.log('Address:', address)
```

---

## Obtenir le réseau [#get-network]

```ts
const { network, networkPassphrase } = await stellar.getNetwork()
console.log({ network, networkPassphrase })
```
