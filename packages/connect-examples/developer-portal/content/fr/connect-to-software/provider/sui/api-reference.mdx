# Référence de l’API

Référence des méthodes et types du fournisseur Sui OneKey.

| Méthode | Description |
|--------|-------------|

| `requestPermissions()` | Demander une connexion |

## Types [#types]

### Compte de portefeuille [#wallet-account]

`getAccounts()` renvoie `AccountInfo[]`. Les entrées de signature nécessitent le compte Wallet Standard `WalletAccount`, dont le champ `publicKey` est un tableau d’octets et qui contient également `chains` et `features`. Obtenez-le via `standard:connect` ; ne convertissez pas `AccountInfo` vers `WalletAccount`.

```typescript
import type { WalletAccount, IdentifierString } from '@mysten/wallet-standard'
import type { Transaction } from '@mysten/sui/transactions'

// provider.getAccounts()
interface AccountInfo {
  address: string
  publicKey: string // Hex-encoded public key
}
```

### Entrée de signature et d’exécution d’un bloc de transaction [#sign-and-execute-transaction-block-input]

Le fournisseur injecté actuel ne transmet pas `options` dans `signAndExecuteTransactionBlock`. Interrogez l’empreinte renvoyée avec un client Sui sur la même chaîne pour demander les effets, événements ou changements d’objets.

```typescript
interface SignAndExecuteTransactionBlockInput {
  account: WalletAccount
  chain: IdentifierString
  transactionBlock: Transaction
  options?: {
    showEffects?: boolean
    showEvents?: boolean
    showObjectChanges?: boolean
    showBalanceChanges?: boolean
    showInput?: boolean
    showRawInput?: boolean
  }
}
```

### Sortie de signature d’un bloc de transaction [#sign-transaction-block-output]

```typescript
interface SignTransactionBlockOutput {
  transactionBlockBytes: string
  signature: string
}
```

### Entrée de signature de message personnel [#sign-personal-message-input]

```typescript
interface SignPersonalMessageInput {
  account: WalletAccount
  chain?: IdentifierString
  message: Uint8Array
}
```

### Sortie de signature de message personnel [#sign-personal-message-output]

```typescript
interface SignPersonalMessageOutput {
  signature: string

}
```
