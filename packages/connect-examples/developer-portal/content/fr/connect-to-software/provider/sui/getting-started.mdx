# Premiers pas

Demandez l’autorisation avant de signer, sélectionnez un compte connecté et lisez la chaîne active. Ces exemples utilisent `@mysten/sui@1.28.2`, qui correspond à `@mysten/wallet-standard@0.14.7` accepté par le fournisseur actuel.

Découvrez comment détecter Sui, s’y connecter et interagir avec lui à l’aide du fournisseur OneKey.

<Callout type="info">
OneKey implémente Sui Wallet Standard pour les intégrations compatibles wallet-standard.
</Callout>

---

## Détection du fournisseur [#provider-detection]

```typescript
// Detect OneKey Sui provider
const provider = window.$onekey?.sui

if (!provider) {
  throw new Error('OneKey Sui provider not detected')
}
```

---

## Vérifier les autorisations [#check-permissions]

```typescript
// Check if already connected
const hasPermission = await provider.hasPermissions()

if (hasPermission) {
  const accounts = await provider.getAccounts()
  console.log('Connected accounts:', accounts)
}
```

---

## Demander une connexion [#request-connection]

```typescript
// Request permissions to connect
const result = await provider.requestPermissions()

if (result) {
  const accounts = await provider.getAccounts()
  console.log('Connected:', accounts[0].address)
}
```

## Contexte du compte pour la signature [#account-context-for-signing]

Installez `@mysten/wallet-standard@0.14.7`. La méthode `getAccounts()` du fournisseur injecté renvoie `AccountInfo[]`, et non le `WalletAccount` requis par les méthodes de signature. L’utilitaire suivant obtient le compte complet via Wallet Standard. Appelez-le à partir d’une action utilisateur après l’enregistrement du portefeuille ; gérez les refus et reconnectez-vous après les changements de compte ou de réseau.

```typescript
import { getWallets, isWalletWithRequiredFeatureSet } from '@mysten/wallet-standard'

async function connectSuiAccount() {
  const wallet = getWallets().get().find(wallet => wallet.name === 'OneKey Wallet')
  if (!wallet || !isWalletWithRequiredFeatureSet(wallet)) {
    throw new Error('OneKey Sui Wallet Standard is not available')
  }

  const { accounts } = await wallet.features['standard:connect'].connect()
  const [account] = accounts
  const chain = await provider.getActiveChain()
  if (!account || !chain || !account.chains.includes(chain)) {
    throw new Error('No connected Sui account for the active chain')
  }
  return { account, chain }
}
```

## Obtenir les comptes [#get-accounts]

```typescript
const accounts = await provider.getAccounts()

accounts.forEach(account => {
  console.log({
    address: account.address,     // Sui address
    publicKey: account.publicKey, // Public key (hex string)
  })
})
```

## Obtenir la chaîne active [#get-active-chain]

```typescript
const chain = await provider.getActiveChain()

console.log('Active chain:', chain) // e.g., 'sui:testnet'
```

## Écouteurs d’événements [#event-listeners]

### Écouter les changements de compte [#listen-for-account-changes]

```typescript
provider.onAccountChange((account) => {
  if (account) {
    console.log('Account changed:', account.address)
  } else {
    console.log('Disconnected')
  }
})
```

### Écouter les changements de réseau [#listen-for-network-changes]

```typescript
provider.onNetworkChange((network) => {
  console.log('Network changed:', network)
})
```

## Utilisation avec Sui Wallet Kit [#using-with-sui-wallet-kit]

Cet exemple React utilise les versions compatibles des paquets fixées ci-dessous :

```bash
npm install @mysten/dapp-kit@0.16.0 @mysten/sui@1.28.2 @tanstack/react-query@^5
```

```tsx
import { SuiClientProvider, WalletProvider } from '@mysten/dapp-kit'
import { getFullnodeUrl } from '@mysten/sui/client'
import { QueryClient, QueryClientProvider } from '@tanstack/react-query'

const queryClient = new QueryClient()
const networks = {
  mainnet: { url: getFullnodeUrl('mainnet') },
  testnet: { url: getFullnodeUrl('testnet') },
}

function App() {
  return (
    <QueryClientProvider client={queryClient}>
      <SuiClientProvider networks={networks} defaultNetwork="mainnet">
        <WalletProvider>
          <YourApp />
        </WalletProvider>
      </SuiClientProvider>
    </QueryClientProvider>
  )
}
```

OneKey est automatiquement détecté via Sui Wallet Standard.
