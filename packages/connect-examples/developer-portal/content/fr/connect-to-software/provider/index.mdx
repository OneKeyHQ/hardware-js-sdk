# API du fournisseur

Utilisez le fournisseur de votre chaîne cible pour demander des comptes, signatures et transactions. Chaque chaîne possède ses propres méthodes, encodages et événements ; un exemple de requête Ethereum n’est pas interchangeable avec un exemple Bitcoin ou Solana.

## Ce que vous trouverez ici [#what-this-gives-you]

- **Références par chaîne** : Retrouvez la documentation de connexion, de signature, de transaction et d’événements de chaque fournisseur.
- **Options de connexion** : Utilisez une bibliothèque d’interface de portefeuille pour proposer un sélecteur, ou accédez directement au fournisseur injecté.
- **Conseils d’implémentation** : Vérifiez l’état du réseau et du compte, gérez les demandes rejetées et nettoyez les écouteurs d’événements.

## Chaînes prises en charge [#supported-chains]

- **EVM** : Ethereum, Polygon, BSC, Arbitrum, Optimism, Base, etc.
- **Bitcoin** : BTC, Lightning Network (WebLN)
- **Solana** : SOL
- **Cosmos** : ATOM et chaînes Cosmos SDK
- **Move** : Aptos, Sui
- **Autres** : Stellar, TON, TRON, Polkadot, Cardano, Algorand, Conflux, NEAR, Nostr

Sélectionnez une chaîne dans la barre latérale pour consulter les méthodes détaillées du fournisseur, les processus de signature et les exemples.
