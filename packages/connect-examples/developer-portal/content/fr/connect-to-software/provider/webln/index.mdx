# WebLN

Utilisez le fournisseur WebLN OneKey pour interagir avec les applications compatibles Lightning.

## Liens rapides [#quick-links]

- [Guide](guide)
- [Référence de l’API](api-reference)
- [Événements](event)

## Modèle minimal [#minimal-pattern]

```js
const provider = window.$onekey?.webln
if (!provider) throw new Error('OneKey WebLN provider not detected')

await provider.enable()
const info = await provider.getInfo()
```
