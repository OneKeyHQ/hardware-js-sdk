# Envoi de transactions

Une fois l’application web connectée à OneKey, elle peut envoyer des transactions au nom de l’utilisateur, avec son autorisation.

Pour envoyer une transaction, l’application web doit :

* Créer une ou plusieurs transactions non signées.
* Les faire signer et soumettre au réseau par le portefeuille OneKey de l’utilisateur.

Pour en savoir plus sur la nature des transactions sur Near, nous vous recommandons de consulter la [documentation](https://docs.near.org/tools/near-api) de `near-api-js` ainsi que la documentation officielle [Near](https://docs.near.org/).

[Créer une transaction](/fr/connect-to-software/provider/near/integrating/sending-transactions/create-transaction)

[Signer et envoyer une transaction](/fr/connect-to-software/provider/near/integrating/sending-transactions/sign-and-send-transaction)

Pour signer sans diffuser, utilisez la méthode de signature seule et soumettez la transaction signée depuis votre application.

[Signer une transaction](/fr/connect-to-software/provider/near/integrating/sending-transactions/signing-transaction)
