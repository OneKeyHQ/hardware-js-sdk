# NEAR

Intégrez NEAR Protocol à votre dApp à l’aide du fournisseur NEAR OneKey. Utilisez le SDK du fournisseur et sa version prise en charge de near-api-js pour les méthodes documentées ci-dessous.

## Fonctionnalités [#features]

- Connexion et gestion des comptes
- Signature et envoi de transactions
- Signature de message
- Lecture de l’état du réseau (mainnet/testnet)
- Requêtes RPC via le point de terminaison du réseau sélectionné

## Installation [#installation]

```bash
npm install @onekeyfe/onekey-near-provider near-api-js@^0.44.2
# or
yarn add @onekeyfe/onekey-near-provider near-api-js@^0.44.2
```

## Démarrage rapide [#quick-start]

```typescript
import { OneKeyNearProvider } from '@onekeyfe/onekey-near-provider'

// Create provider instance
const provider = new OneKeyNearProvider()

// Request account access
const accounts = await provider.requestSignIn()
console.log('Connected accounts:', accounts)

// Get current network
const network = await provider.request({ method: 'near_network' })
console.log('Current network:', network)
```
