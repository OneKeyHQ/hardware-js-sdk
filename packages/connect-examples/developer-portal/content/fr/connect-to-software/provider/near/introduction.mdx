# Introduction

[**OneKey**](https://www.onekey.so) est un portefeuille et une extension de navigateur permettant de gérer des actifs numériques et d’accéder à des applications décentralisées sur la blockchain [Near](https://docs.near.org).

Il crée et gère des clés privées pour ses utilisateurs, leur permettant de stocker des fonds et de signer des transactions.

Les applications web peuvent interagir avec le portefeuille de l’extension, par exemple pour demander l’autorisation d’effectuer une transaction.
