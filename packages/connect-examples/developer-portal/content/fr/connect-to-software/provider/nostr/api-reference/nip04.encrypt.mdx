# nip04.encrypt

## Méthode [#method]

```typescript
// provider.nip04.encrypt
(pubkey: string, plaintext: string) => Promise<string>
```

## Réponse [#response]

Renvoie le texte chiffré et l’IV conformément à NIP-04.

## Paramètres [#params]

* `pubkey` — _obligatoire_ `string`  la clé publique du destinataire
* `plaintext` — _obligatoire_ `string` le texte en clair à chiffrer

## Exemple [#example]

```javascript
const provider = (window.$onekey && window.$onekey.nostr) || window.nostr;

const encrypted = await provider.nip04.encrypt(pubkey, "Data to be encrypted")
```
