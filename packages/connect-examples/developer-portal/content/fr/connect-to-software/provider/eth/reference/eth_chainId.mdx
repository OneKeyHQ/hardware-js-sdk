# eth_chainId

Renvoie l’ID de chaîne du réseau actuellement connecté. L’ID de chaîne sert à empêcher les attaques par rejeu entre différents réseaux.

---

## Paramètres [#parameters]

Aucun

---

## Valeur de retour [#returns]

`string` - L’ID de chaîne sous forme de chaîne hexadécimale

---

## Exemple [#example]

```typescript
const chainId = await window.$onekey.ethereum.request({
  method: 'eth_chainId'
})

console.log('Chain ID (hex):', chainId)
console.log('Chain ID (decimal):', parseInt(chainId, 16))
```

### Vérifier le réseau [#check-network]

```typescript
const CHAIN_IDS = {
  ETHEREUM: '0x1',
  POLYGON: '0x89',
  BSC: '0x38',
  ARBITRUM: '0xa4b1',
  OPTIMISM: '0xa',
  BASE: '0x2105'
}

async function checkNetwork() {
  const chainId = await window.$onekey.ethereum.request({
    method: 'eth_chainId'
  })

  switch (chainId) {
    case CHAIN_IDS.ETHEREUM:
      console.log('Connected to Ethereum Mainnet')
      break
    case CHAIN_IDS.POLYGON:
      console.log('Connected to Polygon')
      break
    default:
      console.log('Connected to chain:', parseInt(chainId, 16))
  }

  return chainId
}
```

### Exiger un réseau précis [#require-specific-network]

```typescript
async function requireNetwork(requiredChainId) {
  const chainId = await window.$onekey.ethereum.request({
    method: 'eth_chainId'
  })

  if (chainId !== requiredChainId) {
    try {
      await window.$onekey.ethereum.request({
        method: 'wallet_switchEthereumChain',
        params: [{ chainId: requiredChainId }]
      })
    } catch (error) {
      if (error.code === 4902) {
        throw new Error('Please add this network to your wallet')
      }
      throw error
    }
  }
}

// Usage
await requireNetwork('0x1') // Require Ethereum Mainnet
```

## Remarques [#notes]

- L’ID de chaîne est toujours renvoyé sous forme de chaîne hexadécimale avec `0x` comme préfixe
- Écoutez l’événement `chainChanged` pour détecter les changements de réseau
- Défini par [EIP-695](https://eips.ethereum.org/EIPS/eip-695)

```typescript
window.$onekey.ethereum.on('chainChanged', (chainId) => {
  console.log('Network changed to:', chainId)
  // Recommended: reload the page
  window.location.reload()
})
```
