<Callout type="info">
Toutes les méthodes sont appelées via `window.$onekey.ethereum.request({ method, params })`.
</Callout>

## Méthodes Ethereum standard [#standard-ethereum-methods]

Les méthodes JSON-RPC Ethereum supplémentaires dépendent du réseau connecté et de l’implémentation du portefeuille. Consultez la [spécification JSON-RPC Ethereum](https://ethereum.github.io/execution-apis/) pour la liste complète.

Les méthodes courantes comprennent :
- `eth_blockNumber` - Obtenir le numéro du bloc actuel
- `eth_getBalance` - Obtenir le solde du compte
- `eth_getCode` - Obtenir le code du contrat
- `eth_getLogs` - Obtenir les journaux d’événements
