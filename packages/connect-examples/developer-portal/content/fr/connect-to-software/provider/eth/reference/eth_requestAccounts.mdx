# eth_requestAccounts

Demande à l’utilisateur de fournir une adresse Ethereum pour l’identifier. Cette méthode déclenche une fenêtre de connexion si l’utilisateur n’est pas déjà connecté.

---

## Paramètres [#parameters]

Aucun

---

## Valeur de retour [#returns]

`string[]` - Tableau d’adresses Ethereum. Gérez le cas d’un tableau vide et ne supposez pas un nombre fixe de comptes.

---

## Exemple [#example]

```typescript
const accounts = await window.$onekey.ethereum.request({
  method: 'eth_requestAccounts'
})

console.log('Connected account:', accounts[0])
// "0x742d35Cc6634C0532925a3b844Bc9e7595f..."
```

---

## Erreurs [#errors]

| Code | Message | Description |
|------|---------|-------------|
| 4001 | L’utilisateur a rejeté la demande | L’utilisateur a refusé la demande de connexion |
| -32002 | Demande déjà en cours | Une demande précédente attend encore la réponse de l’utilisateur |

---

## Remarques [#notes]

- Cette méthode doit uniquement être appelée en réponse à une action utilisateur (par exemple, un clic sur un bouton)
- Si l’utilisateur est déjà connecté, cette méthode renvoie les comptes connectés sans afficher de fenêtre
- Équivalent à l’ancienne méthode `ethereum.enable()`
- Défini par [EIP-1102](https://eips.ethereum.org/EIPS/eip-1102)
