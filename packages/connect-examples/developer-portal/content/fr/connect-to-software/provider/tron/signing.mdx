# Signature

Connectez le fournisseur et utilisez l’instance TronWeb associée au même portefeuille. Remplacez les adresses abrégées et les méthodes de contrat par des valeurs valides. Vérifiez le réseau sélectionné avant de préparer une transaction.

Découvrez comment signer des messages sur TRON.

---

## Signer un message V1 (hex) [#sign-message-v1-hex]

Signer des messages encodés en hexadécimal :

```typescript
const message = tronWeb.toHex('Hello TRON!')
const signature = await provider.signMessage(message)

console.log('Signature:', signature)
```

---

## Signer un message V2 (UTF-8) [#sign-message-v2-utf-8]

Signer directement des messages UTF-8 :

```typescript
const message = 'Hello TRON!'
const signature = await provider.signMessageV2(message)

console.log('Signature:', signature)
```

---

## Vérifier la signature [#verify-signature]

```typescript
const message = 'Hello TRON!'
const signature = await provider.signMessageV2(message)

// Verify using TronWeb
const address = await tronWeb.trx.verifyMessageV2(message, signature)
console.log('Signer:', address)
```

---

## Gestion des erreurs [#error-handling]

```typescript
try {
  const result = await provider.request({
    method: 'tron_requestAccounts'
  })

  if (result.code === 4001) {
    console.log('A connection request is already pending')
  } else if (result.code !== 200) {
    console.log('Connection was not approved:', result.message)
  }
} catch (error) {
  console.error('Request failed:', error)
}
```
