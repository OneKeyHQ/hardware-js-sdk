# Solana

Utilisez le fournisseur Solana OneKey dans les applications web.

## Liens rapides [#quick-links]

- [Détecter le fournisseur](detecting-the-provider)
- [Établir une connexion](establishing-a-connection)
- [Envoi d’une transaction](sending-a-transaction)
- [Signature d’un message](signing-a-message)

## Modèle minimal [#minimal-pattern]

```js
// Detect
const provider = window?.$onekey?.solana || window?.solana
if (!provider?.isOneKey) throw new Error('OneKey Solana provider not detected')

// Connect
const { publicKey } = await provider.connect()
console.log(publicKey.toString())
```

## Événements [#events]

- `connect`, `disconnect`, `accountChanged`
