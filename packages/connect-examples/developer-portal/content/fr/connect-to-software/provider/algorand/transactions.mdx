# Transactions

Connectez le fournisseur avant de signer. Les exemples de transaction utilisent les champs de style algosdk 2 `from`/`to` ; adaptez-les à la version majeure du SDK que vous installez. `algodClient`, les adresses et les transactions groupées doivent être préparés avant d’exécuter les extraits. Les exemples de navigateur utilisant `Buffer` nécessitent une importation explicite de `buffer` ou un encodeur base64 équivalent.

Découvrez comment signer et envoyer des transactions sur Algorand.

---

## Signer des transactions (ARC-0001) [#sign-transactions-arc-0001]

Signer une ou plusieurs transactions :

```typescript
import algosdk from 'algosdk'

// Create transaction
const suggestedParams = await algodClient.getTransactionParams().do()

const txn = algosdk.makePaymentTxnWithSuggestedParamsFromObject({
  from: senderAddress,
  to: recipientAddress,
  amount: 1000000, // 1 ALGO (microAlgos)
  suggestedParams,
})

// Prepare for signing
const walletTxns = [{
  txn: Buffer.from(algosdk.encodeUnsignedTransaction(txn)).toString('base64'),
}]

// Sign
const signedTxns = await provider.signTxns(walletTxns)

console.log('Signed transactions:', signedTxns)
```

## Signer plusieurs transactions [#sign-multiple-transactions]

```typescript
// Group transactions
const txns = [txn1, txn2, txn3]
algosdk.assignGroupID(txns)

// Prepare for signing
const walletTxns = txns.map(txn => ({
  txn: Buffer.from(algosdk.encodeUnsignedTransaction(txn)).toString('base64'),
}))

// Sign all
const signedTxns = await provider.signTxns(walletTxns)
```

## Signature partielle (multisignature) [#partial-signing-multi-sig]

```typescript
// Only sign specific transactions in a group
const walletTxns = [
  { txn: encodedTxn1 },
  { txn: encodedTxn2, signers: [] }, // Skip this one
  { txn: encodedTxn3 },
]

const signedTxns = await provider.signTxns(walletTxns)
// signedTxns[1] will be null
```

## Publier des transactions [#post-transactions]

Diffuser des transactions signées :

```typescript
const completeTxns = signedTxns.filter((txn) => txn !== null)
if (completeTxns.length !== signedTxns.length) {
  throw new Error('Complete all required signatures before broadcasting the group')
}
const result = await provider.postTxns(completeTxns)
console.log('Transaction IDs:', result.txnIDs)
```

---

## Signer et publier [#sign-and-post]

Signer et diffuser en une seule étape :

```typescript
const result = await provider.signAndPostTxns(walletTxns)
console.log('Transaction IDs:', result.txnIDs)
```

## API de transaction historique [#legacy-transaction-api]

### Signer une transaction (historique) [#sign-transaction-legacy]

```typescript
// Create transaction as Uint8Array
const txnBytes = algosdk.encodeUnsignedTransaction(txn)

// Sign
const signedTxnBytes = await provider.signTransaction([txnBytes])

// Send
const { txId } = await algodClient.sendRawTransaction(signedTxnBytes[0]).do()
```

```typescript
const result = await provider.signAndSendTransaction([txnBytes])
console.log('Transaction ID:', result.txId)
```

## Exemple complet [#complete-example]

```typescript
import algosdk from 'algosdk'

async function sendAlgo() {
  // Connect
  const provider = window.$onekey?.algo
  if (!provider) throw new Error("OneKey Algorand provider is unavailable")
  const { address } = await provider.connect()

  // Setup client
  const algodClient = new algosdk.Algodv2(
    '',
    'https://mainnet-api.algonode.cloud',
    ''
  )

  // Get params
  const suggestedParams = await algodClient.getTransactionParams().do()

  // Create transaction
  const txn = algosdk.makePaymentTxnWithSuggestedParamsFromObject({
    from: address,
    to: 'RECIPIENT_ADDRESS',
    amount: 1000000, // 1 ALGO
    suggestedParams,
  })

  // Sign
  const walletTxns = [{
    txn: Buffer.from(algosdk.encodeUnsignedTransaction(txn)).toString('base64'),
  }]

  const signedTxns = await provider.signTxns(walletTxns)

  if (!signedTxns[0]) throw new Error("The transaction was not signed")

  // Send
  const { txId } = await algodClient.sendRawTransaction(
    Buffer.from(signedTxns[0], 'base64')
  ).do()

  console.log('Transaction ID:', txId)

  // Wait for confirmation
  await algosdk.waitForConfirmation(algodClient, txId, 4)
  console.log('Confirmed!')
}
```
