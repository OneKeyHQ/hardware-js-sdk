# API de base

Méthodes fondamentales du SDK pour la découverte d’appareils, la gestion des sessions et le traitement des événements.

| [Ouvrir une session de portefeuille](./open-wallet-session) | Ouvrir ou sélectionner le portefeuille standard / caché |
