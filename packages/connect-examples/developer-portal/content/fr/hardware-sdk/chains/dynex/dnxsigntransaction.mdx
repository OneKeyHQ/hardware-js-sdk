# dnxSignTransaction

### Dynex : signer une transaction [#dynex-sign-transaction]

Signe la transaction Dynex donnée avec la clé privée dérivée du chemin BIP32 spécifié. L’utilisateur est invité à confirmer les détails de la transaction sur OneKey.

```typescript
const result = await HardwareSDK.dnxSignTransaction(connectId, deviceId, params);
```

#### Exigences [#requirements]

* Versions minimales du micrologiciel
  * classic : 3.8.0

#### Paramètres [#parameters]

connectId : `string`

* Identifiant unique de la connexion

deviceId : `string`

* Identifiant unique de l’appareil matériel

params : `object`

* path : `string` - Chemin BIP32 (par exemple "m/44'/0'/0'/0/0") \[obligatoire\]
* inputs : `array` - Tableau des entrées de transaction \[obligatoire\]
  * prevIndex : `number` - Indice de la sortie précédente
  * globalIndex : `number` - Indice global
  * txPubkey : `string` - Clé publique de transaction
  * prevOutPubkey : `string` - Clé publique de la sortie précédente
  * amount : `string` - Montant de l’entrée
* toAddress : `string` - Adresse de destination \[obligatoire\]
* amount : `string` - Montant de la transaction \[obligatoire\]
* fee : `string` - Frais de transaction \[obligatoire\]
* paymentIdHex : `string` - ID de paiement facultatif (doit contenir 32 octets)

#### Exemple [#example]

```typescript
const response = await HardwareSDK.dnxSignTransaction('connect1', 'device1', {
    path: "m/44'/0'/0'/0/0",
    inputs: [{
        prevIndex: 0,
        globalIndex: 323,
        txPubkey: "0d708b68003ae5fee4c9f9aad56a8cfdb0a5dcbcdd2e3fc18eb813349457a78c",
        prevOutPubkey: "ff4df9a9fc83e48f2c0242c4d94f3906546a889950bccd8ba4392f3e7886c3a1",
        amount: "1000000000"
    }],
    toAddress: "XwmxTF8FxAy2s5cvtS62oSGxY3fzvDcgo2CiJ6rrpz9te68sApSDs3LQihubFtpsfT5z6NYHZzMKUjavNpTkW46i2dYgHBULG",
    amount: "1000000000",
    fee: "100000",
});
```

#### Valeur de retour [#returns]

Réponse de réussite :

```typescript
{
    success: true,
    payload: {
        path: string,              // BIP32 path used for signing
        txKey: {
            ephemeralTxSecKey: string,  // Transaction secret key
            ephemeralTxPubKey: string   // Transaction public key
        },
        computedKeyImages: string[],    // Array of computed key images
        signatures: string[],           // Array of signatures
        outputKeys: string[]            // Array of output keys
    }
}
```

Réponse d’erreur :

```typescript
{
    success: false,
    payload: {
        error: string,
        code?: string | number
    }
}
```
