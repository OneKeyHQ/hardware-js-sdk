# polkadotGetAddress

## Exigences [#requirements]

* Versions minimales du micrologiciel
  * Touch : 4.3.0
  * Classic/Mini : 3.0.0
* Versions minimales du micrologiciel pour la chaîne Joystream
  * Touch : 4.7.0
  * Classic/Mini : 3.6.0
* Versions minimales du micrologiciel pour la chaîne Manta
  * Touch : 4.9.0
  * Classic/Mini : 3.7.0

## Polkadot : obtenir une adresse [#polkadot-get-address]

Dérive et renvoie l’adresse au chemin spécifié. Utilisez `showOnOneKey` pour demander confirmation sur l’appareil.

```typescript
const result = await HardwareSDK.polkadotGetAddress(connectId, deviceId, params);
```

## Paramètres [#params]

[**Paramètres communs facultatifs**](/fr/hardware-sdk/concepts/common-params)

### Adresse unique [#single-address]

* `path` - _obligatoire_ `string | Array<number>` La longueur minimale du SDK est `3`. [en savoir plus](/fr/hardware-sdk/concepts/common-params#hd-path)
* `prefix` - _obligatoire_ `number` Préfixe d’adresse SS58 ; utilisez `0` pour Polkadot
* `network` - _obligatoire_ `string` Nom du réseau, par exemple `polkadot`
* `showOnOneKey` - _facultatif_ `boolean` Indique s’il faut afficher l’adresse sur l’appareil. Valeur par défaut : `true`.

#### Plusieurs adresses [#multiple-addresses]

* `bundle` - tableau d’objets contenant les champs `path`, `prefix`, `network`, `showOnOneKey`

### Exemple [#example]

Renvoyer l’adresse du premier compte Polkadot :

```typescript
HardwareSDK.polkadotGetAddress(connectId, deviceId, {
    path: "m/44'/354'/0'/0'/0'",
    showOnOneKey: true,
    network: "polkadot",
    prefix: 0
});
```

Renvoyer un lot d’adresses de plusieurs comptes Polkadot :

```typescript
HardwareSDK.polkadotGetAddress(connectId, deviceId, {
    bundle: [
        { path: "m/44'/354'/0'/0'/1'", network: "polkadot", prefix: 0 }, // account 1
        { path: "m/44'/354'/0'/0'/2'", network: "polkadot", prefix: 0 }, // account 2
        { path: "m/44'/354'/0'/0'/3'", network: "polkadot", prefix: 0 }  // account 3
    ]
});
```

### Résultat [#result]

Réponse pour une seule adresse

```typescript
{
    success: true,
    payload: {
        path: string, // serialized BIP32 path
        address: string,   // address
        publicKey: string, // publicKey
    }
}
```

Réponse d’adresses par lot

```typescript
{
    success: true,
    payload: [
        { path, address, publicKey }, // account 1
        { path, address, publicKey }, // account 2
        { path, address, publicKey }, // account 3
    ]
}
```

Erreur

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
