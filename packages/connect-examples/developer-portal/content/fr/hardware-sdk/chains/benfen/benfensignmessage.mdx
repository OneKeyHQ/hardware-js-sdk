# benfenSignMessage

**Exigences**

* Versions minimales du micrologiciel
  * Pro : 4.12.0
  * Classic 1S / Classic 1S Pure : 3.11.0

### Benfen : signer un message [#benfen-sign-message]

Signer un message avec la clé privée dérivée du chemin BIP32 spécifié. L’utilisateur doit confirmer l’action sur l’appareil OneKey.

```typescript
const result = await HardwareSDK.benfenSignMessage(connectId, deviceId,{
  path: "m/44'/728'/0'/0'/0'",
  messageHex: "68656c6c6f" // "hello" in hex
});
```

#### Paramètres [#params]

**Paramètres communs facultatifs**

* `path` - _obligatoire_ `string | Array<number>` La longueur minimale du SDK est `3`. [Format du chemin](/fr/hardware-sdk/concepts/common-params#hd-path)
* `messageHex` - _obligatoire_ `string` Message à signer au format hexadécimal

#### Valeur de retour [#returns]

* `success` - _boolean_ True en cas de réussite
* `payload`
  * `signature` - _string_ Signature au format hexadécimal
  * `address` - _string_ Adresse au format BFC utilisée pour signer

Exemple :

```typescript
const params = {
  path: "m/44'/728'/0'/0'/0'",
  messageHex: "68656c6c6f" // "hello" in hex
};

const response = await HardwareSDK.benfenSignMessage(connectId, deviceId, params);
```

Résultat

```typescript
{
  success: true,
  payload: {
    signature: string,
    address: string,
  }
}
```

Erreur

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
