# benfenGetAddress

### Benfen : obtenir une adresse [#benfen-get-address]

Dérive et renvoie l’adresse au chemin spécifié. Lorsque `showOnOneKey` vaut `true`, l’utilisateur doit confirmer l’adresse sur l’appareil.

**Exigences**

* Versions minimales du micrologiciel
  * Pro : 4.12.0
  * Classic 1S / Classic 1S Pure : 3.11.0

```typescript
const result = await HardwareSDK.benfenGetAddress(connectId, deviceId, params);
```

#### Paramètres [#params]

**Paramètres communs facultatifs**

* `path` - _obligatoire_ `string | Array<number>` La longueur minimale du SDK est `3`. [Format du chemin](/fr/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _facultatif_ `boolean` indique s’il faut afficher l’adresse sur l’appareil

#### Valeur de retour [#returns]

* success : boolean - True en cas de réussite
* payload :
  * address : string - Adresse dérivée au format BFC
  * path : string - Chemin BIP32 utilisé
  * pub?: string - Clé publique si disponible

Exemple :

```typescript
const params = {
  path: "m/44'/728'/0'/0'/0'",
  showOnOneKey: false
};

// Single address
const response = await HardwareSDK.benfenGetAddress(connectId, deviceId, params);

// Batch addresses
const batchParams = {
  bundle: [
    {
      path: "m/44'/728'/0'/0'/0'",
      showOnOneKey: false
    },
    {
      path: "m/44'/728'/1'/0'/0'",
      showOnOneKey: false
    }
  ]
};
const batchResponse = await HardwareSDK.benfenGetAddress(connectId, deviceId, batchParams);
```

**Résultat**

Réponse pour une seule adresse

```typescript
{
    success: true,
    payload: {
        address: string,     // displayed address
        pub?: string,
        path: string // serialized BIP32 path
    }
}
```

Réponse par lot, dans le même ordre que la requête

```typescript
{
    success: true,
    payload: [
        { address: string, pub?: string, path: string }, // account 1
        { address: string, pub?: string, path: string }, // account 2
        { address: string, pub?: string, path: string }  // account 3
    ]
}
```

Erreur

```
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
