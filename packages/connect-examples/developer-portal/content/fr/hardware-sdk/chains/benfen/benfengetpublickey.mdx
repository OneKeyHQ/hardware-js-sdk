# benfenGetPublicKey

Benfen : obtenir une clé publique

Obtenir la clé publique de l’appareil à l’aide d’un chemin BIP32.

**Exigences**

* Versions minimales du micrologiciel
  * Pro : 4.12.0
  * Classic 1S / Classic 1S Pure : 3.11.0

```typescript
const result = await HardwareSDK.benfenGetPublicKey(connectId, deviceId, {
  path: "m/44'/728'/0'/0'/0'",
  showOnOneKey: false
});
```

#### Paramètres [#params]

**Paramètres communs facultatifs**

* `path` - _obligatoire_ `string | Array<number>` La longueur minimale du SDK est `3`. [Format du chemin](/fr/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _facultatif_ `boolean` indique s’il faut afficher la clé publique sur l’appareil

Valeurs de retour :

* success : boolean - True en cas de réussite
* payload :
  * path : string - Chemin BIP32 utilisé
  * pub : string - Clé publique au format hexadécimal

Exemple :

```typescript
const params = {
  path: "m/44'/728'/0'/0'/0'",
  showOnOneKey: false
};

// Single public key
const response = await HardwareSDK.benfenGetPublicKey(connectId, deviceId, params);

// Batch public keys
const batchParams = {
  bundle: [
    {
      path: "m/44'/728'/0'/0'/0'",
      showOnOneKey: false
    },
    {
      path: "m/44'/728'/1'/0'/0'",
      showOnOneKey: false
    }
  ]
};
const batchResponse = await HardwareSDK.benfenGetPublicKey(connectId, deviceId, batchParams);
```
