# kaspaGetAddress

### Exigences [#requirements]

* Versions minimales du micrologiciel
  * Touch : 4.3.0
  * Classic/Mini : 3.0.0

## Kaspa : obtenir une adresse [#kaspa-get-address]

Dérive et renvoie l’adresse au chemin spécifié. Lorsque `showOnOneKey` vaut `true`, l’utilisateur doit confirmer l’adresse sur l’appareil.

```typescript
const result = await HardwareSDK.kaspaGetAddress(connectId, deviceId, params);
```

## Paramètres [#params]

[**Paramètres communs facultatifs**](/fr/hardware-sdk/concepts/common-params)

### Adresse unique [#single-address]

* `path` - _obligatoire_ `string | Array<number>` La longueur minimale du SDK est `3`. [en savoir plus](/fr/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _facultatif_ `boolean` Indique s’il faut afficher l’adresse sur l’appareil. Valeur par défaut : `true`.
* `prefix` - _facultatif_ `string` Préfixe d’adresse. La valeur par défaut est `kaspa`
* `scheme` - _facultatif_ `string` Mode de l’algorithme de chiffrement. La valeur par défaut est `schnorr`

#### Plusieurs adresses [#multiple-addresses]

* `bundle` - tableau d’objets contenant les champs `path`, `showOnOneKey`, `prefix`, et `scheme`

### Exemple [#example]

Renvoyer l’adresse du premier compte Kaspa :

```typescript
HardwareSDK.kaspaGetAddress(connectId, deviceId, {
    path: "m/44'/111111'/0'/0/0",
    showOnOneKey: true,
    prefix: "kaspa",
    scheme: "schnorr",
});
```

Renvoyer un lot d’adresses de plusieurs comptes Kaspa :

```typescript
HardwareSDK.kaspaGetAddress(connectId, deviceId, {
    bundle: [
        { path: "m/44'/111111'/0'/0/0" }, // account 1
        { path: "m/44'/111111'/0'" }, // account 2
        { path: "m/44'/111111'/0'/0/1" }  // account 3
    ]
});
```

### Résultat [#result]

Réponse pour une seule adresse

```typescript
{
    success: true,
    payload: {
        path: string, // serialized BIP32 path
        address: string,   // address
    }
}
```

Réponse d’adresses par lot

```typescript
{
    success: true,
    payload: [
        { path, address }, // account 1
        { path, address }, // account 2
        { path, address }, // account 3
    ]
}
```

Erreur

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
