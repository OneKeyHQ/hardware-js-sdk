# tonGetAddress

### Exigences [#requirements]

* Versions minimales du micrologiciel
  * Touch : 4.10.0

### TON : obtenir une adresse [#ton-get-address]

Dérive et renvoie l’adresse au chemin spécifié. Lorsque `showOnOneKey` vaut `true`, l’utilisateur doit confirmer l’adresse sur l’appareil.

```typescript
const response = await HardwareSDK.tonGetAddress(connectId, deviceId, {
    path: "m/44'/607'/0'",
    showOnOneKey: true,
    walletVersion: 3,
    isBounceable: false,
    isTestnetOnly: false
});
```

#### Paramètres [#params]

[Paramètres communs facultatifs](/fr/hardware-sdk/concepts/common-params)

**Adresse unique**

* `path` - _obligatoire_ `string | Array<number>` La longueur minimale du SDK est `3`. [Format du chemin](/fr/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _facultatif_ `boolean` Indique s’il faut afficher l’adresse sur l’appareil. Valeur par défaut : `true`.
* `walletVersion` - _facultatif_ `TonWalletVersion` Version du portefeuille TON (par défaut : 3)
* `isBounceable` - _facultatif_ `boolean` indique si l’adresse peut recevoir des retours (par défaut : false)
* `isTestnetOnly` - _facultatif_ `boolean` indique s’il faut utiliser le testnet (par défaut : false)

**Plusieurs adresses**

* `bundle` - tableau d’objets contenant les champs `path` et `showOnOneKey`

#### Exemple [#example]

```typescript
// Get single address
const response = await HardwareSDK.tonGetAddress(connectId, deviceId, {
    path: "m/44'/607'/0'",
    showOnOneKey: false,
    walletVersion: 3,
    isBounceable: false,
    isTestnetOnly: false,
});

// Get multiple addresses
const batchResponse = await HardwareSDK.tonGetAddress(connectId, deviceId, {
    bundle: [
        {
            path: "m/44'/607'/0'",
            showOnOneKey: false
        },
        {
            path: "m/44'/607'/1'",
            showOnOneKey: false
        }
    ]
});
```

**Résultat**

Réponse pour une seule adresse

```typescript
{
    success: true,
    payload: {
        address: string,     // displayed address
        publicKey: string,
        path: string // serialized BIP32 path
    }
}
```

Réponse par lot, dans le même ordre que la requête

```typescript
{
    success: true,
    payload: [
        { address: string, publicKey: string, path: string }, // account 1
        { address: string, publicKey: string, path: string }, // account 2
        { address: string, publicKey: string, path: string }  // account 3
    ]
}
```

Erreur

```
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
