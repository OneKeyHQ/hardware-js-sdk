# nexaSignTransaction

### Exigences [#requirements]

* Versions minimales du micrologiciel
  * Touch : 4.4.0
  * Classic/Mini : 3.2.0

## Nexa : signer une transaction [#nexa-sign-transaction]

Demande une signature de transaction avec la clé dérivée du chemin spécifié. L’utilisateur vérifie et confirme la demande sur l’appareil.

```typescript
const result = await HardwareSDK.nexaSignTransaction(connectId, deviceId, params);
```

### Paramètres [#params]

[**Paramètres communs facultatifs**](/fr/hardware-sdk/concepts/common-params)

* `inputs` - _obligatoire_ `Array` entrées de transaction
  * `path` - _obligatoire_ `string` La longueur minimale du SDK est `3`. [Format du chemin](/fr/hardware-sdk/concepts/common-params#hd-path)
  * `message` - _obligatoire_ `string` Transaction sérialisée encodée sous forme de chaîne hexadécimale.
  * `prefix` - _obligatoire_ `string` Préfixe d’adresse du réseau souhaité. Le SDK ne fournit pas de valeur par défaut ; l’exemple sélectionne explicitement `nexatest`.
### Exemples [#examples]

```typescript
const response = await HardwareSDK.nexaSignTransaction(
  connectId,
  deviceId,
  {
    inputs: [
      {
         path: "m/44'/29223'/0'/0/0",
         message: '000578c6c76f10156fbc7ee4a8faa7a4e92b6adadc978abf66ae70f13a03b75d36cd7a6acc0967cc9f2f632f585cb7b4297873858c23233792767fd4ae662ec1093bb13029ce7b1f559ef5e747fcac439f1455a2ec7c5f09b72290795e70665044026cad0dba749a112e0d2ea420fa68e0218453db6bb0744e44eb51edc76af8bb6871190000000000',
         prefix: 'nexatest',
      }
    ],
  }
);
```

Résultat

```typescript
{
  success: true,
  payload: [
    { index: 0, signature: "signed data" }
  ]
}
```

Erreur

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
