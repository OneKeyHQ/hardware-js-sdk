# starcoinVerifyMessage

## Starcoin : vérifier un message [#starcoin-verify-message]

Vérifie un message à l’aide de la clé publique du signataire et de la signature.

ES6

```typescript
const result = await HardwareSDK.starcoinVerifyMessage(connectId, deviceId, params);
```

## Paramètres [#params]

[**Paramètres communs facultatifs**](/fr/hardware-sdk/concepts/common-params)

* `publicKey` - _obligatoire_ `string` publicKey du signataire.
* `messageHex` - _obligatoire_ `string` Message signé encodé sous forme de chaîne hexadécimale.
* `signature` - _obligatoire_ `string` signature au format hexadécimal.

## Exemple [#example]

```typescript
HardwareSDK.starcoinVerifyMessage(connectId, deviceId, {
    publicKey: "cf90aea8962229869bcba527f0cf0de73ad4c22fe27ad2875007e967db7056f5",
    messageHex: "0x6578616d706c65206d657373616765",
    signature: "447d2c3131c32d176106482d8fc780d933f13b37b0f06beee27de5e73a945e8c807f7764d269a196306f53383a26ab632913f4076457e3230b9defafe1c6ba0b",
});
```

## Résultat [#result]

```typescript
{
    success: true,
    payload: {
        message: "Message verified"
    }
}
```

Erreur

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
