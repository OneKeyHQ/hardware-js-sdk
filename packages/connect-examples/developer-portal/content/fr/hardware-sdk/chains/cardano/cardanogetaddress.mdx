# cardanoGetAddress

## Exigences [#requirements]

* Versions minimales du micrologiciel
  * Touch : 4.1.0
  * Classic/Mini : 3.0.0

## Cardano : obtenir une adresse [#cardano-get-address]

Dérive et renvoie une adresse Cardano avec les paramètres d’adresse spécifiés. Lorsque `showOnOneKey` vaut `true`, l’utilisateur doit confirmer l’adresse sur l’appareil.

```typescript
const response = await HardwareSDK.cardanoGetAddress(connectId, deviceId, params)
```

### Paramètres [#params]

[Paramètres communs facultatifs](/fr/hardware-sdk/concepts/common-params)

**Adresse unique**

* `addressParameters` - _obligatoire_ voir la description ci-dessous
* `protocolMagic` - _obligatoire_ `Integer` 764824073 pour Mainnet, 1 pour Preprod Testnet, 2 pour Preview Testnet
* `networkId` - _obligatoire_ `Integer` 1 pour Mainnet, 0 pour Testnet
* `address` - _facultatif_ `string` Adresse attendue, utilisée pour la validation
* `showOnOneKey` - _obligatoire_ `boolean` Indique s’il faut afficher l’adresse sur l’appareil. Valeur par défaut : `true`.
* `derivationType` - _obligatoire_ énumération `CardanoDerivationType`. Sélectionne l’algorithme de dérivation. La valeur par défaut à l’exécution est `ICARUS` (`1`).
* `isCheck` - _facultatif_ `boolean` vérifie uniquement l’adresse de base

**Plusieurs adresses**

* `bundle` - tableau d’objets avec les champs d’une adresse unique

**Paramètres d’adresse**

* `addressType` - _obligatoire_ `CardanoAddressType`/`number` - Utilisez `PROTO.CardanoAddressType` comme énumération.
* `path` - `string | Array<number>` Obligatoire pour les adresses de paiement basées sur une clé ; omettre pour les adresses de paiement/récompense de script. La longueur minimale du SDK, lorsque présent, est `3`.
* `stakingPath` - _facultatif_ `string | Array<number>` La longueur minimale du SDK est `3`. Utilisé pour la dérivation des adresses de base et de récompense
* `stakingKeyHash` - _facultatif_ `string` chaîne hexadécimale du hash de clé de staking. Utilisée pour dériver une adresse de base (comme alternative à `stakingPath`)
* `certificatePointer` - _facultatif_ Objet CardanoCertificatePointer. Doit contenir les champs `blockIndex`, `txIndex` et `certificateIndex` de type `number`. Utilisé pour la dérivation des adresses à pointeur.
* `paymentScriptHash` - _facultatif_ `string` chaîne hexadécimale du hash du script de paiement.
* `stakingScriptHash` - _facultatif_ `string` chaîne hexadécimale du hash du script de staking.

L’API TypeScript actuelle exige explicitement ces champs, même si les valeurs par défaut à l’exécution sont ICARUS et `showOnOneKey: true`.

### Exemple [#example]

Afficher l’adresse Byron du premier compte Cardano :

```javascript
import { PROTO } from "@onekeyfe/hd-core";

HardwareSDK.cardanoGetAddress(connectId, deviceId, {
    addressParameters: {
        addressType: PROTO.CardanoAddressType.BYRON,
        path: "m/44'/1815'/0'/0/0",
    },
    protocolMagic: 764824073,
    networkId: 1,
    derivationType: PROTO.CardanoDerivationType.ICARUS,
    showOnOneKey: true,
});
```

Afficher l’adresse de base du premier compte Cardano :

```javascript
import { PROTO } from "@onekeyfe/hd-core";

HardwareSDK.cardanoGetAddress(connectId, deviceId, {
    addressParameters: {
        addressType: PROTO.CardanoAddressType.BASE,
        path: "m/1852'/1815'/0'/0/0",
        stakingPath: "m/1852'/1815'/0'/2/0",
    },
    protocolMagic: 764824073,
    networkId: 1,
    derivationType: PROTO.CardanoDerivationType.ICARUS,
    showOnOneKey: true,
});
```

Afficher une adresse de base dont la partie paiement est un script :

Renvoyer un lot d’adresses Cardano sans les afficher sur l’appareil :

```javascript
import { PROTO } from "@onekeyfe/hd-core";

HardwareSDK.cardanoGetAddress(connectId, deviceId, {
    bundle: [
        // byron address, account 1, address 1
        {
            addressParameters: {
                addressType: 8,
                path: "m/44'/1815'/0'/0/0",
            },
            protocolMagic: 764824073,
            networkId: 1,
            derivationType: PROTO.CardanoDerivationType.ICARUS,
            showOnOneKey: false,
        },
        // base address with staking key hash, account 1, address 1
        {
            addressParameters: {
                addressType: 0,
                path: "m/1852'/1815'/0'/0/0",
                stakingKeyHash: '1bc428e4720702ebd5dab4fb175324c192dc9bb76cc5da956e3c8dff',
            },
            protocolMagic: 764824073,
            networkId: 1,
            derivationType: PROTO.CardanoDerivationType.ICARUS,
            showOnOneKey: false,
        },
        // byron address, account 2, address 3, testnet
        {
            addressParameters: {
                addressType: 8,
                path: "m/44'/1815'/1'/0/2",
            },
            protocolMagic: 1,
            networkId: 0,
            derivationType: PROTO.CardanoDerivationType.ICARUS,
            showOnOneKey: false,
        },
    ],
});
```
