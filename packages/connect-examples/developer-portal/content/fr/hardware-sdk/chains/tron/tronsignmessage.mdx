# tronSignMessage

## TRON : signer un message <a href="#ethereum-sign-message" id="ethereum-sign-message"></a> [#tron-sign-message-]

Demande une signature de message avec la clé dérivée du chemin spécifié.

```typescript
const result = await HardwareSDK.tronSignMessage(connectId, deviceId, params);
```

### Paramètres [#params]

[**Paramètres communs facultatifs**](/fr/hardware-sdk/concepts/common-params)

* `path` - _obligatoire_ `string | Array<number>` La longueur minimale du SDK est `3`. [Format du chemin](/fr/hardware-sdk/concepts/common-params#hd-path)
* `messageHex` - _obligatoire_ `string` Message à signer, encodé sous forme de chaîne hexadécimale.

* `messageType` - `"V2"`. Transmettez cette valeur explicitement : l’environnement d’exécution actuel rejette les valeurs omises et les anciennes requêtes `"V1"`. Le type public inclut toujours les deux valeurs.

### Exemple [#example]

```typescript
// Original message
const message = "Hello World";

// Convert to hex
const messageHex = Buffer.from(message).toString('hex');

HardwareSDK.tronSignMessage(connectId, deviceId, {
    path: "m/44'/195'/0'/0/0",
    messageHex,
    messageType: 'V2'
});
```

Résultat

```typescript
{
    success: true,
    payload: {
        signature: string;
        address: string;
    }
}
```

Erreur

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
