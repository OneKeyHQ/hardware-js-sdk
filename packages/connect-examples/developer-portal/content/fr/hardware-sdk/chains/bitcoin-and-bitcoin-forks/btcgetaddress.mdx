# btcGetAddress

## Bitcoin : obtenir une adresse [#bitcoin-get-address]

Dérive et renvoie l’adresse au chemin spécifié. Lorsque `showOnOneKey` vaut `true`, l’utilisateur doit confirmer l’adresse sur l’appareil.

```typescript
const result = await HardwareSDK.btcGetAddress(connectId, deviceId, params);
```

### Paramètres [#params]

[**Paramètres communs facultatifs**](/fr/hardware-sdk/concepts/common-params)

#### Adresse unique [#single-address]

* `path` - _obligatoire_ `string | Array<number>` La longueur minimale du SDK est `1`. [en savoir plus](/fr/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _facultatif_ `boolean` Indique s’il faut afficher l’adresse sur l’appareil. Valeur par défaut : `true`.
* `coin` - _facultatif_ `string` détermine la définition du réseau spécifiée dans le fichier [coins.json](https://github.com/OneKeyHQ/hardware-js-sdk/blob/onekey/packages/core/src/data/coins/bitcoin.json). Les champs `shortcut`, `name` ou `label` de la monnaie peuvent être utilisés. Si `coin` n’est pas défini, l’API tente d’obtenir la définition du réseau depuis `path`.
* `multisig` - _facultatif_ MultisigRedeemScriptType, informations du script de rachat (adresses multisignatures uniquement)
* `scriptType` - _facultatif_ InputScriptType, type de script d’adresse

#### Plusieurs adresses [#multiple-addresses]

* `bundle` - tableau d’objets contenant les champs `path`, `showOnOneKey`, `coin`

### Obtenir différents types d’adresses [#get-different-types-of-addresses]

Les différents types d’adresses BTC nécessitent des paramètres de chemin de dérivation différents.

| Type                | Chemin            | Ex.                                                          |
| ------------------- | --------------- | ------------------------------------------------------------ |
| Historique BIP44        | m/44'/0'/x'/x/x | Commence par "1" et comporte de 26 à 35 caractères     |
| SegWit imbriqué BIP49 | m/49'/0'/x'/x/x | Commence par "3" et comporte de 26 à 35 caractères     |
| SegWit natif BIP84 | m/84'/0'/x'/x/x | Mainnet commence par `bc1q` ; testnet commence par `tb1q` |
| Taproot BIP86       | m/86'/0'/x'/x/x | Mainnet commence par `bc1p` ; testnet commence par `tb1p`     |

## Exemple [#example]

Afficher la troisième adresse du premier compte bitcoin :

```typescript
HardwareSDK.btcGetAddress(connectId, deviceId, {
    path: "m/49'/0'/0'/0/2",
    coin: "btc"
});
```

Renvoyer un lot d’adresses du premier compte bitcoin sans les afficher sur l’appareil :

```typescript
HardwareSDK.btcGetAddress(connectId, deviceId, {
    bundle: [
        { path: "m/49'/0'/0'/0/0", showOnOneKey: false }, // address 1
        { path: "m/49'/0'/0'/0/1", showOnOneKey: false }, // address 2
        { path: "m/49'/0'/0'/0/2", showOnOneKey: false }  // address 3
    ]
});
```

#### Résultat [#result]

Réponse pour une seule adresse

```typescript
{
    success: true,
    payload: {
        address: string,     // displayed address
        path: string // serialized BIP32 path
    }
}
```

Réponse d’adresses par lot

```typescript
{
    success: true,
    payload: [
        { address: string, path: string }, // address 1
        { address: string, path: string }, // address 2
        { address: string, path: string }, // address 3
    ]
}
```

Erreur

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
