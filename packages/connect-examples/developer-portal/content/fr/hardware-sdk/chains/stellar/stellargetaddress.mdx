# stellarGetAddress

## Stellar : obtenir une adresse [#stellar-get-address]

Dérive et renvoie l’adresse au chemin spécifié. Lorsque `showOnOneKey` vaut `true`, l’utilisateur doit confirmer l’adresse sur l’appareil.

```typescript
const response = await HardwareSDK.stellarGetAddress(connectId, deviceId, params)
```

### Paramètres [#params]

[Paramètres communs facultatifs](/fr/hardware-sdk/concepts/common-params)

**Adresse unique**

* `path` - _obligatoire_ `string | Array<number>`  Un chemin de compte Stellar entièrement renforcé, tel que `m/44'/148'/0'`. [plus d’informations](/fr/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _facultatif_ `boolean` Indique s’il faut afficher l’adresse sur l’appareil. Valeur par défaut : `true`.

**Plusieurs adresses**

* `bundle` - tableau d’objets contenant les champs `path` et `showOnOneKey`

#### Exemple [#example]

Afficher l’adresse du premier compte stellar :

```typescript
HardwareSDK.stellarGetAddress(connectId, deviceId, {
    path: "m/44'/148'/0'"
});
```

Renvoyer un lot d’adresses stellar sans les afficher sur l’appareil :

```typescript
HardwareSDK.stellarGetAddress(connectId, deviceId, {
    bundle: [
        { path: "m/44'/148'/0'", showOnOneKey: false }, // account 1
        { path: "m/44'/148'/1'", showOnOneKey: false }, // account 2
        { path: "m/44'/148'/2'", showOnOneKey: false }  // account 3
    ]
});
```

#### Résultat [#result]

Réponse pour une seule adresse

```typescript
{
    success: true,
    payload: {
        address: string,     // displayed address
        path: string // serialized BIP32 path
    }
}
```

Réponse par lot, dans le même ordre que la requête

```typescript
{
    success: true,
    payload: [
        { address: string, path: string }, // account 1
        { address: string, path: string }, // account 2
        { address: string, path: string }  // account 3
    ]
}
```

Erreur

```
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
