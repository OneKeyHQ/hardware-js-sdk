# nostrGetPublicKey

### Exigences [#requirements]

* Versions minimales du micrologiciel exigées par le SDK
  * Touch / Pro (`model_touch`): 4.7.0
  * Classic / Classic1s / Classic Pure / Mini (`model_mini`): 3.6.0

## Nostr : obtenir publicKey [#nostr-get-publickey]

Renvoie la clé publique dérivée du chemin spécifié. Utilisez `showOnOneKey` pour demander confirmation sur l’appareil.

```typescript
const result = await HardwareSDK.nostrGetPublicKey(connectId, deviceId, params);
```

## Paramètres [#params]

[**Paramètres communs facultatifs**](/fr/hardware-sdk/concepts/common-params)

### Clé publique unique [#single-public-key]

* `path` - _obligatoire_ `string | Array<number>` La longueur minimale du SDK est `1`. [en savoir plus](/fr/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _facultatif_ `boolean` Indique s’il faut afficher la clé publique sur l’appareil. Valeur par défaut : `true`.

#### Plusieurs clés publiques [#multiple-public-keys]

* `bundle` - tableau d’objets contenant les champs `path`, `showOnOneKey`

### Exemple [#example]

Renvoyer la clé publique de la première clé Nostr :

```typescript
HardwareSDK.nostrGetPublicKey(connectId, deviceId, {
    path: "m/44'/1237'/0'/0/0",
    showOnOneKey: true,
});
```

Renvoyer un lot de clés publiques de plusieurs clés Nostr :

```typescript
HardwareSDK.nostrGetPublicKey(connectId, deviceId, {
    bundle: [
        { path: "m/44'/1237'/0'/0/0" }, // account 1
        { path: "m/44'/1237'/0'" }, // account 2
        { path: "m/44'/1237'/0'/0/1" }  // account 3
    ]
});
```

### Résultat [#result]

Réponse pour une seule clé publique

```typescript
{
    success: true,
    payload: {
        path: string, // serialized BIP32 path
        pub?: string, // public key in hexadecimal
        publickey?: string, // legacy runtime alias
        npub?: string,        // npub
    }
}
```

Réponse de clés publiques par lot

```typescript
{
    success: true,
    payload: [
        { path, pub, publickey, npub }, // account 1
        { path, pub, publickey, npub }, // account 2
        { path, pub, publickey, npub }, // account 3
    ]
}
```

Erreur

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```

Utilisez `pub` pour la clé publique. L’environnement d’exécution renvoie également l’ancien alias `publickey` ; le nom facultatif `publicKey` de la déclaration actuelle ne décrit pas cet alias.
