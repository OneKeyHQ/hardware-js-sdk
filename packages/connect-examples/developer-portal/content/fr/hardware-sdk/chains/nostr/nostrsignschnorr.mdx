# nostrSignSchnorr

### Exigences [#requirements]

Le SDK actuel déclare ces contraintes de micrologiciel : `model_touch` ≥ 4.7.0 et `model_mini` ≥ 3.6.0. Il s’agit de clés de plages du SDK ; confirmez la correspondance des modèles d’appareils et la prise en charge des micrologiciels publiés pour votre intégration.

## Nostr : signer en Schnorr [#nostr-sign-schnorr]

Demande une signature Schnorr du hash fourni avec la clé au chemin spécifié. L’utilisateur confirme la demande sur l’appareil.

```typescript
const result = await HardwareSDK.nostrSignSchnorr(connectId, deviceId, params);
```

### Paramètres [#params]

[**Paramètres communs facultatifs**](/fr/hardware-sdk/concepts/common-params)

* `path` - _obligatoire_ `string | Array<number>` La longueur minimale du SDK est `5`. [en savoir plus](/fr/hardware-sdk/concepts/common-params#hd-path)
* `hash` - _obligatoire_ `string`. Un hash de 32 octets encodé en hexadécimal.

### Exemples [#examples]

```typescript
const response = await HardwareSDK.nostrSignSchnorr(
  connectId,
  deviceId,
  {
    path: "m/44'/1237'/0'/0/0",
    hash: '2118c65161c7d68b4bdbe1374f658532670057ab1bb0c99937d0ff7cff45cb5e',
  }
);
```

Résultat

```typescript
{
  success: true,
  payload: {
    path: string;
    rawHash: string,
    signature: string,
  }
}
```

Erreur

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
