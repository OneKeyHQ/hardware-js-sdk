# scdoSignMessage

#### Exigences [#requirements]

* Versions minimales du micrologiciel
  * Touch : 4.10.0

#### SCDO : signer un message [#scdo-sign-message]

Signe un message avec la clé privée dérivée du chemin BIP32 spécifié.

```typescript
// Original message
const message = "Hello World";

// Convert to hex
const messageHex = Buffer.from(message).toString('hex');

const response = await HardwareSDK.scdoSignMessage(connectId, deviceId, {
    path: "m/44'/541'/0'/0/0",
    messageHex: messageHex
});
```

**Paramètres**

Paramètres communs facultatifs

* `path` - _obligatoire_ `string | Array<number>` La longueur minimale du SDK est `3`. [Format du chemin](/fr/hardware-sdk/concepts/common-params#hd-path)
* `messageHex` - _obligatoire_ `string` message à signer au format hexadécimal

**Exemple**

```typescript
// Original message
const message = "Hello World";

// Convert to hex
const messageHex = Buffer.from(message).toString('hex');

const response = await HardwareSDK.scdoSignMessage(connectId, deviceId, {
    path: "m/44'/541'/0'/0/0",
    messageHex,
});
```

Résultat

```typescript
{
    success: true,
    payload: {
        signature: string,
        address: string
    }
}
```

Erreur

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number  // error code
    }
}
```
