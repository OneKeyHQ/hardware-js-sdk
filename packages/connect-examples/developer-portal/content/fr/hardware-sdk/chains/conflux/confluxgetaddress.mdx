# confluxGetAddress

## Exigences [#requirements]

* Versions minimales du micrologiciel
  * Touch : 3.0.0
  * Classic/Mini : 2.4.0

## Conflux : obtenir une adresse [#conflux-get-address]

Dérive et renvoie l’adresse au chemin spécifié. Lorsque `showOnOneKey` vaut `true`, l’utilisateur doit confirmer l’adresse sur l’appareil.

```typescript
const response = await HardwareSDK.confluxGetAddress(connectId, deviceId, params)
```

### Paramètres [#params]

[Paramètres communs facultatifs](/fr/hardware-sdk/concepts/common-params)

**Adresse unique**

* `path` - _obligatoire_ `string | Array<number>`  La longueur minimale du SDK est `3`. [plus d’informations](/fr/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _facultatif_ `boolean` Indique s’il faut afficher l’adresse sur l’appareil. Valeur par défaut : `true`.
* `chainId` - _facultatif  `number`_ identifiant de chaîne, la valeur par défaut est `1029`.

**Plusieurs adresses**

* `bundle` - tableau d’objets contenant les champs `path` et `showOnOneKey`

#### Exemple [#example]

Afficher l’adresse du premier compte conflux :

```typescript
HardwareSDK.confluxGetAddress(connectId, deviceId, {
    path: "m/44'/503'/0'/0/0",
    chainId: 1029
});
```

Renvoyer un lot d’adresses conflux sans les afficher sur l’appareil :

```typescript
HardwareSDK.confluxGetAddress(connectId, deviceId, {
    bundle: [
        { path: "m/44'/503'/0'/0/0", chainId: 1029, showOnOneKey: false }, // account 1
        { path: "m/44'/503'/1'/0/0", chainId: 1029, showOnOneKey: false }, // account 2
        { path: "m/44'/503'/2'/0/0", chainId: 1029, showOnOneKey: false }  // account 3
    ]
});
```

#### Résultat [#result]

Réponse pour une seule adresse

```typescript
{
    success: true,
    payload: {
        address: string,     // displayed address
        path: string // serialized BIP32 path
    }
}
```

Réponse par lot, dans le même ordre que la requête

```typescript
{
    success: true,
    payload: [
        { address: string, path: string }, // account 1
        { address: string, path: string }, // account 2
        { address: string, path: string }  // account 3
    ]
}
```

Erreur

```
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
