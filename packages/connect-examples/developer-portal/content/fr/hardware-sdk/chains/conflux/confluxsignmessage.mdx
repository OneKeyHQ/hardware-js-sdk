# confluxSignMessage

## Exigences [#requirements]

* Versions minimales du micrologiciel
  * Touch : 3.0.0
  * Classic/Mini : 2.4.0

## Conflux : signer un message <a href="#ethereum-sign-message" id="ethereum-sign-message"></a> [#conflux-sign-message-]

Demande une signature de message avec la clé dérivée du chemin spécifié.

```typescript
const result = await HardwareSDK.confluxSignMessage(connectId, deviceId, params);
```

### Paramètres [#params]

[**Paramètres communs facultatifs**](/fr/hardware-sdk/concepts/common-params)

* `path` - _obligatoire_ `string | Array<number>` La longueur minimale du SDK est `3`. [Format du chemin](/fr/hardware-sdk/concepts/common-params#hd-path)
* `messageHex` - _obligatoire_ `string` Message à signer, encodé sous forme de chaîne hexadécimale.

### Exemple [#example]

```typescript
// Original message
const message = "Hello World";

// Convert to hex
const messageHex = Buffer.from(message).toString('hex');

HardwareSDK.confluxSignMessage(connectId, deviceId, {
    path: "m/44'/503'/0'/0/0",
    messageHex
});
```

Résultat

```typescript
{
    success: true,
    payload: {
        signature: string;
        address: string;
    }
}
```

Erreur

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
