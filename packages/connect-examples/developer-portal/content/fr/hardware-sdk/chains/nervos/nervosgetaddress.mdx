# nervosGetAddress

### Nervos : obtenir une adresse [#nervos-get-address]

Dérive et renvoie l’adresse au chemin spécifié. Lorsque `showOnOneKey` vaut `true`, l’utilisateur doit confirmer l’adresse sur l’appareil.

```typescript
const result = await HardwareSDK.nervosGetAddress(connectId, deviceId, params);
```

#### Exigences [#requirements]

* Versions minimales du micrologiciel
  * Touch : 4.9.0
  * mini : 3.7.0

#### Paramètres [#parameters]

connectId : `string`

* Identifiant unique de la connexion

deviceId : `string`

* Identifiant unique de l’appareil matériel

params : `object`

* path : _obligatoire_ `string` - Chemin BIP32 de l’adresse demandée (par exemple "m/44'/309'/0'/0/0")
* network : _obligatoire_`string` - Nom du réseau (par exemple "ckb")
* showOnOneKey : _facultatif_ `boolean` - Indique s’il faut afficher l’adresse sur l’appareil

#### Exemple [#example]

```typescript
const response = await HardwareSDK.nervosGetAddress('connect1', 'device1', {
    path: "m/44'/309'/0'/0/0",
    showOnOneKey: true,
    network: "ckb"
});

if (response.success === false) throw new Error(response.payload.error);
console.log(response.payload.address);
```

#### Valeur de retour [#returns]

Renvoie une Promise qui se résout en :

```typescript
{
    success: true,
    payload: {
        address: string,     // Nervos address
        path: string  // BIP32 path used for derivation
    }
}
```

Réponse d’erreur :

```typescript
{
    success: false,
    payload: {
        error: string,  // Error message
        code?: string | number    // Error code
    }
}
```
