# Intégrations historiques

Utilisez cette section pour maintenir une ancienne intégration. Ces références expliquent les interfaces historiques et leurs alternatives actuelles ; elles ne certifient pas leur prise en charge dans une version actuelle du portefeuille, du SDK ou du micrologiciel.

- [OneKey Bridge](./bridge) : vérifications historiques du pont de bureau et parcours de migration vers WebUSB.
- [Aptos WalletConnect v1](./aptos-walletconnect) : méthodes personnalisées historiques et parcours actuel d’intégration navigateur.
- [API firmwareUpdate d’origine](./firmware-update) : différences entre l’ancienne API et les méthodes versionnées de micrologiciel.

Pour les nouvelles intégrations, [commencez ici](/fr/getting-started). L’initialisation et l’effacement de l’appareil sont traités séparément dans [gestion des appareils](/fr/integration-guides/device-management).
