# React Hooks

Typsichere React Hooks für Ethereum. Erstellen Sie Ihre eigene Wallet-Verbindungsoberfläche mit voller Kontrolle über das Nutzererlebnis.

<Callout>
**Ideal für individuelle Oberflächen.** Verwenden Sie React Hooks, wenn Sie Ihren eigenen Wallet-Verbindungsablauf gestalten möchten.
</Callout>

## Wann verwenden [#when-to-use]

Verwenden Sie React Hooks, wenn Sie:
- Volle Kontrolle über die Wallet-Verbindungsoberfläche benötigen
- Typsichere Hooks für Ethereum-Interaktionen wünschen
- Eine React-Anwendung entwickeln
- Keinen vorgefertigten Wallet-Auswahldialog benötigen

---

## Kurzes Beispiel [#quick-example]

Richten Sie `WagmiProvider` und `QueryClientProvider` mithilfe der [wagmi-Anleitung](/de/connect-to-software/react-hooks/wagmi) zuerst ein. Diese Komponente verwendet die konfigurierten Konnektoren.

```tsx
import { useAccount, useConnect, useDisconnect } from 'wagmi'

function ConnectButton() {
  const { address, isConnected } = useAccount()
  const { connect, connectors, isPending, error } = useConnect()
  const { disconnect } = useDisconnect()

  if (isConnected) {
    return (
      <div>
        <p>{address}</p>
        <button onClick={() => disconnect()}>Disconnect</button>
      </div>
    )
  }

  return (
    <div>
      {connectors.map((connector) => (
        <button key={connector.uid} disabled={isPending} onClick={() => connect({ connector })}>
          Connect {connector.name}
        </button>
      ))}
      {error && <p role="alert">{error.message}</p>}
    </div>
  )
}
```
