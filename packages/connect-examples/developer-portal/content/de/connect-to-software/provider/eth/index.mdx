# Ethereum / EVM

Verwenden Sie den injizierten EIP-1193-Provider, um EVM-dApps mit OneKey zu erstellen. Alle EVM-kompatiblen Chains (Ethereum, Polygon, BSC, Arbitrum, Optimism, Base usw.) verwenden denselben Provider.

---

## Provider erkennen [#provider-detection]

### EIP-6963 (empfohlen) [#eip-6963-recommended]

Moderne Erkennung mehrerer Wallets ohne Konflikte:

```typescript
let onekeyProvider = null
const onAnnounce = (event) => {
  if (event.detail.info.rdns === 'so.onekey.app.wallet') {
    onekeyProvider = event.detail.provider
  }
}
window.addEventListener('eip6963:announceProvider', onAnnounce)
window.dispatchEvent(new Event('eip6963:requestProvider'))

// Call from your Connect button after the user selects OneKey.
async function connectOneKey() {
  if (!onekeyProvider) throw new Error('OneKey has not announced a provider yet')
  return onekeyProvider.request({ method: 'eth_requestAccounts' })
}
// On component cleanup:
// window.removeEventListener('eip6963:announceProvider', onAnnounce)
```

### Direkter Zugriff (Ausweichlösung) [#direct-access-fallback]

```typescript
const provider = window.$onekey?.ethereum
if (!provider) throw new Error('OneKey not detected')

const accounts = await provider.request({ method: 'eth_requestAccounts' })
```

## Ereignisse [#events]

```typescript
// Account changed
provider.on('accountsChanged', (accounts) => {
  console.log('Account:', accounts[0])
})

// Network changed
provider.on('chainChanged', (chainId) => {
  console.log('Chain:', chainId)
  window.location.reload() // Recommended
})

// Connected
provider.on('connect', (info) => {
  console.log('Connected to chain:', info.chainId)
})
```

## Fehlercodes [#error-codes]

| Code | Beschreibung | Lösung |
|------|-------------|----------|
| 4001 | Vom Nutzer abgelehnt | Ablehnung angemessen behandeln |
| 4902 | Unbekannte Chain | Chain hinzufügen mit `wallet_addEthereumChain` |
| -32602 | Ungültige Parameter | Verwenden Sie `0x`-präfixierte Hex-Zeichenfolgen |
| -32603 | Interner Fehler | Anfrageformat prüfen |
