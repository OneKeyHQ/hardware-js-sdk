# JSON-RPC-Referenz

Referenz gängiger Ethereum-JSON-RPC- und Wallet-Methoden für die Verwendung mit OneKey.

<Callout type="info">
Alle Methoden werden aufgerufen über `window.$onekey.ethereum.request({ method, params })`.
</Callout>

## Standardmäßige Ethereum-Methoden [#standard-ethereum-methods]

Weitere Ethereum-JSON-RPC-Methoden hängen vom verbundenen Netzwerk und der Wallet-Implementierung ab. Die vollständige Liste finden Sie in der [Ethereum-JSON-RPC-Spezifikation](https://ethereum.github.io/execution-apis/).

Häufige Methoden sind:
- `eth_blockNumber` - Aktuelle Blocknummer abrufen
- `eth_getBalance` - Kontoguthaben abrufen
- `eth_getCode` - Vertragscode abrufen
- `eth_getLogs` - Ereignisprotokolle abrufen
