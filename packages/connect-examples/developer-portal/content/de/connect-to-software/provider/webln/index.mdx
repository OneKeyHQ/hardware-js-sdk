# WebLN

Verwenden Sie den WebLN-Provider von OneKey, um mit Lightning-fähigen Apps zu interagieren.

## Direktlinks [#quick-links]

- [Anleitung](guide)
- [API-Referenz](api-reference)
- [Ereignisse](event)

## Minimales Muster [#minimal-pattern]

```js
const provider = window.$onekey?.webln
if (!provider) throw new Error('OneKey WebLN provider not detected')

await provider.enable()
const info = await provider.getInfo()
```

## Ereignisse [#events]

- Siehe [Ereignisse](event) zu Einschränkungen bei Benachrichtigungen

## Häufige Fehler [#common-errors]

- 4001: vom Nutzer abgelehnt
- Ungültige Parameter/Daten: auf korrekte Rechnungs-/Nachrichtenformate achten
