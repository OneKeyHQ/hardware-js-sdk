# makeInvoice

Den Nutzer auffordern, eine Rechnung zur Verwendung durch die Web-App zu erstellen. Dies gibt eine [BOLT-11](https://github.com/lightningnetwork/lightning-rfc/blob/master/11-payment-encoding.md) -Rechnung zurück. Rechnungen können in mehreren Formen angefordert werden:

* Durch Angabe eines ausdrücklichen `amount` sollte der Provider des Nutzers sicherstellen, dass der Nutzer eine Rechnung mit einem bestimmten Betrag erstellt
* Durch Angabe eines `minimumAmount` und / oder `maximumAmount` sollte der Provider des Nutzers sicherstellen, dass der Nutzer eine Rechnung erstellt, deren Betragsfeld durch diesen Betrag begrenzt ist
* Wenn kein ausdrücklicher `amount` gesetzt ist, kann der Nutzer einen Betrag innerhalb der angeforderten Grenzen wählen.

Beträge werden in Satoshis angegeben. JavaScript-Zahlen stellen Ganzzahlen nur exakt dar bis `Number.MAX_SAFE_INTEGER` (`2^53 - 1`). Verwenden Sie für Werte darüber eine dezimale Zeichenfolge; die API akzeptiert Zeichenfolgen und Zahlen.

## Methode [#method]

```typescript
declare function makeInvoice(args: RequestInvoiceArgs): Promise<RequestInvoiceResponse>;
```

## Parameter [#params]

* `args` — _erforderlich_ `object`
  * `amount` — _optional_ `string|number`  die zu sendenden Satoshis
  * `defaultAmount` — _optional_ `string|number`
  * `minimumAmount` — _optional_ `string|number`
  * `maximumAmount` — _optional_ `string|number`
  * `defaultMemo` — _optional_ `string`

```typescript
interface RequestInvoiceArgs {
  amount?: string | number; // unit is sats
  defaultAmount?: string | number; // unit is sats
  minimumAmount?: string | number; // unit is sats
  maximumAmount?: string | number; // unit is sats
  defaultMemo?: string;
}
```

## Antwort [#response]

```typescript
interface RequestInvoiceResponse {
  paymentRequest: string;
  paymentHash: string;
  rHash: string;
}
```

## Beispiel [#example]

```typescript
const provider = (window.$onekey && window.$onekey.webln) || window.webln;

await provider.enable();
const invoice = await provider.makeInvoice({
  amount: 1000,
});
```
