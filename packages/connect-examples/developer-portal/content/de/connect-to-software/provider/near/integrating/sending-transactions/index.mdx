# Transaktionen senden

Sobald die Webanwendung mit OneKey verbunden ist, kann sie mit Erlaubnis des Nutzers Transaktionen in dessen Namen senden.

Zum Senden einer Transaktion muss die Webanwendung:

* Eine oder mehrere unsignierte Transaktionen erstellen.
* Diese von der OneKey-Wallet des Nutzers signieren und an das Netzwerk senden lassen.

Für weitere Informationen zur Funktionsweise von Transaktionen auf Near empfehlen wir die `near-api-js` [Dokumentation](https://docs.near.org/tools/near-api) sowie die offizielle [Near-Dokumentation](https://docs.near.org/).
