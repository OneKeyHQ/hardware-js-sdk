# Solana

Den Solana-Provider von OneKey in Web-Apps verwenden.

## Direktlinks [#quick-links]

- [Provider erkennen](detecting-the-provider)
- [Verbindung herstellen](establishing-a-connection)
- [Eine Transaktion senden](sending-a-transaction)
- [Eine Nachricht signieren](signing-a-message)

## Minimales Muster [#minimal-pattern]

```js
// Detect
const provider = window?.$onekey?.solana || window?.solana
if (!provider?.isOneKey) throw new Error('OneKey Solana provider not detected')

// Connect
const { publicKey } = await provider.connect()
console.log(publicKey.toString())
```

## Ereignisse [#events]

- `connect`, `disconnect`, `accountChanged`
