# Anleitung

## Übersicht [#overview]

Diese Anleitung zeigt, wie Sie mit der OneKey-Provider-API einfach Webanwendungen erstellen, die mit BTC interagieren können.


## Installieren [#install]

### 1. OneKey Wallet herunterladen [#1-download-onekey-wallet]

Laden Sie [OneKey Wallet](https://onekey.so/download?client=browserExtension). Installieren Sie die OneKey-Browsererweiterung.

#### 2. Erklärung der API-Injektion [#2-api-injection-explanation]

* Die OneKey-Browsererweiterung injiziert `Provider API` in besuchte Websites.
* Es werden zwei API-Typen bereitgestellt: `window.unisat` und `window.$onekey.btc`.
* Empfohlen wird `window.$onekey.btc`.

> Bevorzugen Sie `window.$onekey.btc`, um gezielt OneKey auszuwählen. Die globale Variable `window.unisat` kann zu einer anderen Wallet gehören, wenn mehrere Erweiterungen installiert sind.

### Unterstützung der Provider-API erkennen [#detecting-provider-api-support]

Prüfen Sie vor Anfragen, ob ein Provider verfügbar ist:

```javascript
const provider = (window.$onekey && window.$onekey.btc) || window.unisat;

if (!provider) {
  throw new Error("No Bitcoin provider is available.");
}
```

### Mit OneKey verbinden [#connecting-to-onekey]

Bevor Sie die folgende API verwenden, müssen Sie zuerst mit der Methode `provider.requestAccounts` beim Nutzer Zugriff auf das entsprechende BTC-Konto anfordern.

```
await provider.requestAccounts();
```

Andere APIs können erst nach Autorisierung durch den Nutzer aufgerufen werden.

## API [#api]

Wählen Sie die API für den Vorgang, den Ihre Anwendung benötigt.

* Kontoinformationen des Nutzers abrufen: [`provider.getAccounts`](/de/connect-to-software/provider/btc/api-reference/getaccounts)
* Zahlung senden: [`provider.sendBitcoin`](/de/connect-to-software/provider/btc/api-reference/sendbitcoin)
* Signatur für eine beliebige Nachricht anfordern: [`provider.signMessage`](/de/connect-to-software/provider/btc/api-reference/signmessage)

**Weitere Schnittstellen**: [Details anzeigen](/de/connect-to-software/provider/btc/api-reference)

## Ereignis [#event]

* **Wichtige Vorgänge**: Zum Beispiel Kontowechsel
* **Weitere Informationen**: [Mehr anzeigen](/de/connect-to-software/provider/btc/event)

## Anfragen behandeln [#handling-requests]

Führen Sie Wallet-Anfragen in einer asynchronen Funktion oder einem ES-Modul aus. Fangen Sie abgelehnte Promises ab und zeigen Sie den Fehler in Ihrer Anwendung an. Fordern Sie Verbindungen, Signaturen und Zahlungen über eine Nutzeraktion an und deaktivieren Sie die auslösende Schaltfläche, solange eine Anfrage aussteht.
