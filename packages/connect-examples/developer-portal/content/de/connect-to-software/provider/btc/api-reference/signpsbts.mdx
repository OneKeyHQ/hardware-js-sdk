# signPsbts


Mehrere PSBTs gleichzeitig signieren. Diese Methode durchläuft zum Signieren alle Eingaben, die der aktuellen Adresse entsprechen.

## Kompatibilität von Wallets und Adresstypen [#wallet--address-type-compatibility]

| Wallet-Typ     | Modell          | Unterstützte Adresstypen                |
| --------------- | -------------- | -------------------------------------- |
| Software-Wallet | Alle            | p2wpkh (Native Segwit), p2tr (Taproot) |
| Hardware-Wallet | Pro, Classic1S | p2tr (Taproot)                         |

## Methode [#method]

```typescript
declare function signPsbts(
    psbtHexs: string[],
    options?: {
        autoFinalized?: boolean;
        toSignInputs?: Array<{
            index: number;
            address?: string;
            publicKey?: string;
            sighashTypes?: number[];
            disableTweakSigner?: boolean;
            useTweakedSigner?: boolean;
        }>;
    },
): Promise<string[]>
```

## Parameter [#parameters]

* `psbtHexs` — _erforderlich_ `string[]` Array von Hex-Zeichenfolgen der zu signierenden PSBTs
* `options` — _optional_ `object`
  * `autoFinalized` — _optional_ `boolean` Ob PSBTs nach dem Signieren finalisiert werden sollen; Standard ist `true`
  * `toSignInputs` — _optional_ `array` Festlegen, welche Eingaben signiert werden sollen
    * `index` — _erforderlich_ `number` Welche Eingabe signiert werden soll
    * `address` — _optional_ `string` Welcher zugehörige private Schlüssel zum Signieren verwendet werden soll (entweder address oder publicKey angeben)
    * `publicKey` — _optional_ `string` Welcher zugehörige private Schlüssel zum Signieren verwendet werden soll (entweder address oder publicKey angeben)
    * `sighashTypes` — _optional_ `number[]` Optionale sighash-Typen
    * `disableTweakSigner` — _optional_ `boolean` Standard ist `false`. Setzen Sie `true`, um beim Signieren von Taproot-Eingaben den ursprünglichen privaten Schlüssel zu verwenden
    * `useTweakedSigner` — _optional_ `boolean` Erzwingen, ob ein angepasster Signierer verwendet wird; höhere Priorität als `disableTweakSigner`

## Rückgabe [#returns]

* `Promise<string[]>` Array von Hex-Zeichenfolgen der signierten PSBTs

## Beispiel [#example]

```typescript
const provider = (window.$onekey && window.$onekey.btc) || window.unisat;

try {
    const psbtHexs = [
        "70736274ff01007d...",
        "70736274ff01007d..."
    ];

    const signeds = await provider.signPsbts(psbtHexs, {
        autoFinalized: true,
        toSignInputs: [
            {
                index: 0,
                publicKey: "02abc...",
                useTweakedSigner: true
            },
            {
                index: 1,
                address: "bc1p...",
                disableTweakSigner: true
            }
        ]
    });

    console.log(signeds);
} catch (e) {
    console.log(e);
}
```

Die verkürzten Werte sind Platzhalter. Ersetzen Sie sie durch vollständige PSBTs, Adressen und öffentliche Schlüssel. Die veröffentlichte Provider-Schnittstelle stellt `autoFinalized` bereit; erweiterte Eingabeoptionen hängen von der Wallet-Implementierung ab und sollten anhand der Zielversion geprüft werden. Das Signieren überträgt keine Transaktion.
