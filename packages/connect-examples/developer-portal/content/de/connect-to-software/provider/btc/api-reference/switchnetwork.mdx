# switchNetwork

Einen Wechsel zum angegebenen Bitcoin-Netzwerk anfordern.

## Methode [#method]

```typescript
declare function switchNetwork(network: 'livenet' | 'testnet'): Promise<void>;
```

## Parameter [#params]

`network` — das Zielnetzwerk: `livenet` oder `testnet`. Das Promise wird ohne Wert aufgelöst.

## Beispiel [#example]

```typescript
const provider = (window.$onekey && window.$onekey.btc) || window.unisat;

await provider.switchNetwork("livenet");
```
