# getPublicKey

Den öffentlichen Schlüssel des aktuellen Kontos abrufen.

## Methode [#method]

```typescript
declare function getPublicKey(): Promise<string>;
```

## Antwort [#response]

Der öffentliche Schlüssel als Zeichenfolge.

## Beispiel [#example]

```typescript
const provider = (window.$onekey && window.$onekey.btc) || window.unisat;

const publicKey = await provider.getPublicKey();
```
