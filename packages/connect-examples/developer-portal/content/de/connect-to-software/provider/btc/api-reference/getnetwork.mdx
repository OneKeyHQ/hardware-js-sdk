# getNetwork

Netzwerk des aktuellen Kontos abrufen

## Methode [#method]

```typescript
declare function getNetwork(): Promise<string>;
```

## Antwort [#response]

das Netzwerk. `livenet` und `testnet`

## Beispiel [#example]

```typescript
const provider = (window.$onekey && window.$onekey.btc) || window.unisat;

const network = await provider.getNetwork()
```
