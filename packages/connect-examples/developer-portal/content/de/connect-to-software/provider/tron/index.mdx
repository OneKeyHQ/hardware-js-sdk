# TRON

Integrieren Sie die TRON-Blockchain mit dem TronLink-kompatiblen Provider von OneKey. Zugriff über `window.$onekey.tron` oder `window.tronWeb`.

<Callout type="info">
OneKey stellt einen TronLink-kompatiblen Provider und eine TronWeb-Integration bereit. Die Verfügbarkeit von Funktionen hängt von der Wallet-Version und dem ausgewählten Netzwerk ab.
</Callout>

## Provider erkennen [#provider-detection]

```typescript
// OneKey injects both the provider and TronWeb instances
const provider = window.$onekey?.tron

// TronWeb is available globally after connection
let tronWeb = provider?.tronWeb

if (!provider) {
  throw new Error('OneKey TRON provider not detected')
}

// Check if it's TronLink compatible
console.log('isTronLink:', provider.isTronLink) // true
```

## Schnellstart [#quick-start]

### Konten anfordern [#request-accounts]

```typescript
// Request connection
const result = await provider.request({
  method: 'tron_requestAccounts'
})

if (result.code === 200) {
  tronWeb = provider.tronWeb
  if (!tronWeb) throw new Error('OneKey TronWeb is not ready')
  console.log('Connected!')
  const address = tronWeb.defaultAddress.base58
  console.log('Address:', address)
} else {
  console.log('Connection rejected:', result.message)
}
```

### Verbindungsstatus prüfen [#check-connection-status]

```typescript
// Check if TronWeb is ready
if (provider.ready && tronWeb && tronWeb.defaultAddress.base58) {
  console.log('Connected:', tronWeb.defaultAddress.base58)
} else {
  console.log('Not connected')
}
```

## TronWeb verwenden [#using-tronweb]

Nach dem Verbinden verwenden Sie `provider.tronWeb`, damit Anfragen OneKey zugeordnet bleiben:

### Guthaben abrufen [#get-balance]

```typescript
const balance = await tronWeb.trx.getBalance(tronWeb.defaultAddress.base58)
console.log('Balance:', tronWeb.fromSun(balance), 'TRX')
```

### TRX senden [#send-trx]

```typescript
const tx = await tronWeb.trx.sendTransaction(
  'TRecipientAddress...',
  tronWeb.toSun(10) // 10 TRX
)

console.log('Transaction:', tx.txid)
```

### TRC20-Token senden [#send-trc20-token]

```typescript
const contractAddress = 'TTokenContractAddress...'
const contract = await tronWeb.contract().at(contractAddress)

// Get decimals
const decimals = await contract.decimals().call()

// Transfer tokens
const amount = (100n * 10n ** BigInt(decimals.toString())).toString() // 100 tokens, exact integer
const tx = await contract.transfer(
  'TRecipientAddress...',
  amount
).send()

console.log('Transaction:', tx)
```

## Transaktionen [#transactions]

### Transaktion signieren [#sign-transaction]

Eine Transaktion signieren, ohne sie zu übertragen:

```typescript
// Build transaction
const tx = await tronWeb.transactionBuilder.sendTrx(
  'TRecipientAddress...',
  tronWeb.toSun(10),
  tronWeb.defaultAddress.base58
)

// Sign via provider
const signedTx = await provider.sign(tx)

console.log('Signed transaction:', signedTx)

// Broadcast manually
const result = await tronWeb.trx.sendRawTransaction(signedTx)
```

### Smart-Contract-Interaktion [#smart-contract-interaction]

```typescript
// Call contract method
const contract = await tronWeb.contract().at(contractAddress)

// Read (view function)
const result = await contract.someViewFunction().call()

// Write (requires signing)
const tx = await contract.someWriteFunction(param1, param2).send({
  feeLimit: 100_000_000, // 100 TRX
  callValue: 0,
})
```

### Smart Contract auslösen [#trigger-smart-contract]

```typescript
const tx = await tronWeb.transactionBuilder.triggerSmartContract(
  contractAddress,
  'transfer(address,uint256)',
  { feeLimit: 100_000_000 },
  [
    { type: 'address', value: recipientAddress },
    { type: 'uint256', value: amount }
  ],
  tronWeb.defaultAddress.base58
)

const signedTx = await provider.sign(tx.transaction)
const result = await tronWeb.trx.sendRawTransaction(signedTx)
```

## Nachrichten signieren [#message-signing]

### Nachricht signieren V1 (Hex) [#sign-message-v1-hex]

Hexkodierte Nachrichten signieren:

```typescript
const message = tronWeb.toHex('Hello TRON!')
const signature = await provider.signMessage(message)

console.log('Signature:', signature)
```

### Nachricht signieren V2 (UTF-8) [#sign-message-v2-utf-8]

UTF-8-Nachrichten direkt signieren:

```typescript
const message = 'Hello TRON!'
const signature = await provider.signMessageV2(message)

console.log('Signature:', signature)
```

### Signatur prüfen [#verify-signature]

```typescript
const message = 'Hello TRON!'
const signature = await provider.signMessageV2(message)

// Verify using TronWeb
const address = await tronWeb.trx.verifyMessageV2(message, signature)
console.log('Signer:', address)
```

## Ereignisbehandlung [#event-handling]

### Auf Kontoänderungen reagieren [#listen-for-account-changes]

```typescript
provider.on('accountsChanged', (accounts) => {
  if (accounts[0]) {
    console.log('Account changed:', accounts[0])
  } else {
    console.log('Disconnected')
  }
})
```

### Auf Netzwerkänderungen reagieren [#listen-for-network-changes]

```typescript
provider.on('chainChanged', (chainId) => {
  console.log('Network changed:', chainId)
  // Recommend page reload for network changes
})
```

### Window-Ereignisse (TronLink-kompatibel) [#window-events-tronlink-compatible]

```typescript
// Listen for TronLink initialization
window.addEventListener('tronLink#initialized', () => {
  console.log('TronLink initialized')
})

// Listen for messages
window.addEventListener('message', (event) => {
  if (event.source === window && event.data?.isTronLink && event.data?.message) {
    const { action, data } = event.data.message
    console.log('TronLink event:', action, data)
  }
})
```

## API-Referenz [#api-reference]

### Provider-Methoden [#provider-methods]

| Methode | Beschreibung |
|--------|-------------|
| `request({ method, params })` | Allgemeine JSON-RPC-Anfrage |
| `sign(transaction)` | Eine Transaktion signieren |
| `signMessage(hexMessage)` | Hex-Nachricht signieren (V1) |
| `signMessageV2(message)` | UTF-8-Nachricht signieren (V2) |

### Anfragemethoden [#request-methods]

| Methode | Beschreibung |
|--------|-------------|
| `tron_requestAccounts` | Verbindung anfordern |
| `tron_getProviderState` | Provider-Status abrufen |
| `tron_signTransaction` | Transaktion signieren |
| `signMessageV1` | Nachricht signieren V1 |
| `signMessageV2` | Nachricht signieren V2 |

### Antwortcodes [#response-codes]

Prüfen Sie bei `tron_requestAccounts` das Feld `code` in der aufgelösten Antwort. Die aktuelle Provider-Implementierung gibt `4001` für eine bereits ausstehende Anfrage und `4000` zurück, wenn keine Konten zurückgegeben werden oder die Anfrage fehlschlägt. Dies sind keine Ethereum-JSON-RPC-Fehlerbedeutungen.

| Code | Beschreibung |
|------|-------------|
| 200 | Erfolg |
| 4000 | Vom Nutzer abgelehnt |
| 4001 | Anfrage in der Warteschlange |

### Ereignisse [#events]

| Ereignis | Beschreibung |
|-------|-------------|
| `accountsChanged` | Konto geändert |
| `chainChanged` | Netzwerk geändert |
| `connect` | Verbunden |
| `disconnect` | Getrennt |

## SunWeb verwenden [#using-sunweb]

Für DappChain-Vorgänge (Sidechain):

```typescript
const sunWeb = window.sunWeb

// Main chain to side chain
await sunWeb.depositTrx(
  amount,
  depositFee,
  feeLimit
)

// Side chain to main chain
await sunWeb.withdrawTrx(
  amount,
  withdrawFee,
  feeLimit
)
```

## Fehlerbehandlung [#error-handling]

```typescript
try {
  const result = await provider.request({
    method: 'tron_requestAccounts'
  })

  if (result.code === 4001) {
    console.log('A connection request is already pending')
  } else if (result.code !== 200) {
    console.log('Connection was not approved:', result.message)
  }
} catch (error) {
  console.error('Request failed:', error)
}
```

## Migration von TronLink [#migration-from-tronlink]

OneKey ist TronLink-kompatibel. Aktualisieren Sie Ihre Erkennungslogik:

```typescript
// Before (TronLink only)
const tronWeb = window.tronWeb

// After (OneKey with TronLink fallback)
const provider = window.$onekey?.tron || window.tronLink
const tronWeb = window.tronWeb // Compatibility global; verify which wallet owns it
```
