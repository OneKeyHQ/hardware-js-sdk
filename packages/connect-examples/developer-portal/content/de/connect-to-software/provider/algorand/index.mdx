# Algorand

Integrieren Sie die Algorand-Blockchain mit dem Provider von OneKey. Zugriff über `window.$onekey.algo`.

<Callout type="info">
Der Algorand-Provider von OneKey unterstützt sowohl ältere als auch ARC-0001-konforme Schnittstellen.
</Callout>

## Provider erkennen [#provider-detection]

```typescript
// Detect OneKey Algorand provider
const provider = window.$onekey?.algo

if (!provider) {
  throw new Error('OneKey Algorand provider not detected')
}

// Check compatibility
console.log('isOneKey:', provider.isOneKey) // true
```

## Schnellstart [#quick-start]

### Verbinden (Legacy-API) [#connect-legacy-api]

```typescript
const { address } = await provider.connect()
console.log('Connected:', address)

// Check connection status
console.log('isConnected:', provider.isConnected)
console.log('Address:', provider.address)
```

### Aktivieren (ARC-0001) [#enable-arc-0001]

```typescript
const result = await provider.enable({
  genesisID: 'mainnet-v1.0',
  genesisHash: 'wGHE2Pwdvd7S12BL5FaOP20EGYesN73ktiC1qzkkit8=',
})

console.log('Accounts:', result.accounts)
console.log('Genesis Hash:', result.genesisHash)
```

### Trennen [#disconnect]

```typescript
await provider.disconnect()
console.log('Disconnected')
```

## Transaktionen [#transactions]

### Transaktionen signieren (ARC-0001) [#sign-transactions-arc-0001]

Eine oder mehrere Transaktionen signieren:

```typescript
import algosdk from 'algosdk'

// Create transaction
const suggestedParams = await algodClient.getTransactionParams().do()

const txn = algosdk.makePaymentTxnWithSuggestedParamsFromObject({
  from: senderAddress,
  to: recipientAddress,
  amount: 1000000, // 1 ALGO (microAlgos)
  suggestedParams,
})

// Prepare for signing
const walletTxns = [{
  txn: Buffer.from(algosdk.encodeUnsignedTransaction(txn)).toString('base64'),
}]

// Sign
const signedTxns = await provider.signTxns(walletTxns)

console.log('Signed transactions:', signedTxns)
```

### Mehrere Transaktionen signieren [#sign-multiple-transactions]

```typescript
// Group transactions
const txns = [txn1, txn2, txn3]
algosdk.assignGroupID(txns)

// Prepare for signing
const walletTxns = txns.map(txn => ({
  txn: Buffer.from(algosdk.encodeUnsignedTransaction(txn)).toString('base64'),
}))

// Sign all
const signedTxns = await provider.signTxns(walletTxns)
```

### Teilweise signieren (Multi-Sig) [#partial-signing-multi-sig]

```typescript
// Only sign specific transactions in a group
const walletTxns = [
  { txn: encodedTxn1 },
  { txn: encodedTxn2, signers: [] }, // Skip this one
  { txn: encodedTxn3 },
]

const signedTxns = await provider.signTxns(walletTxns)
// signedTxns[1] will be null
```

### Transaktionen übertragen [#post-transactions]

Signierte Transaktionen übertragen:

```typescript
const completeTxns = signedTxns.filter((txn) => txn !== null)
if (completeTxns.length !== signedTxns.length) {
  throw new Error('Complete all required signatures before broadcasting the group')
}
const result = await provider.postTxns(completeTxns)
console.log('Transaction IDs:', result.txnIDs)
```

### Signieren und übertragen [#sign-and-post]

In einem Schritt signieren und übertragen:

```typescript
const result = await provider.signAndPostTxns(walletTxns)
console.log('Transaction IDs:', result.txnIDs)
```

## Nachrichten signieren [#message-signing]

### Beliebige Nachricht signieren [#sign-arbitrary-message]

```typescript
const message = new TextEncoder().encode('Hello Algorand!')

const { signature, address } = await provider.signMessage(
  message,
  'utf8' // or 'hex'
)

console.log('Signature:', signature)
console.log('Signer:', address)
```

### Signatur prüfen [#verify-signature]

```typescript
import nacl from 'tweetnacl'

const message = new TextEncoder().encode('Hello Algorand!')
const { signature } = await provider.signMessage(message)

// Get public key from address
const publicKey = algosdk.decodeAddress(provider.address).publicKey

const isValid = nacl.sign.detached.verify(message, signature, publicKey)
console.log('Valid:', isValid)
```

## Fehlerbehandlung [#error-handling]

```typescript
try {
  const signedTxns = await provider.signTxns(walletTxns)
} catch (error) {
  if (error.code === 4001) {
    console.log('User rejected the request')
  } else if (error.code === 4100) {
    console.log('The account or method is not authorized')
  } else {
    console.error('Error:', error.message)
  }
}
```

### Häufige Fehlercodes [#common-error-codes]

| Code | Beschreibung |
|------|-------------|
| 4001 | Nutzer hat die Anfrage abgelehnt |
| 4100 | Nicht autorisiert |
| 4200 | Nicht unterstützte Methode |
| -32602 | Ungültige Parameter |

## Vollständiges Beispiel [#complete-example]

```typescript
import algosdk from 'algosdk'

async function sendAlgo() {
  // Connect
  const provider = window.$onekey?.algo
  if (!provider) throw new Error("OneKey Algorand provider is unavailable")
  const { address } = await provider.connect()

  // Setup client
  const algodClient = new algosdk.Algodv2(
    '',
    'https://mainnet-api.algonode.cloud',
    ''
  )

  // Get params
  const suggestedParams = await algodClient.getTransactionParams().do()

  // Create transaction
  const txn = algosdk.makePaymentTxnWithSuggestedParamsFromObject({
    from: address,
    to: 'RECIPIENT_ADDRESS',
    amount: 1000000, // 1 ALGO
    suggestedParams,
  })

  // Sign
  const walletTxns = [{
    txn: Buffer.from(algosdk.encodeUnsignedTransaction(txn)).toString('base64'),
  }]

  const signedTxns = await provider.signTxns(walletTxns)

  if (!signedTxns[0]) throw new Error("The transaction was not signed")

  // Send
  const { txId } = await algodClient.sendRawTransaction(
    Buffer.from(signedTxns[0], 'base64')
  ).do()

  console.log('Transaction ID:', txId)

  // Wait for confirmation
  await algosdk.waitForConfirmation(algodClient, txId, 4)
  console.log('Confirmed!')
}
```
