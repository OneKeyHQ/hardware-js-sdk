# API-Referenz

Referenz der Methoden und Typen des Polkadot-Providers von OneKey.

---

## Methoden [#methods]

| Methode | Beschreibung |
|--------|-------------|
| `web3Enable(dappName)` | Erweiterung für dApp aktivieren |
| `web3Accounts(anyType?)` | Alle Konten abrufen |
| `web3AccountsSubscribe(callback)` | Kontoänderungen abonnieren |
| `web3SignPayload(payload)` | Transaktionsnutzlast signieren |
| `web3SignRaw(payload)` | Rohnachricht signieren |
| `web3RpcSend(request)` | RPC-Anfrage senden |
| `web3RpcSubscribe(request, callback)` | RPC-Ereignisse abonnieren |
| `web3RpcUnSubscribe()` | Alle Abonnements beenden |
| `web3RpcListProviders()` | RPC-Provider auflisten |
| `web3RpcStartProvider(key)` | Bestimmten Provider starten |

## Typen [#types]

### Injiziertes Konto [#injected-account]

```typescript
interface InjectedAccount {
  address: string          // Substrate address
  name?: string            // Account name
  type?: 'sr25519' | 'ed25519' | 'ecdsa'
  genesisHash?: string     // Optional chain restriction
}
```

### Signierer-Nutzlast als JSON [#signer-payload-json]

```typescript
interface SignerPayloadJSON {
  address: string
  blockHash: string
  blockNumber: string
  era: string
  genesisHash: string
  method: string
  nonce: string
  specVersion: string
  tip: string
  transactionVersion: string
  signedExtensions: string[]
  version: number
}
```

### Rohe Signierer-Nutzlast [#signer-payload-raw]

```typescript
interface SignerPayloadRaw {
  address: string
  data: string             // Hex-encoded data
  type: 'bytes' | 'payload'
}
```

### Signierergebnis [#signer-result]

```typescript
interface SignerResult {
  id: number
  signature: string        // Hex signature
}
```
