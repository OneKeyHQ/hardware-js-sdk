# deviceSupportFeatures

Prüfen Sie die Funktionsobjekte zur Laufzeit. Lesen Sie `.support`, nicht den Wahrheitswert des Objekts; `{ support: false }` gilt in JavaScript weiterhin als wahrer Wert. `require` kann eine Mindest-Firmware-Version angeben.

```ts
const result = await HardwareSDK.deviceSupportFeatures(connectId);
if (!result.success) throw new Error(result.payload.error);
const canEnterPinOnHost = result.payload.inputPinOnSoftware.support;
```

```typescript
const response = await HardwareSDK.deviceSupportFeatures(connectId);
```

### Parameter [#params]

[Optionale gemeinsame Parameter](/de/hardware-sdk/concepts/common-params)

### Beispiel [#example]

```typescript
const response = await HardwareSDK.deviceSupportFeatures(connectId);
```

Ergebnis

```typescript
{
    success: true,
    payload: {
      inputPinOnSoftware: { support: boolean, require?: string },
      modifyHomescreen: { support: boolean, require?: string },
      device: Device | null
    }
}
```

Fehler

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
