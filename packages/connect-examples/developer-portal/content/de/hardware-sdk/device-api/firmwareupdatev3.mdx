# firmwareUpdateV3

## Firmware-Update (V3) [#firmware-update-v3]

Protocol-V1-Update-Ablauf für OneKey Pro. Unterstützt bei Bedarf die Aktualisierung von Bootloader, Hauptfirmware, BLE-Firmware und Ressourcenpaket in einem einzigen Ablauf.

- Gerät: nur OneKey Pro (Protocol V1)
- Boot-Anforderung: Boot-Version ≥ 4.8.0
- Pro 2 / Neo: verwenden Sie [firmwareUpdateV4](/de/hardware-sdk/device-api/firmwareupdatev4)

```typescript
// Select versions from verified release metadata for this device.
declare const targetFirmwareVersion: number[];
declare const targetBleVersion: number[];
declare const targetBootloaderVersion: number[];

const res = await HardwareSDK.firmwareUpdateV3(connectId, {
  platform: 'desktop', // 'native' | 'desktop' | 'ext' | 'web' | 'web-embed'

  // Option A: specify versions (pick any subset)
  firmwareVersion: targetFirmwareVersion,
  bleVersion: targetBleVersion,
  bootloaderVersion: targetBootloaderVersion,

  // Option B: custom binaries (as needed)
  // firmwareBinary: ArrayBuffer,
  // bleBinary: ArrayBuffer,
  // bootloaderBinary: ArrayBuffer,
  // resourceBinary: ArrayBuffer,

  // Optional: force updating resource package
  forcedUpdateRes: false,
});
if (!res.success) throw new Error(res.payload.error);
```

Das Beispiel setzt voraus, dass der Nutzer dieses Gerät ausgewählt und das Update genehmigt hat. Ermitteln Sie Zielversionen aus geprüften Release-Metadaten; codieren Sie keine aus der Dokumentation kopierte Version fest.

### Parameter [#params]

[Optionale gemeinsame Parameter](/de/hardware-sdk/concepts/common-params)

- `platform` - erforderlich `"native" | "desktop" | "ext" | "web" | "web-embed"` Ausführungsumgebung
- `firmwareVersion` - optional `number[]` Zielversion der Hauptfirmware
- `firmwareBinary` - optional `ArrayBuffer` Eigene Hauptfirmware
- `bleVersion` - optional `number[]` Zielversion der BLE-Firmware
- `bleBinary` - optional `ArrayBuffer` Eigene BLE-Firmware
- `bootloaderVersion` - optional `number[]` Zielversion des Bootloaders
- `bootloaderBinary` - optional `ArrayBuffer` Eigener Bootloader
- `resourceBinary` - optional `ArrayBuffer` Binärdatei des Ressourcenpakets
- `forcedUpdateRes` - optional `boolean` Aktualisierung des Ressourcenpakets erzwingen

### Ergebnis [#result]

```typescript
{
  success: true,
  payload: {
    bleVersion: string,
    firmwareVersion: string,
    bootloaderVersion: string,
  }
}
```

### Fehler [#error]

```typescript
{
  success: false,
  payload: {
    error: string, // error message
    code?: string | number   // error code
  }
}
```
