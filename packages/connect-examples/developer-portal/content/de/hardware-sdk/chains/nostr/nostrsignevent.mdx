# nostrSignEvent

### Voraussetzungen [#requirements]

Das aktuelle SDK deklariert diese Firmware-Prüfungen: `model_touch` ≥ 4.7.0 und `model_mini` ≥ 3.6.0. Dies sind SDK-Bereichsschlüssel; prüfen Sie die Gerätemodellzuordnung und die Unterstützung veröffentlichter Firmware für Ihre Integration.

## Nostr: Nostr-Ereignis signieren [#nostr-sign-nostr-event]

Fordert eine Signatur eines Nostr-Ereignisses mit dem Schlüssel am angegebenen Pfad an. Der Nutzer bestätigt die Anfrage auf dem Gerät.

```typescript
const result = await HardwareSDK.nostrSignEvent(connectId, deviceId, params);
```

### Parameter [#params]

[**Optionale gemeinsame Parameter**](/de/hardware-sdk/concepts/common-params)

* `path` - _erforderlich_ `string | Array<number>` Die SDK-Mindestlänge ist `5`. [Mehr erfahren](/de/hardware-sdk/concepts/common-params#hd-path)
* `event` - _erforderlich_ `NostrEvent` Nostr-Ereignis.

```
enum EventKind {
  Metadata = 0,
  Text = 1,
  RelayRec = 2,
  Contacts = 3,
  DM = 4,
  Deleted = 5,
  Reaction = 7,

  ChannelCreation = 40,
  ChannelMetadata = 41,
  ChannelMessage = 42,
  ChannelHideMessage = 43,
  Reporting = 1984,
  ZapRequest = 9734,

  RelayListMetadata = 10002,

  ProfileBadges = 30008,
  BadgeDefinition = 30009,

}

type NostrEvent = {
  id?: string;
  kind: EventKind;
  pubkey?: string;
  content: string;
  tags: string[][];
  created_at: number;
  sig?: string;
};
```

### Beispiele [#examples]

```typescript
const response = await HardwareSDK.nostrSignEvent(
  connectId,
  deviceId,
  {
    path: "m/44'/1237'/0'/0/0",
    event: {
      kind: 1,
      content: 'Hello world',
      tags: [],
      created_at: 1702268010,
    },
  }
);
```

Ergebnis

```typescript
{
  success: true,
  payload: {
    path: string,
    event: {
      kind: 1,
      content: 'Hello world',
      tags: [],
      created_at: 1702268010,
      sig: 'signature returned by the device',
    },
  }
}
```

Fehler

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
