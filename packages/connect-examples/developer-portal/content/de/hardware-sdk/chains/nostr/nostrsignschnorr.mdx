# nostrSignSchnorr

### Voraussetzungen [#requirements]

Das aktuelle SDK deklariert diese Firmware-Prüfungen: `model_touch` ≥ 4.7.0 und `model_mini` ≥ 3.6.0. Dies sind SDK-Bereichsschlüssel; prüfen Sie die Gerätemodellzuordnung und die Unterstützung veröffentlichter Firmware für Ihre Integration.

## Nostr: Schnorr signieren [#nostr-sign-schnorr]

Fordert eine Schnorr-Signatur des angegebenen Hashs mit dem Schlüssel am angegebenen Pfad an. Der Nutzer bestätigt die Anfrage auf dem Gerät.

```typescript
const result = await HardwareSDK.nostrSignSchnorr(connectId, deviceId, params);
```

### Parameter [#params]

[**Optionale gemeinsame Parameter**](/de/hardware-sdk/concepts/common-params)

* `path` - _erforderlich_ `string | Array<number>` Die SDK-Mindestlänge ist `5`. [Mehr erfahren](/de/hardware-sdk/concepts/common-params#hd-path)
* `hash` - _erforderlich_ `string`. Ein hexadezimal kodierter 32-Byte-Hash.

### Beispiele [#examples]

```typescript
const response = await HardwareSDK.nostrSignSchnorr(
  connectId,
  deviceId,
  {
    path: "m/44'/1237'/0'/0/0",
    hash: '2118c65161c7d68b4bdbe1374f658532670057ab1bb0c99937d0ff7cff45cb5e',
  }
);
```

Ergebnis

```typescript
{
  success: true,
  payload: {
    path: string;
    rawHash: string,
    signature: string,
  }
}
```

Fehler

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
