# nostrEncryptMessage

### Voraussetzungen [#requirements]

* Vom SDK geforderte Mindest-Firmware-Versionen
  * Touch / Pro (`model_touch`): 4.7.0
  * Classic / Classic1s / Classic Pure / Mini (`model_mini`): 3.6.0

## Nostr: Nachricht verschlüsseln [#nostr-encrypt-message]

Fordert die Verschlüsselung einer Nachricht mit dem Schlüssel am angegebenen Pfad und dem öffentlichen Schlüssel des anderen Teilnehmers an.

```typescript
const result = await HardwareSDK.nostrEncryptMessage(connectId, deviceId, params);
```

### Parameter [#params]

[**Optionale gemeinsame Parameter**](/de/hardware-sdk/concepts/common-params)

* `path` - _erforderlich_ `string | Array<number>` Die SDK-Mindestlänge ist `5`. [Mehr erfahren](/de/hardware-sdk/concepts/common-params#hd-path)
* `pubkey` - _erforderlich_ `string`. Der öffentliche Schlüssel des anderen Teilnehmers.
* `plaintext` - _erforderlich_ `string`. Die zu verschlüsselnde Klartextnachricht.
* `showOnOneKey` - _optional_ `boolean` Ob die Anfrage auf dem Gerät angezeigt werden soll. Standard ist `true`.

### Beispiele [#examples]

```typescript
const response = await HardwareSDK.nostrEncryptMessage(
  connectId,
  deviceId,
  {
     path: "m/44'/1237'/0'/0/0",
     pubkey: '2118c65161c7d68b4bdbe1374f658532670057ab1bb0c99937d0ff7cff45cb5e',
     plaintext: 'Hello world',
     showOnOneKey: true,
  }
);
```

Ergebnis

```typescript
{
  success: true,
  payload: {
    path: string;
    pubkey: string;
    plaintext: string;
    encryptedMessage: string;
  }
}
```

Fehler

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
