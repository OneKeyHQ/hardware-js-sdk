# tonGetAddress

### Voraussetzungen [#requirements]

* Mindest-Firmware-Versionen
  * Touch: 4.10.0

### TON: Adresse abrufen [#ton-get-address]

Leitet die Adresse am angegebenen Pfad ab und gibt sie zurück. Wenn `showOnOneKey` gleich `true` ist, muss der Nutzer die Adresse auf dem Gerät bestätigen.

```typescript
const response = await HardwareSDK.tonGetAddress(connectId, deviceId, {
    path: "m/44'/607'/0'",
    showOnOneKey: true,
    walletVersion: 3,
    isBounceable: false,
    isTestnetOnly: false
});
```

#### Parameter [#params]

[Optionale gemeinsame Parameter](/de/hardware-sdk/concepts/common-params)

**Einzelne Adresse**

* `path` - _erforderlich_ `string | Array<number>` Die SDK-Mindestlänge ist `3`. [Pfadformat](/de/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _optional_ `boolean` Ob die Adresse auf dem Gerät angezeigt werden soll. Standard ist `true`.
* `walletVersion` - _optional_ `TonWalletVersion` TON-Wallet-Version (Standard: 3)
* `isBounceable` - _optional_ `boolean` Ob die Adresse bounceable ist (Standard: false)
* `isTestnetOnly` - _optional_ `boolean` Ob das Testnet verwendet werden soll (Standard: false)

**Mehrere Adressen**

* `bundle` - Array von Objekten mit `path` und `showOnOneKey`-Feldern

#### Beispiel [#example]

```typescript
// Get single address
const response = await HardwareSDK.tonGetAddress(connectId, deviceId, {
    path: "m/44'/607'/0'",
    showOnOneKey: false,
    walletVersion: 3,
    isBounceable: false,
    isTestnetOnly: false,
});

// Get multiple addresses
const batchResponse = await HardwareSDK.tonGetAddress(connectId, deviceId, {
    bundle: [
        {
            path: "m/44'/607'/0'",
            showOnOneKey: false
        },
        {
            path: "m/44'/607'/1'",
            showOnOneKey: false
        }
    ]
});
```

**Ergebnis**

Antwort für eine einzelne Adresse

```typescript
{
    success: true,
    payload: {
        address: string,     // displayed address
        publicKey: string,
        path: string // serialized BIP32 path
    }
}
```

Batch-Antwort in derselben Reihenfolge wie die Anfrage

```typescript
{
    success: true,
    payload: [
        { address: string, publicKey: string, path: string }, // account 1
        { address: string, publicKey: string, path: string }, // account 2
        { address: string, publicKey: string, path: string }  // account 3
    ]
}
```

Fehler

```
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
