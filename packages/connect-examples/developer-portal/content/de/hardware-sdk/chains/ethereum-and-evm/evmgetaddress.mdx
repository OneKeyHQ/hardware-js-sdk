# evmGetAddress

## Ethereum: Adresse abrufen [#ethereum-get-address]

Leitet die Adresse am angegebenen Pfad ab und gibt sie zurück. Wenn `showOnOneKey` gleich `true` ist, muss der Nutzer die Adresse auf dem Gerät bestätigen.

```typescript
const response = await HardwareSDK.evmGetAddress(connectId, deviceId, params)
```

### Parameter [#params]

[**Optionale gemeinsame Parameter**](/de/hardware-sdk/concepts/common-params)

**Einzelne Adresse**

* `path` - _erforderlich_ `string | Array<number>`  Die SDK-Mindestlänge ist `3`. [Weitere Informationen](/de/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _optional_ `boolean` Ob die Adresse auf dem Gerät angezeigt werden soll. Standard ist `true`.
* `chainId` - _optional_ `number` Die ChainId in ETH ist eine eindeutige Kennung für ein bestimmtes Ethereum-Netzwerk und dient zur Unterscheidung verschiedener Versionen der Blockchain. [Referenz](https://github.com/ethereum-lists/chains/tree/master/\_data/chains).

**Mehrere Adressen**

* `bundle` - Array von Objekten mit `path` und `showOnOneKey`-Feldern

#### Beispiel [#example]

Adresse des ersten Ethereum-Kontos anzeigen:

```typescript
HardwareSDK.evmGetAddress(connectId, deviceId, {
    path: "m/44'/60'/0'/0/0",
    chainId: 1
});
```

Ein Bündel von Ethereum-Adressen zurückgeben, ohne sie auf dem Gerät anzuzeigen:

```typescript
HardwareSDK.evmGetAddress(connectId, deviceId, {
    bundle: [
        { path: "m/44'/60'/0'/0/0", chainId: 1, showOnOneKey: false }, // account 1
        { path: "m/44'/60'/1'/0/0", chainId: 1, showOnOneKey: false }, // account 2
        { path: "m/44'/60'/2'/0/0", chainId: 1, showOnOneKey: false }  // account 3
    ]
});
```

#### Ergebnis [#result]

Antwort für eine einzelne Adresse

```typescript
{
    success: true,
    payload: {
        address: string,     // displayed address
        path: string // serialized BIP32 path
    }
}

```

Batch-Antwort in derselben Reihenfolge wie die Anfrage

```typescript
{
    success: true,
    payload: [
        { address: string, path: string }, // account 1
        { address: string, path: string }, // account 2
        { address: string, path: string }  // account 3
    ]
}
```

Fehler

```
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
