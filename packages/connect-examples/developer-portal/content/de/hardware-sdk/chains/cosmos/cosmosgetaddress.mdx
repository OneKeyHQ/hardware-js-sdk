# cosmosGetAddress

## Voraussetzungen [#requirements]

* Mindest-Firmware-Versionen
  * Touch: 4.0.0
  * Classic/Mini: 2.10.0

## Cosmos: Adresse abrufen [#cosmos-get-address]

Leitet die Adresse am angegebenen Pfad ab und gibt sie zurück. Wenn `showOnOneKey` gleich `true` ist, muss der Nutzer die Adresse auf dem Gerät bestätigen.

```typescript
const response = await HardwareSDK.cosmosGetAddress(connectId, deviceId, params)
```

### Parameter [#params]

[Optionale gemeinsame Parameter](/de/hardware-sdk/concepts/common-params)

**Einzelne Adresse**

* `path` - _erforderlich_ `string | Array<number>`  Die SDK-Mindestlänge ist `3`. [Weitere Informationen](/de/hardware-sdk/concepts/common-params#hd-path)
* `hrp` - _optional_ `string` Adresspräfix
* `showOnOneKey` - _optional_ `boolean` Ob die Adresse auf dem Gerät angezeigt werden soll. Standard ist `true`.

**Mehrere Adressen**

* `bundle` - Array von Objekten mit `path` und `showOnOneKey`-Feldern

#### Beispiel [#example]

Adresse des ersten Cosmos-Kontos anzeigen:

```typescript
HardwareSDK.cosmosGetAddress(connectId, deviceId, {
    path: "m/44'/118'/0'/0/0"
});
```

Ein Bündel von Cosmos-Adressen zurückgeben, ohne sie auf dem Gerät anzuzeigen:

```typescript
HardwareSDK.cosmosGetAddress(connectId, deviceId, {
    bundle: [
        { path: "m/44'/118'/0'/0/0", showOnOneKey: false }, // account 1
        { path: "m/44'/118'/1'/0/0", showOnOneKey: false }, // account 2
        { path: "m/44'/118'/2'/0/0", showOnOneKey: false }  // account 3
    ]
});
```

#### Ergebnis [#result]

Antwort für eine einzelne Adresse

```typescript
{
    success: true,
    payload: {
        address: string,     // displayed address
        path: string // serialized BIP32 path
    }
}
```

Batch-Antwort in derselben Reihenfolge wie die Anfrage

```typescript
{
    success: true,
    payload: [
        { address: string, path: string }, // account 1
        { address: string, path: string }, // account 2
        { address: string, path: string }  // account 3
    ]
}
```

Fehler

```
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
