# cardanoSignMessage

## Voraussetzungen [#requirements]

* Mindest-Firmware-Versionen
  * Touch: 4.1.0
  * Classic/Mini: 3.0.0

## Cardano: Nachricht signieren <a href="#ethereum-sign-message" id="ethereum-sign-message"></a> [#cardano-sign-message-]

Fordert eine Nachrichtensignatur mit dem aus dem angegebenen Pfad abgeleiteten Schlüssel an.

```typescript
const result = await HardwareSDK.cardanoSignMessage(connectId, deviceId, params);
```

### Parameter [#params]

[**Optionale gemeinsame Parameter**](/de/hardware-sdk/concepts/common-params)

* `path` - _erforderlich_ `string | Array<number>` Die SDK-Mindestlänge ist `3`. [Pfadformat](/de/hardware-sdk/concepts/common-params#hd-path)
* `message` - _erforderlich_ `string` Zu signierende Nachricht als hexadezimale Zeichenfolge kodiert.
* `networkId` - _erforderlich_ `Integer` 1 für Mainnet, 0 für Testnet
* `derivationType` - _erforderlich_ `CardanoDerivationType`-Enum. Wählt den Ableitungsalgorithmus. Die Laufzeit verwendet standardmäßig `ICARUS` (`1`).

Die aktuelle TypeScript-API verlangt `derivationType` ausdrücklich, obwohl die Laufzeit standardmäßig ICARUS verwendet.

### Beispiel [#example]

```typescript
import { PROTO } from "@onekeyfe/hd-core";

// Original message
const message = "Hello World";

// Convert to hex
const messageHex = Buffer.from(message).toString('hex');

HardwareSDK.cardanoSignMessage(connectId, deviceId, {
    path: "m/1852'/1815'/0'/0/0",
    message: messageHex,
    networkId: 1,
    derivationType: PROTO.CardanoDerivationType.ICARUS
});
```

Ergebnis

```typescript
{
    success: true,
    payload: {
        signature: string;
        key: string;
    }
}
```

Fehler

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
