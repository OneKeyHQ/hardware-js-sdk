# cardanoGetAddress

## Voraussetzungen [#requirements]

* Mindest-Firmware-Versionen
  * Touch: 4.1.0
  * Classic/Mini: 3.0.0

## Cardano: Adresse abrufen [#cardano-get-address]

Leitet anhand der angegebenen Adressparameter eine Cardano-Adresse ab und gibt sie zurück. Wenn `showOnOneKey` gleich `true` ist, muss der Nutzer die Adresse auf dem Gerät bestätigen.

```typescript
const response = await HardwareSDK.cardanoGetAddress(connectId, deviceId, params)
```

### Parameter [#params]

[Optionale gemeinsame Parameter](/de/hardware-sdk/concepts/common-params)

**Einzelne Adresse**

* `addressParameters` - _erforderlich_ siehe Beschreibung unten
* `protocolMagic` - _erforderlich_ `Integer` 764824073 für Mainnet, 1 für Preprod Testnet, 2 für Preview Testnet
* `networkId` - _erforderlich_ `Integer` 1 für Mainnet, 0 für Testnet
* `address` - _optional_ `string` Erwartete Adresse, zur Validierung verwendet
* `showOnOneKey` - _erforderlich_ `boolean` Ob die Adresse auf dem Gerät angezeigt werden soll. Standard ist `true`.
* `derivationType` - _erforderlich_ `CardanoDerivationType`-Enum. Wählt den Ableitungsalgorithmus. Die Laufzeit verwendet standardmäßig `ICARUS` (`1`).
* `isCheck` - _optional_ `boolean` prüft nur die Basisadresse

**Mehrere Adressen**

* `bundle` - Array von Objekten mit Feldern für eine einzelne Adresse

**Adressparameter**

* `addressType` - _erforderlich_ `CardanoAddressType`/`number` - Verwenden Sie das exportierte `PROTO.CardanoAddressType`-Enum.
* `path` - `string | Array<number>` Erforderlich für schlüsselbasierte Zahlungsadressen; bei Skript-Zahlungs-/Belohnungsadressen weglassen. Die SDK-Mindestlänge bei Angabe ist `3`.
* `stakingPath` - _optional_ `string | Array<number>` Die SDK-Mindestlänge ist `3`. Für die Ableitung von Basis- und Belohnungsadressen verwendet
* `stakingKeyHash` - _optional_ `string` Hex-Zeichenfolge des Staking-Schlüsselhashs. Für die Basisadressableitung verwendet (als Alternative zu `stakingPath`)
* `certificatePointer` - _optional_ CardanoCertificatePointer-Objekt. Muss enthalten: `number`-Werte `blockIndex`, `txIndex` und `certificateIndex`. Für die Ableitung von Pointer-Adressen verwendet.
* `paymentScriptHash` - _optional_ `string` Hex-Zeichenfolge des Zahlungsskripthashs.
* `stakingScriptHash` - _optional_ `string` Hex-Zeichenfolge des Staking-Skripthashs.

Die aktuelle TypeScript-API verlangt diese Felder ausdrücklich, obwohl die Laufzeit standardmäßig ICARUS und `showOnOneKey: true` verwendet.

### Beispiel [#example]

Byron-Adresse des ersten Cardano-Kontos anzeigen:

```javascript
import { PROTO } from "@onekeyfe/hd-core";

HardwareSDK.cardanoGetAddress(connectId, deviceId, {
    addressParameters: {
        addressType: PROTO.CardanoAddressType.BYRON,
        path: "m/44'/1815'/0'/0/0",
    },
    protocolMagic: 764824073,
    networkId: 1,
    derivationType: PROTO.CardanoDerivationType.ICARUS,
    showOnOneKey: true,
});
```

Basisadresse des ersten Cardano-Kontos anzeigen:

```javascript
import { PROTO } from "@onekeyfe/hd-core";

    addressParameters: {

    protocolMagic: 764824073,
    networkId: 1,
    derivationType: PROTO.CardanoDerivationType.ICARUS,

```

            addressParameters: {
                addressType: 8,
                path: "m/44'/1815'/0'/0/0",
            },
            protocolMagic: 764824073,
            networkId: 1,
            derivationType: PROTO.CardanoDerivationType.ICARUS,
            showOnOneKey: false,
        },
        // base address with staking key hash, account 1, address 1
        {
            addressParameters: {
                addressType: 0,
                path: "m/1852'/1815'/0'/0/0",
                stakingKeyHash: '1bc428e4720702ebd5dab4fb175324c192dc9bb76cc5da956e3c8dff',
            },
            protocolMagic: 764824073,
            networkId: 1,
            derivationType: PROTO.CardanoDerivationType.ICARUS,
            showOnOneKey: false,
        },
        // byron address, account 2, address 3, testnet
        {
            addressParameters: {
                addressType: 8,

            },
            protocolMagic: 1,
