# scdoSignTransaction

#### Voraussetzungen [#requirements]

* Mindest-Firmware-Versionen
  * Touch: 4.10.0

#### SCDO: Transaktion signieren [#scdo-sign-transaction]

Signiert eine Transaktion mit dem privaten Schlüssel, der aus dem angegebenen BIP32-Pfad abgeleitet wird.

```typescript
const response = await HardwareSDK.scdoSignTransaction(connectId, deviceId, {
    path: "m/44'/541'/0'/0/0",
    nonce: "0x0",
    gasPrice: "0xbebc200",
    gasLimit: "0x5208",
    to: "1S0118a02f993fc7a4348fd36b7f7a596948f02b31",
    value: "0xf4240",
    timestamp: "0",
    data: "0x", // optional
    txType: 0   // optional
});
```

**Parameter**

Optionale gemeinsame Parameter

* `path` - _erforderlich_ `string | Array<number>` Die SDK-Mindestlänge ist `3`. [Pfadformat](/de/hardware-sdk/concepts/common-params#hd-path)
* `nonce` - _erforderlich_ `string` Transaktions-Nonce in Hex
* `gasPrice` - _erforderlich_ `string` Transaktions-Gaspreis in Hex
* `gasLimit` - _erforderlich_ `string` Transaktions-Gaslimit in Hex
* `to` - _erforderlich_ `string` Zieladresse
* `value` - _erforderlich_ `string` Transaktionswert in Hex
* `timestamp` - _optional_ `string` Transaktionszeitstempel
* `data` - _optional_ `string` Transaktionsdaten in Hex
* `txType` - _optional_ `number` Transaktionstyp

**Beispiel**

```typescript
const response = await HardwareSDK.scdoSignTransaction(connectId, deviceId, {
    path: "m/44'/541'/0'/0/0",
    nonce: "0x0",
    gasPrice: "0xbebc200",
    gasLimit: "0x5208",
    to: "1S0118a02f993fc7a4348fd36b7f7a596948f02b31",
    value: "0xf4240",
    timestamp: "0"
});
```

Ergebnis

```typescript
{
    success: true,
    payload: {
        signature?: string,
        data_length?: number,
        path: string
    }
}
```

Fehler

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number  // error code
    }
}
```
