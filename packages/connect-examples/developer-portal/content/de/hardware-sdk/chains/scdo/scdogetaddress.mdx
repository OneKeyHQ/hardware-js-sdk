# scdoGetAddress

#### Voraussetzungen [#requirements]

* Mindest-Firmware-Versionen
  * Touch: 4.10.0

#### SCDO: Adresse abrufen [#scdo-get-address]

Leitet die Adresse am angegebenen Pfad ab und gibt sie zurück. Wenn `showOnOneKey` gleich `true` ist, muss der Nutzer die Adresse auf dem Gerät bestätigen.

```typescript
const response = await HardwareSDK.scdoGetAddress(connectId, deviceId, {
    path: "m/44'/541'/0'/0/0",
    showOnOneKey: true
});
```

**Parameter**

Optionale gemeinsame Parameter

**Einzelne Adresse**

* `path` - _erforderlich_ `string | Array<number>` Die SDK-Mindestlänge ist `3`. [Pfadformat](/de/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _optional_ `boolean` Ob die Adresse auf dem Gerät angezeigt werden soll. Standard ist `true`.

**Mehrere Adressen**

* `bundle` - Array von Objekten mit `path` und `showOnOneKey`-Feldern

**Beispiel**

```typescript
// Get single address
const response = await HardwareSDK.scdoGetAddress(connectId, deviceId, {
    path: "m/44'/541'/0'/0/0",
    showOnOneKey: false
});

// Get multiple addresses
const bundleResponse = await HardwareSDK.scdoGetAddress(connectId, deviceId, {
    bundle: [
        {
            path: "m/44'/541'/0'/0/0",
            showOnOneKey: false
        },
        {
            path: "m/44'/541'/1'/0/0",
            showOnOneKey: false
        }
    ]
});
```

Ergebnis mit einzelner Adresse

```typescript
{
    success: true,
    payload: {
        address: string,
        path: string
    }
}
```

Batch-Antwort für Adressen

```typescript
{
    success: true,
    payload: [
        { address: string, path: string }, // account 1
        { address: string, path: string }  // account 2
    ]
}
```

Fehler

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number  // error code
    }
}
```
