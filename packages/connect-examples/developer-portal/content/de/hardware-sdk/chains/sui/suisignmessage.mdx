# suiSignMessage

### Voraussetzungen [#requirements]

* Mindest-Firmware-Versionen
  * Touch: 4.6.0
  * Classic/Mini: 3.4.0

### Sui: Nachricht signieren [#sui-sign-message]

Fordert eine Nachrichtensignatur mit dem aus dem angegebenen Pfad abgeleiteten Schlüssel an.

```typescript
const result = await HardwareSDK.suiSignMessage(connectId, deviceId, params);
```

### Parameter [#params]

[**Optionale gemeinsame Parameter**](/de/hardware-sdk/concepts/common-params)

* `path` - _erforderlich_ `string | Array<number>` Die SDK-Mindestlänge ist `3`. [Mehr erfahren](/de/hardware-sdk/concepts/common-params#hd-path)
* `messageHex` - _erforderlich_ `string` Zu signierende Nachricht als hexadezimale Zeichenfolge kodiert.

### Beispiel [#example]

```typescript
// Original message
const message = "Hello World";

// Convert to hex
const messageHex = Buffer.from(message).toString('hex');

HardwareSDK.suiSignMessage(connectId, deviceId, {
    path: "m/44'/784'/0'/0'/0'",
    messageHex,
});
```

#### Ergebnis [#result]

```typescript
{
    success: true,
    payload: {
        address: string,
        signature: string,
    }
}
```

Fehler

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
