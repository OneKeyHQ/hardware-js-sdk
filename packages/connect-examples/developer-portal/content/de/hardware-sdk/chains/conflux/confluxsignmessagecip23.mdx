# confluxSignMessageCIP23

## Voraussetzungen [#requirements]

* Mindest-Firmware-Versionen
  * Touch: 3.0.0
  * Classic/Mini: 2.4.0

## Conflux: Nachricht nach CIP23 signieren <a href="#ethereum-sign-message" id="ethereum-sign-message"></a> [#conflux-sign-message-cip23-]

Fordert eine Nachrichtensignatur mit dem aus dem angegebenen Pfad abgeleiteten Schlüssel an. Diese Methode folgt der [CIP23](https://github.com/Conflux-Chain/CIPs/blob/master/CIPs/cip-23.md) -Spezifikationsimplementierung

### Parameter [#params]

[**Optionale gemeinsame Parameter**](/de/hardware-sdk/concepts/common-params)

* `path` - _erforderlich_ `string | Array<number>` Die SDK-Mindestlänge ist `3`. [Pfadformat](/de/hardware-sdk/concepts/common-params#hd-path)
* `messageHash` - _erforderlich_ `string` Zu signierende Nachricht als hexadezimale Zeichenfolge kodiert.
* `domainHash` - _erforderlich_ `string` Hexkodierter 32-Byte-Hash der CIP-23-Domain.

### Beispiel [#example]

```typescript
HardwareSDK.confluxSignMessageCIP23(connectId, deviceId, {
    path: "m/44'/503'/0'/0/0",
    messageHash: "0x07bc1c4f3268fc74b60587e9bb7e01e38a7d8a9a3f51202bf25332aa2c75c644",
    domainHash: "7c872d109a4e735dc1886c72af47e9b4888a1507557e0f49c85b570019163373"
});
```

Ergebnis

```typescript
{
    success: true,
    payload: {
        signature: string;
        address: string;
    }
}
```

Fehler

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
