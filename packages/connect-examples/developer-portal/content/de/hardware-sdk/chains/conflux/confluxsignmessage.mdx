# confluxSignMessage

## Voraussetzungen [#requirements]

* Mindest-Firmware-Versionen
  * Touch: 3.0.0
  * Classic/Mini: 2.4.0

## Conflux: Nachricht signieren <a href="#ethereum-sign-message" id="ethereum-sign-message"></a> [#conflux-sign-message-]

Fordert eine Nachrichtensignatur mit dem aus dem angegebenen Pfad abgeleiteten Schlüssel an.

```typescript
const result = await HardwareSDK.confluxSignMessage(connectId, deviceId, params);
```

### Parameter [#params]

[**Optionale gemeinsame Parameter**](/de/hardware-sdk/concepts/common-params)

* `path` - _erforderlich_ `string | Array<number>` Die SDK-Mindestlänge ist `3`. [Pfadformat](/de/hardware-sdk/concepts/common-params#hd-path)
* `messageHex` - _erforderlich_ `string` Zu signierende Nachricht als hexadezimale Zeichenfolge kodiert.

### Beispiel [#example]

```typescript
// Original message
const message = "Hello World";

// Convert to hex
const messageHex = Buffer.from(message).toString('hex');

HardwareSDK.confluxSignMessage(connectId, deviceId, {
    path: "m/44'/503'/0'/0/0",
    messageHex
});
```

Ergebnis

```typescript
{
    success: true,
    payload: {
        signature: string;
        address: string;
    }
}
```

Fehler

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
