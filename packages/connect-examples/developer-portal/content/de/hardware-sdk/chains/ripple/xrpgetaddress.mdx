# xrpGetAddress

## Ripple: Adresse abrufen [#ripple-get-address]

Leitet die Adresse am angegebenen Pfad ab und gibt sie zurück. Wenn `showOnOneKey` gleich `true` ist, muss der Nutzer die Adresse auf dem Gerät bestätigen.

```typescript
const response = await HardwareSDK.xrpGetAddress(connectId, deviceId, params)
```

### Parameter [#params]

[Optionale gemeinsame Parameter](/de/hardware-sdk/concepts/common-params)

**Einzelne Adresse**

* `path` - _erforderlich_ `string | Array<number>`  Die SDK-Mindestlänge ist `3`. [Weitere Informationen](/de/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _optional_ `boolean` Ob die Adresse auf dem Gerät angezeigt werden soll. Standard ist `true`.

**Mehrere Adressen**

* `bundle` - Array von Objekten mit `path` und `showOnOneKey`-Feldern

#### Beispiel [#example]

Adresse des ersten Ripple-Kontos anzeigen:

```typescript
HardwareSDK.xrpGetAddress(connectId, deviceId, {
    path: "m/44'/144'/0'/0/0"
});
```

Ein Bündel von Ripple-Adressen zurückgeben, ohne sie auf dem Gerät anzuzeigen:

```typescript
HardwareSDK.xrpGetAddress(connectId, deviceId, {
    bundle: [
        { path: "m/44'/144'/0'/0/0", showOnOneKey: false }, // account 1
        { path: "m/44'/144'/1'/0/0", showOnOneKey: false }, // account 2
        { path: "m/44'/144'/2'/0/0", showOnOneKey: false }  // account 3
    ]
});
```

#### Ergebnis [#result]

Antwort für eine einzelne Adresse

```typescript
{
    success: true,
    payload: {
        address: string,     // displayed address
        publicKey: string,   // account public key
        path: string  // serialized BIP32 path
    }
}
```

Batch-Antwort in derselben Reihenfolge wie die Anfrage

```typescript
{
    success: true,
    payload: [
        { address: string, publicKey: string, path: string }, // account 1
        { address: string, publicKey: string, path: string }, // account 2
        { address: string, publicKey: string, path: string }  // account 3
    ]
}
```

Fehler

```
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
