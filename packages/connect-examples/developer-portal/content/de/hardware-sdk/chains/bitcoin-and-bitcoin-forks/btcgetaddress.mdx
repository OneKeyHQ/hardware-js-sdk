# btcGetAddress

## Bitcoin: Adresse abrufen [#bitcoin-get-address]

Leitet die Adresse am angegebenen Pfad ab und gibt sie zurück. Wenn `showOnOneKey` gleich `true` ist, muss der Nutzer die Adresse auf dem Gerät bestätigen.

```typescript
const result = await HardwareSDK.btcGetAddress(connectId, deviceId, params);
```

### Parameter [#params]

[**Optionale gemeinsame Parameter**](/de/hardware-sdk/concepts/common-params)

#### Einzelne Adresse [#single-address]

* `path` - _erforderlich_ `string | Array<number>` Die SDK-Mindestlänge ist `1`. [Mehr erfahren](/de/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _optional_ `boolean` Ob die Adresse auf dem Gerät angezeigt werden soll. Standard ist `true`.
* `coin` - _optional_ `string` bestimmt die Netzwerkdefinition in der [coins.json](https://github.com/OneKeyHQ/hardware-js-sdk/blob/onekey/packages/core/src/data/coins/bitcoin.json) -Datei. Coin-`shortcut`, `name` oder `label` kann verwendet werden. Wenn `coin` nicht gesetzt ist, versucht die API, die Netzwerkdefinition abzurufen aus `path`.
* `multisig` - _optional_ MultisigRedeemScriptType, Redeem-Script-Informationen (nur Multisig-Adressen)
* `scriptType` - _optional_ InputScriptType, Adressskripttyp

#### Mehrere Adressen [#multiple-addresses]

* `bundle` - Array von Objekten mit `path`, `showOnOneKey`, `coin`-Feldern

### Verschiedene Adresstypen abrufen [#get-different-types-of-addresses]

Unterschiedliche BTC-Adresstypen erfordern unterschiedliche Ableitungspfadparameter.

| Typ                | Pfad            | Z. B.                                                          |
| ------------------- | --------------- | ------------------------------------------------------------ |
| Legacy BIP44        | m/44'/0'/x'/x/x | Beginnt mit einer "1" und besteht aus 26 bis 35 Zeichen     |
| Nested SegWit BIP49 | m/49'/0'/x'/x/x | Beginnt mit einer "3" und besteht aus 26 bis 35 Zeichen     |
| Native SegWit BIP84 | m/84'/0'/x'/x/x | Mainnet beginnt mit `bc1q`; Testnet beginnt mit `tb1q` |
| Taproot BIP86       | m/86'/0'/x'/x/x | Mainnet beginnt mit `bc1p`; Testnet beginnt mit `tb1p`     |

## Beispiel [#example]

Dritte Adresse des ersten Bitcoin-Kontos anzeigen:

```typescript
HardwareSDK.btcGetAddress(connectId, deviceId, {
    path: "m/49'/0'/0'/0/2",
    coin: "btc"
});
```

Ein Bündel von Adressen des ersten Bitcoin-Kontos zurückgeben, ohne sie auf dem Gerät anzuzeigen:

```typescript
HardwareSDK.btcGetAddress(connectId, deviceId, {
    bundle: [
        { path: "m/49'/0'/0'/0/0", showOnOneKey: false }, // address 1
        { path: "m/49'/0'/0'/0/1", showOnOneKey: false }, // address 2
        { path: "m/49'/0'/0'/0/2", showOnOneKey: false }  // address 3
    ]
});
```

#### Ergebnis [#result]

Antwort für eine einzelne Adresse

```typescript
{
    success: true,
    payload: {
        address: string,     // displayed address
        path: string // serialized BIP32 path
    }
}
```

Batch-Antwort für Adressen

```typescript
{
    success: true,
    payload: [
        { address: string, path: string }, // address 1
        { address: string, path: string }, // address 2
        { address: string, path: string }, // address 3
    ]
}
```

Fehler

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
