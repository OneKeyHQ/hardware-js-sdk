# btcGetPublicKey

## Bitcoin: Öffentlichen Schlüssel abrufen [#bitcoin-get-public-key]

Gibt den aus dem angegebenen Pfad abgeleiteten öffentlichen Schlüssel zurück. Verwenden Sie `showOnOneKey`, um eine Bestätigung auf dem Gerät anzufordern.

```typescript
const result = await HardwareSDK.btcGetPublicKey(connectId, deviceId, params);
```

## Parameter [#params]

[**Optionale gemeinsame Parameter**](/de/hardware-sdk/concepts/common-params)

### Einzelner öffentlicher Schlüssel [#single-public-key]

* `path` - _erforderlich_ `string | Array<number>` Die SDK-Mindestlänge ist `1`. [Mehr erfahren](/de/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _optional_ `boolean` Ob der öffentliche Schlüssel auf dem Gerät angezeigt werden soll. Standard ist `true`.
* `coin` - _optional_ `string` bestimmt die Netzwerkdefinition in der Datei coins.json. Coin-`shortcut`, `name` oder `label` kann verwendet werden. Wenn `coin` nicht gesetzt ist, versucht die API, die Netzwerkdefinition abzurufen aus `path`.
* `scriptType` - _optional_ InputScriptType, Adressskripttyp

#### Mehrere öffentliche Schlüssel [#multiple-public-keys]

* `bundle` - Array von Objekten mit `path`, `coin`-Feldern

### Beispiel [#example]

Öffentlichen Schlüssel des fünften Bitcoin-Kontos zurückgeben:

```typescript
HardwareSDK.btcGetPublicKey(connectId, deviceId, {
    path: "m/49'/0'/4'",
    coin: "btc"
});
```

Ein Bündel öffentlicher Schlüssel mehrerer Bitcoin-Konten zurückgeben:

```typescript
HardwareSDK.btcGetPublicKey(connectId, deviceId, {
    bundle: [
        { path: "m/49'/0'/0'" }, // account 1
        { path: "m/49'/0'/1'" }, // account 2
        { path: "m/49'/0'/2'" }  // account 3
    ]
});
```

### Ergebnis [#result]

Antwort für einen einzelnen öffentlichen Schlüssel

```typescript
{
    success: true,
    payload: {
        path: string, // serialized BIP32 path
        xpub: string,        // xpub in legacy format
        xpubSegwit?: string, // optional for segwit accounts: xpub in segwit format
        root_fingerprint?: number,
        node: {
            depth: number,
            fingerprint: number,
            child_num: number,
            chain_code: string,
            public_key: string,
        },
    }
}
```

[Mehr zum BIP32-Serialisierungsformat erfahren](https://github.com/bitcoin/bips/blob/master/bip-0032.mediawiki#Serialization\_format)

Batch-Antwort für öffentliche Schlüssel

```typescript
{
    success: true,
    payload: [
        { path, xpub, xpubSegwit, root_fingerprint, node }, // account 1
        { path, xpub, xpubSegwit, root_fingerprint, node }, // account 2
        { path, xpub, xpubSegwit, root_fingerprint, node }  // account 3
    ]
}
```

Fehler

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
