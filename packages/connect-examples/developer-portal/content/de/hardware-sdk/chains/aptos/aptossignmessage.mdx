# aptosSignMessage

## Voraussetzungen [#requirements]

* Mindest-Firmware-Versionen
  * Touch: 3.0.0
  * Classic/Mini: 2.6.0

## Aptos: Nachricht signieren <a href="#ethereum-sign-message" id="ethereum-sign-message"></a> [#aptos-sign-message-]

Fordert eine Nachrichtensignatur mit dem aus dem angegebenen Pfad abgeleiteten Schlüssel an.

```typescript
const result = await HardwareSDK.aptosSignMessage(connectId, deviceId, params);
```

### Parameter [#params]

[**Optionale gemeinsame Parameter**](/de/hardware-sdk/concepts/common-params)

* `path` - _erforderlich_ `string | Array<number>` Die SDK-Mindestlänge ist `3`. [Pfadformat](/de/hardware-sdk/concepts/common-params#hd-path)
* `payload` - `AptosMessagePayload`-Typ
  * `address` - _optional  `string`_ Die vom Pfad abgeleitete Adresse
  * `chainId` - _optional  `string`_ ID der Chain
  * `application` - _optional  `string`_ URL der dApp-Website
  * `nonce` - _erforderlich  `string`_ Zufallszahl
  * `message` - _erforderlich_ `string` Zu signierender Nachrichtentext

### Beispiel [#example]

```typescript
HardwareSDK.aptosSignMessage(connectId, deviceId, {
    path: "m/44'/637'/0'/0'/0'",
    payload: {
        nonce: "1",
        message: "hello world"
    }
});
```

Ergebnis

```typescript
{
    success: true,
    payload: {
        path: string;
        fullMessage: string;
        signature: string;
        address: string;
    }
}
```

Fehler

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
