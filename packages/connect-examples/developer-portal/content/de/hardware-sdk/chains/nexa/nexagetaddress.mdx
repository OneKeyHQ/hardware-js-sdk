# nexaGetAddress

### Voraussetzungen [#requirements]

* Mindest-Firmware-Versionen
  * Touch: 4.4.0
  * Classic/Mini: 3.2.0

## Nexa: Adresse abrufen [#nexa-get-address]

Leitet die Adresse am angegebenen Pfad ab und gibt sie zurück. Verwenden Sie `showOnOneKey`, um eine Bestätigung auf dem Gerät anzufordern.

```typescript
const result = await HardwareSDK.nexaGetAddress(connectId, deviceId, params);
```

## Parameter [#params]

[**Optionale gemeinsame Parameter**](/de/hardware-sdk/concepts/common-params)

### Einzelne Adresse [#single-address]

* `path` - _erforderlich_ `string | Array<number>` Die SDK-Mindestlänge ist `3`. [Mehr erfahren](/de/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _optional_ `boolean` Ob die Adresse auf dem Gerät angezeigt werden soll. Standard ist `true`.
* `prefix` - _optional_ `string` Adresspräfix, zum Beispiel `nexa` für Mainnet; geben Sie das vorgesehene Netzwerk ausdrücklich an
* `scheme` - _optional_ `string` Modus des Verschlüsselungsalgorithmus. Standard ist `schnorr`

#### Mehrere Adressen [#multiple-addresses]

* `bundle` - Array von Objekten mit `path`, `prefix`, `scheme`, `showOnOneKey`-Feldern

### Beispiel [#example]

Adresse des ersten Nexa-Kontos zurückgeben:

```typescript
HardwareSDK.nexaGetAddress(connectId, deviceId, {
    path: "m/44'/29223'/0'/0/0",
    showOnOneKey: true,
    prefix: "nexa"
});
```

Ein Bündel von Adressen mehrerer Nexa-Konten zurückgeben:

```typescript
HardwareSDK.nexaGetAddress(connectId, deviceId, {
    bundle: [
        { path: "m/44'/29223'/0'/0/0" }, // account 1
        { path: "m/44'/29223'/0'" }, // account 2
        { path: "m/44'/29223'/0'/0/1" }  // account 3
    ]
});
```

### Ergebnis [#result]

Antwort für eine einzelne Adresse

```typescript
{
    success: true,
    payload: {
        path: string, // serialized BIP32 path
        address: string,   // address
    }
}
```

Batch-Antwort für Adressen

```typescript
{
    success: true,
    payload: [
        { path, address }, // account 1
        { path, address }, // account 2
        { path, address }, // account 3
    ]
}
```

Fehler

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
