# kaspaGetAddress

### Voraussetzungen [#requirements]

* Mindest-Firmware-Versionen
  * Touch: 4.3.0
  * Classic/Mini: 3.0.0

## Kaspa: Adresse abrufen [#kaspa-get-address]

Leitet die Adresse am angegebenen Pfad ab und gibt sie zurück. Wenn `showOnOneKey` gleich `true` ist, muss der Nutzer die Adresse auf dem Gerät bestätigen.

```typescript
const result = await HardwareSDK.kaspaGetAddress(connectId, deviceId, params);
```

## Parameter [#params]

[**Optionale gemeinsame Parameter**](/de/hardware-sdk/concepts/common-params)

### Einzelne Adresse [#single-address]

* `path` - _erforderlich_ `string | Array<number>` Die SDK-Mindestlänge ist `3`. [Mehr erfahren](/de/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _optional_ `boolean` Ob die Adresse auf dem Gerät angezeigt werden soll. Standard ist `true`.
* `prefix` - _optional_ `string` Adresspräfix. Standard ist `kaspa`
* `scheme` - _optional_ `string` Modus des Verschlüsselungsalgorithmus. Standard ist `schnorr`

#### Mehrere Adressen [#multiple-addresses]

* `bundle` - Array von Objekten mit `path`, `showOnOneKey`, `prefix`, und `scheme`-Feldern

### Beispiel [#example]

Adresse des ersten Kaspa-Kontos zurückgeben:

```typescript
HardwareSDK.kaspaGetAddress(connectId, deviceId, {
    path: "m/44'/111111'/0'/0/0",
    showOnOneKey: true,
    prefix: "kaspa",
    scheme: "schnorr",
});
```

Ein Bündel von Adressen mehrerer Kaspa-Konten zurückgeben:

```typescript
HardwareSDK.kaspaGetAddress(connectId, deviceId, {
    bundle: [
        { path: "m/44'/111111'/0'/0/0" }, // account 1
        { path: "m/44'/111111'/0'" }, // account 2
        { path: "m/44'/111111'/0'/0/1" }  // account 3
    ]
});
```

### Ergebnis [#result]

Antwort für eine einzelne Adresse

```typescript
{
    success: true,
    payload: {
        path: string, // serialized BIP32 path
        address: string,   // address
    }
}
```

Batch-Antwort für Adressen

```typescript
{
    success: true,
    payload: [
        { path, address }, // account 1
        { path, address }, // account 2
        { path, address }, // account 3
    ]
}
```

Fehler

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
