# benfenGetPublicKey

Benfen: Öffentlichen Schlüssel abrufen

Öffentlichen Schlüssel über einen BIP32-Pfad vom Gerät abrufen.

**Voraussetzungen**

* Mindest-Firmware-Versionen
  * Pro: 4.12.0
  * Classic 1S / Classic 1S Pure: 3.11.0

```typescript
const result = await HardwareSDK.benfenGetPublicKey(connectId, deviceId, {
  path: "m/44'/728'/0'/0'/0'",
  showOnOneKey: false
});
```

#### Parameter [#params]

**Optionale gemeinsame Parameter**

* `path` - _erforderlich_ `string | Array<number>` Die SDK-Mindestlänge ist `3`. [Pfadformat](/de/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _optional_ `boolean` Ob der öffentliche Schlüssel auf dem Gerät angezeigt werden soll

Rückgabe:

* success: boolean - True bei Erfolg
* payload:
  * path: string - Verwendeter BIP32-Pfad
  * pub: string - Öffentlicher Schlüssel im Hexformat

Beispiel:

```typescript
const params = {
  path: "m/44'/728'/0'/0'/0'",
  showOnOneKey: false
};

// Single public key
const response = await HardwareSDK.benfenGetPublicKey(connectId, deviceId, params);

// Batch public keys
const batchParams = {
  bundle: [
    {
      path: "m/44'/728'/0'/0'/0'",
      showOnOneKey: false
    },
    {
      path: "m/44'/728'/1'/0'/0'",
      showOnOneKey: false
    }
  ]
};
const batchResponse = await HardwareSDK.benfenGetPublicKey(connectId, deviceId, batchParams);
```
