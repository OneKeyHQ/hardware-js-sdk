# benfenGetAddress

### Benfen: Adresse abrufen [#benfen-get-address]

Leitet die Adresse am angegebenen Pfad ab und gibt sie zurück. Wenn `showOnOneKey` gleich `true` ist, muss der Nutzer die Adresse auf dem Gerät bestätigen.

**Voraussetzungen**

* Mindest-Firmware-Versionen
  * Pro: 4.12.0
  * Classic 1S / Classic 1S Pure: 3.11.0

```typescript
const result = await HardwareSDK.benfenGetAddress(connectId, deviceId, params);
```

#### Parameter [#params]

**Optionale gemeinsame Parameter**

* `path` - _erforderlich_ `string | Array<number>` Die SDK-Mindestlänge ist `3`. [Pfadformat](/de/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _optional_ `boolean` Ob die Adresse auf dem Gerät angezeigt werden soll

#### Rückgabe [#returns]

* success: boolean - True bei Erfolg
* payload:
  * address: string - Abgeleitete Adresse im BFC-Format
  * path: string - Verwendeter BIP32-Pfad
  * pub?: string - Öffentlicher Schlüssel, sofern verfügbar

Beispiel:

```typescript
const params = {
  path: "m/44'/728'/0'/0'/0'",
  showOnOneKey: false
};

// Single address
const response = await HardwareSDK.benfenGetAddress(connectId, deviceId, params);

// Batch addresses
const batchParams = {
  bundle: [
    {
      path: "m/44'/728'/0'/0'/0'",
      showOnOneKey: false
    },
    {
      path: "m/44'/728'/1'/0'/0'",
      showOnOneKey: false
    }
  ]
};
const batchResponse = await HardwareSDK.benfenGetAddress(connectId, deviceId, batchParams);
```

**Ergebnis**

Antwort für eine einzelne Adresse

```typescript
{
    success: true,
    payload: {
        address: string,     // displayed address
        pub?: string,
        path: string // serialized BIP32 path
    }
}
```

Batch-Antwort in derselben Reihenfolge wie die Anfrage

```typescript
{
    success: true,
    payload: [
        { address: string, pub?: string, path: string }, // account 1
        { address: string, pub?: string, path: string }, // account 2
        { address: string, pub?: string, path: string }  // account 3
    ]
}
```

Fehler

```
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
