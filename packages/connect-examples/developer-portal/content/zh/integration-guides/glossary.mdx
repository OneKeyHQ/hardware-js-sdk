# 术语表

以下术语用于 OneKey 钱包及硬件集成。不同链的格式和行为不同，以具体链的方法参考为准。

## 钱包

管理密钥、展示账户并帮助用户授权操作的应用或设备。资产和交易状态记录在区块链上，并不存放在钱包应用内部。

## 账户

具有相应状态的链上身份。以太坊外部账户由私钥控制，合约账户由代码控制。并非每个账户都等同于一对公私钥。

## 地址

用于接收资产或与账户、合约交互的标识。以太坊地址长 20 字节，常表示为 `0x` 后跟 40 个十六进制字符。地址不等于公钥。

## 公钥

密码学密钥对的公开部分，用于验证签名，并可按链规则派生地址。编码与长度取决于签名方案和格式。

## 私钥

通过签名授权操作的秘密材料。不要要求用户将私钥粘贴到 dApp、集成表单、日志或问题报告中。

## 恢复短语

用于备份钱包派生密钥所需材料的一组单词。BIP-39 定义了助记词及其转换为种子的方法。恢复短语属于秘密，集成流程不应索取。

## 种子

分层密钥派生的输入。在 BIP-39 中，由助记词和可选 passphrase 派生种子。种子不能与单个账户的私钥互换。

## 派生路径

在分层钱包中定位密钥的索引序列。链、账户、地址类型和找零分支均可能影响路径。使用目标方法和链要求的格式。

## Passphrase

与恢复短语共同用于派生另一钱包的可选值。不同值可能生成不同钱包；它不是设备 PIN 的另一种写法。

## PIN

用于保护硬件设备访问的代码，区别于恢复短语和 passphrase。遵循 SDK 提供的设备对应 PIN 流程。

## Provider

dApp 向钱包请求账户、链上信息或签名的 JavaScript 接口。以太坊 Provider 通常遵循 EIP-1193，其他链有不同接口。

## 传输通道

与设备交换数据的连接，如 USB 或蓝牙。连接成功本身不代表已经获得账户权限或签名授权。

## 签名与广播

签名使用密钥授权消息或交易；广播将已签名交易发送到网络。两者是不同操作，应核对具体 API 是否只签名或同时广播。

## Air gap

签名设备与应用之间没有直接有线或无线电连接的通信流程。二维码集成通过 QR 数据交换请求和响应；应用广播交易仍需联网。

## Keystore

加密后的密钥材料及解密所需参数。保护程度取决于加密设置和密码；密文长度并非统一固定。

## 十六进制

使用 `0–9` 和 `a–f` 的十六进制记法。API 可能要求 `0x` 前缀、不接受前缀，或直接接受字节。以参数说明为准。
