# 参与贡献

先找到负责相关功能的仓库，阅读 README、贡献说明和安全策略。

| 范围 | 仓库 |
| --- | --- |
| 应用和浏览器扩展 | [app-monorepo](https://github.com/OneKeyHQ/app-monorepo) |
| 硬件 SDK 与本开发者门户 | [hardware-js-sdk](https://github.com/OneKeyHQ/hardware-js-sdk) |
| 注入的钱包 Provider | [cross-inpage-provider](https://github.com/OneKeyHQ/cross-inpage-provider) |
| 固件 | [firmware](https://github.com/OneKeyHQ/firmware) |
| 历史 GitBook 文档 | [docs](https://github.com/OneKeyHQ/docs) |

## 提议修改

新增链或修改集成时，说明运行环境、签名方法、序列化格式，以及所需设备或固件支持。软件钱包和硬件签名的修改可能属于不同仓库。开始前先检查已有 Issue 和 PR。

## 提交修复

1. 遵循目标仓库的开发说明。
2. 保持修改范围集中，并更新受影响的示例和文档。
3. 运行仓库要求的检查。
4. 在 PR 中说明问题、修改后的行为及验证证据。

文档问题应附页面地址和具体错误内容。集成失败请使用[问题报告清单](/zh/troubleshooting)。安全漏洞请按对应仓库的安全策略报告，不要在公开 Issue 中发布利用细节。
