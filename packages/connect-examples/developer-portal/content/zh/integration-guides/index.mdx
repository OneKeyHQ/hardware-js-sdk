# 集成指南

从连接成功，到用户能够可靠地完成操作。这些指南涵盖钱包选择、应用元信息、交易上下文，以及集成后的维护。

| 要完成的事 | 指南 |
| --- | --- |
| 在安装多个钱包的浏览器中选择 OneKey | [Provider 选择](./provider-selection) |
| 在连接提示中标识你的应用 | [站点元信息](./site-metadata) |
| 请求用户关注某种代币 | [代币元信息](./token-metadata) |
| 准确解释合约调用 | [合约元信息](./contract-metadata) |
| 连接独立的钱包应用 | [WalletConnect 会话](./walletconnect) |
| 实现由用户明确发起的设备管理流程 | [设备初始化与擦除](./device-management) |
| 理解钱包与签名术语 | [术语表](./glossary) |
| 报告问题或提交修改 | [参与贡献](./contributing) |

第一次接入 OneKey，请先[选择集成方式](/zh/getting-started)。维护旧应用时，请查阅[历史集成](/zh/legacy)。
