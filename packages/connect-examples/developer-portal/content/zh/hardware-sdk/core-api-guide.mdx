# 硬件 SDK 核心接口指南

生命周期 how-to：init → search → 事件 → 第一次受保护调用 → cleanup。

参数表在 [通用参数](/zh/hardware-sdk/concepts/common-params)。机型和协议差异在 [设备](/zh/hardware-sdk/concepts/devices) 和 [Protocol V1 与 V2](/zh/hardware-sdk/concepts/protocol)。

## 快速流程
<div id="request-basics" />

- 方法签名：`HardwareSDK.method(connectId, deviceId?, params)` → `Promise<{ success, payload }>`，先判断 `success` 再读 `payload`
- 标识：`connectId` 来自 `searchDevices`；`deviceId` 来自 `getFeatures` / `getDeviceState`（BLE 必填，WebUSB 建议带）。擦除 / 恢复后刷新 `deviceId`。完整表：[标识符](/zh/hardware-sdk/concepts/identifiers)
- 事件：入口订一次 `UI_EVENT`，只对输入类 `UI_REQUEST`（PIN / Passphrase / Bootloader 选择）调用 `uiResponse`
- 同一设备串行调用。隐藏钱包用 `openWalletSession`（兼容路径用 `initSession + passphraseState`）

```ts
const res = await HardwareSDK.evmGetAddress(connectId, deviceId, {
  path: "m/44'/60'/0'/0/0",
  useEmptyPassphrase: true,
});

if (!res.success) throw new Error(res.payload.error);
console.log(res.payload.address);
```

## 核心标识与环境

| 标识 | 作用 | 获取来源 | 何时变化 |
| --- | --- | --- | --- |
| `connectId` | 哪条连接 | `searchDevices()` | USB 重插、BLE 重新配对、切换传输 |
| `deviceId` | 哪一次种子生命周期 | `getFeatures` / `getDeviceState` | 擦除、恢复、换种子 |

同一台设备的 USB 和 BLE `connectId` 不同，要分开缓存。见 [标识符](/zh/hardware-sdk/concepts/identifiers) 和 [重连与释放](/zh/hardware-sdk/transport/reconnect)。

**运行时要求**

- `webusb` — HTTPS + 用户手势
- `react-native` — BLE 权限（Android 上常常还要定位）
- `lowlevel` — 宿主侧 64 字节帧适配器
- 固件 — Bootloader 下部分 API 会失败

### 哪些标识是必填的？

| 要求 | 说明 | 示例 API |
| :--- | :--- | :--- |
| 🟢 不需要标识 | 初始化、配置、事件 | `init` `on/off` `searchDevices` `getLogs` `dispose` `uiResponse` |
| 🟡 只要 `connectId` | 设备管理、状态、固件 | `getFeatures` `getDeviceState` `openWalletSession` `cancel` `deviceSettings` |
| 🔵 `connectId` + `deviceId` | 链上签名、地址、加密 | `evmSignTransaction` `btcSignTransaction` `solanaSignMessage` `allNetworkGetAddress` |

## 标准生命周期
<div id="standard-lifecycle" />

`init → search → getFeatures/getDeviceState → 订阅 UI/DEVICE/FIRMWARE → call + uiResponse → cleanup`

```ts
import HardwareSDK, { UI_EVENT, UI_REQUEST, UI_RESPONSE } from '@onekeyfe/hd-common-connect-sdk';

await HardwareSDK.init({ env: 'webusb', fetchConfig: true, debug: false });

const devices = await HardwareSDK.searchDevices();
if (!devices.success || !devices.payload.length) throw new Error('No device');
const { connectId } = devices.payload[0];

const features = await HardwareSDK.getFeatures(connectId);
if (!features.success) throw new Error(features.payload.error);
const deviceId = features.payload.device_id;

HardwareSDK.on(UI_REQUEST.REQUEST_PIN, () => {
  // 打开 UI，收集输入，再 uiResponse
});
HardwareSDK.on(UI_REQUEST.REQUEST_PASSPHRASE, () => {});

await HardwareSDK.evmSignTransaction(connectId, deviceId, {
  path: "m/44'/60'/0'/0/0",
  useEmptyPassphrase: true,
});
```

同一设备串行。切换设备后刷新 features。卸载时移除监听。只有拆除传输时才 `HardwareSDK.dispose()` —— 见 [重连与释放](/zh/hardware-sdk/transport/reconnect)。

## 事件处理
<div id="events-ui" />

在应用入口订一次。只对输入类请求调用 `uiResponse`。

**需要 `uiResponse` 的 UI 请求**

| UI_REQUEST | 触发时机 | 应答 |
| --- | --- | --- |
| `REQUEST_PIN` | 受保护调用且设备锁定 | `UI_RESPONSE.RECEIVE_PIN` |
| `REQUEST_PASSPHRASE` | 软件输入隐藏钱包 | `UI_RESPONSE.RECEIVE_PASSPHRASE` |
| `REQUEST_PASSPHRASE_ON_DEVICE` | 设备输入隐藏钱包 | `UI_RESPONSE.RECEIVE_PASSPHRASE`（`passphraseOnDevice: true`） |
| `REQUEST_DEVICE_IN_BOOTLOADER_FOR_WEB_DEVICE` | Web Bootloader 选择 | `UI_RESPONSE.SELECT_DEVICE_IN_BOOTLOADER_FOR_WEB_DEVICE` |

**仅展示（不要 `uiResponse`）**

| UI_REQUEST | 作用 |
| --- | --- |
| `REQUEST_BUTTON` | 请在设备确认。固件升级的 `reason='firmware-update'` 同样不要 `uiResponse` |
| `DEVICE_PROGRESS` | 长耗时进度 |
| `FIRMWARE_PROCESSING` / `FIRMWARE_PROGRESS` / `FIRMWARE_TIP` | 固件升级状态 |
| `BLUETOOTH_PERMISSION` / `LOCATION_PERMISSION` | BLE 权限 |
| `BOOTLOADER` / `REQUIRE_MODE` / `NOT_INITIALIZE` / `FIRMWARE_NOT_SUPPORTED` | 模式 / 支持性提示 |

**设备 / 固件事件**

| 通道 | 事件 | 建议动作 |
| --- | --- | --- |
| `DEVICE_EVENT` | `CONNECT` | 刷新设备列表 |
| `DEVICE_EVENT` | `DISCONNECT` | 连接作废；不要重放有副作用的调用。[重连](/zh/hardware-sdk/transport/reconnect) |
| `DEVICE_EVENT` | `ACQUIRE` / `RELEASE` | 卡住并发 |
| `DEVICE_EVENT` | `CHANGED` | 重新 `getDeviceState` / `getFeatures` |
| `DEVICE_EVENT` | `USED_ELSEWHERE` | 关掉占用的 Bridge / 标签页 |
| `FIRMWARE_EVENT` | `RELEASE_INFO` / `BLE_RELEASE_INFO` | 安全时机提示升级。[固件升级](/zh/hardware-sdk/firmware-update) |

```ts
import HardwareSDK, { UI_EVENT, UI_REQUEST, UI_RESPONSE } from '@onekeyfe/hd-common-connect-sdk';

const handleUiEvent = (msg) => {
  switch (msg.type) {
    case UI_REQUEST.REQUEST_PIN:
      openPinModal(({ value }) =>
        HardwareSDK.uiResponse({ type: UI_RESPONSE.RECEIVE_PIN, payload: value })
      );
      return;
    case UI_REQUEST.REQUEST_PASSPHRASE:
      openPassphraseModal(({ value, onDevice, save }) =>
        HardwareSDK.uiResponse({
          type: UI_RESPONSE.RECEIVE_PASSPHRASE,
          payload: { value, passphraseOnDevice: onDevice, attachPinOnDevice: false, save },
        })
      );
      return;
    default:
      break;
  }
};

HardwareSDK.on(UI_EVENT, handleUiEvent);
```

## 错误处理
<div id="error-codes" />

| 分组 | 常见原因 | 建议动作 |
| --- | --- | --- |
| Device (101–118, 200) | 模式错误、忙、`deviceId` 不匹配、未初始化 | 确认模式，重连后 `init` + `getDeviceState` |
| IFrame (300–305) | 未 init、加载/超时/拦截 | 确认 `init` 成功；检查 CSP / iframe |
| Method/Firmware (400–418) | 参数错误、必须升级、forbidden path | 校验 HD Path；[固件升级](/zh/hardware-sdk/firmware-update) |
| Transport (600–603) | 传输未配置、并发调用 | 检查 `env`，串行调用 |
| Bluetooth (700–722) | 扫描/权限/连接/超时 | 权限与距离；绑定过期不要死循环 |
| Runtime/Bridge (800–821) | PIN 取消、Bridge 超时 | 重试或启动 Bridge |
| Web device (901–902) | WebUSB 未授权 | HTTPS + 用户手势 |

认 `payload.code`，不要解析 `payload.error` 文案。定义见 [`HardwareError.ts`](https://github.com/OneKeyHQ/hardware-js-sdk/blob/onekey/packages/shared/src/HardwareError.ts)。
