# AI Agent 集成

OneKey 提供一套**钱包 Skills**，让 AI 编程助手（Claude Code、Cursor、Codex、OpenCode、OpenClaw 等）代你执行真实的钱包操作 —— 余额查询、转账、兑换、行情研究、代币安全审计 —— 背后接的钱包可以是任意类型，**包括 OneKey 硬件钱包**。

Skills 和各工具的安装流程都在专属仓库里维护：

👉 **[OneKeyHQ/onekey-wallet-skills](https://github.com/OneKeyHQ/onekey-wallet-skills)**

## Skills

四个按领域划分的 skill：

| Skill | 功能范围 |
|---|---|
| **onekey-wallet** | 余额、持仓、转账、历史记录、导入 / 登出 |
| **onekey-swap** | Swap 报价、执行、跨链桥、状态查询 |
| **onekey-market** | 代币价格、热度、K 线、流动性、持有人、研究 |
| **onekey-security** | 代币审计、蜜罐检查、交易模拟 |

每个 skill 都通过 `onekey` CLI（npm 包 [`@onekeyfe/cli`](https://www.npmjs.com/package/@onekeyfe/cli)）执行命令。首次使用时 skill 会自动 `npm install -g @onekeyfe/cli`，无需单独安装。

## 用 OneKey 硬件钱包

登录时选择硬件作为钱包类型 —— `--hardware` **只**出现在 `auth login` 这一条命令上：

```bash
onekey auth login --hardware
```

CLI 会引导你完成设备发现、PIN 输入（在设备屏上）、以及 passphrase（如启用）。详见 [PIN 码](/zh/hardware-sdk/concepts/pin) 和 [Passphrase](/zh/hardware-sdk/concepts/passphrase)。

登录完成后，**后续所有**由 skill 驱动的命令都自动走硬件钱包。业务命令上**不要**再传 `--hardware`，它只在 `auth login` 上生效：

```bash
# 一次性：硬件登录
onekey auth login --hardware

# 之后：skills 会直接调这些命令，不用再传 --hardware
onekey balance --chain eth
onekey transfer --chain eth --to 0x... --amount 0.01
onekey swap --from eth --to usdc --amount 0.5
onekey history --chain eth
```

用完登出：

```bash
onekey auth logout
```

## 输出格式

每个 skill 命令都返回结构化 JSON，便于程序消费：

```json
{
  "status": "success",
  "api_version": "1",
  "data": { "...各命令特定字段..." },
  "metadata": { "timestamp": "2026-04-19T..." }
}
```

失败时外层结构不变，`status` 变成 `"error"`，再带上类型化 `code` + `message`。

## 仅硬件的轻量选择

如果你的场景是**只做硬件操作**（设备管理、CI 流水线的原始签名、只关心设备协议的窄范围 agent）、不想走 `onekey` 账户层，可以用另一个独立 CLI：[`@onekeyfe/hardware-cli`](https://www.npmjs.com/package/@onekeyfe/hardware-cli)（命令 `onekey-hw`）。它功能窄一些，但**不需要账户登录**，插上设备就能跑。

```bash
npm install -g @onekeyfe/hardware-cli
onekey-hw search
onekey-hw get-address --chain evm --use-empty-passphrase
```

做终端用户级别的 agent 工作流 → 用 `@onekeyfe/cli` + skills；只要硬件协议 → 用 `@onekeyfe/hardware-cli`。
