# AI Agent 集成

`@onekeyfe/hardware-cli` 使 AI Agent（Claude Code、Codex、Gemini CLI 等）能够通过 USB 与 OneKey 硬件钱包交互。

## 安装

### 1. 安装 CLI

```bash
npm install -g @onekeyfe/hardware-cli
```

### 2. 安装 Claude Code 插件

```bash
claude plugin marketplace add OneKeyHQ/hardware-js-sdk --sparse .claude-plugin packages/hd-cli
claude plugin install onekey-hardware@onekey-hardware-plugins
```

### 3. 其他 AI 工具（Codex、Gemini、Cursor）

将 [AGENTS.md](https://github.com/OneKeyHQ/hardware-js-sdk/blob/onekey/packages/hd-cli/AGENTS.md) 放到你的项目中，AI Agent 会读取它来了解可用命令。

## 技能

| 技能 | 关键命令 |
|------|----------|
| **设备** | `search`, `lock`, `device-verify`, `device-settings`, `device-wipe` |
| **签名**（27 条链） | `get-address`, `sign-transaction`, `sign-message`, `sign-typed-data`, `sign-psbt`, `batch-get-address` |
| **固件**（只读） | `firmware-check`, `firmware-check-all`, `bootloader-check` |
| **安全** | `change-pin`, `toggle-passphrase`, `passphrase-state` |

## 使用

```bash
# 搜索已连接的设备（自动获取设备信息）
onekey-hw search

# 获取以太坊地址
onekey-hw get-address --chain evm --use-empty-passphrase

# 获取比特币地址
onekey-hw get-address --chain btc --use-empty-passphrase

# 签名消息
onekey-hw sign-message --chain evm --message "hello" --use-empty-passphrase

# 签名 EVM 交易
onekey-hw sign-transaction --chain evm \
  --tx '{"to":"0x...","value":"0xf4240","chainId":1,"nonce":"0x0","gasLimit":"0x5208","gasPrice":"0xbebc200"}' \
  --use-empty-passphrase

# 检查固件
onekey-hw firmware-check-all
```

固件更新需通过 [OneKey App](https://onekey.so/download) 或 [firmware.onekey.so](https://firmware.onekey.so/)。

## 支持的链

| 类别 | 链 |
|------|-----|
| **EVM** | Ethereum, BSC, Polygon, Arbitrum, Base, Optimism, Avalanche 及所有 EVM 兼容链 |
| **Bitcoin 系** | Bitcoin (Legacy/SegWit/Taproot), Litecoin, Bitcoin Cash 及其他 BTC 分叉 |
| **Layer 1** | Solana, Cardano, Polkadot, Cosmos, Near, Aptos, Sui, TON, Stellar, XRP |
| **其他** | Tron, Filecoin, Kaspa, Algorand, Conflux, Nervos, Nostr 等 |

各链参数请参考[链方法文档](/zh/hardware-sdk/chains)。

## 输出格式

所有命令返回结构化 JSON：

```json
{
  "success": true,
  "payload": {
    "address": "0x1234...",
    "path": "m/44'/60'/0'/0/0"
  }
}
```
