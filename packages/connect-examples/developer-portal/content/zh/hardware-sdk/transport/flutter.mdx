# Flutter：通过蓝牙连接（原生）

> 本页基于《[底层传输插件](/zh/hardware-sdk/concepts/low-level-plugin)》，建议先阅读 BLE 收发接口与 Protocol V1/V2 的处理边界。

适用于通过 WebView 或 JS 引擎加载 JS 包并使用底层适配器桥接到 `@onekeyfe/hd-common-connect-sdk` 的 Flutter 应用。

## 步骤 1. 选择运行时

- WebView：稳定且广泛支持；桥接 API 与 iOS/Android 原生外壳相同
- JS 引擎：例如 `flutter_js`，直接在 Dart 中运行构建的 JS 包

## 步骤 2. 构建 JS 包

在 hardware-js-sdk 仓库的原生示例中构建（参见 `web/` 目录）并生成 `web_dist/` 资源。

## 步骤 3. 加载 JS 包

在 Flutter 中加载 `web_dist/` 资源（通过 WebView 或 JS 引擎）。

## 步骤 4. 实现消息桥接

从原生向 JS 暴露 `enumerate/connect/disconnect/send/receive`，保持相同的签名。将未经修改的 BLE 通知块编码为 hex，放入按连接隔离的队列供 `receive(uuid)` 读取。V1/V2 帧处理与重组由 SDK 完成。

## 步骤 5. 处理 UI 事件

为输入请求显示原生弹窗，为设备端操作显示说明。只有输入请求才调用 `HardwareSDK.uiResponse`，并保留响应关联字段。按键确认和设备端 PIN 提示属于通知。参见 [UI 事件处理](/zh/hardware-sdk/core-api-guide#events-ui)。

## BLE UUID

- `serviceUuid = 00000001-0000-1000-8000-00805f9b34fb`
- `writeCharacteristic = 00000002-0000-1000-8000-00805f9b34fb`
- `notifyCharacteristic = 00000003-0000-1000-8000-00805f9b34fb`
