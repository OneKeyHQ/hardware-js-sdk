# tronSignMessage

<span id="tron签名消息" />

## TRON：签名消息 <a href="#ethereum-sign-message" id="ethereum-sign-message"></a>

使用指定路径派生的密钥请求消息签名。

```typescript
const result = await HardwareSDK.tronSignMessage(connectId, deviceId, params);
```

### 参数

[**可选通用参数**](/zh/hardware-sdk/concepts/common-params)

* `path` - _必需_ `string | Array<number>` SDK 校验的最小长度为 `3`。 [路径格式](/zh/hardware-sdk/concepts/common-params#hd-path)
* `messageHex` - _必需_ `string`。以十六进制编码的待签名消息。

* `messageType` - `"V2"`。必须显式传入：当前运行时拒绝省略此字段或使用旧版 `"V1"` 的请求，尽管公开类型仍列出这两个值。

### 示例

```typescript
// Original message
const message = "Hello World";

// Convert to hex
const messageHex = Buffer.from(message).toString('hex');

HardwareSDK.tronSignMessage(connectId, deviceId, {
    path: "m/44'/195'/0'/0/0",
    messageHex,
    messageType: 'V2'
});
```

返回结果

```typescript
{
    success: true,
    payload: {
        signature: string;
        address: string;
    }
}
```

错误

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
