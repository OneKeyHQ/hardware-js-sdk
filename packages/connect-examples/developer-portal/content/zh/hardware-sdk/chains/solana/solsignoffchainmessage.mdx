# solSignOffchainMessage

对 Solana 链下消息签名。SDK 通过同一套公开 API 实现 **Protocol V1 和 V2** 调用。请确认接入所用设备型号的固件支持情况。

```ts
const response = await HardwareSDK.solSignOffchainMessage(connectId, deviceId, {
  path: "m/44'/501'/0'/0'",
  messageHex: '68656c6c6f', // hex of the off-chain payload
});
```

### 参数

[可选通用参数](/zh/hardware-sdk/concepts/common-params)

* `path` - _必需_ `string | number[]`。完全硬化的 Solana 派生路径。
* `messageHex` - _必需_ `string`。以十六进制编码的链下消息。
* `messageVersion` - _可选_ `SolanaOffChainMessageVersion` 枚举。
* `messageFormat` - _可选_ `SolanaOffChainMessageFormat` 枚举。
* `applicationDomainHex` - _可选_ `string`。以十六进制编码的 32 字节应用域。
* `requiredSigners` - _可选_ `string[]`。以十六进制编码的 32 字节公钥，**必须严格排序且不重复**。

### 返回结果

```ts
{
  success: true,
  payload: {
    signature: string,
    pub?: string,
  }
}
```

Pro 2 / Neo 在内部走 Protocol V2。不要按型号给这个调用做分支。

另见：[solSignTransaction](/zh/hardware-sdk/chains/solana/solsigntransaction)
