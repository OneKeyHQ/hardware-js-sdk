# nemGetAddress

### 使用要求

* 固件版本要求
  * Touch: 4.4.0
  * Classic/Mini: 3.2.0

## NEM：获取地址

显示指定 BIP32 路径派生的地址，并返回给调用者。用户需要在 OneKey 上确认导出。

```typescript
const response = await HardwareSDK.nemGetAddress(connectId, deviceId, params)
```

### 参数

[可选通用参数](/zh/hardware-sdk/common-params)

**导出单个地址**

* `path` - _必需_ `string | Array<number>` 最小长度为 5。[更多信息](/zh/hardware-sdk/core-api-guide#hd-path)
* `network` - _可选_ `number` 网络 ID。默认值为 `MAINNET(104)`
* `showOnOneKey` - _可选_ `boolean` 决定是否在设备上显示地址。默认设置为 `true`

**导出批量地址**

* `bundle` - 包含 `path` 和 `showOnOneKey` 字段的对象 `Array`

#### 示例

显示第一个 NEM 账户的地址：

```typescript
HardwareSDK.nemGetAddress(connectId, deviceId, {
    path: "m/44'/43'/0'/0/0"
});
```

返回一批 NEM 地址而不在设备上显示：

```typescript
HardwareSDK.nemGetAddress(connectId, deviceId, {
    bundle: [
        { path: "m/44'/43'/0'/0/0", showOnOneKey: false }, // 账户 1
        { path: "m/44'/43'/1'/0/0", showOnOneKey: false }, // 账户 2
        { path: "m/44'/43'/2'/0/0", showOnOneKey: false }  // 账户 3
    ]
});
```

#### 返回结果

只有一个地址的结果

```typescript
{
    success: true,
    payload: {
        address: string,     // 显示的地址
        path: Array<number> // 强化路径
    }
}
```

按 FIFO 排序的批量地址结果

```typescript
{
    success: true,
    payload: [
        { address: string, path: Array<number> }, // 账户 1
        { address: string, path: Array<number> }, // 账户 2
        { address: string, path: Array<number> }  // 账户 3
    ]
}
```

错误

```
{
    success: false,
    payload: {
        error: string, // 错误信息
        code: number // 错误码
    }
}
```
