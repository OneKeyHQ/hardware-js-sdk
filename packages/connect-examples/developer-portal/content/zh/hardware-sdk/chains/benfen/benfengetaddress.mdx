# benfenGetAddress

### Benfen：获取地址

派生并返回指定路径的地址。`showOnOneKey` 为 `true` 时，用户必须在设备上确认地址。

**使用要求**

* 最低固件版本
  * Pro: 4.12.0
  * Classic 1S / Classic 1S Pure: 3.11.0

```typescript
const result = await HardwareSDK.benfenGetAddress(connectId, deviceId, params);
```

#### 参数

**可选通用参数**

* `path` - _必需_ `string | Array<number>` SDK 校验的最小长度为 `3`。 [路径格式](/zh/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _可选_ `boolean` 是否在设备上显示地址

#### 返回值

* success: boolean - 成功时为 true
* payload:
  * address: string - 派生的 BFC 格式地址
  * path: string - 使用的 BIP32 路径
  * pub?: string - 公钥（如果可用）

示例：

```typescript
const params = {
  path: "m/44'/728'/0'/0'/0'",
  showOnOneKey: false
};

// Single address
const response = await HardwareSDK.benfenGetAddress(connectId, deviceId, params);

// Batch addresses
const batchParams = {
  bundle: [
    {
      path: "m/44'/728'/0'/0'/0'",
      showOnOneKey: false
    },
    {
      path: "m/44'/728'/1'/0'/0'",
      showOnOneKey: false
    }
  ]
};
const batchResponse = await HardwareSDK.benfenGetAddress(connectId, deviceId, batchParams);
```

**返回结果**

单个地址响应

```typescript
{
    success: true,
    payload: {
        address: string,     // displayed address
        pub?: string,
        path: string // serialized BIP32 path
    }
}
```

批量响应，顺序与请求一致

```typescript
{
    success: true,
    payload: [
        { address: string, pub?: string, path: string }, // account 1
        { address: string, pub?: string, path: string }, // account 2
        { address: string, pub?: string, path: string }  // account 3
    ]
}
```

错误

```
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
