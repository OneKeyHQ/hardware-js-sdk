# cosmosGetPublicKey

## 使用要求

* 最低固件版本
  * Touch: 4.0.0
  * Classic/Mini: 2.10.0

## Cosmos：获取公钥

返回指定路径派生的公钥。可通过 `showOnOneKey` 请求用户在设备上确认。

```typescript
const result = await HardwareSDK.cosmosGetPublicKey(connectId, deviceId, params);
```

## 参数

[**可选通用参数**](/zh/hardware-sdk/concepts/common-params)

### 导出单个公钥

* `path` - _必需_ `string | Array<number>` SDK 校验的最小长度为 `3`。
* `curve` - _可选_ `string` 椭圆曲线算法，默认为 `secp256k1`
* `showOnOneKey` - _可选_ `boolean`。是否在设备上显示公钥，默认为 `true`。

#### 导出批量公钥

* `bundle` - 对象数组，每个对象包含 `path`、`showOnOneKey`、`curve` 字段。

### 示例

返回第一个 Cosmos 账户的公钥：

```typescript
HardwareSDK.cosmosGetPublicKey(connectId, deviceId, {
    path: "m/44'/118'/0'/0/0",
    curve: 'secp256k1',
    showOnOneKey: true
});
```

批量返回多个 Cosmos 账户的公钥：

```typescript
HardwareSDK.cosmosGetPublicKey(connectId, deviceId, {
    bundle: [
        { path: "m/44'/118'/0'/0/0" }, // account 1
        { path: "m/44'/118'/1'/0/0" }, // account 2
        { path: "m/44'/118'/2'/0/0" }, // account 3
    ]
});
```

### 返回结果

单个公钥响应

```typescript
{
    success: true,
    payload: {
        path: string, // serialized BIP32 path
        pub: string
    }
}
```


批量公钥响应

```typescript
{
    success: true,
    payload: [
        { path: serializedPath, pub }, // account 1
        { path: serializedPath, pub }, // account 2
        { path: serializedPath, pub }, // account 3
    ]
}
```

错误

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
