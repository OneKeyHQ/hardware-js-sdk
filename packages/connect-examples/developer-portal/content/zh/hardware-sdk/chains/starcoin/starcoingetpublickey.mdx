# starcoinGetPublicKey

## Starcoin：获取公钥

返回指定路径派生的公钥。可通过 `showOnOneKey` 请求用户在设备上确认。

```typescript
const result = await HardwareSDK.starcoinGetPublicKey(connectId, deviceId, params);
```

## 参数

[**可选通用参数**](/zh/hardware-sdk/concepts/common-params)

### 导出单个公钥

* `path` — _必需_ `string | Array<number>` SDK 校验的最小长度为 `3`。 [路径格式](/zh/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` — _可选_ `boolean`。是否在设备上显示公钥，默认为 `true`。

#### 导出批量公钥

* `bundle` - 对象数组，每个对象包含 `path`、`showOnOneKey` 字段。

### 示例

返回第一个 Starcoin 账户的公钥：

```typescript
HardwareSDK.starcoinGetPublicKey(connectId, deviceId, {
    path: "m/44'/101010'/0'/0'/0'",
    showOnOneKey: true
});
```

批量返回多个 Starcoin 账户的公钥：

```typescript
HardwareSDK.starcoinGetPublicKey(connectId, deviceId, {
    bundle: [
        { path: "m/44'/101010'/0'/0'/0'" }, // account 1
        { path: "m/44'/101010'/1'/0'/0'" }, // account 2
        { path: "m/44'/101010'/2'/0'/0'" }  // account 3
    ]
});
```

### 返回结果

单个公钥响应

```typescript
{
    success: true,
    payload: {
        path: string, // serialized BIP32 path
        public_key: string
    }
}
```

[了解更多关于 BIP32 序列化格式](https://github.com/bitcoin/bips/blob/master/bip-0032.mediawiki#Serialization\_format)

批量公钥响应

```typescript
{
    success: true,
    payload: [
        { path: serializedPath, public_key }, // account 1
        { path: serializedPath, public_key }, // account 2
        { path: serializedPath, public_key }, // account 3
    ]
}
```

错误

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
