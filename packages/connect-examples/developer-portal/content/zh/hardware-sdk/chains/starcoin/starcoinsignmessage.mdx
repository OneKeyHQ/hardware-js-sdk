# starcoinSignMessage

<span id="starcoin签名消息" />

## Starcoin：签名消息 <a href="#ethereum-sign-message" id="ethereum-sign-message"></a>

使用指定路径派生的密钥请求消息签名。

```typescript
const result = await HardwareSDK.starcoinSignMessage(connectId, deviceId, params);
```

### 参数

[**可选通用参数**](/zh/hardware-sdk/concepts/common-params)

* `path` — _必需_ `string | Array<number>` SDK 校验的最小长度为 `3`。 [路径格式](/zh/hardware-sdk/concepts/common-params#hd-path)
* `messageHex` - _必需_ `string`。以十六进制编码的待签名消息。

### 示例

```typescript
// Original message
const message = "Hello World";

// Convert to hex
const messageHex = Buffer.from(message).toString('hex');

HardwareSDK.starcoinSignMessage(connectId, deviceId, {
    path: "m/44'/101010'/0'/0'/0'",
    messageHex
});
```

返回结果

```typescript
{
    success: true,
    payload: {
        signature: string;
        public_key: string;
    }
}
```

错误

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
