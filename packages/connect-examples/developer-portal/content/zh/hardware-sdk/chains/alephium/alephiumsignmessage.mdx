# alephiumSignMessage

### 使用要求

* 最低固件版本
  * Touch: 4.10.0

### Alephium：签名消息

使用指定 BIP32 路径派生的私钥对消息进行签名。用户需要在 OneKey 设备上确认操作。

```typescript
// Original message
const message = "Hello Alephium";

// Convert to hex
const messageHex = Buffer.from(message).toString('hex');

const result = await HardwareSDK.alephiumSignMessage(connectId, deviceId, {
    path: "m/44'/1234'/0'/0/0",
    messageHex,  // "Hello Alephium" in hex
    messageType: "alephium"
});
```

#### 参数

[可选通用参数](/zh/hardware-sdk/concepts/common-params)

* `path` - _必需_ `string | Array<number>` SDK 校验的最小长度为 `3`。
* `messageHex` - _必需_ `string` 十六进制格式的待签名消息
* `messageType` - _必需_ `"alephium" | "sha256" | "blake2b" | "identity"`。消息签名模式。

#### 示例

```typescript
// Original message
const message = "Hello Alephium";

// Convert to hex
const messageHex = Buffer.from(message).toString('hex');

const response = await HardwareSDK.alephiumSignMessage(connectId, deviceId, {
    path: "m/44'/1234'/0'/0/0",
    messageHex,
    messageType: "alephium"
});
```

返回结果

```typescript
{
    success: true,
    payload: {
        signature: string;
        address: string;
    }
}
```

错误

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
