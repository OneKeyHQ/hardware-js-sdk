# cardanoGetAddress

## 使用要求

* 最低固件版本
  * Touch: 4.1.0
  * Classic/Mini: 3.0.0

## Cardano：获取地址

根据指定地址参数派生并返回 Cardano 地址。`showOnOneKey` 为 `true` 时，用户必须在设备上确认地址。

```typescript
const response = await HardwareSDK.cardanoGetAddress(connectId, deviceId, params)
```

### 参数

[可选通用参数](/zh/hardware-sdk/concepts/common-params)

**导出单个地址**

* `addressParameters` - _必需_ 见下方描述
* `protocolMagic` - _必需_ `Integer` 主网为 764824073，Preprod 测试网为 1，Preview 测试网为 2
* `networkId` - _必需_ `Integer` 主网为 1，测试网为 0
* `address` - _可选_ `string`。用于校验的预期地址。
* `showOnOneKey` - _必需_ `boolean`。是否在设备上显示地址，默认为 `true`。
* `derivationType` - _必需_ `CardanoDerivationType` 枚举。选择派生算法；运行时默认为 `ICARUS`（`1`）。
* `isCheck` - _可选_ `boolean` 仅检查基础地址

**导出批量地址**

* `bundle` - 包含单个地址字段的对象 `Array`

**地址参数**

* `addressType` - _必需_ `CardanoAddressType`/`number`。使用导出的 `PROTO.CardanoAddressType` 枚举。
* `path` - `string | Array<number>` 使用密钥支付地址时必填；脚本支付地址或奖励地址省略。提供时 SDK 校验至少 `3` 级。
* `stakingPath` - _可选_ `string | Array<number>` SDK 校验至少 `3` 级，用于基础地址和奖励地址派生
* `stakingKeyHash` - _可选_ `string` 质押密钥哈希的十六进制字符串。用于基础地址派生（作为 `stakingPath` 的替代）
* `certificatePointer` - _可选_ CardanoCertificatePointer 对象。必须包含 `number` 类型的 `blockIndex`、`txIndex` 和 `certificateIndex`。用于指针地址派生。
* `paymentScriptHash` - _可选_ `string` 支付脚本哈希的十六进制字符串。
* `stakingScriptHash` - _可选_ `string` 质押脚本哈希的十六进制字符串。

当前 TypeScript 接口要求显式提供这些字段；运行时默认值为 ICARUS 和 `showOnOneKey: true`。

### 示例

显示第一个 Cardano 账户的 Byron 地址：

```javascript
import { PROTO } from "@onekeyfe/hd-core";

HardwareSDK.cardanoGetAddress(connectId, deviceId, {
    addressParameters: {
        addressType: PROTO.CardanoAddressType.BYRON,
        path: "m/44'/1815'/0'/0/0",
    },
    protocolMagic: 764824073,
    networkId: 1,
    derivationType: PROTO.CardanoDerivationType.ICARUS,
    showOnOneKey: true,
});
```

显示第一个 Cardano 账户的基础地址：

```javascript
import { PROTO } from "@onekeyfe/hd-core";

    networkId: 1,
```

```javascript
                addressType: 8,
                path: "m/44'/1815'/0'/0/0",
            },
            protocolMagic: 764824073,
            networkId: 1,
            derivationType: PROTO.CardanoDerivationType.ICARUS,
            showOnOneKey: false,
        },
        // base address with staking key hash, account 1, address 1
        {
            addressParameters: {
                addressType: 0,
                path: "m/1852'/1815'/0'/0/0",
                stakingKeyHash: '1bc428e4720702ebd5dab4fb175324c192dc9bb76cc5da956e3c8dff',

            networkId: 1,
            derivationType: PROTO.CardanoDerivationType.ICARUS,
            showOnOneKey: false,
        },
        // byron address, account 2, address 3, testnet
        {
            addressParameters: {
                addressType: 8,

            },
            protocolMagic: 1,
            networkId: 0,

        },
    ],
});
```
