# cardanoSignMessage

## 使用要求

* SDK 要求的最低固件版本
  * Touch / Pro（`model_touch`）：4.10.0

该方法未声明 Classic/Mini 的最低固件版本。没有 SDK 版本门槛并不代表固件一定支持此方法。

## Cardano：签名消息 <a href="#ethereum-sign-message" id="ethereum-sign-message"></a>

使用指定路径派生的密钥请求消息签名。

```typescript
const result = await HardwareSDK.cardanoSignMessage(connectId, deviceId, params);
```

### 参数

[**可选通用参数**](/zh/hardware-sdk/concepts/common-params)

* `path` - _必需_ `string`，至少包含 `3` 段的 BIP32 路径。此方法不接受数字数组。 [路径格式](/zh/hardware-sdk/concepts/common-params#hd-path)
* `message` - _必需_ `string` 要签名的十六进制文本消息
* `networkId` - _必需_ `Integer` 主网为 1，测试网为 0
* `derivationType` - _必需_ `CardanoDerivationType` 枚举。选择派生算法；运行时默认为 `ICARUS`（`1`）。

当前 TypeScript 接口要求显式提供 `derivationType`，运行时默认值为 ICARUS。

### 示例

```typescript
import { PROTO } from "@onekeyfe/hd-core";

// Original message
const message = "Hello World";

// Convert to hex
const messageHex = Buffer.from(message).toString('hex');

HardwareSDK.cardanoSignMessage(connectId, deviceId, {
    path: "m/1852'/1815'/0'/0/0",
    message: messageHex,
    networkId: 1,
    derivationType: PROTO.CardanoDerivationType.ICARUS
});
```

返回结果

```typescript
{
    success: true,
    payload: {
        signature: string;
        key: string;
    }
}
```

错误

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
