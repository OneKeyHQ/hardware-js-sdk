# cardanoGetPublicKey

## 使用要求

* 最低固件版本
  * Touch: 4.1.0
  * Classic/Mini: 3.0.0

## Cardano：获取公钥

返回指定 Cardano 路径派生的扩展公钥。

```typescript
const result = await HardwareSDK.cardanoGetPublicKey(connectId, deviceId, params);
```

## 参数

[**可选通用参数**](/zh/hardware-sdk/concepts/common-params)

### 导出单个公钥

* `path` - _必需_ `string | Array<number>` SDK 校验的最小长度为 `3`。 [路径格式](/zh/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _可选_ `boolean`。是否在设备上显示公钥，默认为 `false`。
* `derivationType` - _可选_ `CardanoDerivationType` 枚举。选择派生算法；运行时默认为 `ICARUS`（`1`）。

#### 导出批量公钥

* `bundle` - 对象数组，每个对象包含 `path`、`showOnOneKey` 字段。

### 示例

返回第一个 Cardano 账户的公钥：

```typescript
HardwareSDK.cardanoGetPublicKey(connectId, deviceId, {
    path: "m/1852'/1815'/0'/0/0",
    showOnOneKey: true
});
```

批量返回多个 Cardano 账户的公钥：

```typescript
HardwareSDK.cardanoGetPublicKey(connectId, deviceId, {
    bundle: [
        { path: "m/1852'/1815'/0'/0/0", }, // account 1
        { path: "m/1852'/1815'/1'/0/0", }, // account 2
        { path: "m/1852'/1815'/2'/0/0", }  // account 3
    ]
});
```

### 返回结果

单个公钥响应

```typescript
{
    success: true,
    payload: {
        path: Array<number>, // hardened path
        serializedPath: string,
        xpub: string,
        node: HDNodeType,
    }
}
```

错误

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
