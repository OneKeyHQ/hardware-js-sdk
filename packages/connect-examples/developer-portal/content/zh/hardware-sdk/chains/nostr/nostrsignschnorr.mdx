# nostrSignSchnorr

### 使用要求

当前 SDK 声明的固件版本校验范围为：`model_touch` ≥ 4.7.0、`model_mini` ≥ 3.6.0。这些名称是 SDK 的范围键；接入时还需确认其对应的设备型号，以及已发布固件的实际支持情况。

## Nostr：签名 Schnorr

使用指定路径的密钥，对传入的哈希请求 Schnorr 签名。用户在设备上确认请求。

```typescript
const result = await HardwareSDK.nostrSignSchnorr(connectId, deviceId, params);
```

### 参数

[**可选通用参数**](/zh/hardware-sdk/concepts/common-params)

* `path` - _必需_ `string | Array<number>` SDK 校验的最小长度为 `5`。 [路径格式](/zh/hardware-sdk/concepts/common-params#hd-path)
* `hash` - _必需_ `string`。以十六进制编码的 32 字节哈希。

### 示例

```typescript
const response = await HardwareSDK.nostrSignSchnorr(
  connectId,
  deviceId,
  {
    path: "m/44'/1237'/0'/0/0",
    hash: '2118c65161c7d68b4bdbe1374f658532670057ab1bb0c99937d0ff7cff45cb5e',
  }
);
```

返回结果

```typescript
{
  success: true,
  payload: {
    path: string;
    rawHash: string,
    signature: string,
  }
}
```

错误

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
