# nostrGetPublicKey

### 使用要求

* 最低固件版本
  * Touch: 4.6.0
  * Classic/Mini: 3.5.0
  * Classic1s: 3.6.0

## Nostr：获取公钥

返回指定路径派生的公钥。可通过 `showOnOneKey` 请求用户在设备上确认。

```typescript
const result = await HardwareSDK.nostrGetPublicKey(connectId, deviceId, params);
```

## 参数

[**可选通用参数**](/zh/hardware-sdk/concepts/common-params)

### 导出单个公钥

* `path` - _必需_ `string | Array<number>` SDK 校验的最小长度为 `1`。 [路径格式](/zh/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _可选_ `boolean`。是否在设备上显示公钥，默认为 `true`。

#### 导出批量公钥

* `bundle` - 对象数组，每个对象包含 `path`、`showOnOneKey` 字段。

### 示例

返回第一个 Nostr 密钥的公钥：

```typescript
HardwareSDK.nostrGetPublicKey(connectId, deviceId, {
    path: "m/44'/1237'/0'/0/0",
    showOnOneKey: true,
});
```

批量返回多个 Nostr 密钥的公钥：

```typescript
HardwareSDK.nostrGetPublicKey(connectId, deviceId, {
    bundle: [
        { path: "m/44'/1237'/0'/0/0" }, // account 1
        { path: "m/44'/1237'/0'" }, // account 2
        { path: "m/44'/1237'/0'/0/1" }  // account 3
    ]
});
```

### 返回结果

单个公钥响应

```typescript
{
    success: true,
    payload: {
        path: string, // serialized BIP32 path
        pub?: string, // public key in hexadecimal
        publickey?: string, // legacy runtime alias
        npub?: string,        // npub
    }
}
```

批量公钥响应

```typescript
{
    success: true,
    payload: [
        { path, pub, publickey, npub }, // account 1
        { path, pub, publickey, npub }, // account 2
        { path, pub, publickey, npub }, // account 3
    ]
}
```

错误

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```

公钥请读取 `pub`。运行时还返回旧别名 `publickey`；当前声明中的可选 `publicKey` 拼写与该别名不一致。
