# nostrEncryptMessage

### 使用要求

* 最低固件版本
  * Touch: 4.6.0
  * Classic/Mini: 3.5.0
  * Classic1s: 3.6.0

## Nostr：加密消息

使用指定路径的密钥和对方的公钥请求消息加密。

```typescript
const result = await HardwareSDK.nostrEncryptMessage(connectId, deviceId, params);
```

### 参数

[**可选通用参数**](/zh/hardware-sdk/concepts/common-params)

* `path` - _必需_ `string | Array<number>` SDK 校验的最小长度为 `5`。 [路径格式](/zh/hardware-sdk/concepts/common-params#hd-path)
* `pubkey` - _必需_ `string`。对方的公钥。
* `plaintext` - _必需_ `string`。待加密的明文消息。
* `showOnOneKey` - _可选_ `boolean`。是否在设备上显示请求，默认为 `true`。

### 示例

```typescript
const response = await HardwareSDK.nostrEncryptMessage(
  connectId,
  deviceId,
  {
     path: "m/44'/1237'/0'/0/0",
     pubkey: '2118c65161c7d68b4bdbe1374f658532670057ab1bb0c99937d0ff7cff45cb5e',
     plaintext: 'Hello world',
     showOnOneKey: true,
  }
);
```

返回结果

```typescript
{
  success: true,
  payload: {
    path: string;
    pubkey: string;
    plaintext: string;
    encryptedMessage: string;
  }
}
```

错误

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
