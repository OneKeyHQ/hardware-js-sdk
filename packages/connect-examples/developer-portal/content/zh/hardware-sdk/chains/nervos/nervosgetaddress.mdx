# nervosGetAddress

### Nervos：获取地址

派生并返回指定路径的地址。`showOnOneKey` 为 `true` 时，用户必须在设备上确认地址。

```typescript
const result = await HardwareSDK.nervosGetAddress(connectId, deviceId, params);
```

#### 使用要求

* 最低固件版本
  * Touch: 4.9.0
  * Mini: 3.7.0

#### 参数

connectId: `string`

* 连接的唯一标识符

deviceId: `string`

* 硬件设备的唯一标识符

params: `object`

* path: _必需_ `string` - 请求地址的 BIP32 路径（例如 "m/44'/309'/0'/0/0"）
* network: _必需_ `string` - 网络名称（例如 "ckb"）
* showOnOneKey: _可选_ `boolean` - 是否在设备上显示地址

#### 示例

```typescript
const response = await HardwareSDK.nervosGetAddress('connect1', 'device1', {
    path: "m/44'/309'/0'/0/0",
    showOnOneKey: true,
    network: "ckb"
});

if (response.success === false) throw new Error(response.payload.error);
console.log(response.payload.address);
```

<span id="返回结果" />

#### 返回值

返回一个 Promise，解析为：

```typescript
{
    success: true,
    payload: {
        address: string,     // Nervos address
        path: string  // BIP32 path used for derivation
    }
}
```

错误响应：

```typescript
{
    success: false,
    payload: {
        error: string,  // Error message
        code?: string | number    // Error code
    }
}
```
