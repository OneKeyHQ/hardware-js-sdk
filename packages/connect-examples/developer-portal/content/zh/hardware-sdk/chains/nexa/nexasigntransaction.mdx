# nexaSignTransaction

### 使用要求

* 最低固件版本
  * Touch: 4.4.0
  * Classic/Mini: 3.2.0

## Nexa：签名交易

使用指定路径派生的密钥请求交易签名。用户在设备上核对并确认请求。

```typescript
const result = await HardwareSDK.nexaSignTransaction(connectId, deviceId, params);
```

### 参数

[**可选通用参数**](/zh/hardware-sdk/concepts/common-params)

* `inputs` - _必需_ `Array`。交易输入数组。
  * `path` - _必需_ `string` SDK 校验的最小长度为 `3`。 [路径格式](/zh/hardware-sdk/concepts/common-params#hd-path)
  * `message` - _必需_ `string`。以十六进制字符串编码的序列化交易。
  * `prefix` - _必需_ `string`。目标网络的地址前缀。SDK 不提供默认值；示例显式选择 `nexatest`。
### 示例

```typescript
const response = await HardwareSDK.nexaSignTransaction(
  connectId,
  deviceId,
  {
    inputs: [
      {
         path: "m/44'/29223'/0'/0/0",
         message: '000578c6c76f10156fbc7ee4a8faa7a4e92b6adadc978abf66ae70f13a03b75d36cd7a6acc0967cc9f2f632f585cb7b4297873858c23233792767fd4ae662ec1093bb13029ce7b1f559ef5e747fcac439f1455a2ec7c5f09b72290795e70665044026cad0dba749a112e0d2ea420fa68e0218453db6bb0744e44eb51edc76af8bb6871190000000000',
         prefix: 'nexatest',
      }
    ],
  }
);
```

返回结果

```typescript
{
  success: true,
  payload: [
    { index: 0, signature: "signed data" }
  ]
}
```

错误

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
