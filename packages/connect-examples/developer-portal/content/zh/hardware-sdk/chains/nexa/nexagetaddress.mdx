# nexaGetAddress

### 使用要求

* 固件版本要求
  * Touch: 4.4.0
  * Classic/Mini: 3.2.0

## Nexa：获取地址

获取指定 BIP32 路径派生的地址。用户需要确认导出。

```typescript
const result = await HardwareSDK.nexaGetAddress(connectId, deviceId, params);
```

## 参数

[**可选通用参数**](/zh/hardware-sdk/concepts/common-params)

### 导出单个公钥

* `path` - _必需_ `string | Array<number>` 最小长度为 `3`。[更多信息](/zh/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _可选_ `boolean` 决定是否在设备上显示地址。默认设置为 `true`
* `prefix` - _可选_ `string` 地址前缀，如主网使用 `nexa`；请显式指定目标网络
* `scheme` - _可选_ `string` 加密算法模式。默认设置为 `schnorr`



#### 导出批量公钥

* `bundle` - 包含 `path`、`prefix`、`scheme`、`showOnOneKey` 字段的对象 `Array`

### 示例

返回第一个 Nexa 账户的公钥：

```typescript
HardwareSDK.nexaGetAddress(connectId, deviceId, {
    path: "m/44'/29223'/0'/0/0",
    showOnOneKey: true,
    prefix: "nexa"
});
```

返回多个 Nexa 账户的公钥集合：

```typescript
HardwareSDK.nexaGetAddress(connectId, deviceId, {
    bundle: [
        { path: "m/44'/29223'/0'/0/0" }, // 账户 1
        { path: "m/44'/29223'/0'" }, // 账户 2
        { path: "m/44'/29223'/0'/0/1" }  // 账户 3
    ]
});
```

### 返回结果

仅返回一个公钥的结果

```typescript
{
    success: true,
    payload: {
        path: string, // 序列化 BIP32 路径
        address: string,   // 地址
    }
}
```

返回批量公钥的结果

```typescript
{
    success: true,
    payload: [
        { path, address }, // 账户 1
        { path, address }, // 账户 2
        { path, address }, // 账户 3
    ]
}
```

错误

```typescript
{
    success: false,
    payload: {
        error: string, // 错误信息
        code?: string | number // 错误码
    }
}
```
