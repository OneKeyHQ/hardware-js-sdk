# evmGetPublicKey

## 以太坊：获取公钥

获取指定 BIP32 路径派生的扩展公钥。用户需要确认导出。

```typescript
const result = await HardwareSDK.evmGetPublicKey(connectId, deviceId, params);
```

## 参数

[**可选通用参数**](/zh/hardware-sdk/concepts/common-params)

### 导出单个公钥

* `path` - _必需_ `string | Array<number>` 最小长度为 `3`。[更多信息](/zh/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _可选_ `boolean` 决定是否在设备上显示地址。默认设置为 `true`
* `chainId` - _可选_ `number` ETH 中的 ChainId 是特定以太坊网络的唯一标识符，用于区分不同版本的区块链。[参考](https://github.com/ethereum-lists/chains/tree/master/_data/chains)

#### 导出批量公钥

* `bundle` - 包含 `path`、`chainId`、`showOnOneKey` 字段的对象 `Array`

### 示例

返回第一个以太坊账户的公钥：

```typescript
HardwareSDK.evmGetPublicKey(connectId, deviceId, {
    path: "m/44'/60'/0'/0/0",
    showOnOneKey: true,
    chainId: 1
});
```

返回多个以太坊账户的批量公钥：

```typescript
HardwareSDK.evmGetPublicKey(connectId, deviceId, {
    bundle: [
        { path: "m/44'/60'/0'/0/0", chainId: 1 }, // 账户 1
        { path: "m/44'/60'/0'", chainId: 1 }, // 账户 2
        { path: "m/44'/60'/0'/0/1", chainId: 1 }  // 账户 3
    ]
});
```

### 返回结果

只有一个公钥的结果

```typescript
{
    success: true,
    payload: {
        path: string, // 序列化 BIP32 路径
        xpub: string,        // 传统格式的 xpub
        pub: string,
        publicKey: string,   // BIP32 序列化格式
    }
}
```

[了解更多关于 BIP32 序列化格式](https://github.com/bitcoin/bips/blob/master/bip-0032.mediawiki#Serialization_format)

批量公钥的结果

```typescript
{
    success: true,
    payload: [
        { path, xpub, publicKey }, // 账户 1
        { path, xpub, publicKey }, // 账户 2
        { path, xpub, publicKey }, // 账户 3
    ]
}
```

错误

```typescript
{
    success: false,
    payload: {
        error: string, // 错误信息
        code?: string | number // 错误码
    }
}
```

`bundle` 请求开启 `useBatch: true` 且走受支持的批量路径时，返回 `{ path, pub, publicKey }`，没有 `xpub` 或 `node`。普通路径会返回扩展公钥和 node；不要在批量响应中强制依赖它们。
