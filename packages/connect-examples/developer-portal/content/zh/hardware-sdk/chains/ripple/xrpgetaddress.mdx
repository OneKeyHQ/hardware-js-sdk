# xrpGetAddress

## Ripple：获取地址

派生并返回指定路径的地址。`showOnOneKey` 为 `true` 时，用户必须在设备上确认地址。

```typescript
const response = await HardwareSDK.xrpGetAddress(connectId, deviceId, params)
```

### 参数

[可选通用参数](/zh/hardware-sdk/concepts/common-params)

**导出单个地址**

* `path` - _必需_ `string | Array<number>`  SDK 校验的最小长度为 `3`。 [路径格式](/zh/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _可选_ `boolean`。是否在设备上显示地址，默认为 `true`。

**导出批量地址**

* `bundle` - 对象数组，每个对象包含 `path`、`showOnOneKey` 字段。

#### 示例

显示第一个 Ripple 账户的地址：

```typescript
HardwareSDK.xrpGetAddress(connectId, deviceId, {
    path: "m/44'/144'/0'/0/0"
});
```

批量返回 Ripple 地址，不在设备上显示：

```typescript
HardwareSDK.xrpGetAddress(connectId, deviceId, {
    bundle: [
        { path: "m/44'/144'/0'/0/0", showOnOneKey: false }, // account 1
        { path: "m/44'/144'/1'/0/0", showOnOneKey: false }, // account 2
        { path: "m/44'/144'/2'/0/0", showOnOneKey: false }  // account 3
    ]
});
```

#### 返回结果

单个地址响应

```typescript
{
    success: true,
    payload: {
        address: string,     // displayed address
        publicKey: string,   // account public key
        path: string  // serialized BIP32 path
    }
}
```

批量响应，顺序与请求一致

```typescript
{
    success: true,
    payload: [
        { address: string, publicKey: string, path: string }, // account 1
        { address: string, publicKey: string, path: string }, // account 2
        { address: string, publicKey: string, path: string }  // account 3
    ]
}
```

错误

```
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
