# xrpSignTransaction

### Ripple：签名交易 <a href="#cardano-sign-transaction" id="cardano-sign-transaction"></a>

对指定交易进行签名。用户需要在 OneKey 上确认所有交易详情。

```typescript
const response = await HardwareSDK.xrpSignTransaction(connectId, deviceId, params)
```

### 参数

[**可选通用参数**](/zh/hardware-sdk/concepts/common-params)

* `path` - _必需_ `string | Array<number>` SDK 校验的最小长度为 `5`。[更多信息](/zh/hardware-sdk/concepts/common-params#hd-path)
* `transaction` - _必需_ `XrpTransaction` 类型

#### XrpTransaction 类型

```typescript
type XrpTransaction = {
    fee: string;
    flags?: number;
    sequence: number;
    maxLedgerVersion?: number; // Proto: "last_ledger_sequence"
    payment: XrpPayment;
}

type XrpPayment = {
    amount: number;
    destination: string;
    destinationTag?: number;
}
```

### 示例

下方调用描述当前运行时契约。当前 SDK 的 TypeScript 声明错误地将交易字段展开到顶层，并将 `payment.amount` 声明为 string，与运行时结构不一致。不要为满足该声明而把 `transaction` 内的字段移到顶层。

```typescript
HardwareSDK.xrpSignTransaction(connectId, deviceId, {
    path: "m/44'/144'/0'/0'/0",
    transaction: {
        fee: '12',
        flags: 0,
        sequence: 32841006,
        maxLedgerVersion: 32841630,
        payment: {
            amount: 1000000,
            destination: 'rwgumKP89VhMrJ4dRkGVS4tafRfAmZmKf8',
        }
    }
});
```

返回结果

```typescript
{
    success: true,
    payload: {
        signature: string;
        serializedTx: string;
    }
}
```

错误

```typescript
{
    success: false,
    payload: {
        error: string, // 错误信息
        code?: string | number // 错误码
    }
}
```
