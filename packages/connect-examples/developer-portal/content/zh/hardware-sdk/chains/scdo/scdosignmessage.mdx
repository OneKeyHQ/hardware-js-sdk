# scdoSignMessage

#### 使用要求

* 最低固件版本
  * Touch: 4.10.0

#### SCDO：签名消息

使用指定 BIP32 路径派生的私钥对消息进行签名。

```typescript
// Original message
const message = "Hello World";

// Convert to hex
const messageHex = Buffer.from(message).toString('hex');

const response = await HardwareSDK.scdoSignMessage(connectId, deviceId, {
    path: "m/44'/541'/0'/0/0",
    messageHex: messageHex
});
```

**参数**

可选通用参数

* `path` - _必需_ `string | Array<number>` SDK 校验的最小长度为 `3`。 [路径格式](/zh/hardware-sdk/concepts/common-params#hd-path)
* `messageHex` - _必需_ `string`。以十六进制编码的待签名消息。

**示例**

```typescript
// Original message
const message = "Hello World";

// Convert to hex
const messageHex = Buffer.from(message).toString('hex');

const response = await HardwareSDK.scdoSignMessage(connectId, deviceId, {
    path: "m/44'/541'/0'/0/0",
    messageHex,
});
```

返回结果

```typescript
{
    success: true,
    payload: {
        signature: string,
        address: string
    }
}
```

错误

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number  // error code
    }
}
```
