# tonGetAddress

### 使用要求

* 最低固件版本
  * Touch: 4.10.0

### TON：获取地址

派生并返回指定路径的地址。`showOnOneKey` 为 `true` 时，用户必须在设备上确认地址。

```typescript
const response = await HardwareSDK.tonGetAddress(connectId, deviceId, {
    path: "m/44'/607'/0'",
    showOnOneKey: true,
    walletVersion: 3,
    isBounceable: false,
    isTestnetOnly: false
});
```

#### 参数

[可选通用参数](/zh/hardware-sdk/concepts/common-params)

**导出单个地址**

* `path` - _必需_ `string | Array<number>` SDK 校验的最小长度为 `3`。 [路径格式](/zh/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _可选_ `boolean`。是否在设备上显示地址，默认为 `true`。
* `walletVersion` - _可选_ `TonWalletVersion` TON 钱包版本（默认：3）
* `isBounceable` - _可选_ `boolean` 地址是否可弹回（默认：false）
* `isTestnetOnly` - _可选_ `boolean` 是否使用测试网（默认：false）

**导出批量地址**

* `bundle` - 对象数组，每个对象包含 `path`、`showOnOneKey` 字段。

#### 示例

```typescript
// Get single address
const response = await HardwareSDK.tonGetAddress(connectId, deviceId, {
    path: "m/44'/607'/0'",
    showOnOneKey: false,
    walletVersion: 3,
    isBounceable: false,
    isTestnetOnly: false,
});

// Get multiple addresses
const batchResponse = await HardwareSDK.tonGetAddress(connectId, deviceId, {
    bundle: [
        {
            path: "m/44'/607'/0'",
            showOnOneKey: false
        },
        {
            path: "m/44'/607'/1'",
            showOnOneKey: false
        }
    ]
});
```

**返回结果**

单个地址响应

```typescript
{
    success: true,
    payload: {
        address: string,     // displayed address
        publicKey: string,
        path: string // serialized BIP32 path
    }
}
```

批量响应，顺序与请求一致

```typescript
{
    success: true,
    payload: [
        { address: string, publicKey: string, path: string }, // account 1
        { address: string, publicKey: string, path: string }, // account 2
        { address: string, publicKey: string, path: string }  // account 3
    ]
}
```

错误

```
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
