# tonSignMessage

### 使用要求

* 最低固件版本
  * Touch: 4.10.0
  * Pro 2 / Neo：Protocol V2（同一公开方法，SDK 负责字段映射）

### TON：签名消息

使用指定 BIP32 路径派生的私钥对消息或交易进行签名。用户需要在 OneKey 设备上确认操作。

```typescript
const response = await HardwareSDK.tonSignMessage(connectId, deviceId, {
    path: "m/44'/607'/0'",
    destination: "UQBYkuShkZzRYAWX_HrK3kFpeAixiRKd-K7QBXYxl9OBXM0_",
    tonAmount: 100,
    seqno: 0,
    expireAt: Math.floor(Date.now() / 1000) + 60 * 60 * 24,
    walletVersion: 3,
    isBounceable: false,
    isTestnetOnly: false
});
```

#### 参数

[可选通用参数](/zh/hardware-sdk/concepts/common-params)

**必需参数**

* `path` - _必需_ `string | Array<number>` SDK 校验的最小长度为 `3`。
* `destination` - _必需_ `string` 目标地址
* `tonAmount` - _必需_ `number | string`。转账金额，单位为 nanotons。
* `seqno` - _必需_ `number` 序列号
* `expireAt` - _必需_ `number | string`。消息到期时间，使用 Unix 秒级时间戳。

**可选参数**

* `walletVersion` - _可选_ `TonWalletVersion` TON 钱包版本（默认：3）
* `isBounceable` - _可选_ `boolean` 消息是否可弹回（默认：false）
* `isTestnetOnly` - _可选_ `boolean` 是否使用测试网（默认：false）
* `jettonMasterAddress` - _可选_ `string` Jetton 主合约地址
* `jettonAmount` - _可选_ `number | string`。Jetton 数量，以该代币的最小单位表示。
* `fwdFee` - _可选_ `number | string`。Jetton 转账的转发费用，单位为 nanotons。
* `comment` - _可选_ `string` 消息备注
* `mode` - _可选_ `number` 消息模式
* `workchain` - _可选_ `TonWorkChain` TON 工作链
* `walletId` - _可选_ `number` 钱包 ID

#### 示例

```typescript
// Simple TON transfer
const response = await HardwareSDK.tonSignMessage(connectId, deviceId, {
    path: "m/44'/607'/0'",
    destination: "UQBYkuShkZzRYAWX_HrK3kFpeAixiRKd-K7QBXYxl9OBXM0_",
    tonAmount: 100,
    seqno: 0,
    expireAt: Math.floor(Date.now() / 1000) + 60 * 60 * 24,
    walletVersion: 3,
    isBounceable: false,
    isTestnetOnly: false
});

// Multiple native TON transfers
const jettonResponse = await HardwareSDK.tonSignMessage(connectId, deviceId, {
    path: "m/44'/607'/0'",
    destination: 'UQBYkuShkZzRYAWX_HrK3kFpeAixiRKd-K7QBXYxl9OBXM0_',
    tonAmount: 100,
    seqno: 0,
    expireAt: Math.floor(Date.now() / 1000) + 60 * 60 * 24,
    walletVersion: 3,
    isBounceable: false,
    isTestnetOnly: false,
    extDestination: ['UQBYkuShkZzRYAWX_HrK3kFpeAixiRKd-K7QBXYxl9OBXM0_'],
    extTonAmount: [100],
    extPayload: ['48656c6c6f204f6e654b6579'],
});

```

返回结果

```typescript
{
    success: true,
    payload: {
        skip_validate: boolean; // Used to skip validation in classic 1s.
        signature: string;
        signing_message?: string; // Canonical field. Pro2/Neo return this; the SDK also copies it from the legacy V1 typo.
        signning_message?: string; // Deprecated Protocol V1 typo. Do not read this in new code.
    }
}
```

错误

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
