# polkadotSignTransaction

### 使用要求

* 最低固件版本
  * Touch: 4.3.0
  * Classic/Mini: 3.0.0

## Polkadot：签名交易

使用指定路径派生的密钥请求交易签名。用户在设备上核对并确认请求。

```typescript
const result = await HardwareSDK.polkadotSignTransaction(connectId, deviceId, params);
```

### 参数

[**可选通用参数**](/zh/hardware-sdk/concepts/common-params)

* `path` - _必需_ `string | Array<number>` SDK 校验的最小长度为 `3`。 [路径格式](/zh/hardware-sdk/concepts/common-params#hd-path)
* `network` - _必需_ `string` 网络名称，例如 `polkadot`
* `prefix` - _必需_ `number` SS58 地址前缀，Polkadot 使用 `0`
* `rawTx` - _必需_ `string`。以十六进制字符串编码的序列化交易。

### 示例

```typescript
const response = await HardwareSDK.polkadotSignTransaction(
  connectId,
  deviceId,
  {
    path: "m/44'/354'/0'/0'/0'",
    network: "polkadot",
    prefix: 0,
    rawTx: "040300388671dd546ba19495211c8cdc200600f9798cf078fca0fb4749ebbc0579c12a0700e40b5402350128009a24000012000000e143f23803ac50e8f6f8e62695d1ce9e4e1d68aa36c1cd2cfd15340213f3423ee356a704dbe75762aaae87b0f4702aafd09e67eed5d09a3a4b0e7da6c37b6f54"
  }
);
```

返回结果

```typescript
{
  success: true,
  payload: {
    path: "m/44'/354'/0'/0'/0'",
    signature: "signed data"
  }
}
```

错误

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
