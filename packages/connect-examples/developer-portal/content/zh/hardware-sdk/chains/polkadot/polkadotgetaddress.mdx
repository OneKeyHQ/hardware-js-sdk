# polkadotGetAddress

## 使用要求

* 最低固件版本
  * Touch: 4.3.0
  * Classic/Mini: 3.0.0
* Joystream 链固件版本要求
  * Touch: 4.7.0
  * Classic/Mini: 3.6.0
* Manta 链固件版本要求
  * Touch: 4.9.0
  * Classic/Mini: 3.7.0

## Polkadot：获取地址

派生并返回指定路径的地址。可通过 `showOnOneKey` 请求用户在设备上确认。

```typescript
const result = await HardwareSDK.polkadotGetAddress(connectId, deviceId, params);
```

## 参数

[**可选通用参数**](/zh/hardware-sdk/concepts/common-params)

<span id="导出单个公钥" />

### 导出单个地址

* `path` - _必需_ `string | Array<number>` SDK 校验的最小长度为 `3`。 [路径格式](/zh/hardware-sdk/concepts/common-params#hd-path)
* `prefix` - _必需_ `number` SS58 地址前缀，Polkadot 使用 `0`
* `network` - _必需_ `string` 网络名称，例如 `polkadot`
* `showOnOneKey` - _可选_ `boolean`。是否在设备上显示地址，默认为 `true`。

<span id="导出批量公钥" />

#### 导出批量地址

* `bundle` - 对象数组，每个对象包含 `path`、`prefix`、`network`、`showOnOneKey` 字段。

### 示例

返回第一个 Polkadot 账户的地址：

```typescript
HardwareSDK.polkadotGetAddress(connectId, deviceId, {
    path: "m/44'/354'/0'/0'/0'",
    showOnOneKey: true,
    network: "polkadot",
    prefix: 0
});
```

批量返回多个 Polkadot 账户的地址：

```typescript
HardwareSDK.polkadotGetAddress(connectId, deviceId, {
    bundle: [
        { path: "m/44'/354'/0'/0'/1'", network: "polkadot", prefix: 0 }, // account 1
        { path: "m/44'/354'/0'/0'/2'", network: "polkadot", prefix: 0 }, // account 2
        { path: "m/44'/354'/0'/0'/3'", network: "polkadot", prefix: 0 }  // account 3
    ]
});
```

### 返回结果

单个地址响应

```typescript
{
    success: true,
    payload: {
        path: string, // serialized BIP32 path
        address: string,   // address
        publicKey: string, // publicKey
    }
}
```

批量地址响应

```typescript
{
    success: true,
    payload: [
        { path, address, publicKey }, // account 1
        { path, address, publicKey }, // account 2
        { path, address, publicKey }, // account 3
    ]
}
```

错误

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
