# polkadotGetAddress

## 使用要求

* 固件版本要求
  * Touch: 4.3.0
  * Classic/Mini: 3.0.0
* Joystream 链固件版本要求
  * Touch: 4.7.0
  * Classic/Mini: 3.6.0
* Manta 链固件版本要求
  * Touch: 4.9.0
  * Classic/Mini: 3.7.0

## Polkadot：获取地址

获取指定 BIP32 路径派生的地址。用户需要确认导出。

```typescript
const result = await HardwareSDK.polkadotGetAddress(connectId, deviceId, params);
```

## 参数

[**可选通用参数**](/zh/hardware-sdk/concepts/common-params)

### 导出单个公钥

* `path` - _必需_ `string | Array<number>` 最小长度为 `3`。[更多信息](/zh/hardware-sdk/concepts/common-params#hd-path)
* `prefix` - _必需_ `number` SS58 地址前缀，Polkadot 使用 `0`
* `network` - _必需_ `string` 网络名称，例如 `polkadot`
* `showOnOneKey` - _可选_ `boolean` 决定是否在设备上显示地址。默认设置为 `true`



#### 导出批量公钥

* `bundle` - 包含 `path`、`prefix`、`network`、`showOnOneKey` 字段的对象 `Array`

### 示例

返回第一个 Polkadot 账户的公钥：

```typescript
HardwareSDK.polkadotGetAddress(connectId, deviceId, {
    path: "m/44'/354'/0'/0'/0'",
    showOnOneKey: true,
    network: "polkadot",
    prefix: 0
});
```

返回多个 Polkadot 账户的批量公钥：

```typescript
HardwareSDK.polkadotGetAddress(connectId, deviceId, {
    bundle: [
        { path: "m/44'/354'/0'/0'/1'", network: "polkadot", prefix: 0 }, // 账户 1
        { path: "m/44'/354'/0'/0'/2'", network: "polkadot", prefix: 0 }, // 账户 2
        { path: "m/44'/354'/0'/0'/3'", network: "polkadot", prefix: 0 }  // 账户 3
    ]
});
```

### 返回结果

只有一个公钥的结果

```typescript
{
    success: true,
    payload: {
        path: string, // 序列化 BIP32 路径
        address: string,   // 地址
        publicKey: string, // 公钥
    }
}
```

批量公钥的结果

```typescript
{
    success: true,
    payload: [
        { path, address, publicKey }, // 账户 1
        { path, address, publicKey }, // 账户 2
        { path, address, publicKey }, // 账户 3
    ]
}
```

错误

```typescript
{
    success: false,
    payload: {
        error: string, // 错误信息
        code?: string | number // 错误码
    }
}
```
