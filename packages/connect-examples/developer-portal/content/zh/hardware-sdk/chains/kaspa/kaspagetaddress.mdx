# kaspaGetAddress

### 使用要求

* 最低固件版本
  * Touch: 4.3.0
  * Classic/Mini: 3.0.0

## Kaspa：获取地址

派生并返回指定路径的地址。`showOnOneKey` 为 `true` 时，用户必须在设备上确认地址。

```typescript
const result = await HardwareSDK.kaspaGetAddress(connectId, deviceId, params);
```

## 参数

[**可选通用参数**](/zh/hardware-sdk/concepts/common-params)

<span id="导出单个公钥" />

### 导出单个地址

* `path` - _必需_ `string | Array<number>` SDK 校验的最小长度为 `3`。 [路径格式](/zh/hardware-sdk/concepts/common-params#hd-path)
* `showOnOneKey` - _可选_ `boolean`。是否在设备上显示地址，默认为 `true`。
* `prefix` - _可选_ `string` 地址前缀。默认设置为 `kaspa`
* `scheme` - _可选_ `string`。签名算法，默认为 `schnorr`。

<span id="导出批量公钥" />

#### 导出批量地址

* `bundle` - 对象数组，每个对象包含 `path`、`showOnOneKey`、`prefix`、`scheme` 字段。

### 示例

返回第一个 Kaspa 账户的地址：

```typescript
HardwareSDK.kaspaGetAddress(connectId, deviceId, {
    path: "m/44'/111111'/0'/0/0",
    showOnOneKey: true,
    prefix: "kaspa",
    scheme: "schnorr",
});
```

批量返回多个 Kaspa 账户的地址：

```typescript
HardwareSDK.kaspaGetAddress(connectId, deviceId, {
    bundle: [
        { path: "m/44'/111111'/0'/0/0" }, // account 1
        { path: "m/44'/111111'/0'" }, // account 2
        { path: "m/44'/111111'/0'/0/1" }  // account 3
    ]
});
```

### 返回结果

单个地址响应

```typescript
{
    success: true,
    payload: {
        path: string, // serialized BIP32 path
        address: string,   // address
    }
}
```

批量地址响应

```typescript
{
    success: true,
    payload: [
        { path, address }, // account 1
        { path, address }, // account 2
        { path, address }, // account 3
    ]
}
```

错误

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
