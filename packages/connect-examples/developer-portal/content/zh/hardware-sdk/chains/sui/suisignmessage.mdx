# suiSignMessage

### 使用要求

* 最低固件版本
  * Touch: 4.6.0
  * Classic/Mini: 3.4.0

### Sui：签名消息

使用指定路径派生的密钥请求消息签名。

```typescript
const result = await HardwareSDK.suiSignMessage(connectId, deviceId, params);
```

### 参数

[**可选通用参数**](/zh/hardware-sdk/concepts/common-params)

* `path` - _必需_ `string | Array<number>` SDK 校验的最小长度为 `3`。 [路径格式](/zh/hardware-sdk/concepts/common-params#hd-path)
* `messageHex` - _必需_ `string`。以十六进制编码的待签名消息。

### 示例

```typescript
// Original message
const message = "Hello World";

// Convert to hex
const messageHex = Buffer.from(message).toString('hex');

HardwareSDK.suiSignMessage(connectId, deviceId, {
    path: "m/44'/784'/0'/0'/0'",
    messageHex,
});
```

#### 返回结果

```typescript
{
    success: true,
    payload: {
        address: string,
        signature: string,
    }
}
```

错误

```typescript
{
    success: false,
    payload: {
        error: string, // error message
        code?: string | number // error code
    }
}
```
