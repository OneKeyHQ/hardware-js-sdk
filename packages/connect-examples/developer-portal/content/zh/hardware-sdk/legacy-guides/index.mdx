# 迁移指引

根据现有接入选择指南：将 Hardware SDK **1.1.x** 升级到 **1.2.x**，或将 OneKey Bridge 连接迁移到 WebUSB。

## 1.1.x → 1.2.x

- [升级到 Hardware SDK 1.2](./from-1x) — `getDeviceState`、`openWalletSession`、Pro 2 / Neo、firmware V4

## Bridge → WebUSB

只有还在用 OneKey Bridge（`env: 'web'`）时才看这两篇。

- [Bridge 迁到 WebUSB（hd-common-connect-sdk）](./migrate-bridge-to-common-connect-webusb) — 推荐
- [Bridge 迁到 WebUSB（hd-web-sdk）](./migrate-bridge-to-webusb) — 继续用 iframe

新项目请走 [快速开始](/zh/hardware-sdk/getting-started)，包用 `@onekeyfe/hd-common-connect-sdk`。
