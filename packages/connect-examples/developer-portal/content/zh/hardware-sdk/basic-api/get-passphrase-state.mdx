# 获取密码短语状态

<Callout type="warning">
  **已废弃。** Protocol V1 / V2 请用 [`openWalletSession`](/zh/hardware-sdk/basic-api/open-wallet-session)。现有应用仍可调用本方法。
</Callout>

## 获取设备的 passphraseState

请求此 API 将提示用户输入密码短语，并返回公开的隐藏钱包指纹 `passphraseState`。请持久化 `deviceId + passphraseState`，不要持久化固件 `session_id`。

见 [钱包会话](/zh/hardware-sdk/concepts/wallet-session)。

后续地址和签名调用应继续传入 `passphraseState`，以保持同一个隐藏钱包绑定。它是**钱包指纹**，不是固件 `session_id`。

> **错误 112（passphrase state mismatch）**：绑定与当前解锁的钱包不匹配，可能涉及锁定、种子变更或旧指纹。停止操作，让用户通过 `openWalletSession` 重新选择目标钱包。确认恢复后的绑定，再发起新的请求；不要绕过检查或自动重放签名。

```typescript
const response = await HardwareSDK.getPassphraseState(connectId);
```

### 参数

[**可选通用参数**](/zh/hardware-sdk/concepts/common-params)

### 示例

```typescript
const response = await HardwareSDK.getPassphraseState(connectId);
```

### 返回结果

```
{
    success: true,
    payload: string | null | undefined
}
```

### 错误

```typescript
{
    success: false,
    payload: {
        error: string, // 错误消息
        code?: string | number // 错误码
    }
}
```

隐藏钱包指纹为非空字符串。兼容流程中，V1 关闭保护时可能返回 `undefined`，V2 标准钱包可能返回 `null`；不要将这些结果保存为隐藏钱包绑定。
