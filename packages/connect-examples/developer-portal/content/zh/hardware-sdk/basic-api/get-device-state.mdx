# 获取设备状态

读取 Protocol V1 / V2 统一的设备快照。请用本方法，不要再用已废弃的 [`getFeatures`](/zh/hardware-sdk/basic-api/get-features)。

`getFeatures()` 现有应用仍可调用。新代码应调用 `getDeviceState()`，读 `payload.identity.deviceId`。

```ts
const res = await HardwareSDK.getDeviceState(connectId);
```

### 参数

[可选通用参数](/zh/hardware-sdk/concepts/common-params)

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `scope` | `'runtime' \| 'settings' \| 'firmware'` | 否 | 默认 `'runtime'`。scope 只决定这次刷新哪些分区，返回值仍是完整快照 |

- `runtime` — 实时锁定 / PIN / passphrase 状态（V1 `GetFeatures`，V2 应用模式下的 `DeviceStatusGet`）
- `settings` — 同时刷新设置
- `firmware` — 同时刷新身份、版本和校验信息

Bootloader / romloader 会跳过不支持的状态命令，返回当前能拿到的快照。

### 返回结果

```ts
{
  success: true,
  payload: {
    protocol: 'V1' | 'V2',
    identity: {
      deviceId: string | null, // 种子生命周期 — 作为 SDK 第二个参数传入
      serialNo: string,
      deviceType: string,
      // ...
    },
    status: { initialized, unlocked, passphraseProtection, attachToPinEnabled, ... },
    settings: { language, airgapMode, ... },
    versions: { firmware, bootloader, ble, applicationP1, applicationP2, ... },
  }
}
```

签名调用的第二个参数读 `payload.identity.deviceId`。不要把兼容 Features 里的固件 `session_id` 存下来。

返回值**不包含**固件钱包 `session_id` 或原始协议消息。钱包身份仍然来自 [`openWalletSession`](/zh/hardware-sdk/basic-api/open-wallet-session) 或 [`getPassphraseState`](/zh/hardware-sdk/basic-api/get-passphrase-state)。

### 错误

```ts
{
  success: false,
  payload: {
    error: string,
    code: number,
  }
}
```

与 `getFeatures()` 的分工见 [Protocol V1 与 V2](/zh/hardware-sdk/concepts/protocol)。
