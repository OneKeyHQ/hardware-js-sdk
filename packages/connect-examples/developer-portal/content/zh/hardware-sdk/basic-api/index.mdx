# 基础 API

用于设备发现、会话管理和事件处理的核心 SDK 方法。

| 方法 | 描述 |
|------|------|
| [Search Devices](./search-devices) | 扫描并发现已连接的 OneKey 硬件设备 |
| [Get Device State](./get-device-state) | V1/V2 统一设备快照（1.2.0 推荐） |
| [Get Features](./get-features) | 兼容的 Features 读取；现有应用仍可用 |
| [Open Wallet Session](./open-wallet-session) | 打开或恢复标准 / 隐藏钱包 |
| [Get Passphrase State](./get-passphrase-state) | 兼容的 passphrase 钱包绑定 |
| [Response UI Event](./response-ui-event) | 处理来自设备交互的 UI 事件 |
| [Cancel Request](./cancel-request) | 取消正在进行的设备操作 |
