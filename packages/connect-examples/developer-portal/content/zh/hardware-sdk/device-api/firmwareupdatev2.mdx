# firmwareUpdateV2

## 固件更新 (V2)

Protocol V1 固件更新流程。支持下载和更新主固件及蓝牙固件。必须显式传入 `platform` 参数。

```typescript
// Select versions from verified release metadata for this device.
declare const targetFirmwareVersion: number[];

const res = await HardwareSDK.firmwareUpdateV2(connectId, {
  platform: 'desktop', // 'native' | 'desktop' | 'ext' | 'web' | 'web-embed'
  updateType: 'firmware', // or 'ble'
  // Option A: version-based update (recommended)
  version: targetFirmwareVersion,
  // Option B: custom binary (use with caution)
  // binary: ArrayBuffer,
  // Optional flags
  forcedUpdateRes: false,
  isUpdateBootloader: false,
});
if (!res.success) throw new Error(res.payload.error);
```

示例假定用户已经选择目标设备并批准本次升级。目标版本应来自该设备的已验证发布元数据，不要硬编码从文档复制的版本号。

### 参数

[可选通用参数](/zh/hardware-sdk/concepts/common-params)

- `platform` - 必需 `"native" | "desktop" | "ext" | "web" | "web-embed"` 执行环境
- `updateType` - 必需 `'firmware' | 'ble'` 更新目标（主固件或蓝牙）
- `version` - 可选 `number[]` 目标版本号，3 位数组；会下载该版本的官方固件
- `binary` - 可选 `ArrayBuffer` 自定义固件二进制文件；谨慎使用
- `forcedUpdateRes` - 可选 `boolean` 强制更新资源包
- `isUpdateBootloader` - 可选 `boolean` 包含引导加载程序更新

### 返回结果

```typescript
{
  success: true,
  payload: {
    // 底层返回的成功标识
  }
}
```

### 错误

```typescript
{
  success: false,
  payload: {
    error: string, // 错误信息
    code?: string | number   // 错误码
  }
}
```
