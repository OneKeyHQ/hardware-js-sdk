# firmwareUpdateV3

## 固件更新 (V3)

适用于 OneKey Pro 的 Protocol V1 更新流程。支持在单个流程中根据需要更新引导加载程序、主固件、蓝牙固件和资源包。

- 设备：仅限 OneKey Pro（Protocol V1）
- 引导要求：Boot 版本 >= 4.8.0
- Pro 2 / Neo：使用 [firmwareUpdateV4](/zh/hardware-sdk/device-api/firmwareupdatev4)

```typescript
// Select versions from verified release metadata for this device.
declare const targetFirmwareVersion: number[];
declare const targetBleVersion: number[];
declare const targetBootloaderVersion: number[];

const res = await HardwareSDK.firmwareUpdateV3(connectId, {
  platform: 'desktop', // 'native' | 'desktop' | 'ext' | 'web' | 'web-embed'

  // Option A: specify versions (pick any subset)
  firmwareVersion: targetFirmwareVersion,
  bleVersion: targetBleVersion,
  bootloaderVersion: targetBootloaderVersion,

  // Option B: custom binaries (as needed)
  // firmwareBinary: ArrayBuffer,
  // bleBinary: ArrayBuffer,
  // bootloaderBinary: ArrayBuffer,
  // resourceBinary: ArrayBuffer,

  // Optional: force updating resource package
  forcedUpdateRes: false,
});
if (!res.success) throw new Error(res.payload.error);
```

示例假定用户已经选择目标设备并批准本次升级。目标版本应来自该设备的已验证发布元数据，不要硬编码从文档复制的版本号。

### 参数

[可选通用参数](/zh/hardware-sdk/concepts/common-params)

- `platform` - 必需 `"native" | "desktop" | "ext" | "web" | "web-embed"` 执行环境
- `firmwareVersion` - 可选 `number[]` 目标主固件版本
- `firmwareBinary` - 可选 `ArrayBuffer` 自定义主固件
- `bleVersion` - 可选 `number[]` 目标蓝牙固件版本
- `bleBinary` - 可选 `ArrayBuffer` 自定义蓝牙固件
- `bootloaderVersion` - 可选 `number[]` 目标引导加载程序版本
- `bootloaderBinary` - 可选 `ArrayBuffer` 自定义引导加载程序
- `resourceBinary` - 可选 `ArrayBuffer` 资源包二进制文件
- `forcedUpdateRes` - 可选 `boolean` 强制更新资源包

### 返回结果

```typescript
{
  success: true,
  payload: {
    bleVersion: string,
    firmwareVersion: string,
    bootloaderVersion: string,
  }
}
```

### 错误

```typescript
{
  success: false,
  payload: {
    error: string, // 错误信息
    code?: string | number   // 错误码
  }
}
```
