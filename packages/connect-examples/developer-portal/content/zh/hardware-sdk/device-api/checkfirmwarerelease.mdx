# checkFirmwareRelease

## 检查固件版本

检查设备当前固件版本状态。

```typescript
const response = await HardwareSDK.checkFirmwareRelease(connectId);
```

### 参数

[可选通用参数](/zh/hardware-sdk/concepts/common-params)

### 示例

```typescript
const response = await HardwareSDK.checkFirmwareRelease(connectId);
```

返回结果

```typescript
import type { FirmwareReleaseCheckResult } from '@onekeyfe/hd-core';

type ReleaseResult = {
  success: true;
  payload: FirmwareReleaseCheckResult | null;
};
```

`payload` 可能为 `null`。非空时包含 `status`、可选的 `shouldUpdate`、可选的 `changelog`，以及可能为 `undefined` 的 `release`。读取前先检查结果与版本数据是否存在；release 的结构随固件/组件而异。

错误

```typescript
{
    success: false,
    payload: {
        error: string, // 错误信息
        code?: string | number // 错误码
    }
}
```
