# deviceSupportFeatures

### 检测硬件支持的功能

返回值中的能力是对象，应读取 `.support`，不能直接判断对象真假：`{ support: false }` 在 JavaScript 中仍为真值。`require` 可能表示最低固件版本。

```ts
const result = await HardwareSDK.deviceSupportFeatures(connectId);
if (!result.success) throw new Error(result.payload.error);
const canEnterPinOnHost = result.payload.inputPinOnSoftware.support;
```

```typescript
const response = await HardwareSDK.deviceSupportFeatures(connectId);
```

### 参数

[可选通用参数](/zh/hardware-sdk/concepts/common-params)

### 示例

```typescript
const response = await HardwareSDK.deviceSupportFeatures(connectId);
```

返回结果

```typescript
{
    success: true,
    payload: {
      inputPinOnSoftware: { support: boolean, require?: string },
      modifyHomescreen: { support: boolean, require?: string },
      device: Device | null
    }
}
```

错误

```typescript
{
    success: false,
    payload: {
        error: string, // 错误信息
        code?: string | number // 错误码
    }
}
```
