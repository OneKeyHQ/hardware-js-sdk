# deviceUpdateReboot

## 重启设备

在用户明确发起的固件升级流程中，请求 **Protocol V1** 设备进入 bootloader 模式。本方法未声明 Protocol V2 支持；Pro 2 和 Neo 使用 [Protocol V2 升级流程](/zh/hardware-sdk/device-api/firmwareupdatev4)。

设备可能断开，并以不同的连接 ID 重新枚举。继续前重新发现设备并验证状态。

```typescript
const response = await HardwareSDK.deviceUpdateReboot(connectId);
if (!response.success) throw new Error(response.payload.error);
```

## 参数

* 空

## 示例

```typescript
const response = await HardwareSDK.deviceUpdateReboot(connectId);
if (!response.success) throw new Error(response.payload.error);
```

## 返回结果

SDK 成功结果表示请求已被接受。不要通过写死的 payload 结构推断新模式；设备重连后重新读取状态。

错误

```typescript
{
    success: false,
    payload: {
        error: string, // 错误信息
        code?: string | number // 错误码
    }
}
```
