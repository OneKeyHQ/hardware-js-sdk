# 历史集成

本节供维护旧集成时参考，说明历史接口及当前替代路径，不构成对当前钱包、SDK 或固件版本的支持认证。

- [OneKey Bridge](./bridge)：历史桌面桥接检查与 WebUSB 迁移路径。
- [Aptos WalletConnect v1](./aptos-walletconnect)：历史自定义方法与当前浏览器接入方式。
- [原始 firmwareUpdate API](./firmware-update)：旧 API 与后续版本化固件方法的区别。

新集成请从[开始接入](/zh/getting-started)出发。设备初始化和擦除单独记录在[设备管理](/zh/integration-guides/device-management)中。
