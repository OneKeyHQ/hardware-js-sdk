# Wallet Skills

[`onekey-wallet-skills`](https://github.com/OneKeyHQ/onekey-wallet-skills) 让 AI coding assistant 能理解自然语言钱包请求，并转换成安全的 `onekey` CLI 工作流。

用户不需要手写 CLI 命令。Skill 应理解请求，读取实时 schema，运行正确的命令族，并用用户能理解的语言解释结果。

## 先试这些 Prompt

```text
Show my wallet balance and receiving address.
```

```text
What Solana tokens are trending right now?
```

```text
Quote 1 ETH to USDC. Do not execute yet.
```

```text
Is this token safe before I buy it?
```

这四个 prompt 覆盖主要模式：钱包、行情、交易和安全。它们刻意写成用户语言；Skill 会读取当前命令 schema 后再决定实际调用哪个 CLI 命令。

## Schema 契约

每个 skill 都应该把 CLI schema 当作事实来源，而不是硬编码过期示例。

| 检查项 | 预期行为 |
| --- | --- |
| 发现命令 | 能力是否支持不确定时，运行 `onekey schema --list`。 |
| 检查命令 | 选择复杂参数前，使用 `onekey schema <command-name>`。 |
| 名称映射正确 | Schema 名称是 `auth-login`、`swap-quote`、`market-kline`、`security-audit` 这类形式；CLI 命令是 `onekey auth login`、`onekey swap quote` 这类空格形式。 |
| 处理不支持字段 | 当前 schema 没有暴露 prompt 需要的参数时，停止并解释原因。 |
| 保持结构化输出 | 优先输出 result、risk、command route、next step，不把原始 CLI dump 直接甩给用户。 |

## 支持的 AI Clients

| Client | 用户如何交互 |
| --- | --- |
| Claude Code | 通过 `/plugin marketplace add` 和 `/plugin install` 安装，然后直接提钱包问题 |
| Codex | 按 skills 仓库里的 `.codex/INSTALL.md` 接入 |
| Cursor | 使用 Cursor plugin/install flow，在 coding session 里提钱包 prompt |
| OpenCode / OpenClaw | 按仓库里的对应安装说明接入，并使用同样的自然语言 prompt |

## Skill Router

| Skill | 适用请求 | 示例 prompt |
| --- | --- | --- |
| `onekey-wallet` | 登录、活动钱包、余额、收款地址、历史、转账、BTC/SOL 钱包操作、硬件发现 | `Show my wallet balance and receiving address.` |
| `onekey-swap` | Swap、buy、sell、convert、bridge、swap status、BTC sign-only PSBT | `Swap 1 ETH to USDC, but show me the quote first.` |
| `onekey-market` | 价格、token 搜索、trending、K 线、流动性、持仓、BTC/SOL 指标、研究 | `What Solana tokens are trending right now?` |
| `onekey-security` | Token audit、交易模拟、授权风险、硬件安全、secret-safety 检查 | `Is this token safe before I buy it?` |

## `onekey-wallet`

用于钱包状态和转账。

| 自然语言 | Skill 应该做什么 |
| --- | --- |
| `Connect my OneKey Agent Wallet.` | 运行 App Transfer login，并总结活动地址 |
| `What wallet am I using?` | 读取 `auth-status`，展示 login method、wallet kind、address、device |
| `Show my balance.` | 自动使用活动钱包，不要求用户粘贴地址 |
| `Receive BTC.` | 返回 BTC 收款地址；缺少地址类型时只问地址类型 |
| `Send 0.2 SOL to this address.` | 保留 Solana 上下文，校验地址格式，进入确认 |

CLI 能力：

```bash
onekey auth login --app-transfer
onekey auth status
onekey get-address
onekey balance --chain eth
onekey history --chain eth --detail
onekey transfer --to 0x... --amount 50 --token USDC --chain eth
onekey wallet address-types --chain btc
onekey wallet address --chain btc --address-type taproot
```

## `onekey-swap`

用于交易、买入、卖出、兑换、跨链和 BTC sign-only。

| 自然语言 | Skill 应该做什么 |
| --- | --- |
| `Swap 1 ETH to USDC.` | 先 quote，再确认，最后 build/execute |
| `Buy $200 of PEPE on Ethereum.` | 保留 Ethereum 上下文，审计 token，进入交易确认 |
| `Bridge 500 USDC from Ethereum to Base.` | 先发现 bridge 支持，再 quote |
| `Swap 0.01 BTC to USDC using taproot and sign only.` | 保留 taproot，返回 signed/preview PSBT，而不是广播 hash |
| `Yes, confirm the swap.` | 只执行已经确认过的 order |

CLI 能力：

```bash
onekey swap quote --chain eth --from ETH --to USDC --amount 1
onekey swap build --chain eth --from ETH --to USDC --amount 1
onekey swap execute --chain eth --order <orderId>
onekey swap status --order <orderId>
onekey swap networks --bridge
onekey swap history
```

## `onekey-market`

用于只读行情和研究。

| 自然语言 | Skill 应该做什么 |
| --- | --- |
| `What is the BTC price?` | 先返回价格和 24h change，再给 chart 或 trend follow-up |
| `What tokens are trending right now?` | 返回短 trending 列表，不直接开始交易 |
| `Search BONK on Solana.` | 保留 Solana，把标识符当作 SPL token/mint |
| `Show ETH liquidity.` | 返回流动性或持仓视图 |
| `Give me a quick ETH analysis.` | 提供 bias、catalyst、risk 和一个下一步 |

CLI 能力：

```bash
onekey token search --query BONK --chain sol
onekey token info --chain eth --token USDC
onekey token price --chain eth --token 0x...
onekey token trending --chain sol
onekey token trades --chain eth --token 0x...
onekey token liquidity --chain eth --token 0x...
onekey market price --chain eth --token USDC
onekey market prices --tokens "eth:0x...,bsc:0x..."
onekey market kline --chain eth --token ETH --interval 1H
```

## `onekey-security`

用于风险检查和操作前保护。

| 自然语言 | Skill 应该做什么 |
| --- | --- |
| `Is this token safe?` | 运行 token audit，并报告风险等级和原因 |
| `Simulate approving this contract for all my USDC.` | 模拟并提示 unlimited approval 风险 |
| `Send SOL to 0x...` | 因 Solana/EVM 地址不匹配停止 |
| `Show me the App Transfer payload.` | 拒绝暴露 secret，改为提供 `auth-status` 摘要 |
| `Is my hardware wallet safe to use?` | 使用 device/auth status 和设备验证；绝不要求助记词 |

CLI 能力：

```bash
onekey security audit --chain eth --token 0x...
onekey security simulate --chain eth --to 0x... --data 0x...
onekey device verify
onekey auth status
```

## 回答形态

好的 skill 回答应该结果优先、足够短：

```text
Route: swap-quote
Fields: chain=eth, from=ETH, to=USDC, amount=1
Quote: 1 ETH -> <estimated USDC>
Risk: <audit or simulation state>
Next: I can build the transaction and ask for confirmation.
```

涉及资金移动的回答必须以确认问题结束。只读的 market 和 wallet 回答应给一个有用 follow-up，而不是直接引导交易。
