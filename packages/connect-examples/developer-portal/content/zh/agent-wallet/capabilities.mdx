# 能力地图

> 当前为私有测试版。访问资格、支持的命令与钱包流程取决于 OneKey 和 CLI 版本。使用示例前，先检查已安装 CLI 的 schema。

通过四个 OneKey wallet skills，将请求路由到钱包、兑换、行情和安全命令。支持的链、参数与返回字段以已安装 CLI 的 schema 为准。

## Wallet Operations

用户想查余额、收款地址、交易历史、BTC 地址类型或转账时使用这一类能力。

| 用户意图 | 自然语言 | Skill 路由 |
| --- | --- | --- |
| 查看当前钱包 | `我当前使用的是哪个钱包？` | `onekey-wallet` 读取活动会话。 |
| 展示收款地址 | `显示我的 ETH 收款地址。` | `onekey-wallet` 返回当前收款地址。 |
| 查余额 | `查询我在 Ethereum 上的钱包余额。` | `onekey-wallet` 查询活动钱包余额。 |
| 查历史 | `显示最近 5 笔 BTC 交易。` | `onekey-wallet` 获取近期历史。 |
| BTC 地址类型 | `显示我的 BTC Taproot 地址。` | `onekey-wallet` 保留指定 BTC 地址类型。 |
| 转账 | `向这个地址发送 50 USDC。` | `onekey-wallet` 校验、预览并请求确认。 |

转账必须先展示确认信息，包括资产、金额、接收方、链、可用时的费用、余额状态和下一步安全检查。

## Swap and Bridge

用户想交易、买入、卖出、兑换、跨链或签 BTC PSBT 时使用这一类能力。

| 用户意图 | 自然语言 | Skill 路由 |
| --- | --- | --- |
| 获取报价 | `查询 1 ETH 兑换 USDC 的报价。` | `onekey-swap` 只报价，不执行。 |
| 构建交易 | `准备兑换交易，先不要提交。` | `onekey-swap` 在审阅后准备订单。 |
| 确认后执行 | `确认，执行这笔兑换。` | `onekey-swap` 只执行已确认订单。 |
| 查询状态 | `查询这笔兑换的状态。` | `onekey-swap` 跟踪已有订单。 |
| 发现跨链网络 | `能否将 USDC 从 Ethereum 跨链到 Base？` | `onekey-swap` 报价前检查 bridge 支持。 |
| BTC sign-only | `用 Taproot 地址将 BTC 兑换为 USDC，只签名，不广播。` | `onekey-swap` 保留 taproot，返回 signed 或 preview PSBT。 |

标准流程是 quote、安全检查、确认、build、execute。报价和执行不应该合并在同一个 assistant turn。

## Market and Research

用户想查价格、trending tokens、token 信息、K 线、流动性、持仓或研究时使用这一类能力。

| 用户意图 | 自然语言 | Skill 路由 |
| --- | --- | --- |
| 单币价格 | `SOL 当前价格是多少？` | `onekey-market` 返回价格和 24h 上下文。 |
| Trending tokens | `Solana 上有哪些热门代币？` | `onekey-market` 返回短列表。 |
| Token 搜索 | `在 Solana 上搜索 BONK。` | `onekey-market` 保留 Solana 上下文。 |
| Token 详情 | `显示 Ethereum 上 USDC 的代币信息。` | `onekey-market` 解析 token 详情。 |
| K 线 | `显示 ETH 的 1 小时 K 线。` | `onekey-market` 返回图表数据。 |
| 流动性 / 持仓 | `查询 PEPE 的流动性。` | `onekey-market` 汇总流动性或持仓。 |

Market 回答默认是只读的。如果用户随后要求买入或 swap，Agent 应先完成研究，再进入单独的交易确认流程。

## Security Checks

资金操作和合约交互前，以及用户询问 token 或交易是否安全时使用这一类能力。

| 用户意图 | 自然语言 | Skill 路由 |
| --- | --- | --- |
| Token audit | `这个代币有哪些风险？` | `onekey-security` 报告风险等级和原因。 |
| 交易模拟 | `签署这笔交易会发生什么？` | `onekey-security` 在签名前模拟。 |
| 授权风险 | `检查这笔 USDC 无限授权。` | `onekey-security` 明确提示无限授权风险。 |
| 链不匹配 | `向 0x... 发送 SOL。` | 停止并报告 Solana/EVM 地址不匹配 |
| 假合约风险 | `将 500 USDC 兑换成合约地址为 0x... 的 WETH。` | 因 token/contract mismatch 停止 |

高风险或数据不完整时，应阻断后续资金操作，直到用户明确接受风险。

## Hardware Control

用户想使用设备签名、验证设备真伪、修改 PIN/密码短语设置，或在设备上审阅支持的敏感请求时使用这一类能力。明文签名的展示内容取决于链、设备固件和 CLI 版本。

用户可见路径仍然是自然语言：连接设备、验证真伪、切换到硬件会话、必要时选择 passphrase 行为，并在设备上审阅敏感操作。

硬件登录会切换当前活动会话。登录后，wallet、transfer、swap、sign 命令会自动使用硬件会话。
