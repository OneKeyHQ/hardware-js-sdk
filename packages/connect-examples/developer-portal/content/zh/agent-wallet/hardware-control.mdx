# 硬件控制

> 当前为私有测试版。访问资格、支持的命令与钱包流程取决于 OneKey 和 CLI 版本。使用示例前，先检查已安装 CLI 的 schema。

硬件会话使用已连接的 OneKey 设备处理受支持的签名请求，用户在设备上审阅并确认。设备能力和可展示的交易详情取决于链、固件及 CLI 版本。

## 什么时候升级到硬件

| 场景 | 硬件期望 |
| --- | --- |
| 大额转账 | 用户在 OneKey 设备上复核接收方、金额、链和费用。 |
| 合约交互 | Agent 先运行 simulation；支持时设备展示 clear-signing 信息。 |
| Swap 执行 | Agent 先 quote/build；只有用户确认执行后才进入设备确认。 |
| 隐藏钱包 | 显式声明 passphrase mode，Agent 不猜当前是否为隐藏钱包。 |
| 设备可信检查 | `onekey device verify` 进行设备验证；验证成功不代表某笔交易安全。 |

## 连接并登录

列出已连接设备：

```bash
onekey device search
```

使用硬件钱包认证：

```bash
onekey auth login --hardware
```

多台设备同时连接时，显式选择设备：

```bash
onekey auth login --hardware --device-id <uuid>
```

为目标钱包选择一种密码短语模式。以下是互斥选项，不是连续执行的步骤：

| 模式 | 钱包选择 |
| --- | --- |
| `none` | 不使用密码短语的标准钱包。 |
| `on-host` | 在宿主端输入密码短语的隐藏钱包；密码短语不得进入 Agent 消息或日志。 |
| `on-device` | 在支持设备端输入的硬件上输入密码短语，进入隐藏钱包。 |

选择前检查已安装 CLI 的 schema；登录后核对活动地址。不同密码短语对应不同钱包。

## 活动会话

硬件会话在 `onekey auth status` 中体现为：

| 字段 | 预期值 |
| --- | --- |
| `loginMethod` | `hardware` |
| `walletKind` | `hw` |
| `device` | 已连接的 OneKey 设备信息 |
| `passphraseMode` | `none`、`on_host` 或 `on_device` |

登录完成后，后续命令会自动使用当前活动会话。

## 设备生命周期

先检查已安装 CLI 的 schema，并说明设置变化；仅执行用户要求的操作：

| 操作 | 命令族 |
| --- | --- |
| 验证已连接设备 | `onekey device verify` |
| 修改设备 PIN | `onekey device change-pin` |
| 修改密码短语保护设置 | `onekey device toggle-passphrase` |
| 查看或修改设备设置 | `onekey device settings` |

如果 `onekey schema --list` 中没有该命令，报告当前版本不支持，不猜测参数。

不要绕过物理确认。如果设备锁定、断开、要求 PIN/passphrase，或拒绝请求，Agent 应报告状态并停止。
