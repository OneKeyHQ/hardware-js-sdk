# 安装 Provider SDK

> 使用 SDK 前，请先安装 [OneKey 浏览器扩展](https://onekey.so/download/)。

我们提供了一个名为 [onekey-near-provider](https://www.npmjs.com/package/@onekeyfe/onekey-near-provider) 的 npm 包作为 SDK，同时还需要安装 [near-api-js](https://www.npmjs.com/package/near-api-js)。

SDK 源码见 [GitHub](https://github.com/OneKeyHQ/cross-inpage-provider/tree/master/packages/providers/onekey-near-provider)，完整示例见[示例目录](https://github.com/OneKeyHQ/cross-inpage-provider/tree/master/packages/example)。

```bash
# with npm
npm install near-api-js@^0.44.2 @onekeyfe/onekey-near-provider

# with yarn
yarn add near-api-js@^0.44.2 @onekeyfe/onekey-near-provider

```

provider 源码将 `near-api-js` `^0.44.2` 声明为 peer dependency。这些示例使用该旧版 API，安装其他主版本可能导致集成失效。请核对所安装 provider 版本的 peer dependencies。

在浏览器代码中创建 provider。

```javascript
import { OneKeyNearProvider } from '@onekeyfe/onekey-near-provider';

const provider = new OneKeyNearProvider();

```

> **注意：** Provider SDK 不兼容 SSR。
>
> 使用 [Next.js](https://nextjs.org/) 服务端渲染时，可参考[关闭 SSR 的动态导入方式](https://nextjs.org/docs/app/guides/lazy-loading#skipping-ssr)。
