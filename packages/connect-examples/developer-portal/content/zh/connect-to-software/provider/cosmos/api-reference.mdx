# API 参考

OneKey Cosmos provider 的方法和类型参考。

---

## 方法

| 方法 | 说明 |
|--------|-------------|
| `enable(chainIds)` | 请求访问指定链；成功时不返回值 |
| `disable(chainIds)` | 停用指定链 |
| `disconnect()` | 断开与所有链的连接 |
| `getKey(chainId)` | 获取指定链的账户密钥信息 |
| `signAmino(chainId, signer, signDoc)` | 签署 Amino 编码的交易 |
| `signDirect(chainId, signer, signDoc)` | 签署 Protobuf 编码的交易 |
| `sendTx(chainId, tx, mode)` | 广播已签名交易 |
| `signArbitrary(chainId, signer, data)` | 签署消息 |
| `verifyArbitrary(chainId, signer, data, signature)` | 验证签名 |
| `signEthereum(chainId, signer, data, type)` | 签署 Ethereum 数据 |
| `experimentalSuggestChain(chainInfo)` | 请求添加自定义链 |
| `getOfflineSigner(chainId)` | 获取 Direct 离线签名器 |
| `getOfflineSignerOnlyAmino(chainId)` | 获取仅支持 Amino 的离线签名器 |
| `getOfflineSignerAuto(chainId)` | 自动选择签名器类型 |
| `getChainInfosWithoutEndpoints()` | 获取所有链信息 |
| `getChainInfoWithoutEndpoints(chainId)` | 获取指定链信息 |
| `ping()` | 检查连接 |
| `babylonConnectWallet()` | 连接 Babylon 钱包 |
| `babylonGetKey()` | 获取 Babylon 钱包密钥信息 |

## Key 接口

```typescript
interface Key {
  name: string              // Human-readable name
  algo: string              // Signing algorithm
  pubKey: Uint8Array        // Public key bytes
  address: Uint8Array       // Address bytes
  bech32Address: string     // Bech32 formatted address
  isNanoLedger: boolean     // Ledger compatibility flag
  isKeystone: boolean       // True if Keystone hardware
}
```

## 签名文档类型

### Amino 签名文档

```typescript
interface StdSignDoc {
  chain_id: string
  account_number: string
  sequence: string
  fee: {
    amount: { denom: string; amount: string }[]
    gas: string
  }
  msgs: {
    type: string
    value: any
  }[]
  memo: string
}
```

### Direct 签名文档

```typescript
interface DirectSignDoc {
  bodyBytes: Uint8Array | null
  authInfoBytes: Uint8Array | null
  chainId: string | null
  accountNumber: Long | null
}
```

## 签名响应类型

```typescript
interface AminoSignResponse {
  signed: StdSignDoc
  signature: StdSignature
}

interface DirectSignResponse {
  signed: DirectSignDoc
  signature: StdSignature
}

interface StdSignature {
  pub_key: {
    type: string
    value: string  // Base64 encoded
  }
  signature: string  // Base64 encoded
}
```

## 广播模式

| 模式 | 描述 |
|------|------|
| `block` | 等待区块确认 |
| `sync` | 等待 CheckTx |
| `async` | 立即返回 |

## 支持的链

| 链 | Chain ID | 钱包可用性 |
|-------|----------|----------------|
| Cosmos Hub | `cosmoshub-4` | 在目标钱包中验证 |
| Osmosis | `osmosis-1` | 在目标钱包中验证 |
| Juno | `juno-1` | 在目标钱包中验证 |
| Stargaze | `stargaze-1` | 在目标钱包中验证 |
| Akash | `akashnet-2` | 在目标钱包中验证 |
| Secret Network | `secret-4` | 在目标钱包中验证 |
| Evmos | `evmos_9001-2` | 在目标钱包中验证 |
| Injective | `injective-1` | 在目标钱包中验证 |
| 自定义链 | 由链定义 | 通过 `experimentalSuggestChain` 请求添加；不保证钱包接受 |

## 事件

| 事件 | 描述 |
|------|------|
| `keplr_keystorechange` | 账户或密钥已更改 |
| `connect` | 已连接到链 |
| `disconnect` | 已断开连接 |

```typescript
// Listen for keystore changes
window.addEventListener('keplr_keystorechange', () => {
  console.log('Key changed, refresh account info')
})
```
