# WebLN 事件

不要通过账户或网络事件判断 WebLN 请求是否成功。应等待每次方法调用完成，并处理结果或异常。

provider 类型声明包含 `accountChanged`（单数）和 `disconnect`，但当前 WebLN 实现没有建立账户变化事件订阅。未经目标钱包版本验证，不应依赖这些通知。

必要的连接步骤见[快速开始](/zh/connect-to-software/provider/webln/guide)。
