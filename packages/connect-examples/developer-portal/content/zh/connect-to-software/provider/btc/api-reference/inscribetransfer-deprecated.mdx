# inscribeTransfer (已弃用)

用于创建代币转账铭文的旧版方法。本页为已有集成保留，不建议在新集成中使用。

## 方法

```typescript
declare function inscribeTransfer(
    ticker: string,
    amount: string,
): Promise<string>;
```

## 参数

* `ticker` — _必填_ `string`，代币代码。
* `amount` — _必填_ `string`。

## 响应

`txid` — `string`

## 示例

```typescript
const provider = (window.$onekey && window.$onekey.btc) || window.unisat;

const ticker = "<TOKEN_TICKER>";
const amount = "100"
const txid = await provider.inscribeTransfer(ticker, amount);
```
