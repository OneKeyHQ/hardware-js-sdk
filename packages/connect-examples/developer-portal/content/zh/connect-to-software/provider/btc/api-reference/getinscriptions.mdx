# getInscriptions

列出当前账户的铭文。

## 方法

```typescript
declare function getInscriptions(cursor?: number, size?: number): Promise<InscriptionResponse>;
```

## 参数

* `cursor` — _可选_ `number` 起始索引，默认为 `0`
* `size` — _可选_ `number` 查询数量，默认为 `20`

## 响应

```typescript
export type InscriptionResponse = {
  total: number;
  list: InscriptionInfo[];
};

export type InscriptionInfo = {
  inscriptionId: string;
  inscriptionNumber: number;
  address: string;
  outputValue: number;
  preview: string;
  content: string;
  contentLength: number;
  contentType: string;
  timestamp: number;
  genesisTransaction: string;
  location: string;
  output: string;
  offset: number;
};
```

## 示例

```typescript
const provider = (window.$onekey && window.$onekey.btc) || window.unisat;

const inscriptions = await provider.getInscriptions();
```
