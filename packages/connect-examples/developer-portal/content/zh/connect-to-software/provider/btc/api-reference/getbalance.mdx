# getBalance

获取当前账户的余额。

## 方法

```typescript
declare function getBalance(): Promise<BalanceInfo | number>;
```

## 响应

返回账户余额。为兼容部分实现，provider 类型也允许返回数值；访问余额字段前，请先检查返回值结构。

```typescript
type BalanceInfo = {
    confirmed: number;
    unconfirmed: number;
    total: number
};
```

## 示例

```typescript
const provider = (window.$onekey && window.$onekey.btc) || window.unisat;

const balance = await provider.getBalance();
```
