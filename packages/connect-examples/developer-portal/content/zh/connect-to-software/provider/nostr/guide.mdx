# 指南

## 概述

本指南帮助用户了解如何使用 OneKey Provider API 轻松构建基于 Nostr 协议的网络应用。

OneKey Provider API 遵循 [NIP-07](https://github.com/nostr-protocol/nips/blob/master/07.md) 规范。

## 安装

### 1. 下载 OneKey 钱包

下载 [OneKey 钱包](https://onekey.so/download?client=browserExtension)。安装 OneKey 浏览器扩展。

### 2. API 注入说明

* OneKey 浏览器扩展会将 `Provider API` 注入到访问的网站中。
* 提供两种类型的 API：`window.nostr` 和 `window.$onekey.nostr`。
* 推荐使用 `window.$onekey.nostr`。

> 使用 `window.$onekey.nostr` 明确选择 OneKey。安装多个扩展时，全局 `window.nostr` 可能属于其他钱包。

### 检测 Provider API 支持

发起请求前，请检查 provider 是否存在：

```javascript
const provider = (window.$onekey && window.$onekey.nostr) || window.nostr;

if (!provider) {
  throw new Error("No provider is available.");
}
```

## 请求处理

在 async 函数或 ES 模块中发起钱包请求。捕获 Promise 拒绝，并在应用中显示错误。连接、签名和付款请求应由用户操作触发；等待请求完成期间，禁用触发按钮。
