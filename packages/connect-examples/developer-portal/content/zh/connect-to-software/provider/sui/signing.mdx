# 签名

下方签名示例使用[快速开始](/zh/connect-to-software/provider/sui/getting-started#获取签名账户)中的 `connectSuiAccount()`，获取 Wallet Standard 账户与当前链。示例使用 `@mysten/sui@1.28.2`。在 `@mysten/wallet-standard@0.14.7` 中，旧 `*TransactionBlock` 方法的输入类型也已是 `Transaction`。

了解如何签署消息用于身份验证。

---

## 签署个人消息

签署任意消息用于身份验证：

```typescript
const message = new TextEncoder().encode('Hello, Sui!')
const { account, chain } = await connectSuiAccount()

const result = await provider.signPersonalMessage({
  message,
  account,
  chain,
})

console.log({
  signature: result.signature,   // Base64 编码的签名
  bytes: result.bytes,           // 已签名的消息字节
})
```

## 签署消息（旧版）

```typescript
const message = new TextEncoder().encode('Hello, Sui!')
const { account, chain } = await connectSuiAccount()

const result = await provider.signMessage({
  message,
  account,
})

console.log({
  signature: result.signature,
  messageBytes: result.messageBytes,
})
```

## 验证签名

```typescript
import { verifyPersonalMessageSignature } from '@mysten/sui/verify'

const message = new TextEncoder().encode('Hello, Sui!')
const { account, chain } = await connectSuiAccount()
const { signature } = await provider.signPersonalMessage({ message, account, chain })

const signerKey = await verifyPersonalMessageSignature(message, signature)
const isExpectedSigner = signerKey.toSuiAddress() === account.address
console.log('签名者是否为预期账户:', isExpectedSigner)
```

## 错误处理

```typescript
try {
  await provider.requestPermissions()
} catch (error) {
  if (error.code === 4001) {
    console.log('用户拒绝了连接请求')
  } else {
    console.error('连接错误:', error.message)
  }
}
```

---

## 常见错误码

| 错误码 | 描述 |
|--------|------|
| 4001 | 用户拒绝请求 |
| 4100 | 未授权 |
| -32603 | 内部错误 |
