# 快速开始

了解如何检测、连接和与 Sui 进行交互。

<Callout type="info">
OneKey 实现了 Sui Wallet Standard，确保与所有 Sui dApp 兼容。
</Callout>

## Provider 检测

```typescript
// 检测 OneKey Sui provider
const provider = window.$onekey?.sui

if (!provider) {
  throw new Error('未检测到 OneKey Sui provider')
}
```

---

## 检查权限

```typescript
// 检查是否已连接
const hasPermission = await provider.hasPermissions()

if (hasPermission) {
  const accounts = await provider.getAccounts()
  console.log('已连接的账户:', accounts)
}
```

---

## 请求连接

```typescript
// 请求连接权限
const result = await provider.requestPermissions()

if (result) {
  const accounts = await provider.getAccounts()
  console.log('已连接:', accounts[0].address)
}
```

## 获取签名账户

安装 `@mysten/wallet-standard@0.14.7`。注入 Provider 的 `getAccounts()` 返回 `AccountInfo[]`，不是签名接口要求的 `WalletAccount`。下面通过 Wallet Standard 获取完整账户。在钱包注册完成后由用户操作触发，处理拒绝请求，并在账户或网络变化后重新获取上下文。

```typescript
import { getWallets, isWalletWithRequiredFeatureSet } from '@mysten/wallet-standard'

async function connectSuiAccount() {
  const wallet = getWallets().get().find(wallet => wallet.name === 'OneKey Wallet')
  if (!wallet || !isWalletWithRequiredFeatureSet(wallet)) {
    throw new Error('OneKey Sui Wallet Standard is not available')
  }

  const { accounts } = await wallet.features['standard:connect'].connect()
  const [account] = accounts
  const chain = await provider.getActiveChain()
  if (!account || !chain || !account.chains.includes(chain)) {
    throw new Error('No connected Sui account for the active chain')
  }
  return { account, chain }
}
```

## 获取账户

```typescript
const accounts = await provider.getAccounts()

accounts.forEach(account => {
  console.log({
    address: account.address,     // Sui 地址
    publicKey: account.publicKey, // 公钥（hex 字符串）
  })
})
```

## 事件监听

### 监听账户变更

```typescript
provider.onAccountChange((account) => {
  if (account) {
    console.log('账户已变更:', account.address)
  } else {
    console.log('已断开连接')
  }
})
```

### 监听网络变更

```typescript
provider.onNetworkChange((network) => {
  console.log('网络已变更:', network)
})
```

## 使用 Sui Wallet Kit

对于 React 应用，使用官方的 Sui Wallet Kit：

```bash
npm install @mysten/dapp-kit@0.16.0 @mysten/sui@1.28.2 @tanstack/react-query@^5
```

```tsx
import { SuiClientProvider, WalletProvider } from '@mysten/dapp-kit'
import { getFullnodeUrl } from '@mysten/sui/client'
import { QueryClient, QueryClientProvider } from '@tanstack/react-query'

const queryClient = new QueryClient()
const networks = {
  mainnet: { url: getFullnodeUrl('mainnet') },
  testnet: { url: getFullnodeUrl('testnet') },
}

function App() {
  return (
    <QueryClientProvider client={queryClient}>
      <SuiClientProvider networks={networks} defaultNetwork="mainnet">
        <WalletProvider>
          <YourApp />
        </WalletProvider>
      </SuiClientProvider>
    </QueryClientProvider>
  )
}
```

OneKey 会通过 Sui Wallet Standard 自动被检测。
