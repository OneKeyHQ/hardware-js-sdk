# JSON-RPC 参考

OneKey 常用 Ethereum JSON-RPC 和钱包方法参考。

<Callout type="info">
所有方法均通过 `window.$onekey.ethereum.request({ method, params })` 调用。
</Callout>

---

## 账户方法

| 方法 | 说明 |
|--------|-------------|
| [eth_requestAccounts](./eth_requestAccounts) | 请求访问用户账户，可触发连接弹窗 |
| [eth_accounts](./eth_accounts) | 获取已连接账户，不弹窗 |
| [wallet_requestPermissions](./wallet_requestPermissions) | 请求指定权限 |
| [wallet_getPermissions](./wallet_getPermissions) | 获取当前权限 |

| 方法 | 说明 |
|--------|-------------|

## 标准 Ethereum 方法

其他 Ethereum JSON-RPC 方法是否可用，取决于连接的网络和钱包实现。完整列表见 [Ethereum JSON-RPC 规范](https://ethereum.github.io/execution-apis/)。

常用方法包括：

- `eth_blockNumber` — 获取当前区块号。
- `eth_getBalance` — 获取账户余额。
- `eth_getCode` — 获取合约代码。
- `eth_getLogs` — 获取事件日志。
