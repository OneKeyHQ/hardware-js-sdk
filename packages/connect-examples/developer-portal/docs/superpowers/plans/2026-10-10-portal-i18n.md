# Portal internationalization delivery plan

Add complete French, German, Spanish and Japanese editions while preserving the existing English and Chinese portal, its custom interactions, Roobert typography, routes and links.

## Maintenance model

English is canonical. Each language contains readable MDX and navigation files at the same relative paths. Shared UI copy uses readable English keys in `i18n/ui/<locale>.json`. People or AI assistants update the corresponding language files together; no translation API, Secret, scheduled generation job or opaque translation database is required.

This follows the user's October 11 instruction to translate this edition directly and keep the repository easy for future AI maintenance. It replaces the earlier proposal for an external translation provider.
