# Portal internationalization implementation plan

Goal: add complete French, German, Spanish and Japanese documentation directly to this portal, and regenerate affected translations when English changes.

Architecture: English is the source. Translation catalogs store source-text hashes and target text; a deterministic MDX renderer changes prose and locale-aware URLs only. Code, API identifiers, imports and original English anchors remain stable. Existing reviewed Chinese is retained as the initial baseline. Automated translation uses a configured OpenAI-compatible service and opens a reviewable update; it does not deploy.

Global constraints: preserve all English/Chinese routes, Roobert, custom navigation, simulator, static export and Pagefind. No real device, signing, broadcast or firmware operations. Never expose provider credentials to browser bundles or untrusted PR code. Never advertise incomplete locales. Do not notify Slack of deployment readiness until all content, build, browser and remote checks pass.

Review focus: source deletion/rename; malformed or truncated provider responses; accidental code/link/number changes; language-switch anchors and base paths; stale translation catalogs and no-op updates; partial provider failure and interrupted runs.
