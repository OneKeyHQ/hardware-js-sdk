## Troubleshooting

### Webpack 5 Polyfill Errors (Buffer / process)

Some SDK dependencies rely on Node.js core modules like `Buffer` and `process`. In Webpack 5, these are no longer polyfilled automatically, which can cause errors like `Buffer is not defined` or `process is not defined`.

**Solution:**
Add the following polyfills to your Webpack config:

```js
const webpack = require('webpack');

module.exports = {
  // ... other config
  plugins: [
    new webpack.ProvidePlugin({
      process: 'process/browser',
      Buffer: ['buffer', 'Buffer'],
    }),
  ],
  resolve: {
    fallback: {
      buffer: require.resolve('buffer/'),
      process: require.resolve('process/browser'),
      // ... other fallbacks you might need
    },
  },
};
```

### Device Not Found / Connection Failed

If you are unable to connect to your device, check the following:

- Is the OneKey device plugged in and unlocked?
- Are you using a supported browser (Google Chrome is recommended for WebUSB)?
- (For JSBridge) Is the OneKey Bridge application installed and running?
- Ensure no other application (like the OneKey desktop app) is currently connected to the device, as it can claim the USB interface.

---

### Permission Issues (WebUSB)

- Make sure you have granted USB permissions to the site.
- Try unplugging and replugging the device, then refresh the page.
- If you see a browser prompt, select your OneKey device and click "Connect".
