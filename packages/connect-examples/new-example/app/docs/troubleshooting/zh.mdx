## 问题排查

### Webpack 5 Polyfill 错误（Buffer / process）

部分 SDK 依赖 Node.js 核心模块（如 `Buffer` 和 `process`），Webpack 5 不再自动 polyfill，可能导致 `Buffer is not defined` 或 `process is not defined` 错误。

**解决方法：**
在 Webpack 配置中添加如下 polyfill：

```js
const webpack = require('webpack');

module.exports = {
  // ... 其他配置
  plugins: [
    new webpack.ProvidePlugin({
      process: 'process/browser',
      Buffer: ['buffer', 'Buffer'],
    }),
  ],
  resolve: {
    fallback: {
      buffer: require.resolve('buffer/'),
      process: require.resolve('process/browser'),
      // ... 其他你可能需要的 fallback
    },
  },
};
```

### 未找到设备 / 连接失败

如果无法连接设备，请检查：

- OneKey 设备是否已插入并解锁？
- 是否使用支持的浏览器（推荐 Chrome，支持 WebUSB）？
- （JSBridge 场景）OneKey Bridge 应用是否已安装并运行？
- 是否有其他应用（如 OneKey 桌面端）占用设备？

---

### 权限问题（WebUSB）

- 确认已授权 USB 权限给当前站点。
- 尝试重新插拔设备并刷新页面。
- 如果浏览器弹窗，选择 OneKey 设备并点击"连接"。

---

> 更多排查技巧请参考 [官方文档](https://developer.onekey.so/connect-to-hardware/page-1/started)
