## 概述与架构

OneKey SDK 是一个 monorepo 项目，它提供了一套完整的工具，用于在不同平台（Web、桌面、移动端）与 OneKey 硬件钱包进行通信。它的核心设计理念是提供一个统一且简化的 API，自动处理底层复杂的通信协议，让开发者可以专注于业务逻辑的实现。

下面的架构图清晰地展示了不同平台下的应用如何选择对应的 SDK，以及这些 SDK 如何利用不同的通信层（Transports）与硬件进行交互。

### 架构解析

- **应用层 (Application)**: 这是您的应用程序，根据目标平台的不同，您可以构建 Web、React Native 或原生移动/Node.js 应用。

- **SDK 抽象层 (SDK Abstraction)**: 我们提供了三个核心的 SDK 包，每个都针对特定的开发环境进行了优化：

  - `@onekeyfe/hd-web-sdk`: 专为浏览器和基于 Web 技术的桌面应用（如 Electron）设计。它内部处理了 **WebUSB** 和 **JSBridge** 两种通信方式。

  - `@onekeyfe/hd-ble-sdk`: 专为 **React Native** 应用设计，用于通过蓝牙（BLE）与硬件通信。

  - `@onekeyfe/hd-common-connect-sdk`: 一个更通用的包，适用于 **原生移动应用 (iOS/Android)** 和 **Node.js** 后端服务。它能够处理蓝牙（BLE）和原生 USB (HID) 连接。

- **传输层 (Transports)**: 这是实现与硬件直接通信的底层模块。SDK 会根据环境和配置自动选择最合适的传输方式。
