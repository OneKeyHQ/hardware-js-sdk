## 概述与架构

OneKey SDK 是一个 monorepo 项目，提供了跨平台（Web、桌面、移动端）与 OneKey 硬件钱包通信的统一工具集。其核心设计理念是通过统一且简化的 API，自动处理底层复杂的通信协议，让开发者专注于业务逻辑。

**集成流程：**
- **选择适合平台和环境的 transport**（如 WebUSB、HTTP(JSBridge/Bridge)、BLE、HID、Lowlevel 等）。
- **选择对应的 SDK**：
  - Web/桌面端用 `@onekeyfe/hd-web-sdk`
  - React Native 用 `@onekeyfe/hd-ble-sdk`
  - 原生移动端用 `@onekeyfe/hd-common-connect-sdk`（需手动选择 transport）

### 架构解析

- **应用层**：您的应用（Web、React Native 或原生移动），根据目标平台选择。
- **SDK 层**：OneKey 提供三大核心 SDK 包，分别针对不同开发环境：
  - `@onekeyfe/hd-web-sdk`：适用于浏览器和基于 Web 技术的桌面应用（如 Electron），内部处理 **WebUSB** 和 **JSBridge**。
  - `@onekeyfe/hd-ble-sdk`：适用于 **React Native** 应用，通过蓝牙（BLE）与硬件通信。
  - `@onekeyfe/hd-common-connect-sdk`：适用于 **原生移动应用 (iOS/Android)**，可处理 BLE、HTTP(JSBridge)、Lowlevel 等多种 transport。
- **传输层**：实现与硬件直接通信的底层模块，SDK 会自动选择或允许手动指定最合适的 transport：
  - `@onekeyfe/hd-transport-webusb`
  - `@onekeyfe/hd-transport-http`
  - `@onekeyfe/hd-transport-ble`
  - `@onekeyfe/hd-transport-hid`
  - `@onekeyfe/hd-transport-lowlevel`
- **协议层**：Protobuf Protocol（统一消息编解码）
- **硬件层**：OneKey 硬件钱包

> 详细文档请参考 [OneKey 硬件 SDK 官方文档](https://developer.onekey.so/connect-to-hardware/page-1/started)
