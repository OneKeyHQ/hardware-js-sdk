### Architecture Explained

- **Application Layer**: This is your application, which can be a Web, React Native, or Native Mobile/Node.js app, depending on your target platform.

- **SDK Abstraction Layer**: We provide three core SDK packages, each optimized for a specific development environment:

  - `@onekeyfe/hd-web-sdk`: Designed for browsers and web-based desktop applications (like Electron). It internally handles both **WebUSB** and **JSBridge** communication methods.

  - `@onekeyfe/hd-ble-sdk`: Specifically for **React Native** applications, used for communicating with hardware via Bluetooth (BLE).

  - `@onekeyfe/hd-common-connect-sdk`: A more generic package suitable for **native mobile applications (iOS/Android)** and **Node.js** backend services. It can handle both Bluetooth (BLE) and native USB (HID) connections.

- **Transport Layer**: These are the low-level modules that implement direct communication with the hardware. The SDK automatically selects the most suitable transport method based on the environment and configuration.
