## Quick Start (Web)

Follow these steps to get up and running with the OneKey Web SDK.

> **Prerequisites:**
>
> - A modern browser with WebUSB support (e.g., Chrome, Edge)
> - A OneKey hardware device connected via USB
> - (Optional) OneKey Bridge running for JSBridge fallback

---

### 1. Installation

Install the `@onekeyfe/hd-web-sdk` package in your project:

```bash
# Using Yarn
yarn add @onekeyfe/hd-web-sdk

# Using npm
npm install @onekeyfe/hd-web-sdk
```

---

### 2. Initialization

Initialize the SDK once at the start of your application lifecycle. The `connectSrc` parameter points to the secure bridge that handles low-level device communication in a sandboxed iframe.

```ts
import { HardwareSDK, UI_EVENT } from '@onekeyfe/hd-web-sdk';

async function initializeSDK() {
  await HardwareSDK.init({
    connectSrc: 'https://jssdk.onekey.so/',
    env: 'webusb', // 'webusb' for direct USB; 'jsbridge' for JSBridge fallback
    debug: true, // Enable debug logging
  });

  console.log('✅ OneKey SDK Initialized');
}

// Optional: handle PIN and Passphrase events globally
HardwareSDK.on(UI_EVENT.REQUEST_PIN, async (_, callback) => {
  const pin = await showPinDialog();
  callback(null, pin);
});

HardwareSDK.on(UI_EVENT.REQUEST_PASSPHRASE, async (_, callback) => {
  const passphrase = await showPassphraseDialog();
  callback(null, passphrase);
});

initializeSDK();
```

---

### 3. Search for Devices

After initialization, search and connect to the first available OneKey device:

```ts
async function findAndConnectDevice() {
  const devices = await HardwareSDK.searchDevices({ timeout: 5000 });
  if (devices.length === 0) {
    throw new Error('🔍 No OneKey devices found');
  }
  console.log('🔌 Connected to device:', devices[0].features.model);
  return devices[0];
}

const device = await findAndConnectDevice();
```

---

### 4. Fetch an Ethereum Address

Once connected, you can invoke any supported hardware method. For example, to retrieve an EVM address:

```ts
async function getEthereumAddress(path = "m/44'/60'/0'/0/0") {
  try {
    const result = await HardwareSDK.evmGetAddress({
      path,
      showOnOneKey: true, // Prompt user on device to confirm
    });

    if (result.success) {
      console.log('🔑 Address:', result.payload.address);
    } else {
      console.error('❌ Error:', result.payload.error);
    }
  } catch (error) {
    console.error('💥 Unexpected error:', error);
  }
}

const addressInfo = await getEthereumAddress();
```
