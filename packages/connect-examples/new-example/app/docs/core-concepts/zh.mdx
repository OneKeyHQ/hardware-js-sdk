import { HardwareSDK, UI_EVENT } from '@onekeyfe/hd-web-sdk';

## 核心概念

为确保与 OneKey 硬件的稳健集成，需理解以下核心概念：

---

### 事件处理

OneKey SDK 采用事件驱动模型处理用户交互（PIN、Passphrase 等）。应用**必须**监听并响应这些事件，否则硬件操作会超时。

**建议：** 在应用初始化时设置全局事件监听。

- `UI_EVENT.REQUEST_PIN`：硬件请求 PIN，弹出 PIN 输入框。
- `UI_EVENT.REQUEST_PASSPHRASE`：硬件请求 Passphrase，弹出 Passphrase 输入框。
- `DEVICE.CONNECT` / `DEVICE.DISCONNECT`：设备连接状态变化。

**示例：**

```ts
HardwareSDK.on(UI_EVENT.REQUEST_PIN, async (device, callback) => {
  const pin = await showPinDialog();
  callback(null, pin);
});

HardwareSDK.on(UI_EVENT.REQUEST_PASSPHRASE, async (device, callback) => {
  const passphrase = await showPassphraseDialog();
  callback(null, passphrase);
});
```

---

### Passphrase（BIP39 密码短语）

Passphrase 是 BIP39 标准的额外密码，可创建"隐藏钱包"。同一助记词下，不同 Passphrase 派生不同账户。

- **安全性：** 忘记 Passphrase 无法找回隐藏钱包。
- 不需要时可用空 Passphrase 访问主钱包。

#### `passphrase` 与 `passphraseState`

- `passphrase`：字符串，仅用于**单次** API 调用，不缓存。
- `passphraseState`：设备返回的加密状态，SDK 可复用（缓存 10 分钟）。
- `getPassphraseState` 需传入 `passphrase`，返回 `passphraseState`。如两者都传，优先用 `passphraseState`。

**示例：**

```ts
const userPassphrase = await showPassphraseDialog();
const state = await HardwareSDK.getPassphraseState({ passphrase: userPassphrase });
const address = await HardwareSDK.evmGetAddress({
  path: "m/44'/60'/0'/0/0",
  passphraseState: state,
});
```

---

### PIN 码处理

- PIN 用于解锁设备。设备锁定时签名操作会触发 PIN 请求。
- **设备输入：** Touch/Pro 型号需在设备上输入 PIN（不会触发 `REQUEST_PIN` 事件）。
- **客户端输入：** Classic/Mini 型号需在应用输入 PIN（SDK 触发 `UI_EVENT.REQUEST_PIN` 事件）。

**示例：**

```ts
HardwareSDK.on(UI_EVENT.REQUEST_PIN, (device, callback) => {
  if (!device.features?.pin_protection_always_on_device) {
    const pin = await showPinDialog();
    callback(null, pin);
  } else {
    showUserNotification('请在 OneKey 设备上输入 PIN。');
    callback(null, '');
  }
});
```
