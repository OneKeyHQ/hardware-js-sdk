# @onekeyfe/hwk-trezor-transport-common

Environment-agnostic Trezor transport abstractions vendored from `@trezor/transport-common`:
sessions coordination, THP protocol handling, abstract transport/API base classes, and a
structural (DOM-free) USB device interface. Consumed by `@onekeyfe/hwk-trezor-transport` and
`@onekeyfe/hwk-trezor-transport-web`, which supply the concrete platform transports.

See `TREZOR_SOURCE.md` for provenance and local changes.
